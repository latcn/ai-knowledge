**物理场景回顾**：进行 \(n\) 次独立重复试验。每次试验有 \(r\) 种互斥结果 \(A_1, A_2, \dots, A_r\)，发生概率分别为 \(p_1, p_2, \dots, p_r\)（且 \(\sum p_i = 1\)）。\(X_i\) 表示在这 \(n\) 次试验中，结果 \(A_i\) 发生的总次数。

## 一、 联合分布列的推导（怎么算概率？）

我们要求的是联合概率：\(P(X_1=n_1, X_2=n_2, \dots, X_r=n_r)\)。
（其中 \(n_1 + n_2 + \dots + n_r = n\)）。

推导的核心思想是：**先算特定顺序的概率，再乘上排列总数**。

### 1. 算特定顺序
假设这 \(n\) 次试验的结果是这样排列的：前 \(n_1\) 次全是 \(A_1\)，接下来 \(n_2\) 次全是 \(A_2\)，……，最后 \(n_r\) 次全是 \(A_r\)。
因为每次试验是**独立**的，所以这种特定顺序出现的概率，就是把各自的概率连乘：
\[
 P(\text{特定顺序}) = \underbrace{p_1 \cdots p_1}_{n_1 \text{个}} \cdot \underbrace{p_2 \cdots p_2}_{n_2 \text{个}} \cdots \underbrace{p_r \cdots p_r}_{n_r \text{个}} = p_1^{n_1} p_2^{n_2} \cdots p_r^{n_r} 
\]

### 2. 算排列总数（多项式系数）
在真实的 \(n\) 次试验中，\(A_1\) 不一定全在前面，它们可以互相穿插。
这是一个经典的“**多重分组**”问题：
*   从 \(n\) 个位置里挑 \(n_1\) 个给 \(A_1\)，有 \(\binom{n}{n_1}\) 种。
*   从剩下的 \(n-n_1\) 个位置里挑 \(n_2\) 个给 \(A_2\)，有 \(\binom{n-n_1}{n_2}\) 种。
*   以此类推。
把它们乘起来展开：
\[
 \frac{n!}{n_1!(n-n_1)!} \cdot \frac{(n-n_1)!}{n_2!(n-n_1-n_2)!} \cdots = \frac{n!}{n_1! n_2! \cdots n_r!} 
\]

### 3. 得出最终公式
将排列总数乘以特定顺序的概率，得到联合分布列：
\[
 P(X_1=n_1, \dots, X_r=n_r) = \frac{n!}{n_1! n_2! \cdots n_r!} p_1^{n_1} p_2^{n_2} \cdots p_r^{n_r} 
\]
*(注：这也是多项式 \((p_1 + \dots + p_r)^n\) 展开式的通项公式。)*

## 二、 协方差 \(Cov(X_i, X_j)\) 的推导（为什么是负数？）

**结论**：对于 \(i \neq j\)，其协方差为 \(Cov(X_i, X_j) = -n p_i p_j\)。

**物理直觉**：总次数 \(n\) 是固定的。如果 \(A_i\) 发生得多了（\(X_i\) 变大），留给 \(A_j\) 的次数就必然变少（\(X_j\) 变小）。这就是“此消彼长”，所以协方差必然为**负**。

我们提供两种推导方法：**代数降维法**（极其优雅）和**微积分硬算法**（极其硬核）。

### 方法一：指示变量法 + 矩阵视角（优雅降维）

定义单次试验的指示变量：如果第 \(k\) 次试验发生了 \(A_i\)，则 \(I_{ik}=1\)，否则为 \(0\)。显然 \(X_i = \sum_{k=1}^n I_{ik}\)。

利用协方差的**双线性性质**，和的协方差等于协方差的和。我们可以展开成一个 \(n \times n\) 的矩阵：
\[
 Cov(X_i, X_j) = \sum_{k=1}^n \sum_{m=1}^n Cov(I_{ik}, I_{jm}) 
\]

看这个 \(n \times n\) 的矩阵：
1.  **非对角线元素（\(k \neq m\)）**：代表不同次试验。因为各次试验**相互独立**，所以协方差全为 \(0\)。这里有 \(n^2 - n\) 个 0。
2.  **对角线元素（\(k = m\)）**：代表同一次试验。在同一次试验中，\(A_i\) 和 \(A_j\) 是**互斥**的（不可能同时发生）。所以 \(I_{ik} \cdot I_{jk} \equiv 0\)。
    计算其协方差：
    \[
 Cov(I_{ik}, I_{jk}) = E(I_{ik}I_{jk}) - E(I_{ik})E(I_{jk}) = 0 - p_i p_j = -p_i p_j 
\]
    对角线上有 \(n\) 个元素，每个都是 \(-p_i p_j\)。

全部加起来，结果就是 \(n \times (-p_i p_j) + 0 = \mathbf{-n p_i p_j}\)。

### 方法二：生成函数微积分法（硬核求 \(E(X_i X_j)\)）

如果不用指示变量，我们需要用定义式：\(Cov(X_i, X_j) = E(X_i X_j) - E(X_i)E(X_j)\)。
已知 \(E(X_i) = np_i, E(X_j) = np_j\)。难点在于求 \(E(X_i X_j)\)。

我们可以对多项式 \((p_i A + p_j B + (1-p_i-p_j) C)^n\) 做文章。
*   等式右边展开后，求和的每一项是 \(P(X_i=x, X_j=y) A^x B^y C^{n-x-y}\)。
*   如果对 \(A\) 求一次偏导，对 \(B\) 求一次偏导，指数 \(x\) 和 \(y\) 会变成系数掉下来。
*   然后令 \(A=B=C=1\)，右边恰好变成了 \(\sum x \cdot y \cdot P(\dots)\)，也就是 \(E(X_i X_j)\)。
*   左边求两次导后令 \(A=B=C=1\)，算出来是 \(n(n-1)p_i p_j\)。

所以：
\[
 E(X_i X_j) = n(n-1) p_i p_j 
\]
代入协方差公式：
\[
 Cov(X_i, X_j) = n(n-1)p_i p_j - (np_i)(np_j) 
\]
\[
 = n^2p_ip_j - np_ip_j - n^2p_ip_j = \mathbf{-np_ip_j} 
\]

---

### 💡 总结

*   **联合分布列**的本质是：**独立概率的乘积** \(\times\) **多项式系数**。
*   **协方差**的本质是：跨次试验看是**独立**（等于0），同次试验看是**互斥**（产生负值）。总共 \(n\) 次试验，就累积了 \(n\) 份负的协方差。
*   正是因为固定了总次数 \(n\)，多项分布的各个维度之间就像一块固定大小的披萨，你分得多，我分得就少，天然具有负相关的属性。
