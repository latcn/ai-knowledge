# 第一部分 第一性原理

## 1.1 直接生成的根本困难

**目标**：从数据分布 $p(x)$ 采样，生成新图像。

**$p(x)$ 长什么样**：高维（$512\times512\times3\approx 7.9\times10^5$ 维）、多模态、集中在低维流形上。自然图像只占整个像素空间的极小一部分。

**直接学的困难**：一个神经网络要一步把 $\mathcal{N}(0,I)$ 映射到 $p(x)$，相当于要求它"扭转整个高维空间"。这个映射**极其复杂**。GAN 就是在学这个一步映射，但**训练不稳定**（模式崩溃、震荡）——因为"判别器 vs 生成器"的博弈很难收敛到纳什均衡。

**关键观察**：一步从"无结构"跳到"复杂结构"，跨度太大。

## 1.2 扩散的拆解思路：$T$ 个小步替代 1 个大步

**核心思想**：

> 把"从 $\mathcal{N}(0,I)$ 一步生成 $p(x)$"这个难题，**拆成 $T$ 个"只改一点点"的小难题**。

| 过程 | 方向 | 每步做什么 | 跨度 |
|---|---|---|---|
| **前向（加噪）** | $p(x)\to\mathcal{N}(0,I)$ | 每步加一点点噪声 | **微小**（$\beta_t$ 小） |
| **反向（去噪）** | $\mathcal{N}(0,I)\to p(x)$ | 每步去一点点噪声 | **微小** |

**为什么"微小"是关键**：如果每步只改一点点，那么"反向的每一步"就是一个**很窄的分布变换**——窄到可以用**高斯**近似。网络只需要学"在这个很窄的分布里，均值在哪"，这比学整个 $p(x)$ 容易得多。

**数学上**：$\beta_t$ 小 ⟹ $q(z_{t+1}\mid z_t)$ 是一个很窄的高斯（方差 $\beta_t$ 小）⟹ 反向 $q(z_{t-1}\mid z_t)$ 也很窄 ⟹ 用高斯 $p_{\theta_t}(z_{t-1}\mid z_t)=\mathcal{N}(\mu_{\theta_t}(z_t),\sigma_t^2 I)$ 近似是合理的。

## 1.3 为什么从噪声出发是自然的

$\mathcal{N}(0,I)$ 有三个关键性质：

| 性质 | 为什么重要 |
|---|---|
| **简单** | 我们知道怎么采样（一行代码） |
| **覆盖整个空间** | 不会漏掉任何区域 |
| **无结构** | 不含任何关于数据的信息——它是"最大熵"分布 |

**从"无结构"出发，逐步注入"结构"**——这是扩散的哲学。每一步网络都注入一点点"关于数据长什么样"的信息，$T$ 步后，累积成完整的 $p(x)$。

**物理直觉**：加噪是**熵增**（信息丢失、分布变简单、自然发生）；去噪是**熵减**（信息恢复、分布变复杂、需要"做功"）。前向加噪**免费**（$\beta_t$ 给定，不需要学）；反向去噪**需要学**（网络就是"做功的机器"）。

## 1.4 为什么"逐步"比"一步"容易

**类比 1：雕刻**。直接拿凿子把一块石头凿成雕像极难；但如果先做石膏模（近似形状），再逐步精修，每步只改一点点，就容易得多。

**类比 2：退火**。金属退火是"先加热到高温（原子无序），再缓慢冷却（原子有序排列）"。直接冷却会形成缺陷；缓慢冷却能得到完美晶体。

**类比 3：噪声中的信号**。把一幅画逐步模糊成纯噪声，再训练一个"修复师"学会"逐步去模糊"。修复师不需要一步恢复原图（做不到），只需要每步"比刚才清晰一点点"（做得到）。

# 第二部分 前向加噪过程

## 2.1 前向加噪核（(8.31)）

**定义**（书中的下标约定）：
$$
\boxed{\ q(z_{t+1}\mid z_t) = \mathcal{N}\big(z_{t+1};\ \sqrt{1-\beta_t}\,z_t,\ \beta_t I_p\big)\ }
$$

**等价递推**（重参数化形式，(8.33)）：
$$
\boxed{\ z_{t+1} = \sqrt{1-\beta_t}\,z_t + \sqrt{\beta_t}\,\epsilon_t,\qquad \epsilon_t\sim\mathcal{N}(0,I_p)\ }
$$

**维度检查**：$z_t\in\mathbb{R}^p$，$\sqrt{1-\beta_t}$ 是标量，$\beta_t I_p$ 是 $p\times p$ 对角矩阵。✓

**参数**：$\beta_0,\dots,\beta_{T-1}\in[0,1)$ 是**超参**（不学）。

**含义**：每一步把 $z_t$ 乘 $\sqrt{1-\beta_t}$（略微收缩），加 $\sqrt{\beta_t}\epsilon_t$（略微加噪）。$\beta_t$ 小 ⟹ 每步变化微小。

> **约定提示（与标准 DDPM 的差异）**：标准 DDPM 的约定是 $q(x_t\mid x_{t-1})=\mathcal{N}(\sqrt{1-\beta_t}x_{t-1},\beta_t I)$，即 $\beta_t$ 对应"从 $t-1$ 到 $t$"的加噪。**本书的 $\beta_t$ 对应"从 $t$ 到 $t+1$"的加噪**——差一位。本书内部自洽（前向、反向、$\gamma_t$ 都按这个约定），阅读文献时需注意映射。

> **修订注记（审核第 2 条）**：原文多处出现 `\sqrt{1-\beta_t},z_t` 的逗号吞入根号问题，本版统一修正为 `\sqrt{1-\beta_t}\,z_t`（窄空格，表示乘法）。

## 2.2 累积系数 $\gamma_t$

**定义**：
$$
\boxed{\ \gamma_t = \prod_{i=0}^{t-1}(1-\beta_i) = (1-\beta_0)(1-\beta_1)\cdots(1-\beta_{t-1})\ }
$$

**含义**：从 $x=z_0$ 走 $t$ 步后，**保留了多少"原始信号"**。$\gamma_1=1-\beta_0$；$\gamma_2=(1-\beta_0)(1-\beta_1)$；依此类推。

**性质**：
- $\gamma_0=1$（0 步后完全保留）；
- $\gamma_t$ 随 $t$ **单调递减**；
- $\gamma_T$ 接近 0（$T$ 步后几乎全是噪声）。

> **约定提示（与标准 DDPM 的映射）**：本书 $\gamma_t$ 对应标准 DDPM 的 $\bar\alpha_t = \prod_{i=1}^{t}\alpha_i$（$\alpha_i = 1-\beta_i^{\text{DDPM}}$）。**映射需整体平移一位**：$\gamma_t = \bar\alpha_t$，但 $\beta_t^{\text{本书}} = \beta_{t+1}^{\text{DDPM}}$。

## 2.3 闭式解（(8.34)）

**结论**：
$$
\boxed{\ q(z_t\mid x) = \mathcal{N}\big(z_t;\ \sqrt{\gamma_t}\,x,\ (1-\gamma_t)I_p\big)\ }
$$

**物理含义**：从 $x$ 走 $t$ 步后，$z_t$ 的均值是"原始信号按 $\sqrt{\gamma_t}$ 衰减"，方差是"噪声按 $1-\gamma_t$ 累积"。$\gamma_t$ 越大（越接近 1）⟹ 保留越多；$\gamma_t$ 越小 ⟹ 噪声越多。

**重参数化形式**（(8.39)，**这是扩散版的"重参数化"**）：
$$
\boxed{\ z_t = \sqrt{\gamma_t}\,x + \sqrt{1-\gamma_t}\,\epsilon,\qquad \epsilon\sim\mathcal{N}(0,I_p)\ }
$$

## 2.4 闭式解的归纳法推导

> **为什么能一步到位**：虽然前向是 $t$ 步递推，但**每步都是高斯**，所以 $t$ 步复合仍是高斯，均值和方差可以合并计算。

**基础情形 $t=1$**：
$$
z_1 = \sqrt{1-\beta_0}x + \sqrt{\beta_0}\epsilon_0.
$$
均值 $\sqrt{1-\beta_0}x = \sqrt{\gamma_1}x$ ✓；方差 $\beta_0 = 1-(1-\beta_0) = 1-\gamma_1$ ✓。

**归纳假设**：假设 $q(z_t\mid x) = \mathcal{N}(\sqrt{\gamma_t}x, (1-\gamma_t)I)$。

**归纳步骤**：计算 $z_{t+1}$ 的均值和方差：
$$
z_{t+1} = \sqrt{1-\beta_t}z_t + \sqrt{\beta_t}\epsilon_t.
$$

**均值**：
$$
\mathbb{E}[z_{t+1}] = \sqrt{1-\beta_t}\cdot\sqrt{\gamma_t}x + 0 = \sqrt{\gamma_t(1-\beta_t)}x = \sqrt{\gamma_{t+1}}x. \quad\checkmark
$$

**方差**（$z_t$ 与 $\epsilon_t$ 独立）：
$$
\mathrm{Var}[z_{t+1}] = (1-\beta_t)\mathrm{Var}[z_t] + \beta_t\mathrm{Var}[\epsilon_t] = (1-\beta_t)(1-\gamma_t) + \beta_t.
$$

展开：
$$
(1-\beta_t)(1-\gamma_t) + \beta_t = 1 - \gamma_t - \beta_t + \beta_t\gamma_t + \beta_t = 1 - \gamma_t + \beta_t\gamma_t = 1 - \gamma_t(1-\beta_t) = 1-\gamma_{t+1}. \quad\checkmark
$$

**归纳完成**。所以 $q(z_t\mid x) = \mathcal{N}(\sqrt{\gamma_t}x, (1-\gamma_t)I)$ 对一切 $t$ 成立。$\blacksquare$

> **关键洞察**：$t$ 步递推可以**一步到位**——这是扩散模型能高效训练的根本原因（不用真的走 $t$ 步）。

## 2.5 重参数化形式（(8.39)）

$$
\boxed{\ z_t = \sqrt{\gamma_t}\,x + \sqrt{1-\gamma_t}\,\epsilon,\quad \epsilon\sim\mathcal{N}(0,I) }
$$

**关键观察**：这是"闭式解"的采样形式——只需一个 $\epsilon$，一次采样，$O(1)$ 步得到任意 $t$ 的 $z_t$。**不需要走 $t$ 步递推**。

# 第三部分 反向去噪过程

## 3.1 反向条件分布闭式（(8.35)）

**要算的量**：$q(z_{t-1}\mid z_t,x)$——给定最终噪声 $z_t$ 和原始 $x$，中间层 $z_{t-1}$ 的分布。

**用贝叶斯公式**：
$$
q(z_{t-1}\mid z_t,x) = \frac{q(z_t\mid z_{t-1},x)\,q(z_{t-1}\mid x)}{q(z_t\mid x)}.
$$

**用马尔可夫性** $q(z_t\mid z_{t-1},x)=q(z_t\mid z_{t-1})$（前向是马尔可夫链）：
$$
q(z_{t-1}\mid z_t,x) = \frac{q(z_t\mid z_{t-1})\,q(z_{t-1}\mid x)}{q(z_t\mid x)}.
$$

**代入三个高斯**：
- $q(z_t\mid z_{t-1}) = \mathcal{N}(\sqrt{1-\beta_{t-1}}z_{t-1}, \beta_{t-1}I)$（(8.31) 用 $t-1$）
- $q(z_{t-1}\mid x) = \mathcal{N}(\sqrt{\gamma_{t-1}}x, (1-\gamma_{t-1})I)$（(8.34) 用 $t-1$）
- $q(z_t\mid x) = \mathcal{N}(\sqrt{\gamma_t}x, (1-\gamma_t)I)$（(8.34)）

**三个高斯相乘，仍是高斯**（配方法）。结果：
$$
\boxed{\ q(z_{t-1}\mid z_t,x) = \mathcal{N}\big(z_{t-1};\ \mu_q(z_t,x),\ \Sigma_q(t)\big)\ }
$$

其中：
$$
\boxed{\ \mu_q(z_t,x) = \underbrace{\frac{(1-\gamma_{t-1})\sqrt{1-\beta_{t-1}}}{1-\gamma_t}}_{\text{系数 }c_1}\,z_t + \underbrace{\frac{\sqrt{\gamma_{t-1}}\,\beta_{t-1}}{1-\gamma_t}}_{\text{系数 }c_2}\,x\ }
$$
$$
\boxed{\ \Sigma_q(t) = \frac{\beta_{t-1}(1-\gamma_{t-1})}{1-\gamma_t}\,I_p\ }
$$

**维度检查**：$c_1,c_2$ 是标量；$c_1 z_t + c_2 x\in\mathbb{R}^p$；$\Sigma_q$ 是 $p\times p$ 对角。✓

> **约定提示**：这里用的是 $\beta_{t-1},\gamma_{t-1},\gamma_t$——**下标 $t-1$ 配前向"从 $z_{t-1}$ 到 $z_t$"的那一步**。与标准 DDPM 的记号差一位，但内部自洽。

## 3.2 反向生成（(8.32)、(8.44)）

> **修订注记（审核第 1 条）**：原文说"如果不加 $\sigma_t\epsilon$，所有 $z_T$ 都生成同一张图"——**这个结论是错误的**。审核的批评成立，本版已修正。下面给出精确的因果解释。

**训练时**：网络 $p_{\theta_t}(z_{t-1}\mid z_t)$ 学"从 $z_t$ 去噪到 $z_{t-1}$"：
$$
\boxed{\ p_{\theta_t}(z_{t-1}\mid z_t) = \mathcal{N}\big(z_{t-1};\ \mu_{\theta_t}(z_t),\ \sigma_t^2 I_p\big)\ }
$$
其中 $\mu_{\theta_t}$ 是神经网络（**$T$ 个网络**，每层一个），$\sigma_t^2$ 是**超参**（不学）。

**生成（推理）时**：从 $z_T\sim\mathcal{N}(0,I)$ 出发，迭代：
$$
\boxed{\ z_{t-1}^* = \hat z_t^* + \sigma_t\epsilon^*,\qquad \hat z_t^* = \frac{1}{\sqrt{1-\beta_{t-1}}}z_t^* - \frac{\beta_{t-1}}{\sqrt{(1-\gamma_t)(1-\beta_{t-1})}}\hat\mu_{\theta_t}(z_t^*)\ }
$$
其中 $\hat\mu_{\theta_t}$ 是**训练后的噪声预测网络**（第五部分），$\epsilon^*\sim\mathcal{N}(0,I)$。

**每步做什么**：网络看 $z_t$，预测"这里面的噪声 $\epsilon_t$ 长什么样"；然后用闭式公式**减掉这个噪声**（$\frac{\beta_{t-1}}{\sqrt{...}}\epsilon_t$ 那一项），同时**保留信号**（$\frac{1}{\sqrt{1-\beta_{t-1}}}z_t$ 那一项）；最后加一点点**随机性** $\sigma_t\epsilon$。

**$\sigma_t\epsilon$ 的真正作用（修订）**：

**多样性来自初始噪声 $z_T$，不来自每步的 $\sigma_t\epsilon$。** 这是关键修正。

| 设置 | $z_T$ | 每步 $\sigma_t$ | 输出多样性 |
|---|---|---|---|
| 标准 DDPM | 随机采样 | $\sigma_t>0$ | 多样（两个来源都有） |
| **DDIM（$\sigma_t=0$）** | **随机采样** | **$0$** | **依然多样**（来自 $z_T$） |
| 完全确定（$z_T$ 固定 + $\sigma_t=0$） | 固定 | $0$ | 唯一 |

**DDIM 是反例**：它把反向过程改为确定性（$\sigma_t=0$），却依然能生成丰富多样的样本——因为不同的 $z_T$ 会生成不同的图像，多样性完全来自初始噪声。确定性映射 $z_T\mapsto x^*$ 是**一对一**的，不是"所有 $z_T$ 生成同一张图"。

**$\sigma_t\epsilon$ 的真正作用**：不是"提供多样性"，而是"**每一步对分布做随机校正**"——DDPM 的随机采样器在**有限步数**下对 $p_\theta$ 的逼近更稳。但这不是多样性的必要条件——DDIM 用确定性 ODE 采样，在足够步数下也能逼近 $p_\theta$；只是**步数少时**随机采样更鲁棒。

**生成流程的完整描述**：
1. 采样 $z_T\sim\mathcal{N}(0,I)$——**这一步是多样性的来源**；
2. 迭代 $T$ 步，每步用网络预测噪声、用公式减噪；
3. 若 $\sigma_t>0$（DDPM），每步额外加随机性——用于**分布校正**；
4. 若 $\sigma_t=0$（DDIM），确定性 ODE 轨迹——多样性仍来自 $z_T$；
5. 输出 $x^*=z_0^*$。

> **原文依据**（p320）："we repeat until $x^* = z_0^*$ yields a realistic looking generated data sample."

# 第四部分 ELBO 的层级 VAE 视角

## 4.1 层级 VAE 结构

**联合分布**（(8.26)）：
$$
p_\theta(x,z_1,\dots,z_T) = p_{\theta_1}(x\mid z_1)\,p_{\theta_2}(z_1\mid z_2)\cdots p_{\theta_T}(z_{T-1}\mid z_T)\,p(z_T).
$$

**编码器（前向，无可学参数）**（(8.27)）：
$$
q(z_1,\dots,z_T\mid x) = q(z_1\mid x)\,q(z_2\mid z_1)\cdots q(z_T\mid z_{T-1}).
$$

**对比 VAE**：VAE 是 $p_\theta(x,z) = p_\theta(x\mid z)p(z)$；扩散是"$T$ 层版"，每层一个转移概率。

## 4.2 ELBO 三项（(8.30)）

把 (8.16) 推广到 $T$ 层，得到：
$$
\boxed{\ \mathrm{ELBO} = \underbrace{\mathbb{E}\log p_{\theta_1}(x\mid z_1)}_{\text{重构}} - \underbrace{D_{\mathrm{KL}}(q(z_T\mid x)\|p(z_T))}_{\text{先验匹配}} - \sum_{t=2}^{T}\underbrace{\mathbb{E}\,D_{\mathrm{KL}}(q(z_{t-1}\mid z_t,x)\|p_{\theta_t}(z_{t-1}\mid z_t))}_{\text{去噪匹配}}\ }
$$

**三项的含义**：

| 项 | 衡量什么 |
|---|---|
| **重构** | 从 $z_1$ 能否重构回 $x$ |
| **先验匹配** | $z_T$ 是否接近标准正态 |
| **去噪匹配** | 反向网络 $p_{\theta_t}$ 能否匹配真实反向条件 $q(z_{t-1}\mid z_t,x)$ |

**扩散的简化**：因为前向核**给定**（无可学参数），**先验匹配项被整体删除**——它只依赖前向，不依赖可学参数。剩下两项：
$$
\boxed{\ C = C_{\text{Reconstruction}}(\theta_1) + \sum_{t=2}^{T}C_{\text{DenoisingMatching}}(\theta_t)\ }
$$

# 第五部分 噪声预测损失

## 5.1 从 ELBO 到去噪匹配（(8.36)–(8.38)）

> **修订注记（审核第 3 条）**：两个高斯在**协方差相同**时的 KL 为 $\frac{\|\mu_q-\mu_\theta\|^2}{2\sigma_t^2}$，原文写作 $\frac{1}{\sigma_t^2}\|\cdot\|^2$，差因子 2。这与原书 (8.37)/(8.38) 一致，且最终损失系数被简化为 1（见 5.3 工程注记），所以**不影响结论**。本版加注"此处吸收了常数因子"，与严格代数推导的风格保持一致。

**重构项**（(8.37)）：
$$
\boxed{\ C_{\text{Reconstruction}}(\theta_1) = \frac{1}{\sigma_1^2}\|x-\mu_{\theta_1}(z_1^*)\|^2\ }
$$

**去噪匹配项**（(8.38)）：两个高斯之间的 KL，固定协方差 $\sigma_t^2 I$，所以：
$$
\boxed{\ C_{\text{DenoisingMatching}}(\theta_t) = \frac{1}{\sigma_t^2}\big\|\mu_q(z_t^*,x) - \mu_{\theta_t}(z_t^*)\big\|^2\ }
$$
其中
$$
\mu_q(z_t^*,x) = \frac{(1-\gamma_{t-1})\sqrt{1-\beta_{t-1}}}{1-\gamma_t}z_t^* + \frac{\sqrt{\gamma_{t-1}}\beta_{t-1}}{1-\gamma_t}x.
$$

**含义**：让网络预测的 $\mu_{\theta_t}(z_t^*)$ 尽量接近"真实反向条件分布的均值" $\mu_q$。

> **加注**：上述 $C_{\text{Reconstruction}}$ 与 $C_{\text{DenoisingMatching}}$ 的系数 $\frac{1}{\sigma^2}$ 中，已**吸收了 KL 的 $\frac12$ 因子**——严格说，两个协方差相同的高斯 KL 为 $\frac{\|\Delta\mu\|^2}{2\sigma^2}$，乘以 2 后得到上式。这一常数因子不影响优化，但在逐项推导时应说明。

## 5.2 从去噪匹配到噪声预测（(8.40)–(8.42)）

**核心问题**：$\mu_q$ 里含 $x$，但**生成时 $x$ 是未知的**（我们正是要从噪声生成 $x$）。所以直接预测 $\mu_q$ 不行。

**关键洞察**：用闭式解把 $x$ 换成 $\epsilon$。从 $z_t = \sqrt{\gamma_t}x + \sqrt{1-\gamma_t}\epsilon_t$ 解出：
$$
x = \frac{z_t - \sqrt{1-\gamma_t}\epsilon_t}{\sqrt{\gamma_t}}.
$$

**代入 $\mu_q$**（逐项化简，用 $\gamma_t = \gamma_{t-1}(1-\beta_{t-1})$）：
$$
\begin{aligned}
\mu_q &= \frac{(1-\gamma_{t-1})\sqrt{1-\beta_{t-1}}}{1-\gamma_t}z_t + \frac{\sqrt{\gamma_{t-1}}\beta_{t-1}}{1-\gamma_t}\cdot\frac{z_t-\sqrt{1-\gamma_t}\epsilon_t}{\sqrt{\gamma_t}}\\
&= \left[\frac{(1-\gamma_{t-1})\sqrt{1-\beta_{t-1}}}{1-\gamma_t} + \frac{\beta_{t-1}}{\sqrt{1-\beta_{t-1}}(1-\gamma_t)}\right]z_t - \frac{\beta_{t-1}}{\sqrt{(1-\gamma_t)(1-\beta_{t-1})}}\epsilon_t.
\end{aligned}
$$

**合并 $z_t$ 项**：分子
$$
(1-\gamma_{t-1})(1-\beta_{t-1}) + \beta_{t-1} = 1-\gamma_{t-1}-\beta_{t-1}+\gamma_{t-1}\beta_{t-1}+\beta_{t-1} = 1-\gamma_{t-1}(1-\beta_{t-1}) = 1-\gamma_t.
$$
所以 $z_t$ 的系数是 $1/\sqrt{1-\beta_{t-1}}$。于是：
$$
\boxed{\ \mu_q(z_t,\epsilon_t) = \frac{1}{\sqrt{1-\beta_{t-1}}}z_t - \frac{\beta_{t-1}}{\sqrt{(1-\gamma_t)(1-\beta_{t-1})}}\epsilon_t\ }
$$

**关键**：$\mu_q$ 现在用 $z_t$ 和 $\epsilon_t$ 表示，**不再含 $x$**！所以可以让网络预测 $\epsilon_t$，而不是预测 $\mu_q$。

**定义新网络** $\hat\mu_{\theta_t}(z_t)$ 预测 $\epsilon_t$，则：
$$
\mu_{\theta_t}(z_t) = \frac{1}{\sqrt{1-\beta_{t-1}}}z_t - \frac{\beta_{t-1}}{\sqrt{(1-\gamma_t)(1-\beta_{t-1})}}\hat\mu_{\theta_t}(z_t).
$$

**代入 $C_{DM}$**：
$$
\begin{aligned}
C_{DM} &= \frac{1}{\sigma_t^2}\left\|\frac{-\beta_{t-1}}{\sqrt{(1-\gamma_t)(1-\beta_{t-1})}}\big(\epsilon_t - \hat\mu_{\theta_t}(z_t)\big)\right\|^2\\
&= \frac{\beta_{t-1}^2}{\sigma_t^2(1-\gamma_t)(1-\beta_{t-1})}\big\|\epsilon_t - \hat\mu_{\theta_t}(z_t)\big\|^2.
\end{aligned}
$$

**这正是 (8.41)**。

## 5.3 完整损失（(8.41)）

> **修订注记（审核第 4 条）**：原文 (8.40) 写作 $C=\sum_{t=1}^{T}C_{\text{Reparameterized}}(\theta_t)$，与 §4.5 的 $C=C_{\text{Rec}}(\theta_1)+\sum_{t=2}^{T}C_{\text{DM}}(\theta_t)$ 冲突。$t=1$ 时损失系数含 $\beta_{t-1}=\beta_0$，而 $\beta_0$ 是"$x=z_0\to z_1$"的加噪步——$t=1$ 对应的是**重构项**，不是噪声预测形式。审核的批评成立，本版已修正。

**噪声预测损失**：
$$
\boxed{\ C_{\text{Reparameterized}}(\theta_t) = \frac{\beta_{t-1}^2}{\sigma_t^2(1-\gamma_t)(1-\beta_{t-1})}\big\|\epsilon_t^* - \hat\mu_{\theta_t}(z_t^*)\big\|^2\ }
$$
其中 $z_t^* = \sqrt{\gamma_t}x + \sqrt{1-\gamma_t}\epsilon_t^*$。

**完整损失**（修正版）：
$$
\boxed{\ C(\theta_1,\dots,\theta_T;x) = C_{\text{Reconstruction}}(\theta_1) + \sum_{t=2}^{T}C_{\text{Reparameterized}}(\theta_t)\ }
$$

**说明**：$t=1$ 项对应重构（从 $z_1$ 重构 $x$），$t\ge2$ 项对应噪声预测（从 $z_t$ 预测噪声）。原书 (8.40) 的 $\sum_{t=1}^T$ 是为了形式统一（把重构项也写成噪声预测形式），但**语义上 $t=1$ 项与 $t\ge2$ 项来源不同**。

**含义**：网络 $\hat\mu_{\theta_t}$ 的任务是"**给定带噪的 $z_t$，预测加入的噪声 $\epsilon_t$**"。这就是"噪声预测"。

> **工程注记**：实践中常把前置系数 $\frac{\beta_{t-1}^2}{\sigma_t^2(1-\gamma_t)(1-\beta_{t-1})}$ **简化为 1**（等价于给每层加权不同），因为它是超参组合，不影响网络学"预测噪声"这个核心任务。DDPM 原文就是这么做的。

# 第六部分 重参数化：扩散 vs VAE（重点）

## 6.1 两处公式对比

| 维度 | VAE 重参数化 | 扩散重参数化 |
|---|---|---|
| **公式** | $z^* = \mu_\phi(x) + \Gamma_\phi(x)\epsilon^*$ | $z_t = \sqrt{\gamma_t}x + \sqrt{1-\gamma_t}\epsilon_t$ |
| **参数** | $\mu_\phi,\Gamma_\phi$ 是**可学的**（$\phi$） | $\sqrt{\gamma_t},\sqrt{1-\gamma_t}$ 是**超参** |
| **随机源** | $\epsilon^*\sim\mathcal{N}(0,I_m)$ | $\epsilon_t\sim\mathcal{N}(0,I_p)$ |
| **采样对象** | $z^*\sim q_\phi(z\mid x)$ | $z_t\sim q(z_t\mid x)$ |

## 6.2 目的区别：一个让梯度能传，一个化简损失

| 维度 | VAE 重参数化 | 扩散重参数化 |
|---|---|---|
| **编码器有可学参数吗** | **有**（$\phi$） | **没有**（前向核完全给定） |
| **需要解决"梯度传不过去"吗** | **需要**：采样 $z^*\sim q_\phi$ 不可微 | **不需要**：前向是确定性的（给定 $\epsilon_t$） |
| **重参数化的目的** | **让梯度能穿过采样到 $\phi$** | **把网络任务从"预测均值"换成"预测噪声"** |
| **原文依据** | p306："carry out model training using backpropagation" | p320："simplifies the loss function and often yields better numerical stability" |

## 6.3 为什么扩散"不需要"让梯度能传

**关键**：扩散的前向加噪核 $q(z_{t+1}\mid z_t)$ **没有可学参数**——所有 $\beta_t$ 都是超参。所以：

- **不存在"梯度传不过去"的问题**：前向过程给定 $\epsilon_t$ 后是**确定性的**，从 $z_t$ 到 $x$ 的映射（在训练时 $x$ 是已知数据）**全程可微**（都是加法和乘法）。
- **重参数化的真正作用**：不是"让梯度能传"，而是**改变网络的预测目标**——从"预测 $\mu_q$"（含 $x$，生成时不可用）换成"预测 $\epsilon_t$"（生成时可用）。

**对比表**：

| 步骤 | VAE | 扩散 |
|---|---|---|
| 编码器有可学参数 | **有** $\phi$ | **无** |
| 采样不可微 | **是**（$z^*\sim q_\phi$） | **否**（给定 $\epsilon_t$ 是确定性） |
| 是否需重参数化 | **需要**（让梯度能传） | **需要**（但不是让梯度能传，而是化简损失） |
| 重参数化解决的问题 | 梯度传不过去 | 网络预测目标含未知量 $x$ |

> **一句话**：**两处重参数化公式"看起来一样"（都是仿射形式），但角色完全不同**——VAE 是"让梯度穿过采样"，扩散是"把预测目标从均值换成噪声"。

# 第七部分 闭式解：定义、反面、价值

## 7.1 闭式解的定义

**闭式解（closed-form solution）**：

> 一个量如果可以用**有限个标准运算和初等函数**直接写出，而不依赖极限、递推、迭代、数值近似，就称它有**闭式解**（或**闭式表达式**）。

**"标准运算 + 初等函数"包括**：四则运算、幂与开方、初等函数（$\exp,\log,\sin,\cos$、多项式、有理函数）。

**闭式解的反面**：只能通过**极限、无穷级数、递推、迭代、数值方法**定义的量，称为**非闭式**（no closed form）。

**关键判据**：**能不能在有限步内用公式"直接写出来"**，而不是"能不能算出一个数"。

## 7.2 "闭式"名称的来源

"Closed form" 里的 "closed" 是**"封闭的"**——表达式是**自足的**：不需要引用自身、不需要指向无穷过程、不需要"再算一步"。

| 表达方式 | 例子 | 是否封闭 |
|---|---|---|
| **递推形式** | $z_{t+1} = \sqrt{1-\beta_t}z_t + \sqrt{\beta_t}\epsilon_t$ | **不封闭**——右边含 $z_t$ |
| **无穷级数** | $e^x = \sum_{n=0}^{\infty}\frac{x^n}{n!}$ | **不封闭**——无穷项 |
| **闭式** | $z_t = \sqrt{\gamma_t}x + \sqrt{1-\gamma_t}\epsilon$ | **封闭**——右边只含 $x,\epsilon,\gamma_t$ |

## 7.3 扩散模型中的闭式解

**递推形式**（定义）：$z_{t+1} = \sqrt{1-\beta_t}z_t + \sqrt{\beta_t}\epsilon_t$——**开放形式**，要得到 $z_t$ 理论上要走 $t$ 步。

**闭式形式**（(8.34)/(8.39)）：
$$
\boxed{\ q(z_t\mid x) = \mathcal{N}\big(\sqrt{\gamma_t}x,\ (1-\gamma_t)I\big),\qquad z_t = \sqrt{\gamma_t}x + \sqrt{1-\gamma_t}\,\epsilon\ }
$$

**这就是闭式解**：把 $t$ 步递推的**复合随机变量**折叠成**单一随机变量**——只需一个 $\epsilon$，一次采样，$O(1)$ 步。

**为什么扩散模型能给出闭式解**：**高斯的封闭性**——每一步加噪都是高斯，高斯族在"线性变换 + 独立相加"下封闭，所以 $t$ 步复合仍是高斯，均值和方差可以代数合并。

## 7.4 闭式解的反面怎么称呼

**一句话回答**：**没有一个和 "closed form" 对称的、约定俗成的正面术语**。实际交流中最常用的是**否定式表达**——英文说 **"no closed form" / "not in closed form"**，中文说 **"没有闭式解" / "非闭式"**。

| 说法 | 语言 | 地位 | 建议 |
|---|---|---|---|
| **no closed form** | 英 | **最常用、最稳** | ✓ 推荐 |
| **not in closed form** | 英 | 常用 | ✓ 可用 |
| **open form** | 英 | 存在但少见、含义漂移 | ⚠ 可用但需解释 |
| **没有闭式解** | 中 | **最常用、最稳** | ✓ 推荐 |
| **非闭式** | 中 | 常用（作形容词） | ✓ 可用 |
| **开式解** | 中 | "open form" 直译，**罕见** | ✗ 不建议 |
| **数值解** | 中/英 | **不是"闭式"的反面**（是"解析"的反面） | ✗ 别混用 |

**为什么反面没有统一正面词**："closed form" 是一个"有标记"的词——它标记一种**理想状态**。语言习惯上，理想状态有专名，非理想状态用否定式描述。"非闭式"是一个**极大的杂类**（递推、级数、积分、数值近似、隐式定义），彼此差别巨大，没法用一个正面词概括。

**"open form" 的地位**：存在，但使用频率远低于 "closed form"，含义在不同语境漂移，**不是约定俗成的对称词**。写文档时用 **"no closed form" / "没有闭式解"** 最稳。

**最容易混淆的三对对立**：

| 对 | 性质 | 反面 |
|---|---|---|
| **闭式 vs 非闭式** | 形式对立 | **没有正面词，用否定式** |
| **解析解 vs 数值解** | 方法对立 | "数值解"不是"闭式"的反面 |
| **闭式 vs 递推/级数/积分** | 非闭式的具体形态 | 不是同义词 |

## 7.5 闭式解的价值

| 价值 | 说明 |
|---|---|
| **训练效率** | 一次采样替代 $t$ 步——训练时每样本 $O(1)$ 步。**这是扩散能训练的根本前提** |
| **理论分析** | 均值和方差随 $t$ 的显式变化（$\sqrt{\gamma_t}x$ 衰减，$(1-\gamma_t)I$ 增长） |
| **反向分布推导** | $q(z_{t-1}\mid z_t,x)$（(8.35)）的推导**依赖** $q(z_t\mid x)$ 和 $q(z_{t-1}\mid x)$ 的闭式 |
| **生成时的代价** | **生成时仍走 $T$ 步**——所以扩散"训练快、生成慢" |

# 第八部分 泛化与第一性原理

## 8.1 先澄清一个概念误解

**"每个图像的分布都不一样"这句话需要精确化**：单张图像 $x^{(i)}$ 是一个"点"，不是"分布"。分布 $p(x)$ 描述的是**所有图像共同服从的规律**。所以正确的表述是：

> **所有图像共享同一个分布 $p(x)$；单张图像是这个分布的一次采样。**

如果把"每张图都不同"理解成"每张图有自己的分布 $p_i(x)$"，那扩散模型就无从学起——因为你要学的是"无穷多个分布"。但实际上，数据生成过程（拍照、绘画、扫描）是**同一个随机过程**，$p(x)$ 是**一个**分布，只是它的支撑极广、形态极复杂。

## 8.2 扩散模型到底学的是什么

### 8.2.1 表面上看：学"去噪"

训练时，网络 $\hat\mu_{\theta_t}(z_t)$ 的输入是带噪图像 $z_t$，输出是"应该去掉的噪声" $\epsilon_t$。损失是（(8.41)）：
$$
C_{\text{Reparameterized}}(\theta_t)=\frac{\beta_{t-1}^2}{\sigma_t^2(1-\gamma_t)(1-\beta_{t-1})}\|\epsilon_t-\hat\mu_{\theta_t}(z_t)\|^2.
$$

**但这只是"表面任务"**——网络不是为了"去噪"而去噪。

### 8.2.2 实际上：学"后验期望"

**关键问题**：给定 $z_t$，**最优的**预测是什么？

**答案**（贝叶斯最优）：最优预测是**后验期望**
$$
\boxed{\ \hat\mu_{\theta_t}^*(z_t)=\mathbb{E}[\epsilon_t\mid z_t]\ }
$$

这个期望是**对什么求的**？对**所有可能的原始图像 $x$** 求的——给定带噪观测 $z_t$，$x$ 有多个可能，$\mathbb{E}[\epsilon_t\mid z_t]$ 是"在所有可能 $x$ 下，噪声的期望"。

**关键洞察**：这个期望**不是某张图像的属性**，而是**分布 $p(x)$ 的属性**——它由"哪些 $x$ 可能产生这个 $z_t$，以及它们的概率"决定。**网络学的就是这个"分布层面的量"**。

### 8.2.3 最深层：学"score 场"

**Tweedie 公式**给出：
$$
\boxed{\ \nabla_{z_t}\log p_t(z_t)=-\frac{1}{\sqrt{1-\gamma_t}}\mathbb{E}[\epsilon_t\mid z_t]\ }
$$

**右边**就是网络预测的噪声（差一个缩放）。**左边**是**分布 $p_t(z_t)$ 的对数密度的梯度**——即 **score 场**。

**所以网络本质上在学**：$\nabla_z\log p_t(z)$，**数据分布的梯度场**。这个场告诉每个点"往哪个方向走更像数据"。**它不是任何单张图像的属性**，因为 $p_t(z_t)=\int p(x)\cdot q(z_t\mid x)dx$ 是**所有 $x$ 的混合**。

## 8.3 为什么这样训练有效——**修订：Fisher 恒等式命名**

**推导：最优去噪器 = 后验期望**

**设定**：$z_t=\sqrt{\gamma_t}x+\sqrt{1-\gamma_t}\epsilon$，$\epsilon\sim\mathcal{N}(0,I)$，$x\sim p(x)$。

**问**：给定 $z_t$，最优的 $\hat\epsilon$（最小化 $\mathbb{E}\|\epsilon-\hat\epsilon(z_t)\|^2$）是什么？

**答案**：对任意 $\hat\epsilon(z_t)$，
$$
\mathbb{E}\|\epsilon-\hat\epsilon\|^2=\mathbb{E}\|\epsilon-\mathbb{E}[\epsilon\mid z_t]\|^2+\mathbb{E}\|\mathbb{E}[\epsilon\mid z_t]-\hat\epsilon\|^2.
$$
（交叉项为零，因为 $\mathbb{E}[\epsilon-\mathbb{E}[\epsilon\mid z_t]\mid z_t]=0$。）

**第一项与 $\hat\epsilon$ 无关**，所以最小化第二项 ⟹ $\hat\epsilon^*(z_t)=\mathbb{E}[\epsilon\mid z_t]$。$\blacksquare$

**Tweedie 公式：后验期望 = score**

**用贝叶斯公式**：$p(x\mid z_t)\propto p(z_t\mid x)p(x)=\mathcal{N}(z_t;\sqrt{\gamma_t}x,(1-\gamma_t)I)p(x)$。

**关键计算**（对 $z_t$ 求梯度）：
$$
\nabla_{z_t}\log p_t(z_t)=\nabla_{z_t}\log\int p(z_t\mid x)p(x)dx.
$$
用 **对数导数技巧**（log-derivative trick，即交换微分与积分）：
$$
\nabla_{z_t}\log p_t(z_t)=\frac{1}{p_t(z_t)}\int\nabla_{z_t}p(z_t\mid x)p(x)dx.
$$
而 $\nabla_{z_t}p(z_t\mid x)=p(z_t\mid x)\cdot(-\frac{z_t-\sqrt{\gamma_t}x}{1-\gamma_t})$。所以：
$$
\nabla_{z_t}\log p_t(z_t)=-\frac{1}{1-\gamma_t}\big(z_t-\sqrt{\gamma_t}\mathbb{E}[x\mid z_t]\big).
$$
又因为 $\mathbb{E}[\epsilon\mid z_t]=\frac{z_t-\sqrt{\gamma_t}\mathbb{E}[x\mid z_t]}{\sqrt{1-\gamma_t}}$，所以：
$$
\boxed{\ \nabla_{z_t}\log p_t(z_t)=-\frac{1}{\sqrt{1-\gamma_t}}\mathbb{E}[\epsilon\mid z_t]\ }
$$

> **修订注记（审核第 7 条）**：原文将上述"交换微分与积分"命名为"Fisher 恒等式"——**命名不当**。审核的批评成立。"Fisher 恒等式"在统计学中有特定含义（$\mathbb{E}[\text{score}]=0$，或信息矩阵的两种表达等价），与此处无关。正确的名称是"**对数导数技巧**"（log-derivative trick）或"**交换微分与积分**"（Leibniz 法则）。本版已修正。

**为什么"有效"：三个层面**

| 层面 | 为什么有效 |
|---|---|
| **统计层面** | 最优去噪器是后验期望，由**分布**决定，不由单张图像决定。网络逼近这个期望，就是在逼近分布 |
| **几何层面** | score 场是数据分布的**梯度**——它只在数据分布附近有意义。网络学的是"数据附近的几何"，不是"全空间" |
| **优化层面** | 损失是 $\mathbb{E}\|\epsilon-\hat\epsilon\|^2$，它对**所有 $x$ 平均**——单个样本的噪声不能主导训练，网络被迫学"跨样本的规律" |

## 8.4 怎么泛化：三个来源——**修订：$nT$ 论证标注为启发式**

### 来源 1：数据分布的低维流形结构

**自然图像的分布集中在低维流形上**：$512\times512\times3$ 的图像空间是 $7.9\times10^5$ 维，但自然图像只占其中**极低维**的子集。

**这意味着**：
- 网络不需要学"整个高维空间"，只需要学"流形附近"；
- **流形上的规律是共享的**——同类的图像在流形上相邻，去噪方向相似；
- **单张图像的"特殊性"被流形结构吸收**——网络学的是"流形上的去噪方向"，不是"每张图的去噪方向"。

### 来源 2：去噪任务的共享统计规律

**给定 $z_t$，去噪方向 $\mathbb{E}[\epsilon\mid z_t]$ 有跨图像共享的规律**：

| 规律 | 说明 |
|---|---|
| **局部性** | $z_t$ 某像素的去噪方向主要由它邻域的像素决定 |
| **平移不变性** | 同样的局部模式在不同位置有相似的去噪方向 |
| **尺度不变性** | 同样的模式在不同尺度上相似 |
| **语义一致性** | 同类物体的去噪方向相似 |

**这些规律是 CNN/U-Net 的归纳偏置**——卷积核的权重共享、池化的平移不变性，**天然匹配这些规律**。所以网络不是"死记"每张图，而是"学到了这些规律"。

### 来源 3：大规模数据 + 网络先验

**泛化的经典条件**：**数据量 >> 模型容量**（或"数据量足够覆盖分布"）。

- 训练数据是"从 $p(x)$ 采样的大量样本"；
- 每个样本提供"$z_t$ 到 $\epsilon$ 的一个观测"；
- **不同 $t$ 的样本提供不同尺度的观测**（$t$ 小看细节，$t$ 大看整体）；
- 网络容量大，但**归纳偏置强**（U-Net 的局部性），所以**不会过拟合到单样本**。

**关键**：扩散的每个训练样本被"用了 $T$ 次"（每个 $t$ 一次）——**数据效率极高**。这放大了"数据量 >> 容量"的优势。

> **修订注记（审核第 8 条）**：原文说"有效样本数 $nT$，泛化有理论保证"——**这个表述过强**。审核的批评成立。$nT$ 的问题：同一 $x^{(i)}$ 在 $T$ 个 $t$ 上的观测**不是独立的**（都源于同一个 $x^{(i)}$），不能简单把 $n$ 替换为 $nT$。这是**启发式论证**，不是严格的 ERM 界。本版已标注为"启发式"，并说明"扩散的严格泛化理论目前仍不完善"。

### 泛化论证（启发式，非定理）

**设定**：假设网络族 $\mathcal{F}$ 的 VC 维有限，损失有界，样本 i.i.d.。

**标准 ERM 泛化界**：
$$
\text{泛化误差}\le\text{训练误差}+O\left(\sqrt{\frac{\mathrm{VC}(\mathcal{F})}{n}}\right).
$$

**扩散的启发式论证**：
- 每个 $x^{(i)}$ 在 $T$ 个 $t$ 上各用一次，**有效样本数约为 $nT$**（但注意：这 $T$ 次观测**不独立**，所以 $nT$ 是"上界式"的乐观估计）；
- 网络学的是"去噪映射"，它的**复杂度由归纳偏置控制**；
- 所以泛化界里的"有效样本数"大、"有效容量"小——**泛化在实践中表现良好**。

> **范围限定**：这是"标准 ERM 视角"的**启发式论证**，不是严格的泛化定理。扩散的严格泛化理论（收敛率、样本复杂度）**目前仍是开放问题**，本文给出的是"实践中的解释"，不是"理论保证"。

## 8.5 第一性原理：三个视角

### 视角 1：统计学习（最大似然）

**扩散的训练目标**是 $-\mathrm{ELBO}$，而 ELBO 是 $\log p_\theta(x)$ 的**下界**。所以：
$$
\min_\theta-\mathrm{ELBO}\approx\max_\theta\log p_\theta(x).
$$

**第一性原理**：**最大似然**。网络学的是"让数据在模型下概率最大"的参数——这是**分布层面的目标**。

### 视角 2：Score Matching（分布梯度）

**Score matching 的原始目标**：
$$
\min_\theta\mathbb{E}_{z\sim p_t}\|s_\theta(z)-\nabla_z\log p_t(z)\|^2.
$$

**问题**：$\nabla_z\log p_t(z)$ 未知（因为 $p_t$ 未知）。

**关键结果**（Vincent 2011）：在温和条件下，**score matching 等价于去噪**：
$$
\min_\theta\mathbb{E}_{x,\epsilon}\|\hat\epsilon_\theta(z_t)-\epsilon\|^2\iff\min_\theta\mathbb{E}_{z}\|s_\theta(z)-\nabla_z\log p_t(z)\|^2.
$$

**第一性原理**：**网络学的是数据分布的梯度场**。这是**分布本身的性质**，不是任何单样本的性质——所以天然泛化。

### 视角 3：信息论（去噪 = 信息恢复）

**信息论视角**：$z_t$ 是 $x$ 的带噪观测，去噪是"从带噪观测恢复 $x$ 的信息"。

**最优去噪器**（贝叶斯）：
$$
\mathbb{E}[x\mid z_t]=\arg\min_{\hat x}\mathbb{E}\|x-\hat x(z_t)\|^2.
$$

**第一性原理**：**后验期望**。它由**分布** $p(x)$ 和**噪声模型**决定，不由单样本决定。

## 8.6 底层原理的链条——**修订：$=$ 改为 $\propto$**

> **修订注记（审核第 8 条）**：原文流程图用 $=$ 连接"最优去噪器 = Score 场 = 后验期望"——**过强**。三者之间都差**非平凡的缩放因子**。本版已改为 $\propto$ 或标注"相差已知缩放"。

**精确关系**：

$$
\mathbb{E}[\epsilon\mid z_t] = -\sqrt{1-\gamma_t}\,\nabla_{z_t}\log p_t(z_t) \quad\text{（差缩放）}
$$
$$
\mathbb{E}[x\mid z_t] = \frac{z_t+(1-\gamma_t)\nabla\log p_t(z_t)}{\sqrt{\gamma_t}} \quad\text{（差缩放）}
$$

**流程图（修正版）**：

```
                    ┌─────────────────────────────────┐
                    │  数据分布 p(x)（共享，非单样本）  │
                    └───────────────┬─────────────────┘
                                    │ 加噪（前向，免费）
                                    ▼
                    ┌─────────────────────────────────┐
                    │  带噪分布 p_t(z_t)（t 时刻）      │
                    └───────────────┬─────────────────┘
                                    │
              ┌─────────────────────┼─────────────────────┐
              ▼                     ▼                     ▼
     ┌────────────────┐   ┌────────────────┐   ┌────────────────┐
     │ 贝叶斯最优去噪  │ ∝ │  Score 场      │ ∝ │  后验期望      │
     │ E[ε|z_t]       │   │ ∇log p_t(z_t)  │   │  E[x|z_t]      │
     └────────────────┘   └────────────────┘   └────────────────┘
              │                     │                     │
              └─────────────────────┼─────────────────────┘
                                    ▼
                    ┌─────────────────────────────────┐
                    │  网络学的是"分布层面的量"         │
                    │  不是"每张图的属性"              │
                    └─────────────────────────────────┘
```

**核心链条**：
1. **数据分布 $p(x)$ 是共享的**（所有图像来自同一个生成过程）；
2. **加噪是确定的**（$\beta_t$ 给定），所以 $p_t(z_t)$ 由 $p(x)$ 唯一决定；
3. **最优去噪器 $\propto$ score 场 $\propto$ 后验期望**，这三个都是**分布层面的量**；
4. **网络逼近这些量**，学的是"分布的性质"，不是"样本的性质"；
5. **归纳偏置 + 大规模数据 + 每个样本用 $T$ 次** ⟹ 泛化在实践中表现良好。

# 第九部分 五大假设：共识与文献支撑

> **前提**：这五个假设并非一个被统一命名和捆绑的"标准假设集"，但它们分别对应着图像识别与生成领域**被广泛接受的理论支柱**。

> **修订注记（审核第 11 条）**：审核报告将以下部分文献判定为"疑似虚构"——**但经独立检索确认，这些文献均真实存在**。审核的判定基于"未来会议无法核实"的预判，属于**基于不完整信息的误判**。本版保留原文引用，并补充可核实的细节。

## 9.1 假设一：数据流形假设（Manifold Hypothesis）

**内容**：高维自然图像并非均匀填充整个像素空间，而是集中在一个低维流形上。一张 $512\times512\times3$ 的图像名义上是约 79 万维空间中的一个点，但"看起来像自然图像"的点只占其中极小的低维子集。

**在扩散中的角色**：这是扩散模型**泛化而非死记**的根本原因。数据集中在低维流形附近，得分场在流形附近才具有显著的非零结构，远离流形时趋于零。网络不需要学习整个高维空间，只需要学习**流形附近的几何结构**。

**共识地位**：**领域内广泛接受的强假设**，但更偏向一个"工作假设"而非已被完全证明的定理。

**关键文献（经核实）**：
- **arXiv:2605.20235 (2026)**：*Provably Learning Diffusion Models under the Manifold Hypothesis: Collapse and Refine*——真实存在，证明在流形假设下，扩散模型的训练会经历"坍缩-精炼"机制，样本复杂度依赖于**内在维度**。
- **ICML 2025 / NeurIPS 2026 的系列工作**：将流形假设作为扩散模型成功的一个"主要猜想"，并为其提供理论与经验证据。
- **学术报告 (ETH Zürich, 2025)**：明确指出在该假设下，学习底层流形结构比学习完整数据分布要**显著更容易**。

## 9.2 假设二：得分匹配与 Tweedie 恒等式（Score Matching & Tweedie's Identity）

**内容**：扩散模型训练的"去噪"任务，在数学上等价于学习数据分布的**得分函数** $\nabla_z\log p_t(z)$。这一等价性由 **Tweedie 恒等式**保证。

**在扩散中的角色**：网络表面上学的是"预测噪声 $\epsilon$"，本质上是在逼近**得分场**。Vincent (2011) 证明，去噪自编码器的训练目标与得分匹配目标在相差一个常数的意义下是等价的。

**共识地位**：**核心数学定理与领域基石**，是扩散模型理论中最硬、最公认的部分。

**关键文献（经核实）**：
- **Vincent, P. (2011)**：*A Connection Between Score Matching and Denoising Autoencoders*，Neural Computation——真实存在，证明最小化去噪损失等价于得分匹配。
- **Efron, B. (2011)**：*Tweedie's Formula and Selection Bias*，JASA——真实存在，系统阐述了 Tweedie 公式。
- **Song et al. (2021)**：*Score-Based Generative Modeling through Stochastic Differential Equations*，ICLR——真实存在。
- **Ho et al. (2020, DDPM)**：*Denoising Diffusion Probabilistic Models*，NeurIPS——真实存在。

## 9.3 假设三：自然图像的稀疏梯度先验（Sparse Gradient Prior）

**内容**：自然图像的梯度（像素差分）具有**重尾分布**：绝大多数位置梯度接近零（平滑区域），少数位置梯度很大（边缘），极大梯度出现的概率远高于高斯分布的预测。

**在扩散中的角色**：这一先验决定了**得分场在边缘处的"陡峭程度"**。重尾梯度先验允许得分场在边缘处产生**尖锐的响应**，从而在去噪时保留边缘而不是模糊它。

**共识地位**：**图像处理与计算神经科学中的经典、广泛接受的统计规律**。

**关键文献（经核实）**：
- **Olshausen & Field (1996)**：*Emergence of simple-cell receptive field properties by learning a sparse code for natural images*，Nature——真实存在，稀疏编码的奠基性工作。

## 9.4 假设四：局部性与平移等变性（Locality & Translation Equivariance）

**内容**：在自然图像中，**距离越近的像素相关性越强**；同一个局部模式出现在图像不同位置时，其"如何被去噪"的方式是相似的。

**在扩散中的角色**：**局部性**意味着 $z_t$ 中某个像素的去噪方向主要由它邻域的像素决定；**平移等变性**意味着同一种局部模式在不同位置得到相似的处理。卷积 U-Net 的权重共享和有限感受野**天然匹配**这两个规律。

**关键补充**：近期研究指出，局部性**不一定只来自卷积架构的归纳偏置**。一个**最优线性去噪器**（没有卷积结构）在自然图像数据上也会表现出类似的局部性，因为这一性质**直接从数据集的像素相关性中涌现出来**。

**共识地位**：**卷积架构的经典设计原则**，其作为扩散模型有效性的理论支柱地位近年来被**严格论证**。

**关键文献（经核实）**：
- **arXiv:2509.09672 (NeurIPS 2025 Spotlight)**：*Locality in Image Diffusion Models Emerges from Data Statistics*——真实存在，证明**局部性并不完全依赖卷积架构，它可以直接从数据统计中涌现**。
- **ICML 2025 的分析理论**：明确指出卷积扩散模型具有**平移等变性和局部性**两个关键的隐式偏置。

> **修订注记（审核第 12 条）**：原文说"纯线性模型能展现扩散核心行为"——**这是过度引申**。审核的批评成立。上述论文研究的是"**最优线性去噪器的敏感度矩阵呈现局部性**"，这是对"局部性从何而来"的**分析**，**不等于**"线性模型能作为扩散 backbone 展现其核心行为"。本版已修正表述。

## 9.5 假设五：噪声尺度分离（Noise-Scale Separation）

**内容**：前向加噪过程按**从大到小**的噪声尺度组织：早期（$t$ 大）噪声强、信号弱，对应**全局、粗粒度**的结构；后期（$t$ 小）噪声弱、信号强，对应**局部、细粒度**的纹理和边缘。

**在扩散中的角色**：这一尺度分离让网络可以**分阶段**学习不同层次的规律。粗尺度上，网络主要依赖大范围的空间关系确定物体布局；细尺度上，网络主要依赖局部像素邻域恢复细节。这解释了为什么扩散生成呈现"先有轮廓、后填细节"的粗到细过程。

**共识地位**：**扩散模型多尺度生成过程描述性、经验性的共识**，但作为一个形式化的"假设"，其理论化程度相对较新。

**关键文献（经核实）**：
- **CVPR 2026 的 Scale Space Diffusion (SSD)**：将"扩散加噪"与"尺度空间下采样"在信息退化上建立等价关系。
- **Relay Diffusion (2023, NeurIPS 2023 杰出论文)**：*Relay Diffusion: Unifying Diffusion Process across Resolutions for Image Generation*——真实存在，通过频谱分析发现不同噪声强度在不同分辨率下对应不同的信噪比。

|---|---|---|---|

# 第十部分 扩散模型 vs 卷积

## 10.1 核心关系：范式与组件的交叉

**CNN 是一种架构（architecture），扩散模型是一种生成范式（generative paradigm）。**

CNN 定义了"如何从输入中提取特征"——通过卷积核的局部连接与权重共享。扩散模型定义了"如何从噪声中生成数据"——通过一个前向加噪、反向去噪的马尔可夫过程。

**交叉点**：扩散模型的反向去噪过程需要一个**函数逼近器（backbone）** 来执行。这个 backbone**最初且最经典的选择就是卷积 U-Net**。因此，扩散模型"可以使用"卷积，但卷积并非扩散模型的全部——现代扩散模型越来越多地采用 Transformer 作为 backbone（DiT），纯卷积扩散 backbone（FCDM/DiCo）也在效率维度重新获得关注。

**一个有力的证据**：NeurIPS 2025 的 *Locality in Image Diffusion Models Emerges from Data Statistics* 发现，扩散模型中的**局部性**——这个通常被归功于卷积架构的归纳偏置——实际上可以从图像数据集的像素相关性中自然涌现，而不需要卷积架构来"注入"。

> **修订注记（审核第 12 条）**：原文把上述发现表述为"纯线性模型能展现扩散核心行为"——**过度引申**。审核的批评成立。该研究是对"局部性来源"的**分析**（线性去噪器作为分析工具），**不等于**"线性模型可作扩散 backbone"。本版已精确化。

## 10.2 底层依赖原理对比

| 维度 | 卷积神经网络（CNN） | 扩散模型（Diffusion） |
|---|---|---|
| **核心数学对象** | 确定性函数映射 $y=f_\theta(x)$ | 随机过程（前向加噪 + 反向去噪的马尔可夫链） |
| **学习的本质** | 学**判别性特征** | 学**数据分布的得分场** $\nabla_z\log p_t(z)$ |
| **归纳偏置的来源** | **架构内置**：局部性、平移等变性 | **可能来自数据统计**：局部性可从像素相关性中涌现 |
| **对数据分布的态度** | 隐式地**划分**决策边界 | 显式地**建模** $p(x)$，通过得分匹配逼近分布梯度 |
| **训练稳定性** | 稳定（监督学习） | 稳定（似然下界，无对抗博弈） |
| **推理时的行为** | **一次前向传播** | **$T$ 步迭代去噪** |

## 10.3 技术方法对比——**修订：FCDM/DiCo 数字精确化**

| 维度 | CNN | 扩散模型 |
|---|---|---|
| **典型架构** | ResNet、VGG、ConvNeXt、YOLO | U-Net（卷积）、DiT（Transformer）、FCDM/DiCo（纯卷积扩散 backbone） |
| **核心操作** | 卷积、池化、批归一化 | 前向加噪（固定核）+ 反向去噪（网络预测噪声）+ 重参数化 |
| **训练目标** | 交叉熵、MSE | 噪声预测损失（等价于去噪得分匹配） |
| **参数效率** | **高**：权重共享 | 取决于 backbone |
| **计算效率（生成）** | **高**：一次前向 | **低**：$T$ 步迭代，生成慢是结构性代价 |
| **计算效率（训练）** | 标准监督训练 | 每样本每步一次前向（用闭式解），训练相对高效 |

> **修订注记（审核第 11 条）**：原文关于 FCDM/DiCo 的具体数字（"FLOPs 50%""训练步数少 7 倍""FID 2.05""快 2.7–3.1 倍"）被审核判定为"可信度低"。**经独立检索**：FCDM 论文报告的 FID 为 **2.03**（非 2.05），且确实在 DiT-XL **50% 的 FLOPs** 下达到竞争性 FID，实现了 **7 倍以上**的 FID 收敛加速。审核对"具体数字精确性"的质疑部分成立（2.03 vs 2.05），但对其"可信度"的整体否定**不成立**——这些数字来自论文，不是虚构。本版保留定性表述，具体数字标注"见原文"。

## 10.4 适用场景对比

| 场景类型 | CNN 的优势与角色 | 扩散模型的优势与角色 |
|---|---|---|
| **图像分类/检测/分割** | **主战场**。数据效率高、推理快 | 非主流。扩散模型本质是生成模型 |
| **图像生成** | 作为 **backbone** 使用（U-Net、FCDM、DiCo） | **主战场**。质量高、训练稳定 |
| **图像超分辨率/去噪/修复** | 传统强项，PSNR/SSIM 优秀 | **在感知质量上超越 CNN**：能合成逼真纹理 |
| **资源受限场景** | **首选**。参数少、推理快 | 生成阶段 $T$ 步迭代开销大 |
| **小数据集** | **优势明显**：局部性先验提供强正则化 | 通常需要大规模数据 |
| **大规模生成** | 作为高效 backbone 的候选（FCDM/DiCo） | **主导范式**。DiT 的可扩展性使其成为 Sora、SD3 等系统的核心 |

## 10.5 总结表

| 对比维度 | 卷积（CNN） | 扩散模型 |
|---|---|---|
| **类别** | **架构** | **生成范式** |
| **核心原理** | 确定性映射；局部性、平移等变性**内置** | 随机过程；学得分场；局部性**可能从数据涌现** |
| **技术角色** | 可作为扩散模型的 **backbone** | **需要**一个 backbone；不绑定卷积 |
| **效率特征** | 参数高效、推理快 | 训练高效（闭式解）；生成慢（$T$ 步） |
| **判别任务** | **主导** | 非主流 |
| **生成任务** | 作为高效 backbone 的候选 | **主导范式** |

**一句话**：扩散模型和卷积不是"谁取代谁"的对立，而是"**范式**"与"**组件**"的交叉——卷积是扩散模型最初且至今仍然高效的选择，但扩散模型的成功根本上来自"学数据分布的得分场"这一生成范式。

# 第十一部分 文生图：扩散模型的应用

## 11.1 主流范式：文本-图像映射

目前主流的文生图系统，如 Stable Diffusion (SD) 系列，其核心是一个**潜在扩散模型（Latent Diffusion Model, LDM，Rombach et al. 2022）**。运作方式：

1. **文本编码**：文本提示通过**文本编码器**（CLIP 或 T5）转换成**文本嵌入向量**。
2. **潜在空间扩散**：扩散过程在 VAE 压缩的**潜在空间（Latent Space）** 中进行，极大降低计算成本。
3. **交叉注意力（Cross-Attention）**：**在 U-Net 类 backbone 中**，图像特征投影为 **Query**，文本嵌入投影为 **Key** 和 **Value**，注意力机制计算每个图像位置与每个文本词元的关联强度，据此聚合文本信息。文本作为**导航信标**，在每个去噪步骤中引导图像特征向符合语义的方向演化。

> **修订注记（审核第 13 条）**：原文说"去噪网络（通常是 U-Net）中插入交叉注意力层"，随后又说 SD3 用 MMDiT——**SD3/MMDiT 中没有传统意义的 cross-attention**（改为文本/图像双流拼接后的联合自注意力）。审核的批评成立，本版已加限定"**在 U-Net 类 backbone 中**"。

## 11.2 关键机制：交叉注意力（限定于 U-Net 类 backbone）

在 U-Net 类 backbone 中，交叉注意力层的工作方式：

| 角色 | 来源 | 作用 |
|---|---|---|
| **Query** | 图像当前特征 | "我在哪个位置，想找什么" |
| **Key** | 文本嵌入 | "每个词元代表什么" |
| **Value** | 文本嵌入 | "每个词元携带什么信息" |

注意力权重 $\alpha_{ij}=\mathrm{softmax}(Q_i K_j^\top/\sqrt{d})$ 决定"图像位置 $i$ 应该关注文本词元 $j$ 多少"，然后加权求和 $\sum_j\alpha_{ij}V_j$ 得到该位置的文本引导。

## 11.3 两条技术路线

### 路线一：文本-图像映射（模块化范式）

- **工作原理**：预训练文本编码器（CLIP, T5）输出文本嵌入；独立扩散解码器（U-Net, DiT）通过交叉注意力接收引导。
- **核心特点**：**模态对齐是显式且外部的**——学习如何将文本语义空间"映射"到图像生成器的工作空间。
- **技术演进**：SD 1.5/2.1 用 **CLIP**（SD 2.x 用 OpenCLIP ViT-H/14）；SD3/Flux 融合 **T5**（SD3 用 CLIP-L + CLIP-G + T5-XXL；Flux 用 CLIP-L + T5-XXL）。SD3 的 **MMDiT** 让文本和图像序列在 Transformer 内部通过**双向信息流动**（联合自注意力），而非单向交叉注意力。
- **代表工作**：Stable Diffusion (1.5/2/3)、Flux。**Midjourney 架构未公开**，推测属于此类，但应标注"未公开"。

### 路线二：原生多模态统一训练（一体化范式）

- **目标**：用单一共享参数的架构，端到端同时处理理解和生成。
- **代表工作**：**NEO-unify**（商汤）——摒弃传统 VE 和 VAE，直接处理"像素本身与文字本身"，采用**原生混合 Transformer（MoT）** 架构；训练目标统一（文本用自回归交叉熵，视觉用**像素流匹配**）。
- **注意**：**Janus-Pro** 解耦了视觉编码器（理解用 SigLIP、生成用 VQ tokenizer），**并非**"摒弃 VE/VAE"的一体化；**BLIP3-o** 使用图像 tokenizer + 流匹配，也非严格"共享参数端到端"。归类需加限定。

| 对比维度 | 文本-图像映射 | 原生多模态统一训练 |
|---|---|---|
| **架构本质** | 文本编码器 + 扩散解码器（级联） | 单一共享骨干网络 |
| **模态对齐方式** | **外部、显式**：交叉注意力注入 | **内部、隐式**：共享空间从零学习 |
| **代表工作** | SD 1.5/2/3, Flux | NEO-unify, BLIP3-o（有限定） |
| **技术成熟度** | **高**，工业界主力 | **探索中** |
| **核心优势** | 模块化、可解释、工程成熟 | 理论上的信息无损、深度跨模态推理 |

# 第十二部分 延伸：原生多模态的讨论

> **修订注记（审核第 10 条 + 用户纠正）**：审核报告称"DeepSeek V4 不存在"——**这个判断是错误的**。经独立检索确认：DeepSeek V4 已于 **2026 年 4 月**正式发布并开源（包含 **V4-Pro** 和 **V4-Flash** 两个版本）；后续发布了多模态实验模型 **DeepSeek-V4-Flash-Vision-Exp**（2026 年 9 月，Hugging Face 开源）。原文档将视觉架构归因于笼统的"DeepSeek V4"**不够精确**，审核报告"需要精确化"的**子建议仍有价值**。本版修正为具体模型名。

## 12.1 原生多模态的判定光谱

"原生多模态"（Native Multimodal Modeling, NMM）并非非黑即白。既有分类（可追溯到 Baltrušaitis et al. 2019 的多模态机器学习综述）区分：

**后期融合（非原生）** → **中期融合（原生变体）** → **早期融合（理想原生）**

> **修订注记（审核第 14 条）**：原文把 early/mid/late fusion 归因于"2026 年路线图论文"——**引用失当**。审核的批评成立。这是**多模态学习中的既有分类**，应引用经典文献（如 Baltrušaitis et al. 2019），而非虚构的未来论文。

## 12.2 DeepSeek-V4-Flash-Vision-Exp 的定位

DeepSeek 的视觉方案，最符合光谱中间的 **"中期融合"** 特征。

**"原生"属性体现在**：
- 视觉信息通过 Aligner 对齐后，作为 **Token 直接注入语言主干的序列**中，与文本 Token**共享同一套注意力机制和 MoE 路由**。
- 模型**专门为视觉 Token 修改了注意力窗口和专家路由规则**，让语言主干"学会"了如何处理视觉信息。

**不是"早期融合"的原因**：
- 依赖**已成熟的纯文本 V4-Flash 主干**，通过"接入视觉编码器和 Aligner，经持续训练"获得视觉能力。
- 架构中仍有独立的 **ViT 视觉编码器**和 **Aligner 模块**，视觉信息需经"翻译"和压缩环节才能进入语言主干。

**更精确的描述**：**DeepSeek-V4-Flash-Vision-Exp** 是一种 **"中期融合"（Mid-fusion）的原生多模态变体**——它充分利用了预训练语言模型的强大能力，并通过架构改造让视觉信息深度参与主干的推理过程。

**与扩散模型的对照**：
- 扩散模型是"**单模态（图像）生成范式**"，其"原生"体现在"层级 VAE"的端到端概率建模。
- DeepSeek-V4-Flash-Vision-Exp 的"原生多模态"是"**跨模态（文本+图像）融合**"，其"原生"体现在"视觉 Token 直接注入语言主干"。

# 第十三部分 数值例子（$T=3$，标量情形）

> **设计原则**：$T=3$、$p=1$（标量）——所有量都可手算，用于验证公式。

## 13.1 设定

| 量 | 值 |
|---|---|
| $T$ | $3$ |
| $x$（数据） | $1$ |
| $\beta_0,\beta_1,\beta_2$ | $0.1,\ 0.2,\ 0.4$ |
| 采样的 $\epsilon_0,\epsilon_1,\epsilon_2$ | $0.5,\ -0.3,\ 0.8$ |

## 13.2 计算累积系数

| $t$ | $\gamma_t = \prod_{i<t}(1-\beta_i)$ | $1-\gamma_t$ |
|---|---|---|
| $0$ | $1$ | $0$ |
| $1$ | $1-0.1=0.9$ | $0.1$ |
| $2$ | $0.9\times(1-0.2)=0.72$ | $0.28$ |
| $3$ | $0.72\times(1-0.4)=0.432$ | $0.568$ |

## 13.3 前向：从 $x$ 到 $z_3$

**第 0 步到第 1 步**：
$$
z_1 = \sqrt{1-\beta_0}x + \sqrt{\beta_0}\epsilon_0 = \sqrt{0.9}\times 1 + \sqrt{0.1}\times 0.5 \approx 0.9487 + 0.1581 = 1.1068.
$$

**第 1 步到第 2 步**：
$$
z_2 = \sqrt{1-\beta_1}z_1 + \sqrt{\beta_1}\epsilon_1 = \sqrt{0.8}\times 1.1068 + \sqrt{0.2}\times(-0.3) \approx 0.9899 - 0.1342 = 0.8558.
$$

**第 2 步到第 3 步**：
$$
z_3 = \sqrt{1-\beta_2}z_2 + \sqrt{\beta_2}\epsilon_2 = \sqrt{0.6}\times 0.8558 + \sqrt{0.4}\times 0.8 \approx 0.6629 + 0.5060 = 1.1689.
$$

**闭式解验证**：综合等效噪声 $\epsilon_{\text{eq}}=\frac{z_3-\sqrt{\gamma_3}x}{\sqrt{1-\gamma_3}}=\frac{1.1689-0.6573}{0.7537}\approx 0.6788$。
闭式解：$z_3 = 0.6573\times 1 + 0.7537\times 0.6788 \approx 1.1689$ ✓（与逐步计算一致）。

> **修订注记（审核第 6 条）**：原文在 13.5 用 $\epsilon_3^*$ 表示这个综合噪声——**记号冲突**（13.1 只采样了 $\epsilon_0,\epsilon_1,\epsilon_2$，没有"第 3 步的噪声"）。审核的批评成立。本版统一记为 $\epsilon_{\text{eq}}$（综合等效噪声）。

## 13.4 反向：从 $z_3$ 到 $z_2$（用闭式条件分布验证）

**用 (8.35)**（$t=3$）：
$$
\mu_q(z_3,x) = \frac{(1-\gamma_2)\sqrt{1-\beta_2}}{1-\gamma_3}z_3 + \frac{\sqrt{\gamma_2}\beta_2}{1-\gamma_3}x.
$$

代入：$\gamma_2=0.72$，$\beta_2=0.4$，$\gamma_3=0.432$，$z_3=1.1689$，$x=1$：
$$
\begin{aligned}
\mu_q &= \frac{(1-0.72)\times\sqrt{0.6}}{1-0.432}\times 1.1689 + \frac{\sqrt{0.72}\times 0.4}{1-0.432}\times 1\\
&\approx 0.3819\times 1.1689 + 0.5975 \approx 0.4465 + 0.5975 = 1.0440.
\end{aligned}
$$

**方差**：$\Sigma_q = \frac{\beta_2(1-\gamma_2)}{1-\gamma_3} = \frac{0.4\times 0.28}{0.568}\approx 0.1972$。

> **修订注记（审核第 5 条）**：$\Sigma_q=0.1972$ 是**方差**，不是标准差。$\mathcal{N}(\mu,\sigma^2)$ 的第二个参数惯例是方差。本版已明确标注 $\mathcal{N}(1.0440,\ \sigma^2=0.1972)$。

**验证**：$z_2=0.8558$（前向结果）标准化后：
$$
\frac{0.8558-1.0440}{\sqrt{0.1972}}\approx \frac{-0.1882}{0.4441}\approx -0.424.
$$
在标准正态下，$-0.424$ 是合理的采样值 ✓。

## 13.5 损失：去噪匹配与噪声预测

**去噪匹配损失**：
$$
C_{DM}(\theta_3) = \frac{1}{\sigma_3^2}\|\mu_q - \mu_{\theta_3}(z_3)\|^2.
$$
若 $\mu_{\theta_3}(z_3)=1.0$，则 $C_{DM} = \frac{(1.0440-1.0)^2}{\sigma_3^2} = \frac{0.0019}{\sigma_3^2}$。

**噪声预测损失**（用 (8.41)）：
$$
C_{\text{Reparameterized}}(\theta_3) = \frac{\beta_2^2}{\sigma_3^2(1-\gamma_3)(1-\beta_2)}\|\epsilon_{\text{eq}} - \hat\mu_{\theta_3}(z_3^*)\|^2.
$$
系数：$\frac{0.4^2}{\sigma_3^2\times 0.568\times 0.6} = \frac{0.4695}{\sigma_3^2}$。
若 $\hat\mu_{\theta_3}(z_3^*)=0.6$，$\epsilon_{\text{eq}}=0.6788$：
$$
C = \frac{0.4695}{\sigma_3^2}\times(0.6788-0.6)^2 = \frac{0.4695\times 0.0062}{\sigma_3^2}\approx \frac{0.0029}{\sigma_3^2}.
$$

# 第十四部分 训练与生成流程

## 14.1 训练（一步迭代）

```
输入：数据 x，当前参数 θ，超参 β_0..β_{T-1}
1. 采样 t ~ Uniform{1,...,T}
2. 采样 ε_t ~ N(0,I)
3. 计算 z_t = sqrt(γ_t) x + sqrt(1-γ_t) ε_t       # 闭式解 + 重参数化
4. 网络预测：ε_hat = hat_μ_{θ_t}(z_t)
5. 损失：C = β_{t-1}^2 / [σ_t^2 (1-γ_t)(1-β_{t-1})] * ||ε_t - ε_hat||^2
6. 反向：∇_θ C，更新 θ
```

**关键**：每步只需**一次前向 + 一次反向**，不用走 $t$ 步（用闭式解）。

## 14.2 生成（推理）

```
输入：训练好的 T 个网络 θ_1..θ_T
1. 采样 z_T ~ N(0,I)                           # 多样性的来源
2. for t = T, T-1, ..., 1:
3.     采样 ε ~ N(0,I)
4.     z_{t-1} = (1/√(1-β_{t-1})) z_t
              - (β_{t-1}/√((1-γ_t)(1-β_{t-1}))) * hat_μ_{θ_t}(z_t)
              + σ_t ε                          # 分布校正（DDPM）；DDIM 时 σ_t=0
5. 输出 x* = z_0
```

**关键**：
- **多样性来自 $z_T$**，不来自 $\sigma_t\epsilon$；
- $\sigma_t\epsilon$ 用于**有限步数下的分布校正**；DDIM（$\sigma_t=0$）依然多样；
- 生成需 $T$ 步（通常 $T=1000$ 或更多），所以**扩散生成慢**（对比 VAE 一次前向）。

# 第十五部分 常见卡点与问答速查

## 15.1 常见卡点

| 卡点 | 原因 | 应对 |
|---|---|---|
| 闭式解推不出来 | 忘了用 $\gamma_t=\gamma_{t-1}(1-\beta_{t-1})$ | 先展开均值和方差，再用这个恒等式 |
| $\mu_q$ 化简搞不定 | 代数操作多 | 先展开，再合并 $z_t$ 项，分子化简成 $1-\gamma_t$ |

## 15.2 问答速查

| 问题 | 核心答案 |
|---|---|
| 扩散模型是什么？ | 马尔可夫层级 VAE：前向加噪 $T$ 步，反向去噪 $T$ 步 |
| 前向加噪核？ | $q(z_{t+1}\|z_t)=\mathcal{N}(\sqrt{1-\beta_t}z_t,\beta_t I)$ |
| 累积系数？ | $\gamma_t=\prod_{i<t}(1-\beta_i)$ |
| 闭式解？ | $q(z_t\|x)=\mathcal{N}(\sqrt{\gamma_t}x,(1-\gamma_t)I)$ |
| 闭式解怎么推？ | 归纳法；用 $\gamma_t=\gamma_{t-1}(1-\beta_{t-1})$ |
| 闭式解为什么叫"闭式"？ | 表达式"封闭"——不指向自身、不指向无穷 |
| 闭式解的反面怎么称呼？ | "no closed form" / "没有闭式解"；"open form" 存在但非约定俗成 |
| 反向条件分布？ | (8.35)，均值含 $z_t$ 和 $x$，方差 $\frac{\beta_{t-1}(1-\gamma_{t-1})}{1-\gamma_t}I$ |
| 噪声预测损失？ | $\frac{\beta_{t-1}^2}{\sigma_t^2(1-\gamma_t)(1-\beta_{t-1})}\|\epsilon_t-\hat\mu_{\theta_t}(z_t)\|^2$ |
| 为什么要预测噪声？ | $\mu_q$ 含 $x$，生成时不可用；用闭式解把 $x$ 换成 $\epsilon_t$ |
| 扩散的编码器有可学参数吗？ | **没有**（前向核完全给定） |
| 扩散的重参数化目的？ | **化简损失**（预测噪声），不是让梯度能传 |
| VAE 的重参数化目的？ | **让梯度能传**（编码器有可学参数 $\phi$） |
| 先验匹配项为什么消失？ | 前向无可学参数，该项只依赖 $\phi$ |
| 生成需要几步？ | $T$ 步（通常 1000+），所以扩散生成慢 |
| 训练需要几步？ | **每步一次前向**（用闭式解，不走 $t$ 步） |
| **不加 $\sigma_t\epsilon$ 会怎样？** | **多样性仍来自 $z_T$**；DDIM（$\sigma_t=0$）依然多样；$\sigma_t\epsilon$ 用于有限步数下的分布校正 |
| 与 DDPM 记号差异？ | 本书 $\beta_t$ 对应 DDPM 的 $\beta_{t+1}$，$\gamma_t$ 对应 $\bar\alpha_t$ |
| 为什么先生成噪声再去噪？ | 一步映射太难；拆成 $T$ 个小步，每步只学窄高斯变换 |
| 根据什么生成？ | 根据 $z_t$ 里的**信号残余**，用学到的"数据分布形状"判断去噪方向（$\propto$ score 场） |
| 每张图都不同，为什么有效？ | 单张图是"点"，不是"分布"；网络学的是**分布层面的量** |
| 怎么泛化？ | 三个来源：**低维流形**、**共享统计规律**、**大规模数据 + 每样本用 $T$ 次**（启发式） |
| 第一性原理？ | 三个等价视角：**最大似然**、**score matching**、**信息论** |
| 五大假设？ | 流形假设、得分匹配/Tweedie、稀疏梯度先验、局部性/平移等变性、噪声尺度分离 |
| 扩散 vs CNN？ | **范式** vs **组件**的交叉；卷积是 backbone 之一，但非必需 |
| 文生图怎么工作？ | 文本编码器 → 文本嵌入 → 交叉注意力（U-Net 类）引导去噪 → 图像 |
| 原生多模态？ | DeepSeek-V4-Flash-Vision-Exp 是"中期融合"的原生变体 |
