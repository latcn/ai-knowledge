## 2. 第一性原理：Transformer 块为什么要这样拼

### 2.1 一个块要解决两个问题

**Transformer 块 = "让序列内信息交互" + "让每个位置做非线性变换"**：

| 部件 | 管什么 | 数学 |
|---|---|---|
| **多头自注意力** | **序列内信息交互**（每个位置看所有位置） | $u_{[1]} = \mathrm{MHA}(a_{\text{in}})$ |
| **前馈网络（FFN）** | **每个位置独立的非线性变换** | $u_{[3]} = W^{[2]}S(W^{[1]}u_{[2]}+b^{[1]})+b^{[2]}$ |

**关键**：**注意力管"横向"（位置间），FFN 管"纵向"（每个位置的特征变换）**——**分工明确，缺一不可**。

### 2.2 残差 + LayerNorm 的动机

**残差**（第 11–13 天）：$x + F(x)$——**恒等通路 $I$ 让梯度直通**，绕开矩阵幂。

**LayerNorm**（第 12 天）：$\gamma\odot\frac{z-\mu_z}{\sqrt{\sigma_z^2+\epsilon}}+\beta$——**单样本跨特征归一化**，稳定中间量分布。

**二者组合**：**残差保梯度、LayerNorm 保分布**——**一个管"能不能训"，一个管"训得稳不稳"**。

### 2.3 为什么"先注意力、后 FFN"

**注意力**：**跨位置混合**（每个位置的表示被其他位置"加权平均"）；
**FFN**：**逐位置变换**（每个位置的表示独立过 MLP）。

**顺序**：**先"看全局"（注意力）、再"深加工"（FFN）**——**这是 Transformer 的"标准序"**。

## 4. Transformer 块的完整前向（书中 7.31–7.33）

### 4.1 输入

**块的输入**：$a_{\text{in}}^{(1)},\dots,a_{\text{in}}^{(T)}$，每个 $a_{\text{in}}^{(t)}\in\mathbb{R}^p$。

**拼成矩阵**：$A_{\text{in}} = [a_{\text{in}}^{(1)},\dots,a_{\text{in}}^{(T)}]\in\mathbb{R}^{p\times T}$。

### 4.2 Step 1：多头自注意力

**每个头 $h$**（书中 7.25）：

$$u^{h,(t)} = \sum_{\tau=1}^{T}\alpha^{h,(t)}_\tau\,W_v^h a_{\text{in}}^{(\tau)},\quad \alpha^{h,(t)}_\tau = \frac{e^{s(W_q^h a_{\text{in}}^{(t)}, W_k^h a_{\text{in}}^{(\tau)})}}{\sum_{t'=1}^{T}e^{s(W_q^h a_{\text{in}}^{(t)}, W_k^h a_{\text{in}}^{(t')})}}$$

**多头合并**（书中 7.26）：

$$u_{[1]}^{(t)} = \sum_{h=1}^{H}W_c^h\,u^{h,(t)}$$

**含义**：$u_{[1]}^{(t)}\in\mathbb{R}^p$——**第 $t$ 个位置的"注意力输出"**。

### 4.3 Step 2：残差 + LayerNorm（书中 7.31，Post-LN）

$$\boxed{u_{[2]}^{(t)} = \mathrm{LayerNorm}\big(\underbrace{a_{\text{in}}^{(t)} + u_{[1]}^{(t)}}_{\text{残差}};\gamma,\beta\big)} \tag{7.31}$$

**逐项**：
- **残差**：$a_{\text{in}}^{(t)} + u_{[1]}^{(t)}$——**输入 + 注意力输出**（同维 $p$，可加）；
- **LayerNorm**：$\gamma\odot\frac{v-\mu_v}{\sqrt{\sigma_v^2+\epsilon}}+\beta$——**归一化 + 可学仿射**。

**维度**：$a_{\text{in}}^{(t)}$ 是 $p\times 1$，$u_{[1]}^{(t)}$ 是 $p\times 1$，相加是 $p\times 1$，LayerNorm 保持 $p\times 1$。✓

### 4.4 Step 3：前馈网络（FFN）

$$u_{[3]}^{(t)} = W^{[2]}S\big(W^{[1]}u_{[2]}^{(t)} + b^{[1]}\big) + b^{[2]}$$

**逐项**：
- **第一层**：$W^{[1]}\in\mathbb{R}^{N_1\times p}$，$b^{[1]}\in\mathbb{R}^{N_1}$——把 $p$ 维映射到 $N_1$ 维；
- **激活**：$S(\cdot)$——逐元素（ReLU/GELU）；
- **第二层**：$W^{[2]}\in\mathbb{R}^{p\times N_1}$，$b^{[2]}\in\mathbb{R}^p$——把 $N_1$ 维映回 $p$ 维。

**维度链**：$u_{[2]}^{(t)}$ 是 $p\times 1$ → $W^{[1]}u_{[2]}^{(t)}$ 是 $N_1\times 1$ → $S(\cdot)$ 是 $N_1\times 1$ → $W^{[2]}S(\cdot)$ 是 $p\times 1$ → $u_{[3]}^{(t)}$ 是 $p\times 1$。✓

### 4.5 Step 4：残差 + LayerNorm

$$\boxed{a_{\text{out}}^{(t)} = \mathrm{LayerNorm}\big(u_{[2]}^{(t)} + u_{[3]}^{(t)};\tilde\gamma,\tilde\beta\big)}$$

**含义**：**第二个残差 + LayerNorm**——**FFN 的输入 $u_{[2]}$ 加上 FFN 的输出 $u_{[3]}$，再归一化**。

**维度**：$u_{[2]}^{(t)}, u_{[3]}^{(t)}$ 都是 $p\times 1$，相加 $p\times 1$，LayerNorm 保持。✓

### 4.6 完整流程图

```
a_in (p×T)
  → 多头自注意力 → u_[1] (p×T)
  → 残差(a_in + u_[1]) → LayerNorm → u_[2] (p×T)
  → FFN(W[2]·S(W[1]·u_[2] + b[1]) + b[2]) → u_[3] (p×T)
  → 残差(u_[2] + u_[3]) → LayerNorm → a_out (p×T)
```

## 5. 逐层维度检查（每一步都验算）

### 5.1 多头注意力的维度

**每个头 $h$**：
- $W_q^h, W_k^h$：$m\times p$——把 $p$ 维映到 $m$ 维；
- $W_v^h$：$m_v\times p$——把 $p$ 维映到 $m_v$ 维；
- $u^{h,(t)} = \sum_\tau\alpha_\tau W_v^h a^{(\tau)}$：$m_v\times 1$。

**多头合并**：
- $W_c^h$：$p\times m_v$——把 $m_v$ 维映回 $p$ 维；
- $u_{[1]}^{(t)} = \sum_h W_c^h u^{h,(t)}$：$p\times 1$。✓

### 5.2 残差 + LayerNorm 的维度

- $a_{\text{in}}^{(t)} + u_{[1]}^{(t)}$：$p\times 1$ + $p\times 1$ = $p\times 1$ ✓；
- LayerNorm 保持 $p\times 1$ ✓。

### 5.3 FFN 的维度

- $W^{[1]}u_{[2]}^{(t)}$：$(N_1\times p)(p\times 1) = N_1\times 1$ ✓；
- $+b^{[1]}$：$N_1\times 1$ ✓；
- $S(\cdot)$：$N_1\times 1$ ✓；
- $W^{[2]}S(\cdot)$：$(p\times N_1)(N_1\times 1) = p\times 1$ ✓；
- $+b^{[2]}$：$p\times 1$ ✓。

### 5.4 第二个残差 + LayerNorm

- $u_{[2]}^{(t)} + u_{[3]}^{(t)}$：$p\times 1$ + $p\times 1$ = $p\times 1$ ✓；
- LayerNorm 保持 $p\times 1$ ✓。

**全部维度匹配**。

## 6. 参数量公式 (7.32)：逐项拆解

### 6.1 公式

$$\boxed{\#\text{params} = \underbrace{4p}_{\text{两组 LN}} + \underbrace{2N_1p}_{\text{FFN 权重}} + \underbrace{N_1 + p}_{\text{FFN 偏置}} + \underbrace{H(2mp + 2m_vp)}_{\text{多头}}} \tag{7.32}$$

### 6.2 逐项拆解

**第一项：$4p$——两组 LayerNorm 的 $\gamma,\beta$**

| LayerNorm | 参数 | 数量 |
|---|---|---|
| 第一个（注意力后） | $\gamma,\beta$ | $p + p = 2p$ |
| 第二个（FFN 后） | $\tilde\gamma,\tilde\beta$ | $p + p = 2p$ |
| **合计** | | **$4p$** |

**注意**：**LayerNorm 没有偏置**（$\beta$ 就是平移，不需要额外的偏置）——**$\gamma$ 是缩放、$\beta$ 是平移**，各 $p$ 维。

**第二项：$2N_1p$——FFN 的两层权重**

| FFN 层 | 权重 | 参数量 |
|---|---|---|
| 第一层 | $W^{[1]}$ | $N_1\times p$ |
| 第二层 | $W^{[2]}$ | $p\times N_1$ |
| **合计** | | **$2N_1p$** |

**第三项：$N_1 + p$——FFN 的两层偏置**

| FFN 层 | 偏置 | 参数量 |
|---|---|---|
| 第一层 | $b^{[1]}$ | $N_1$ |
| 第二层 | $b^{[2]}$ | $p$ |
| **合计** | | **$N_1 + p$** |

**第四项：$H(2mp + 2m_vp)$——多头的投影权重**

**每个头 $h$**：
- $W_q^h$：$m\times p$ → $mp$ 参数；
- $W_k^h$：$m\times p$ → $mp$ 参数；
- $W_v^h$：$m_v\times p$ → $m_vp$ 参数；
- $W_c^h$：$p\times m_v$ → $pm_v$ 参数。

**单个头合计**：$2mp + 2m_vp$。

**$H$ 个头合计**：$H(2mp + 2m_vp)$。

### 6.3 注意：哪些参数不在公式里

**公式 (7.32) 不包含**：

| 参数 | 为什么不在 |
|---|---|
| **位置编码** | **固定公式**（正弦 PE），不训练；可学习 PE 才需要算（$T\times p$ 或 $T\times\tilde p$） |
| **输入 embedding** | 不在"块"内——是块之前的独立层 |
| **输出投影（lm_head）** | 不在"块"内——是所有块之后的独立层 |
| **LayerNorm 的 $\epsilon$** | 是超参，不训练 |
| **注意力的偏置** | 书中 (7.32) 假设注意力无偏置（原始 Transformer 的注意力层确实无偏置） |

**这就是为什么"单块参数量"不等于"整个 Transformer 参数量"**——整个模型 = embedding + $L$ 个块 + lm_head。

## 7. 数值核算：$p=512,N_1=2048,m=m_v=64,H=8$ 时 3,150,336

### 7.1 逐项计算

**第一项 $4p$**：

$$4\times 512 = 2{,}048$$

**第二项 $2N_1p$**：

$$2\times 2048\times 512 = 2{,}097{,}152$$

**第三项 $N_1 + p$**：

$$2048 + 512 = 2{,}560$$

**第四项 $H(2mp + 2m_vp)$**：

先算括号内：

$$2mp = 2\times 64\times 512 = 65{,}536$$
$$2m_vp = 2\times 64\times 512 = 65{,}536$$
$$2mp + 2m_vp = 65{,}536 + 65{,}536 = 131{,}072$$

再乘 $H=8$：

$$8\times 131{,}072 = 1{,}048{,}576$$

**四项相加**：

$$2{,}048 + 2{,}097{,}152 + 2{,}560 + 1{,}048{,}576 = 3{,}150{,}336$$

### 7.2 交叉验证

**手算复核**：

$$2{,}048 + 2{,}097{,}152 = 2{,}099{,}200$$
$$2{,}099{,}200 + 2{,}560 = 2{,}101{,}760$$
$$2{,}101{,}760 + 1{,}048{,}576 = 3{,}150{,}336 \quad\checkmark$$

**与书中一致**：$p=512,N_1=2048,m=m_v=64,H=8$ → **3,150,336**（约 315 万）。

### 7.3 占比分析

> **修订注记（审核问题 4）**：原文表格"FFN 权重 2,097,152 → 66.57%"是**不含偏置**的口径；若**含偏置**（$2,099,712$），占比为 **66.65%**。两个数各自正确，读者需注意口径差异。本节保留原文的"66.57%"，但在第 10.3 节注明"含偏置时为 66.65%"。

| 项 | 参数量 | 占比 |
|---|---|---|
| 两组 LN | 2,048 | **0.065%** |
| FFN 权重 | 2,097,152 | **66.57%** |
| FFN 偏置 | 2,560 | **0.081%** |
| 多头 | 1,048,576 | **33.28%** |
| **总计** | **3,150,336** | 100% |

**关键观察**：**FFN 权重占 2/3，多头占 1/3**——**LN 和偏置几乎可以忽略**。

**含义**：**Transformer 块的参数主要在 FFN 和注意力的"投影矩阵"**——**这也是为什么"加宽 FFN（$N_1$）"会显著增加参数量**（$N_1$ 从 2048 到 4096，FFN 权重翻倍）。

### 7.4 与书中原始 Transformer 的对照

**原始 Transformer（Vaswani 2017）** ：$p=512$，$N_1=2048$，$H=8$，$m=m_v=64$——**与本节数值完全一致**。

**这就是书中的"Toy Transformer"配置**——**单块 315 万参数**。

## 8. 并行性 vs 定长输入输出

### 8.1 换来了什么：并行性

**RNN 的串行性**：$h^{(t)}$ 依赖 $h^{(t-1)}$——**必须按时间顺序算**，$T$ 步就是 $T$ 次串行。

**Transformer 的并行性**：**时间 $t$ 不再是"计算的一步"，而是"输入矩阵的一个维度"**。

**数学**：

$$A_{\text{in}} = [a_{\text{in}}^{(1)},\dots,a_{\text{in}}^{(T)}]\in\mathbb{R}^{p\times T}$$

**注意力计算**：

$$Q = W_Q A_{\text{in}},\quad K = W_K A_{\text{in}},\quad V = W_V A_{\text{in}}$$

（$Q,K,V$ 都是 $p\times T$ 矩阵——**所有位置同时算**）

**注意力权重**：

$$A = \mathrm{softmax}\Big(\frac{Q^\top K}{\sqrt{m}}\Big)\in\mathbb{R}^{T\times T}$$

**输出**：

$$U = V A^\top\in\mathbb{R}^{p\times T}$$

> **修订注记（审核问题 1）**：$U=VA^\top$ 在**列向量约定**下正确（$A_{\text{in}}$ 的每列是一个位置）。若按主流的**行向量约定**，等价写法是 $Z=\mathrm{softmax}(QK^\top/\sqrt{m})V$——二者互为转置。**熟悉主流行向量写法的读者可能误以为出错**，此处应加注"本文档采用列向量约定"。

**关键**：**$Q^\top K$ 是一次矩阵乘法**——**所有 $T^2$ 对 $(t,\tau)$ 同时算**——**没有"串行传递"**。

**含义**：**训练时，所有位置可以并行前向**——**这是 Transformer 能"吃大 batch、用满 GPU"的根本原因**。

### 8.2 退回了什么：定长输入输出

> **修订注记（审核问题 5）**：原文"Transformer 要求所有输入长度相同"**过度绝对化**。严格说：**Transformer 的权重与 $T$ 无关**（$W_Q,W_K,W_V,W_O,W^{[1]},W^{[2]}$ 的形状都不含 $T$）——**单个样本可以任意长度**。**"定长"来自两个工程约束**：(a) **批处理对齐**——batch 里多个样本要拼成矩阵，必须对齐到同一 $T$；(b) **位置编码的训练长度上限**——正弦 PE 可外推但效果差，可学习 PE 有硬上限。**正确表述**："**批处理时需要对齐到同一长度**"。

**RNN 的"变长"**：同一个 $f$ 可以用 $T$ 次，$T$ 任意——**天然支持变长序列**。

**Transformer 的"定长"**：**输入是矩阵 $A_{\text{in}}\in\mathbb{R}^{p\times T}$**——**$T$ 必须是"固定长度"**。

**问题**：**真实序列长度不一**——短句可能 5 个词，长句可能 50 个词。**Transformer 要求所有输入长度相同**。

**解法**：**padding**——**用 `<empty>` 或 `<pad>` 填充到固定长度**。

**书中原话（7.5 节）**："sequences are converted to have fixed length by padding with representations of `<empty>` tokens at the end of the sequence, when needed."

**代价**：
- **计算浪费**：短句被 padding 到长句的长度，**padding 部分也算注意力**——浪费计算；
- **注意力被稀释**：padding 的 token 会"分走"注意力权重——**需要 mask 掉**（让 padding 的权重为 0）；
- **信息损失**：超出固定长度的部分被截断（或分段）。

### 8.3 一句话对比

| 维度 | **RNN** | **Transformer** |
|---|---|---|
| **时间维** | 计算的**一步**（$h^{(t)}$ 依赖 $h^{(t-1)}$） | 输入矩阵的**一维**（$p\times T$） |
| **并行性** | **串行**（$T$ 次） | **并行**（一次矩阵乘） |
| **变长** | **天然支持** | **批处理需要对齐** |
| **计算浪费** | 无 | padding 部分浪费 |

**一句话**：**Transformer 用"定长 + padding"换"完全并行"**——**这是"用灵活性换效率"的交易**。

### 8.4 补充注记：训练并行 vs 推理自回归

> **补充注记**：**"完全并行"只在训练时成立**。**推理时，Transformer 是自回归的**——token by token 生成，每步依赖前一步的输出。**KV cache 是隐式的"循环状态"**（每步追加历史 K/V）。**"Transformer 完全抛弃循环"这个表述对训练成立，对推理不成立**——应改为"**训练时无序列依赖、可完全并行；推理时仍需自回归生成**"。

## 9. Post-LN vs Pre-LN（补充注记）

### 9.1 书中是 Post-LN

**书中 (7.31)** ：

$$u_{[2]}^{(t)} = \mathrm{LayerNorm}\big(a_{\text{in}}^{(t)} + u_{[1]}^{(t)};\gamma,\beta\big)$$

**顺序**：**先加残差，再归一化**——**这是 Post-LN**。

**问题**：**主通路 $a_{\text{in}}$ 经过了 LayerNorm**——**梯度要穿过 LN 的雅可比**，训练不稳定（需要 warmup）。

### 9.2 现代 LLM 用 Pre-LN

**Pre-LN**：

$$u_{[2]}^{(t)} = a_{\text{in}}^{(t)} + F\big(\mathrm{LayerNorm}(a_{\text{in}}^{(t)};\gamma,\beta)\big)$$

**顺序**：**先归一化，再进子层，残差加在子层输出上**。

**优势**：**主通路 $a_{\text{in}}$ 不经过 LN**——**梯度有干净的 $I$ 通路**，训练更稳。

**代表模型**：GPT-2、GPT-3、LLaMA、Qwen、DeepSeek——**全部用 Pre-LN（或 Pre-RMSNorm）**。

> **修订注记（审核问题 8）**：原文只给出了注意力子层的 Pre-LN 形式，**省略了完整的 Pre-LN 块的第二个残差**。完整的 Pre-LN 块是：
> $$u_{[2]} = a_{\text{in}} + \text{Attn}(\text{LN}(a_{\text{in}})),\quad a_{\text{out}} = u_{[2]} + \text{FFN}(\text{LN}(u_{[2]}))$$
> 现代实现中，最后一个块之后还有一个 **final norm**（对 $a_{\text{out}}$ 再做一次 LN）。

### 9.3 参数量与顺序无关

**关键**：**Post-LN 和 Pre-LN 的参数量完全相同**——**都是 $4p$（LN 参数）+ $2N_1p$（FFN）+ $N_1+p$（FFN 偏置）+ $H(2mp+2m_vp)$（多头）**。

**区别只在"LN 放在哪"**——**不影响参数量**。

**所以本节 (7.32) 的核算对 Post-LN 和 Pre-LN 都成立**。

### 9.4 补充：RMSNorm

**现代 LLM 多以 RMSNorm 替代 LayerNorm**（LLaMA/Qwen/DeepSeek）——**无均值中心化、无 $\beta$ 偏置**。

**参数量**：**RMSNorm 只有 $\gamma$（$p$ 维），没有 $\beta$**——**每个 LN 从 $2p$ 降到 $p$**。

**对块参数量的影响**：**两组 LN 从 $4p$ 降到 $2p$**——**总参数量从 3,150,336 降到 3,148,288**（差 2,048）。

**但书中 (7.32) 的 $4p$ 假设是 LayerNorm**——**用 RMSNorm 时应改为 $2p$**。

## 10. 块参数量与其他模型的对比

### 10.1 单块 315 万 vs 整个模型

**单个 Transformer 块**：3,150,336（约 315 万）。

**原始 Transformer（6 层编码器 + 6 层解码器）** ：

- 编码器：6 块 ≈ 1,890 万；
- 解码器：6 块（多一个 cross-attention）≈ 2,520 万；
- **总计约 6,300 万**（书中 7.5 节说"约 63M"）。

> **修订注记（审核问题 2）**：原文"总计约 63M"与 Vaswani 论文 **Table 3 官方 65M** 有约 2M 差异。**来源分析**：编码器 18.9M + 解码器 25.2M = 44.1M，加 embedding（37000 vocab × 512 ≈ 18.9M）得 **63.0M**——**是能推出 63M 的**。**与 65M 的 2M 差异可能来自**：vocab size（如 32000 或 50000）、是否算 bias、output projection 是否与 embedding 共享、是否算 final norm 等。**建议注明口径**："书中 63M 为 37000 vocab 口径，论文 Table 3 为 65M；差异来自 vocab size / bias / 共享策略"。

**关键**：**单块 315 万，整个模型 6,300 万（或 6,500 万）**——**块数 × 单块参数 + embedding + lm_head**。

### 10.2 与 RNN/LSTM/GRU 的对比（第 15–16 天数）

**设定**：$p=512$，$m=512$（隐藏维度），$T$ 任意。

| 模型 | 单层参数量 | 特点 |
|---|---|---|
| **RNN** | $m(m+p+1) = 512\times(512+512+1) \approx 52$ 万 | 参数少，但串行 |
| **LSTM** | $\approx 4\times 52$ 万 $\approx 210$ 万 | 4 倍 RNN，加法路径 |
| **GRU** | $\approx 3\times 52$ 万 $\approx 157$ 万 | 3 倍 RNN，两门 |
| **Transformer 块** | **315 万** | 参数最多，但可并行 |

**关键**：**Transformer 块参数最多（315 万 vs RNN 52 万）**——**代价是参数，换来的是并行性和全局注意力**。

### 10.3 参数量的"大头"在哪

> **修订注记（审核问题 4）**：本节"FFN（含偏置）2,099,712 → 66.65%"与第 7.3 节"FFN 权重（不含偏置）2,097,152 → 66.57%"**口径不同**——前者含偏置、后者不含。两个数各自正确，**引用时需注明**。

| 部件 | 参数量 | 占比 |
|---|---|---|
| FFN（含偏置） | 2,099,712 | 66.65% |
| 多头注意力 | 1,048,576 | 33.28% |
| LN | 2,048 | 0.065% |

**含义**：**想省参数，先砍 FFN 的 $N_1$**（如从 2048 降到 1024，FFN 权重减半）；**想加容量，先加 $N_1$ 或 $H$**（这两个是参数量的主要来源）。

| 问题 | 核心答案 |
|---|---|
| **Transformer 块的完整前向？** | 多头自注意力 → 残差+LN → FFN → 残差+LN |

| **$4p$ 是什么？** | 两组 LayerNorm 的 $\gamma,\beta$（每组 $2p$） |
| **$2N_1p$ 是什么？** | FFN 的两层权重（$W^{[1]}$ 和 $W^{[2]}$） |
| **$N_1 + p$ 是什么？** | FFN 的两层偏置（$b^{[1]}$ 和 $b^{[2]}$） |
| **$H(2mp + 2m_vp)$ 是什么？** | 多头注意力的投影权重（每个头 $W_q,W_k,W_v,W_c$） |
| **数值核算？** | $p=512,N_1=2048,m=m_v=64,H=8$ → **3,150,336** |
| **参数大头在哪？** | FFN 权重 66.57%（不含偏置）/ 66.65%（含偏置），多头 33.28%，LN 0.065% |
| **换来了什么？** | **并行性**——时间 $t$ 是矩阵的一维，所有位置同时算 |
| **退回了什么？** | **批处理需要对齐**——padding 到固定长度 |

| **$\alpha$ 是什么？** | **softmax 后的注意力权重**（和为 1，长度 $T_{\text{in}}$）；**不是 $QK^\top$**（打分）、**不是 $QK^\top V$**（上下文向量） |
| **残差维度怎么对齐？** | **$W_c^h$ 把每个头从 $m_v$ 升回 $p$**，求和后是 $p$ 维；**$m_v=p/H$ 让 $H$ 个头拼起来正好是 $p$** |
| **训练为什么并行？** | **训练时逻辑依赖存在（mask）、计算依赖不存在（全文已知）**——"一次算完 $T^2$ 对，再用 mask 遮未来" |

| **FFN 的神经元与参数？** | **$N_1$ 是第一层神经元数、$p$ 是第二层神经元数**——每个神经元"权重 + 1 偏置"；FFN 总参数 $2N_1p + N_1 + p$ |
| **多头是每个头一个 block 吗？** | **不是**——多头只在注意力子层内部并行，合并后走同一套残差/LN/FFN |
| **padding 只在训练时吗？** | **不只是**——训练物理 padding；推理传统框架也 padding，现代用 continuous batching / PagedAttention |
| **序列过长怎么办？** | **滑动窗口、分块、摘要压缩、向量检索、优先级截断**——组合使用 |
| **T 对所有样本固定吗？** | **T 是最大长度上限**；训练用 packing/bucketing，推理用 continuous batching / 长度分桶 |
| **攒批 + 固定 T 为什么加速？** | **攒批摊薄权重加载（memory-bound）+ 固定 T 让 kernel 预编译、内存池复用、tensor core 规整** |

## 13. 苏格拉底式引导 + 费曼复述

### 13.1 苏格拉底引导（你回答，我追问）

**Q1**：Transformer 块为什么要"注意力 + FFN"两个子层？只用注意力不行吗？

（预期：**注意力管"跨位置混合"，FFN 管"逐位置非线性变换"**——**分工不同**。只用注意力，每个位置只是"其他位置的加权平均"——**没有"深加工"**；只用 FFN，每个位置独立变换——**没有"信息交互"**。**两者缺一不可**。）

**Q2**：参数量 $4p$ 是什么？为什么是 $4p$ 不是 $2p$？

（预期：**两组 LayerNorm**——注意力后一组（$2p$）、FFN 后一组（$2p$）——**合计 $4p$**。）

**Q3**：$p=512,N_1=2048,m=m_v=64,H=8$，参数量是多少？逐步展开。

（预期：$4p=2048$，$2N_1p=2,097,152$，$N_1+p=2560$，$H(2mp+2m_vp)=1,048,576$；合计 **3,150,336**。）

**Q4**：Transformer "换来了并行性、退回了定长"——具体是什么意思？

（预期：**换来**——时间 $t$ 是矩阵的一维，**所有位置同时算**。**退回**——批处理需要对齐，**变长序列要 padding**。**训练并行、推理自回归**。）

**Q5**：书中 (7.31) 是 Post-LN，现代 LLM 用 Pre-LN——参数量一样吗？

（预期：**一样**——参数量与 LN 位置无关。**区别只在"主通路是否经过 LN"**。）

**Q6**：LLaMA/Qwen/DeepSeek 用 RMSNorm，块参数量怎么变？

（预期：**RMSNorm 无 $\beta$**——**两组 LN 从 $4p$ 降到 $2p$**，总参数少 2,048。）

**Q7**：$\alpha$ 是 $QK^\top$ 还是 $QK^\top V$？

（预期：**都不是**。$\alpha$ 是 **softmax 后的权重**。$QK^\top$ 是**打分**，$QK^\top V$ 是**上下文向量**。）

**Q8**：$a_{\text{in}}\in\mathbb{R}^p$，$u_{[1]}\in\mathbb{R}^p$——怎么保证同维？

（预期：**$W_c^h$ 把每个头从 $m_v$ 升回 $p$**；**$m_v=p/H$ 让 $H$ 个头拼起来正好是 $p$**。）

**Q9**：训练时"依赖"存在吗？

（预期：**逻辑依赖存在**（mask）；**计算依赖不存在**（全文已知）。**推理时两种依赖都存在**。）
