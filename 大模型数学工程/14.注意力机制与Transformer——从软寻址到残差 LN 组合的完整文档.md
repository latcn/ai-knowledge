## 2. 第一性原理：为什么需要"软寻址"

### 2.1 问题：RNN 的信息传递是"链式"的

**RNN 的痛点**（第 15–16 天）：$h^{(t)}$ 依赖 $h^{(t-1)}$——信息沿时间"逐级传递"，每级都乘 $W_{hh}$。$t=100$ 的信息传到 $t=0$，要乘 $W_{hh}^{100}$——**指数衰减**。

**LSTM/GRU 的改进**：加法路径绕开矩阵幂——但**仍是"沿时间传递"**（只是衰减慢了）。

**核心问题**：**能不能让"任意两个位置"直接连接，不经过中间的任何传递链？**

### 2.2 注意力的第一性原理：软寻址

**类比：查字典**。
- 你有一个**查询（query）** ——"我想找'苹果'的意思"；
- 字典里有**键（key）** ——每个词条；
- 你拿 query 和每个 key 比较**相似度**——"苹果"和"水果"相似度高，"苹果"和"汽车"相似度低；
- 根据相似度给每个词条一个**权重**——"水果"权重 0.8，"汽车"权重 0.01；
- 用权重对**值（value）** 做**加权平均**——得到"综合的意思"。

**这就是注意力**：**用 query 和 key 的相似度，对 value 做"软寻址"（soft addressing）**。

**关键属性**：
- **可微**：相似度、softmax、加权和都是可微的——可以端到端训练；
- **无状态**：每个位置独立计算，不依赖"上一步的状态"——可以并行；
- **全局**：每个位置直接看所有位置——**无时间衰减**。

**这三点一起，解释了为什么注意力取代了 RNN**（书中 7.4 节的核心论点）。

### 2.3 自注意力：query/key/value 从同一序列来

**自注意力（self-attention）** ：query、key、value **都来自同一个序列**。

**含义**：序列内部的每个位置，都"看"序列内部的所有位置——**建模"序列内部的关系"**（如"这个词和那个词是什么关系"）。

**交叉注意力（cross-attention）** ：query 来自一个序列，key/value 来自另一个序列——**建模"两个序列之间的关系"**（如"翻译时，目标语言的词和源语言的词是什么关系"）。

## 4. 注意力的一般框架 (7.20)(7.21)

### 4.1 打分与权重（书中 (7.20)）

**给定**：
- **query 代理向量** $z_q^{(t)}\in\mathbb{R}^{m_q}$（第 $t$ 个位置的查询）；
- **key 代理向量** $z_k^{(1)},\dots,z_k^{(T_{\text{in}})}\in\mathbb{R}^{m_k}$（所有位置的键）；
- **打分函数** $s:\mathbb{R}^{m_q}\times\mathbb{R}^{m_k}\to\mathbb{R}$（query 和 key 的相似度）。

**注意力权重**：

$$\boxed{\alpha^{(t)} = S_{\text{softmax}}\Big(\big[s(z_q^{(t)}, z_k^{(1)}), \dots, s(z_q^{(t)}, z_k^{(T_{\text{in}})})\big]^\top\Big) \in \mathbb{R}^{T_{\text{in}}}} \tag{7.20}$$

**读法**：
- **对每个 key $\tau$**：算 $s(z_q^{(t)}, z_k^{(\tau)})$——一个标量相似度；
- **$T_{\text{in}}$ 个相似度拼成向量**；
- **softmax 归一化**——得到 $T_{\text{in}}$ 维权重，**和为 1**。

**维度检查**：$s(\cdot,\cdot)$ 输出标量，$T_{\text{in}}$ 个拼成 $T_{\text{in}}\times 1$，softmax 保持维度。✓

### 4.2 上下文向量（书中 (7.21)）

**给定**：**value 向量** $v^{(1)},\dots,v^{(T_{\text{in}})}\in\mathbb{R}^{m_v}$。

**上下文向量**：

$$\boxed{u^{(t)} = \sum_{\tau=1}^{T_{\text{in}}}\alpha^{(t)}_\tau\,v^{(\tau)}} \tag{7.21（非因果）}$$

**因果版本**（只看前 $t$ 个）：

$$u^{(t)} = \sum_{\tau=1}^{t}\alpha^{(t)}_\tau\,v^{(\tau)} \tag{7.21（因果）}$$

**读法**：
- **用权重 $\alpha^{(t)}$ 对 value $v^{(\tau)}$ 加权求和**；
- **非因果**：看所有 $T_{\text{in}}$ 个位置（适合编码器、双向任务）；
- **因果**：只看前 $t$ 个（适合解码器、自回归生成）。

**维度检查**：$\alpha^{(t)}_\tau$ 是标量，$v^{(\tau)}$ 是 $m_v\times 1$，加权和是 $m_v\times 1$。✓

### 4.3 一般框架的三个可替换部件

**这就是书中的"一般框架"**——**三个部件都可替换**：

| 部件 | 书中写法 | 可替换为 |
|---|---|---|
| **打分函数** $s(\cdot,\cdot)$ | 内积（最简单） | General、Concat、Additive（第 5 节） |
| **归一化** | softmax | 其他（如 sparsemax，书中未提） |
| **value 来源** | 输入序列 | 可任选（如 cross-attention 用另一序列） |

**关键**：**书中没有把"注意力"绑定到"$\mathrm{softmax}(QK^\top/\sqrt{d_k})V$"这个具体形式**——它给的是**更一般的框架**，具体形式是**实例化**。

### 4.4 "缩放因子"在一般框架里的位置

**书中原话（7.4 节）**："It is typical to have normalization as part of the score function with a factor such as $\sqrt{\max(m_q,m_k)}$. This normalization maintains score values at a reasonable range for numerical stability."

**读法**：
- **缩放是"打分函数的一部分"**（"as part of the score function"）；
- **作用是"数值稳定性"**（"for numerical stability"）；
- **因子是 $\sqrt{\max(m_q,m_k)}$**（不是 $\sqrt{d_k}$）。

**这就是书中与主流的第一处差异**——主流写 $\mathrm{softmax}(QK^\top/\sqrt{d_k})$，把"缩放"单独提出来；书中把"缩放"**内嵌进打分函数**，写成 $s(q,k) = q^\top k / \sqrt{\max(m_q,m_k)}$。

**二者数学上等价**（当 $m_q=m_k=d_k$ 时），但**表述框架不同**：书中是"一般框架 + 缩放是打分的一部分"，主流是"具体公式 + 缩放是显式因子"。

## 5. 打分的三种形式

### 5.1 书中给的三种打分函数（7.4 节）

**内积**（最简单，要求 $m_q=m_k$）：

$$s(z_q, z_k) = z_q^\top z_k$$

**General**（带可学矩阵 $W_s$）：

$$s(z_q, z_k) = z_q^\top W_s\, z_k,\quad W_s\in\mathbb{R}^{m_q\times m_k}$$

**Concat**（拼接后过 MLP）：

$$s(z_q, z_k) = w_s^\top\tanh\big(\tilde W_s[z_q, z_k]\big)$$

（$\tilde W_s\in\mathbb{R}^{\tilde m\times(m_q+m_k)}$，$w_s\in\mathbb{R}^{\tilde m}$）

**Additive**（Bahdanau 注意力）：

$$s(z_q, z_k) = w_s^\top\tanh(W_{sa}z_q + W_{sb}z_k)$$

（$W_{sa}\in\mathbb{R}^{\tilde m\times m_q}$，$W_{sb}\in\mathbb{R}^{\tilde m\times m_k}$，$w_s\in\mathbb{R}^{\tilde m}$）

### 5.2 三种形式的对比

| 形式 | 参数 | 计算复杂度 | 用在哪 |
|---|---|---|---|
| **内积** | 无 | $O(m_q)$ | Transformer（最常用） |
| **General** | $W_s$ | $O(m_q m_k)$ | 一般注意力 |
| **Concat** | $\tilde W_s, w_s$ | $O(\tilde m(m_q+m_k))$ | 较少用 |
| **Additive** | $W_{sa}, W_{sb}, w_s$ | $O(\tilde m(m_q+m_k))$ | Bahdanau（RNN 时代） |

**关键**：**书中把"内积"作为"最简单的打分函数"**，把"缩放"作为"可选的数值稳定性因子"——**没有把"内积 + 缩放"绑定成"注意力的唯一定义"**。

## 6. 缩放因子：$\sqrt{\max(m_q,m_k)}$ 的方差论证

### 6.1 为什么需要缩放（书中定位：数值稳定性）

**问题**：内积 $q^\top k = \sum_{i=1}^{d} q_i k_i$ 的**量级随维度 $d$ 增长**。

**如果 $q_i, k_i$ 各分量独立、零均值、单位方差**：

$$\mathrm{Var}(q^\top k) = \mathrm{Var}\Big(\sum_{i=1}^{d}q_i k_i\Big) = \sum_{i=1}^{d}\mathrm{Var}(q_i k_i)$$

**由独立性**（$q_i$ 和 $k_i$ 独立，且不同 $i$ 之间独立）：

$$\mathrm{Var}(q_i k_i) = \underbrace{\mathbb{E}[q_i]^2\mathrm{Var}(k_i)}_{=0} + \underbrace{\mathrm{Var}(q_i)\mathbb{E}[k_i]^2}_{=0} + \mathrm{Var}(q_i)\mathrm{Var}(k_i) = 1\cdot 1 = 1$$

**所以**：

$$\boxed{\mathrm{Var}(q^\top k) = d}$$

**含义**：**点积的方差是 $d$**——$d$ 越大，点积的"波动"越大。

**后果**：当 $d$ 很大时，$q^\top k$ 的值可能很大（如 $d=512$ 时，标准差 $\sqrt{512}\approx 22.6$）。**softmax 的输入量级太大 → softmax 进入饱和区 → 梯度消失**。

### 6.2 缩放：除以 $\sqrt{d}$

**除以 $\sqrt{d}$**：

$$\mathrm{Var}\Big(\frac{q^\top k}{\sqrt{d}}\Big) = \frac{1}{d}\mathrm{Var}(q^\top k) = \frac{d}{d} = 1$$

**含义**：**缩放后方差恒为 1**——**不随 $d$ 增长**。

**这就是缩放的作用**：**把 softmax 的输入量级"拉回"到合理范围（$\approx 1$），避免饱和**。

### 6.3 书中为什么写 $\sqrt{\max(m_q,m_k)}$ 而不是 $\sqrt{d_k}$

**书中原话**："a factor such as $\sqrt{\max(m_q,m_k)}$"。

**为什么用 $\max(m_q,m_k)$**：
- **内积要求 $m_q=m_k$**（否则维度不匹配）；
- 但**书中允许 $m_q\neq m_k$**（用 General 打分 $z_q^\top W_s z_k$ 时，$W_s$ 把 $m_q$ 映射到 $m_k$）；
- 用 $\max(m_q,m_k)$ 是**保守的缩放**——**保证分母足够大**，不会因为 $m_q\neq m_k$ 而缩放不足。

**主流写 $\sqrt{d_k}$**：假设 $m_q=m_k=d_k$（内积），$\max(m_q,m_k)=d_k$——**二者一致**。

**所以**：**书中的 $\sqrt{\max(m_q,m_k)}$ 是主流的 $\sqrt{d_k}$ 的"一般化版本"**——当 $m_q=m_k$ 时，二者相等；当 $m_q\neq m_k$ 时，书中用 $\max$ 保证保守缩放。

### 6.4 方差论证的数值验证

**设定**：$d=512$，$q,k$ 各分量 $\sim\mathcal{N}(0,1)$，独立。

**未缩放**：$\mathrm{Var}(q^\top k) = 512$，标准差 $\approx 22.6$。

**缩放后**：$\mathrm{Var}(q^\top k/\sqrt{512}) = 1$，标准差 $\approx 1$。

**交叉验证**：模拟 1000 次，未缩放的点积均值 $\approx 0$，标准差 $\approx 22.6$；缩放后标准差 $\approx 1$。✓

**这就是"缩放因子"的严格依据**——**不是"经验技巧"，是"方差控制"**。

## 7. 自注意力（7.23)(7.24)

### 7.1 最简单的自注意力（7.23）

**query/key/value 都直接取输入**：

$$z_q^{(t)} = x^{(t)},\quad z_k^{(t)} = x^{(t)},\quad v^{(t)} = x^{(t)}$$

**因果版本**（7.23）：

$$u^{(t)} = \sum_{\tau\le t}\alpha^{(t)}_\tau\,x^{(\tau)},\quad \alpha^{(t)}_\tau = \frac{e^{s(x^{(t)}, x^{(\tau)})}}{\sum_{t'=1}^{t}e^{s(x^{(t)}, x^{(t')})}} \tag{7.23}$$

**读法**：
- **每个位置 $t$ 的 query 是 $x^{(t)}$**；
- **和前面所有位置 $\tau\le t$ 的 $x^{(\tau)}$ 比较**；
- **用 softmax 权重对 $x^{(\tau)}$ 加权求和**。

**"自"的含义**：query 和 key/value **来自同一个序列**——"自己看自己"。

### 7.2 带参数的自注意力（7.24）

**query/key/value 是输入的线性变换**：

$$z_q^{(t)} = W_q x^{(t)},\quad z_k^{(t)} = W_k x^{(t)},\quad v^{(t)} = W_v x^{(t)}$$

（$W_q, W_k, W_v$ 各 $p\times p$）

**因果版本**（7.24）：

$$u^{(t)} = \sum_{\tau\le t}\alpha^{(t)}_\tau\,W_v x^{(\tau)},\quad \alpha^{(t)}_\tau = \frac{e^{s(W_q x^{(t)}, W_k x^{(\tau)})}}{\sum_{t'=1}^{t}e^{s(W_q x^{(t)}, W_k x^{(t')})}} \tag{7.24}$$

**读法**：
- **$W_q$ 把 $x^{(t)}$ 变成 query**——"我想找什么"；
- **$W_k$ 把 $x^{(\tau)}$ 变成 key**——"我有什么"；
- **$W_v$ 把 $x^{(\tau)}$ 变成 value**——"我提供什么"；
- **三个变换是可学的**——模型自己学"怎么问、怎么答"。

**维度检查**：$W_q x^{(t)}$ 是 $p\times 1$（假设 $W_q$ 是 $p\times p$），$s(\cdot,\cdot)$ 输出标量，softmax 后是 $T_{\text{in}}$ 维，加权和 $W_v x^{(\tau)}$ 是 $p\times 1$。✓

### 7.3 非因果版本

**非因果**（去掉 $\tau\le t$ 的限制）：

$$u^{(t)} = \sum_{\tau=1}^{T}\alpha^{(t)}_\tau\,W_v x^{(\tau)}$$

**含义**：每个位置看**所有**位置——适合编码器（双向理解）。

**因果 vs 非因果**：

| 版本 | 看多少 | 用在哪 |
|---|---|---|
| **因果** | 只看 $\tau\le t$（前 $t$ 个） | 解码器（自回归生成） |
| **非因果** | 看所有 $\tau$ | 编码器（双向理解） |

## 8. 多头注意力（7.25)(7.26）：**加权和，不是 concat**

### 8.1 多头：多个"视角"并行

**动机**：**一个注意力头只能学"一种相似度"**（如"语法关系"）。**多头**让模型同时学**多种相似度**（"语法关系"、"语义关系"、"指代关系"……）。

**$H$ 个头**，每个头有自己的 $W_q^h, W_k^h, W_v^h$：

$$u^{h,(t)} = \sum_{\tau=1}^{T}\alpha^{h,(t)}_\tau\,W_v^h x^{(\tau)},\quad \alpha^{h,(t)}_\tau = \frac{e^{s(W_q^h x^{(t)}, W_k^h x^{(\tau)})}}{\sum_{t'=1}^{T}e^{s(W_q^h x^{(t)}, W_k^h x^{(t')})}} \tag{7.25}$$

**维度**：$W_q^h, W_k^h, W_v^h$ 各 $m\times p$ 或 $m_v\times p$——**每个头把 $p$ 维输入映射到 $m$ 或 $m_v$ 维**（通常 $m = m_v = p/H$，总维度不变）。

### 8.2 多头合并（7.26）：**加权和**

$$\boxed{u^{(t)} = \sum_{h=1}^{H}W_c^h\,u^{h,(t)}} \tag{7.26}$$

**读法**：
- **$W_c^h\in\mathbb{R}^{p\times m_v}$**——第 $h$ 个头的"合并权重矩阵"；
- **$W_c^h u^{h,(t)}\in\mathbb{R}^p$**——把头 $h$ 的输出（$m_v$ 维）映射回 $p$ 维；
- **对 $H$ 个头求和**——**加权和**。

**关键**：**这是"加权和"，不是"concat + projection"**。

### 8.3 与主流写法的对比（第 2 处差异）

**主流写法**（如 Vaswani 2017）：

$$\mathrm{MultiHead}(Q,K,V) = \mathrm{Concat}(\text{head}_1,\dots,\text{head}_H)\,W_O$$

**读法**：
- 每个头输出 $d_v$ 维；
- **concat** 成 $H d_v$ 维；
- **乘 $W_O$**（$H d_v\times d_{\text{model}}$）映射回 $d_{\text{model}}$ 维。

**书中写法**（7.26）：

$$u^{(t)} = \sum_{h=1}^{H}W_c^h\,u^{h,(t)}$$

**读法**：
- 每个头输出 $m_v$ 维；
- **每个头乘自己的 $W_c^h$**（$p\times m_v$）映射到 $p$ 维；
- **求和**。

**二者数学上等价吗？**

**不完全等价**，但有对应关系：
- **主流**：$\mathrm{Concat}(u^1,\dots,u^H)W_O = \sum_h u^h W_O^h$（把 $W_O$ 按头分块）——**也是加权和**；
- **书中**：$\sum_h W_c^h u^h$——**加权和，但 $W_c^h$ 在左边**（行向量约定 vs 列向量约定的差异）。

**关键差异**：
- **主流**：先 concat，再乘一个大矩阵 $W_O$；
- **书中**：每个头乘自己的 $W_c^h$，再求和。

**数学上**：如果 $W_O$ 按头分块为 $[W_O^1,\dots,W_O^H]$，则 $\mathrm{Concat}(u^1,\dots,u^H)W_O = \sum_h u^h W_O^h$——**与书中的 $\sum_h W_c^h u^h$ 形式一致**（只是 $W_c^h$ 和 $W_O^h$ 的转置关系，取决于向量取向）。

**结论**：**书中的"加权和"与主流的"concat + projection"数学上等价**（当 $W_O$ 按头分块时），**但表述形式不同**——书中直接写"加权和"，主流写"concat + projection"。

**"不要纠正"的原因**：书中这样写是**刻意的**——它想强调"多头合并本质是加权和"，而不是"concat 这个操作"。

### 8.4 多头的维度分配

**典型配置**（书中 7.5 节）：$p=512$，$H=8$，$m=m_v=64$——**每个头的维度是 $p/H=64$**，总维度不变。

**$W_q^h, W_k^h, W_v^h$**：各 $m\times p = 64\times 512$。
**$W_c^h$**：$p\times m_v = 512\times 64$。

**参数量**（多头部分）：$H\times(2mp + 2m_vp) = 8\times(2\cdot 64\cdot 512 + 2\cdot 64\cdot 512) = 8\times 131072 = 1{,}048{,}576$。

## 9. 位置编码（7.28)(7.29)(7.30）：为什么必需

### 9.1 自注意力是置换等变的

**关键性质**：**自注意力对输入序列是"置换等变"的**。

**含义**：如果把输入序列打乱（置换 $P$），输出也只是同样打乱——**模型"不知道"词序**。

**数学**：设输入 $X = [x^{(1)},\dots,x^{(T)}]$，置换 $P$ 把 $x^{(i)}$ 换到位置 $j$。则：

$$\mathrm{Attention}(PX) = P\,\mathrm{Attention}(X)$$

**证明直觉**：注意力权重 $\alpha^{(t)}_\tau$ 只依赖 $x^{(t)}$ 和 $x^{(\tau)}$ 的**内容**，不依赖它们的**位置**。所以打乱顺序，权重也打乱，输出也打乱——**"猫追狗"和"狗追猫"在自注意力看来是"同样的两个词，同样的关系"，只是位置不同**。

**后果**：**不注入位置信息，模型无法区分"猫追狗"和"狗追猫"**——语义完全不同，但自注意力"看不出区别"。

### 9.2 位置编码：注入位置信息

**解法**：**给每个位置加一个"位置向量"**——让模型能"看到"位置。

**可学习位置编码**（7.28）：

$$\tilde x^{(t)} = W_1 S\big(W_2 x^{(t)} + W_3 e_t + b_2\big) \tag{7.28}$$

（$e_t$ 是位置 $t$ 的 one-hot 向量，$W_3$ 把它映射到 $\tilde p$ 维）

**正余弦位置编码**（7.29）：

$$\boxed{r^{(t)}_{2i} = \sin\Big(\frac{t}{M^{2i/p_e}}\Big),\quad r^{(t)}_{2i+1} = \cos\Big(\frac{t}{M^{2i/p_e}}\Big)} \tag{7.29}$$

（$i\in\{0,\dots,p_e/2-1\}$，$M=10{,}000$）

**加到输入上**（7.30）：

$$\tilde x^{(t)} = \big(x^{(t)}_1 + r^{(t)}_0,\ x^{(t)}_2 + r^{(t)}_1,\ \dots,\ x^{(t)}_p + r^{(t)}_{p-1}\big) \tag{7.30}$$

### 9.3 正余弦编码的性质

**为什么用正余弦**：
- **有界**：$\sin,\cos\in[-1,1]$——不会让输入爆炸；
- **频率递减**：$i$ 越大，频率 $M^{2i/p_e}$ 越大，$\sin(t/M^{2i/p_e})$ 变化越慢——**低维编码"粗位置"，高维编码"细位置"**；
- **相对位置可推断**：$\sin(t+\Delta)$ 可以用 $\sin(t),\cos(t)$ 的线性组合表示——**模型可以从绝对位置推断相对位置**。

**书中图 7.14**：展示了 $r^{(t)}$ 的热图（不同 $t$、不同 $i$ 的值）和"相邻位置的差异"——**位置越近，编码越相似**。

### 9.4 数值验证

**设定**：$p_e=4$，$M=10000$，$t=1,2,3$。

**$i=0$**：$M^{2\cdot 0/4}=1$——$r^{(t)}_0=\sin(t)$，$r^{(t)}_1=\cos(t)$。
- $t=1$：$\sin(1)\approx 0.841$，$\cos(1)\approx 0.540$；
- $t=2$：$\sin(2)\approx 0.909$，$\cos(2)\approx -0.416$；
- $t=3$：$\sin(3)\approx 0.141$，$\cos(3)\approx -0.990$。

**$i=1$**：$M^{2/4}=100$——$r^{(t)}_2=\sin(t/100)$，$r^{(t)}_3=\cos(t/100)$。
- $t=1$：$\sin(0.01)\approx 0.010$，$\cos(0.01)\approx 0.99995$；
- $t=2$：$\sin(0.02)\approx 0.020$，$\cos(0.02)\approx 0.9998$；
- $t=3$：$\sin(0.03)\approx 0.030$，$\cos(0.03)\approx 0.9996$。

**观察**：低维（$i=0$）变化快（$\sin(1)$ 到 $\sin(2)$ 差异大），高维（$i=1$）变化慢（$\sin(0.01)$ 到 $\sin(0.02)$ 差异小）——**符合"低维粗、高维细"**。

## 10. Transformer 块（7.31)(7.32）：残差 + LayerNorm + FFN

### 10.1 块的内部结构

**Transformer 块**（书中 7.5 节）：

**Step 1：多头自注意力**

$$u_{[1]}^{(1)},\dots,u_{[1]}^{(T)} = \mathrm{MultiHeadSelfAttention}(a_{\text{in}}^{(1)},\dots,a_{\text{in}}^{(T)})$$

**Step 2：残差 + LayerNorm**（7.31）：

$$\boxed{u_{[2]}^{(t)} = \mathrm{LayerNorm}\big(\underbrace{a_{\text{in}}^{(t)} + u_{[1]}^{(t)}}_{\text{残差}};\gamma,\beta\big)} \tag{7.31}$$

**Step 3：前馈网络（FFN）** ：

$$u_{[3]}^{(t)} = W^{[2]}S\big(W^{[1]}u_{[2]}^{(t)} + b^{[1]}\big) + b^{[2]}$$

**Step 4：残差 + LayerNorm**：

$$a_{\text{out}}^{(t)} = \mathrm{LayerNorm}\big(u_{[2]}^{(t)} + u_{[3]}^{(t)};\tilde\gamma,\tilde\beta\big)$$

### 10.2 LayerNorm 的定义

$$\mathrm{LayerNorm}(z;\gamma,\beta) = \gamma\odot\frac{z-\mu_z}{\sqrt{\sigma_z^2+\epsilon}} + \beta$$

（$\mu_z = \frac{1}{p}\sum_i z_i$，$\sigma_z^2 = \frac{1}{p}\sum_i(z_i-\mu_z)^2$——**跨特征维，单样本**）

**与 BatchNorm 的区别**（第 12 天）：
- **BatchNorm**：跨样本，同特征；
- **LayerNorm**：单样本，跨特征——**与 batch 无关，训练推理同一套数学**。

### 10.3 块参数量（7.32）

$$\boxed{\#\text{params} = \underbrace{4p}_{\gamma,\beta,\tilde\gamma,\tilde\beta} + \underbrace{2N_1p}_{W^{[1]},W^{[2]}} + \underbrace{N_1 + p}_{b^{[1]},b^{[2]}} + H\times(\underbrace{2mp}_{W_k^h,W_q^h} + \underbrace{2m_vp}_{W_v^h,W_c^h})} \tag{7.32}$$

**书中例子**：$p=512$，$N_1=2048$，$m=m_v=64$，$H=8$：

$$4\cdot 512 + 2\cdot 2048\cdot 512 + 2048 + 512 + 8\cdot(2\cdot 64\cdot 512 + 2\cdot 64\cdot 512)$$
$$= 2048 + 2{,}097{,}152 + 2560 + 8\cdot 131{,}072$$
$$= 2048 + 2{,}097{,}152 + 2560 + 1{,}048{,}576$$
$$= 3{,}150{,}336$$

**这就是 Transformer 单块的参数量**（约 315 万）。

## 11. **与主流写法的 3 处差异（重点，按原文不要"纠正"）**

### 11.1 差异 1：**没有** $\mathrm{softmax}(QK^\top/\sqrt{d_k})V$ 这个式子

**主流写法**（Vaswani 2017）：

$$\mathrm{Attention}(Q,K,V) = \mathrm{softmax}\Big(\frac{QK^\top}{\sqrt{d_k}}\Big)V$$

**书中写法**（7.20)(7.21）：

$$\alpha^{(t)} = S_{\text{softmax}}\big([s(z_q^{(t)},z_k^{(1)}),\dots,s(z_q^{(t)},z_k^{(T_{\text{in}})})]^\top\big)$$
$$u^{(t)} = \sum_\tau\alpha^{(t)}_\tau v^{(\tau)}$$

**差异**：
- **主流**：把"内积 + 缩放 + softmax + 加权和"**绑定成一个公式**；
- **书中**：给的是**一般框架**——打分函数 $s(\cdot,\cdot)$ 可任选，softmax 是归一化，加权和是输出。

**为什么书中这样写**：**强调"注意力是一个框架，不是一个固定公式"**——内积只是"最简单的打分函数"，缩放只是"可选的数值稳定性因子"，不同的 $s$ 可以产生不同的注意力（如 Additive 注意力）。

**"不要纠正"**：如果你用主流习惯把书中的公式"改写"成 $\mathrm{softmax}(QK^\top/\sqrt{d_k})V$，就**丢失了"一般框架"的视角**——这是书中刻意要传达的。

### 11.2 差异 2：**缩放因子**写 $\sqrt{\max(m_q,m_k)}$，**不是** $\sqrt{d_k}$

**书中原话**："a factor such as $\sqrt{\max(m_q,m_k)}$... maintains score values at a reasonable range for numerical stability."

**差异**：
- **主流**：$\sqrt{d_k}$（假设 $m_q=m_k=d_k$）；
- **书中**：$\sqrt{\max(m_q,m_k)}$（一般化——$m_q\neq m_k$ 时也保守缩放）。

**定位差异**：
- **主流**：常被当作"经验技巧"（"除以 $\sqrt{d_k}$ 是经验上效果好"）；
- **书中**：明确定位为"**数值稳定性因子**"（"maintains score values at a reasonable range"）——**有方差论证支撑**（第 6 节）。

**"不要纠正"**：书中用 $\max(m_q,m_k)$ 是**更一般的写法**——当 $m_q=m_k$ 时与 $\sqrt{d_k}$ 相等；当 $m_q\neq m_k$ 时，$\max$ 保证保守缩放。**用 $\sqrt{d_k}$ 去"纠正"它，反而是特例化**。

### 11.3 差异 3：**多头合并**是加权和，**不是** concat + projection

**书中写法**（7.26）：

$$u^{(t)} = \sum_{h=1}^{H}W_c^h\,u^{h,(t)}$$

**主流写法**：

$$\mathrm{Concat}(u^1,\dots,u^H)W_O$$

**差异**：
- **主流**：先 concat，再乘一个大矩阵 $W_O$；
- **书中**：每个头乘自己的 $W_c^h$，再求和。

**数学上等价**（当 $W_O$ 按头分块时），**但表述不同**：
- 书中强调"**本质是加权和**"；
- 主流强调"**concat 这个操作**"。

**"不要纠正"**：书中的写法**更本质**——它揭示了"多头合并 = 每个头独立投影后加权求和"，而不是"concat 这个拼装操作"。**用 concat + projection 去"纠正"它，反而掩盖了本质**。

### 11.4 三处差异的总结

| 差异 | 主流 | 书中 | 书中的定位 |
|---|---|---|---|
| **1. 公式** | $\mathrm{softmax}(QK^\top/\sqrt{d_k})V$ | 一般框架 $s(\cdot,\cdot)$ + softmax + 加权和 | 强调"注意力是框架，不是固定公式" |
| **2. 缩放** | $\sqrt{d_k}$ | $\sqrt{\max(m_q,m_k)}$ | 数值稳定性因子（有方差论证） |
| **3. 多头合并** | concat + projection | 加权和 $\sum_h W_c^h u^h$ | 本质是加权和，不是拼装操作 |

**一句话**：**书中的写法更"一般"、更"本质"**——它把"注意力"从"一个具体公式"提升为"一个可替换部件的框架"。**主流写法是书中的"实例化"**（$s$ 取内积、$m_q=m_k=d_k$、用 concat 实现加权和）。

## 12. 数值例子

### 12.1 方差验证（缩放因子）

**设定**：$d=512$，$q,k$ 各分量 $\sim\mathcal{N}(0,1)$，独立。

**未缩放**：模拟 1000 次，$\mathrm{Var}(q^\top k)\approx 512$，标准差 $\approx 22.6$。

**缩放后**：$\mathrm{Var}(q^\top k/\sqrt{512})\approx 1$，标准差 $\approx 1$。

**交叉验证**：解析 $\mathrm{Var}(q^\top k)=512$，与模拟一致 ✓。

### 12.2 多头合并验证

**设定**：$H=2$，$m_v=2$，$p=3$。

**头 1**：$u^{1,(t)} = (1, 2)^\top$，$W_c^1 = \begin{bmatrix}1&0\\0&1\\1&0\end{bmatrix}$。

**头 2**：$u^{2,(t)} = (3, 4)^\top$，$W_c^2 = \begin{bmatrix}0&1\\1&0\\0&1\end{bmatrix}$。

**合并**：

$$W_c^1 u^{1} = \begin{bmatrix}1&0\\0&1\\1&0\end{bmatrix}\begin{bmatrix}1\\2\end{bmatrix} = \begin{bmatrix}1\\2\\1\end{bmatrix}$$
$$W_c^2 u^{2} = \begin{bmatrix}0&1\\1&0\\0&1\end{bmatrix}\begin{bmatrix}3\\4\end{bmatrix} = \begin{bmatrix}4\\3\\4\end{bmatrix}$$
$$u^{(t)} = \begin{bmatrix}1\\2\\1\end{bmatrix} + \begin{bmatrix}4\\3\\4\end{bmatrix} = \begin{bmatrix}5\\5\\5\end{bmatrix}$$

**验证**：加权和，不是 concat（concat 会得到 $(1,2,3,4)^\top$，再乘 $W_O$ 是另一种形式）✓。

### 12.3 位置编码验证

**设定**：$p_e=4$，$M=10000$，$t=1,2,3$（见第 9.4 节）。

**观察**：低维变化快，高维变化慢 ✓。

### 12.4 Transformer 块参数量验证

**设定**：$p=512$，$N_1=2048$，$m=m_v=64$，$H=8$。

**逐项**：
- $4p = 2048$；
- $2N_1p = 2\cdot 2048\cdot 512 = 2{,}097{,}152$；
- $N_1 + p = 2048 + 512 = 2560$；
- $H(2mp + 2m_vp) = 8\cdot(2\cdot 64\cdot 512 + 2\cdot 64\cdot 512) = 8\cdot 131{,}072 = 1{,}048{,}576$。

**总计**：$2048 + 2{,}097{,}152 + 2560 + 1{,}048{,}576 = 3{,}150{,}336$ ✓（与书中 (7.32) 一致）。

## 17. 【新增】"任意两个位置直接连接"——链长分析与 RNN vs 注意力

### 17.1 "传递链"的精确含义

**"传递链"** 指的是：**从"位置 $\tau$ 的输入"到"位置 $t$ 的输出"，中间经过了几次"非线性变换 + 状态传递"**。

**"链长"** $=$ 中间经过的"步数"。

- **链长 = 1**：位置 $\tau$ 的输入**直接**进入位置 $t$ 的计算；
- **链长 = $k$**：位置 $\tau$ 的输入要先变成某个中间状态，再传 $k-1$ 次，才到位置 $t$。

**链长越长，信息越容易衰减**——因为每一步都乘一个矩阵（或过激活），$k$ 步就是 $k$ 次连乘，指数效应。

### 17.2 RNN：链长 $= |t-\tau|$

**RNN 的递推**：$h^{(t)} = S_h(W_{hh}h^{(t-1)} + \cdots)$。

**$x^{(\tau)}$ 到 $h^{(t)}$ 的链长**：**$t-\tau$**（要经过 $h^{(\tau)}, h^{(\tau+1)},\dots,h^{(t-1)}$ 共 $t-\tau$ 步）。

**衰减**：$(W_{hh}^\top)^{t-\tau}$——**链越长，衰减越厉害**。

**$T=20$，谱半径 0.9** 的例子：

| 从 $t=20$ 传到 $\tau$ | 链长 $t-\tau$ | 衰减 $0.9^{t-\tau}$ |
|---|---|---|
| $\tau=19$ | 1 | 0.90 |
| $\tau=15$ | 5 | 0.59 |
| $\tau=10$ | 10 | 0.35 |
| $\tau=1$ | 19 | **0.135** |

**含义**：**$x^{(1)}$ 的信息传到 $h^{(20)}$，只剩 13.5%**——**链太长，信息衰减殆尽**。

### 17.3 自注意力：链长 $= 1$

**自注意力的公式**：$u^{(t)} = \sum_{\tau=1}^{T}\alpha_\tau^{(t)}v^{(\tau)}$。

**$v^{(\tau)}$ 到 $u^{(t)}$ 的链长**：**1**（直接加权和，不经过任何中间状态）。

**衰减**：$\alpha_\tau^{(t)}$ 是标量——**链长恒定 1，不随 $|t-\tau|$ 变化**。

**梯度**：$\partial u^{(t)}/\partial v^{(\tau)} = \alpha_\tau^{(t)}$——**是个标量，不随 $|t-\tau|$ 指数变化**。

### 17.4 关键对比

| 维度 | **RNN** | **注意力** |
|---|---|---|
| **$u^{(t)}$ 依赖什么** | 只依赖 $h^{(t-1)}$（+ 当前输入） | **直接依赖所有 $v^{(\tau)}$** |
| **链长** | $|t-\tau|$（随距离增长） | **1**（恒定） |
| **信息衰减** | 指数（$(W_{hh}^\top)^{t-\tau}$） | **无**（直接加权和） |
| **并行性** | **串行** | **并行** |
| **时间/内存** | $O(T)$ / $O(1)$ | **$O(T^2)$ / $O(T^2)$** |

### 17.5 "直接连接"的代价：$O(T^2)$

**"直接连接"不是免费的**——**它用 $O(T^2)$ 的时间和内存，换"链长 1、无衰减"**。

- **时间**：每对 $(t,\tau)$ 都要算相似度，共 $T^2$ 对；
- **内存**：注意力矩阵 $\alpha\in\mathbb{R}^{T\times T}$——$O(T^2)$。

**这就是"长上下文难"的根源**——**注意力"看得到远处，但 $O(T^2)$ 太贵"**。

### 17.6 为什么这不是"魔法"：注意力不是"记忆"，是"每次重新看全部"

**误解**："注意力把信息'直接传过去'，像'记忆'一样。"

**纠正**：**注意力不是"记忆"，是"每次重新看全部"**。

| | **RNN** | **注意力** |
|---|---|---|
| **信息怎么存** | **压缩成 $h$**（一个向量） | **不压缩，保留所有 $v^{(\tau)}$** |
| **怎么"看远处"** | 沿链传（$h$ 一步一步传） | **每次重新算**（$u^{(t)} = \sum_\tau\alpha_\tau v^{(\tau)}$） |
| **"记忆"是什么** | $h$ 是"压缩后的记忆" | **没有"记忆"**——每次前向都重新看所有输入 |

**"看"不衰减，"传"才衰减**——**注意力用"每次重新看"替代"沿链传递"**。

### 17.7 与残差的对照：两种"绕开传递链"，绕开的维度不同

| 维度 | **残差** | **注意力** |
|---|---|---|
| **绕开什么** | **层间**传递链 | **位置间**传递链 |
| **数学** | $I+\partial F/\partial x$ | $\sum_\tau\alpha_\tau v^{(\tau)}$ |
| **解决什么** | 深网络的梯度消失 | 长序列的长程依赖 |
| **代价** | 加一条旁路（$O(1)$ 额外） | $O(T^2)$ 时间/内存 |
| **维度** | **深度**（$L$ 层） | **长度**（$T$ 步） |

**残差和注意力都是"绕开传递链"，但绕开的维度不同**——残差绕开"层间"（深度），注意力绕开"位置间"（长度）。两者结合，就是 Transformer。

## 18. 【新增】"链长"与"层数"是两个独立维度（用户追问 Q1）

### 18.1 两个独立的维度

深度网络有**两个"路径"维度**，必须分清：

| 维度 | 方向 | 管什么 | 例子 |
|---|---|---|---|
| **序列维度（横向）** | 沿时间/位置（$t=1,\dots,T$） | **同一序列内不同位置之间的信息路径** | RNN 的 $h^{(t)}\to h^{(t+1)}$；注意力的 $v^{(\tau)}\to u^{(t)}$ |
| **层维度（纵向）** | 沿深度（$\ell=1,\dots,L$） | **不同层之间的信息路径** | FFN 的 $a^{[\ell]}\to a^{[\ell+1]}$；残差的 $x^{[\ell]}\to x^{[\ell+\tilde\ell]}$ |

**第 17–18 天讨论的"链长"，是"序列维度"的**——**"位置 $\tau$ 到位置 $t$ 的路径长度"**。

### 18.2 用户的理解正确

**用户说**："连接指的是同一输入信息序列的相互之间的联系路径，对于自注意力其步长都为 1，但对于 RNN，相隔的步数是两个信息的间隔。"

**这个理解完全正确**：
- **自注意力**：任意两位置的"步长"（链长）= 1；
- **RNN**：两位置的"步长"= 它们在序列中的间隔 $|t-\tau|$。

**用户说**："这部分讲的和多少层神经网络无关？"

**也正确**：**第 17–18 天讨论的"链长"，是"序列维度"的——与"层数"（纵向）独立**。

### 18.3 为什么与"层数"无关——两个维度的独立性

**序列维度**：$t=1,\dots,T$——**"多长"**。
**层维度**：$\ell=1,\dots,L$——**"多深"**。

**二者独立**：
- **RNN 的链长**：由**序列维度**决定（$|t-\tau|$），与**层数无关**（即使单层 RNN，链长也是 $|t-\tau|$）；
- **自注意力的链长**：由**序列维度**决定（恒为 1），与**层数无关**（即使单层自注意力，链长也是 1）。

**单层 vs 多层**：
- **单层 RNN**（$L=1$）：$h^{(t)}$ 依赖 $h^{(t-1)}$——**链长 $|t-\tau|$ 已经存在**；
- **多层 RNN**（$L=2$）：第 2 层的 $h^{(t)}_2$ 依赖 $h^{(t-1)}_2$，**链长仍是 $|t-\tau|$**——**层数增加了，但"链长"没变**。

**层维度的"直接连接"是残差**（$I+\partial F/\partial x$）——**自注意力是"序列维度的残差"，残差是"层维度的注意力"**。

## 19. 【新增】CNN 不是"链长 1"——卷积的"局部连接 + 层数累积"（用户追问 Q2）

### 19.1 用户直觉

**用户说**："RNN CNN 都是这样吗？好像不是吧？"

**正确**：**CNN 不是"链长 1"**——**CNN 的"空间链长"随层数累积**。

### 19.2 单层卷积：局部连接，链长 $K$

**单层卷积**（第 13 天）：$z_{i',j'} = \sum_{u,v}w_{u,v}x_{i'+u,j'+v}$。

**$x$ 的 $(i',j')$ 邻域（$K\times K$）到 $z_{i',j'}$ 的链长**：**1**（局部加权和）。

**但**：**$K\times K$ 之外的输入，单层卷积"看不到"**——链长**不是 1，是"不存在连接"**。

### 19.3 多层卷积：感受野累积，链长随层数增长

**两层 $3\times3$ 卷积**：**感受野 $5\times5$**（第 13 天 4.2 节）。

**输入 $(i,j)$ 到输出 $(i',j')$ 的"空间链长"**：**经过 2 层卷积，链长 2**。

**$L$ 层 $3\times3$ 卷积**：**感受野 $(2L+1)\times(2L+1)$**，**空间链长 $L$**。

### 19.4 三者"横向路径"对照

| 机制 | **信息怎么从 $\tau$ 到 $t$** | **链长** | **衰减** | **能并行** |
|---|---|---|---|---|
| **RNN** | 沿序列逐级传递 | $|t-\tau|$ | 矩阵幂（指数） | ❌ |
| **CNN** | 沿层逐级传递（感受野累积） | 层数 $L$（空间） | 层间矩阵幂（指数） | ✅ |
| **自注意力** | 全局广播 | **1** | 无 | ✅ |

**关键**：**CNN 的"长程"靠"层数累积"**——**不是"链长 1"，是"链长 $L$，但 $L$ 可以加"**。

## 20. 【新增】RNN/CNN/注意力可以混合——三种机制作用在不同维度/子任务

### 20.1 混合的合法性

**三种机制作用在"不同维度"或"不同子任务"上**，所以**可以混合**：

| 混合 | 各管什么 | 例子 |
|---|---|---|
| **CNN + RNN** | CNN 管"空间特征"，RNN 管"序列依赖" | CRNN（OCR、语音识别） |
| **CNN + 自注意力** | CNN 管"局部特征"，注意力管"全局关系" | Conformer（语音）、CoAtNet（视觉）、Vision Transformer 的混合 |
| **RNN + 自注意力** | RNN 管"局部时序"，注意力管"全局" | Transformer-XL（段间 RNN + 段内注意力） |

### 20.2 为什么"混合"不是"矛盾"

**因为"链长"是分维度讨论的**——**CNN 的"空间链长"和自注意力的"序列链长"是两个独立的"链"**，可以**同时存在**。

**例子：Conformer（语音识别）** ：
- **卷积模块**：管"局部声学特征"（链长 $K$）；
- **自注意力模块**：管"全局时序关系"（链长 1）；
- **两者交替**——**既利用局部性，又利用全局性**。

### 20.3 具体混合架构

**CNN + RNN：CRNN**（OCR、语音识别）：
- **CNN 骨干**：从图像/频谱提取"局部特征"（链长 $K$，感受野随层数增长）；
- **RNN 头**：对 CNN 输出的序列建模"时序依赖"（链长 $|t-\tau|$）。

**CNN + 自注意力：Conformer / CoAtNet**：
- **Conformer（语音）** ：卷积模块（局部声学特征）+ 自注意力模块（全局时序关系），交替堆叠；
- **CoAtNet（视觉）** ：浅层用卷积（局部特征、参数效率），深层用注意力（全局关系）。

**RNN + 自注意力：Transformer-XL**：
- **段内**：自注意力（链长 1）；
- **段间**：缓存上一段的 hidden state（类似 RNN 的"状态传递"）——段间链长 = 段数。

### 20.4 混合的哲学

**没有"唯一正确"的机制**——**RNN、CNN、自注意力各有优劣**：
- **RNN**：参数少、变长，但链长随距离增长；
- **CNN**：局部性、参数效率，但长程靠层数累积；
- **自注意力**：链长 1、全局，但 $O(T^2)$。

**混合 = 按任务需求，组合不同机制的优势**——**这是现代架构设计的常态**。

## 21. 【新增】自注意力之后，RNN 还常使用吗？会被完全替代吗？

### 21.1 结论先行

**RNN 未被完全替代，而是从"通用主力"转变为"特种部队"**——在 Transformer 的瓶颈（长上下文、资源受限、严格因果）处，RNN 的线性复杂度优势不可替代。

### 21.2 RNN 仍活跃的场景

| 场景 | 为什么 RNN 仍优 |
|---|---|
| **资源受限的边缘设备** | RNN 轻量、推理延迟低（IoT、可穿戴、实时生物信号） |
| **长序列时间序列预测** | RNN 是 $O(N)$，Transformer 是 $O(N^2)$——SegRNN 内存降 78%+ |
| **流式/因果推理** | RNN 逐 token 处理，天然因果；无需 KV Cache |
| **数据稀缺领域** | 生物声学、医学信号——紧凑 RNN 比巨型 Transformer 更具竞争力 |

### 21.3 "RNN 回归"趋势：xLSTM 与 Mamba

**Transformer 的瓶颈是 RNN 回归的驱动力**：$O(N^2)$ 复杂度，在百万级 token 或高频数据时不可承受——**这促使研究者重新审视 $O(N)$ 的 RNN 架构**。

**现代 RNN 变体**：
- **xLSTM（2024）** ：指数门控 + 协方差记忆规则，具备与 Transformer 相当的联想检索能力和高度并行性；
- **Mamba / SSM（状态空间模型）** ：吞吐量可达 Transformer 的 **6 倍**，内存仅 **1/3**——被视为 Transformer 的有力替代者。

### 21.4 混合架构是主流

**未来不是"谁替代谁"，是"如何结合"**：
- **谷歌 Titans（NeurIPS 2025）** ：融合 RNN 和 Transformer，处理 **200 万 token** 上下文；
- **RNN-Transformer 混合体**：循环结构（如 SSM）+ 注意力机制，保持线性复杂度的同时恢复长程精确建模。

### 21.5 一句话

> **RNN 的价值定位已转变**：不再是"万能工具"，但凭借**线性复杂度**的数学本质，在**边缘计算、流式处理、超长序列**等 Transformer 的"阿喀琉斯之踵"场景中，RNN 及其现代变体（xLSTM、Mamba）不可替代。**未来的图景是混合架构的天下**——融合循环的效率与注意力的精度。

## 22. 【新增】残差 + LayerNorm 的正确组合：Post-LN、Pre-LN 与你写的 `I + LN(·)` 为什么不是标准形式

### 22.1 结论先行

**残差和 LayerNorm 不是"并联"（`I + LN(·)`），是"串联"**——有两种标准顺序：

| 写法 | 公式 | 主通路是否过 LN | 有子层 |
|---|---|---|---|
| **Post-LN**（书中 7.31） | $\mathrm{LN}(x + F(x))$ | ✅（先加再归一化） | 有 |
| **Pre-LN**（现代主流） | $x + F(\mathrm{LN}(x))$ | ❌（直接透传） | 有 |
| **你写的** | $x + \mathrm{LN}(x)$ | ✅ | **无** |

**你写的 `I + LN(·)` 不是标准形式**——**没有子层 $F$，没有学习**。

### 22.2 书里 7.31 是 Post-LN

$$u_{[2]}^{(t)} = \mathrm{LayerNorm}\big(a_{\text{in}}^{(t)} + u_{[1]}^{(t)};\gamma,\beta\big) \tag{7.31}$$

**顺序**：**先加残差，再归一化**。

**主通路**：$a_{\text{in}}$ **经过了 LayerNorm**（被归一化了）——**这就是 Post-LN 的问题**：主通路不"干净"，梯度要穿过 LayerNorm 的雅可比。

### 22.3 Pre-LN：现代 LLM 的主流

$$u_{[2]}^{(t)} = a_{\text{in}}^{(t)} + F\big(\mathrm{LayerNorm}(a_{\text{in}}^{(t)};\gamma,\beta)\big)$$

**顺序**：**先归一化，再进子层，残差加在子层输出上**。

**主通路**：$a_{\text{in}}$ **不经过 LayerNorm、不经过子层**——**直接透传**。

**这就是"恒等通路"**——**梯度可以从输出直接流回输入，不穿过任何矩阵或归一化**。

### 22.4 你的直觉"$I$ 应该独立"——在 Pre-LN 里实现

**你写的 `I + LN(x)`** 想表达"$I$ 独立于 LN"——**在 Pre-LN 里实现为"$a_{\text{in}}$ 绕过 $F$ 和 LN"**。

**不是"$I$ 和 LN 并列"，是"$I$ 绕过"**。

### 22.5 为什么 `x + LN(x)` 不是标准

**标准 Transformer 块必须有"子层"**（多头注意力或 FFN）——**`x + LN(x)` 没有子层**，**它只是"输入加自己的归一化"**——**没有任何"学习"发生**（没有可学的子层参数）。

### 22.6 四种容易混的写法

| 写法 | 公式 | 是标准吗 | 问题 |
|---|---|---|---|
| **Post-LN**（书中 7.31） | $\mathrm{LN}(x + F(x))$ | ✅ 原始 Transformer | 主通路经过 LN，梯度被压缩 |
| **Pre-LN** | $x + F(\mathrm{LN}(x))$ | ✅ 现代主流 | 无（主通路干净） |
| **你写的** | $x + \mathrm{LN}(x)$ | ❌ 非标准 | 没有子层，没有学习 |
| **另一种错误** | $\mathrm{LN}(x) + F(x)$ | ❌ 非标准 | $F$ 作用于**未归一化的 $x$**——与 Pre-LN 不同 |

**注意第 4 种**：$\mathrm{LN}(x) + F(x)$ 和 $x + F(\mathrm{LN}(x))$ **不同**——**前者 $F$ 作用于 $x$（未归一化），后者 $F$ 作用于 $\mathrm{LN}(x)$（已归一化）**。**Pre-LN 是后者**。

## 23. 【新增】Pre-LN vs Post-LN 的梯度严格对比

### 23.1 Post-LN 的梯度

**Post-LN**：$u = \mathrm{LN}(a + F(a))$。

**对 $a$ 求导**：

$$\frac{\partial u}{\partial a} = \underbrace{J_{\mathrm{LN}}(a+F(a))}_{\text{LayerNorm 的雅可比}}\cdot\Big(I + \frac{\partial F}{\partial a}\Big)$$

**关键**：**$J_{\mathrm{LN}}$ 是 LayerNorm 的雅可比**——**它"夹"在梯度路径中间**。

**$J_{\mathrm{LN}}$ 的性质**：LayerNorm 的雅可比是"投影到与 $\mathbf{1}$ 正交的子空间 + 缩放"——**它会"压缩"梯度**（去掉均值方向、按 $\sigma$ 缩放）。

**后果**：**梯度要穿过 $J_{\mathrm{LN}}$，被"压缩"一次**——**深层时累积压缩，梯度变小**。

### 23.2 Pre-LN 的梯度

**Pre-LN**：$u = a + F(\mathrm{LN}(a))$。

**对 $a$ 求导**：

$$\frac{\partial u}{\partial a} = I + \underbrace{\frac{\partial F}{\partial \mathrm{LN}}\cdot J_{\mathrm{LN}}(a)}_{\text{子层分支的雅可比}}$$

**关键**：**$I$ 这一项是"干净的"**——**不经过 LayerNorm、不经过子层**。

**后果**：**梯度有一条"直通路径"（$I$）**——**即使子层分支的梯度被压缩，$I$ 这一项仍在**——**梯度不会消失**。

### 23.3 对照表

| 维度 | **Post-LN**（书中 7.31） | **Pre-LN**（现代主流） |
|---|---|---|
| **公式** | $\mathrm{LN}(a + F(a))$ | $a + F(\mathrm{LN}(a))$ |
| **主通路** | 经过 LN | **不经过 LN**（直接透传） |
| **梯度** | $J_{\mathrm{LN}}\cdot(I+\partial F/\partial a)$——**被 LN 压缩** | $I + \partial F/\partial \mathrm{LN}\cdot J_{\mathrm{LN}}$——**有干净的 $I$** |
| **训练稳定性** | 需要 warmup | **更稳，warmup 可更短** |
| **代表模型** | 原始 Transformer | GPT-2、GPT-3、LLaMA、Qwen、DeepSeek |

### 23.4 一句话

> **Post-LN 的梯度要穿过 LayerNorm 的雅可比（被压缩）；Pre-LN 的梯度有一条"不经过任何东西"的 $I$ 通路（干净直通）。这就是为什么现代 LLM 用 Pre-LN——不是"数学上更优雅"，是"训练上更稳"。**

## 25. 【新增】全文档终极总结

### 25.1 全文档 18 条核心结论

1–8. 同第 16.1 节（注意力 = 软寻址、一般框架、缩放方差论证、多头加权和、位置编码、Transformer 块、参数量）。

9. **"链长"指"序列维度（横向）"的信息路径**——**自注意力链长 1，RNN 链长 $|t-\tau|$，CNN 链长 = 层数（感受野累积）**。**这与"层数（纵向）"是独立维度**。

10. **"直接连接"不是免费的**——**它用 $O(T^2)$ 的时间和内存，换"链长 1、无衰减"**。注意力不是"记忆"，是"每次重新看全部"——"看"不衰减，"传"才衰减。

11. **残差和注意力都是"绕开传递链"**——**残差绕开"层间"（深度），注意力绕开"位置间"（长度）**。两者结合 = Transformer。

12. **CNN 不是"链长 1"**——**单层卷积只连 $K\times K$ 邻域，多层卷积的感受野随层数累积**。**CNN 的"长程"靠"层数累积"，不是"链长 1"**。

13. **三种机制可以混合**——CNN+RNN（CRNN）、CNN+自注意力（Conformer/CoAtNet）、RNN+自注意力（Transformer-XL）。**混合 = 按任务需求组合优势**。

14. **RNN 未被完全替代**——在边缘、流式、超长序列场景，RNN 的线性复杂度优势不可替代。**现代 RNN 变体（xLSTM、Mamba）正在回归**——Mamba 吞吐量 6 倍、内存 1/3。**未来是混合架构的天下**。

15. **残差 + LayerNorm 不是"并联"（`I + LN(·)`），是"串联"**——**Post-LN**（书中 7.31：先加残差、再 LayerNorm，主通路经过 LN）和 **Pre-LN**（现代主流：先 LayerNorm、再进子层、残差加在子层输出上，主通路不经过 LN）。**你写的 `I + LN(x)` 不是标准形式——没有子层**。

16. **Pre-LN 训练更稳**——**梯度有干净的 $I$ 通路**（$I + \partial F/\partial \mathrm{LN}\cdot J_{\mathrm{LN}}$），不经过 LayerNorm；Post-LN 的梯度被 $J_{\mathrm{LN}}$ 夹住（$J_{\mathrm{LN}}\cdot(I+\partial F/\partial a)$）——**这是现代 LLM 用 Pre-LN 的原因**。

17. **位置编码（7.29)(7.30）**：$r^{(t)}_{2i}=\sin(t/M^{2i/p_e})$，$r^{(t)}_{2i+1}=\cos(t/M^{2i/p_e})$，$M=10^4$。**为什么必需**：自注意力是**置换等变的**——不注入位置，模型不知词序。

18. **块参数量 (7.32)**：$4p+2N_1p+N_1+p+H(2mp+2m_vp)$；$p=512,N_1=2048,m=m_v=64,H=8$ 时 **3,150,336**。

### 25.2 一句话总结（终极版）

> **注意力是"软寻址"——query 和 key 比较相似度，softmax 给权重，对 value 加权和。它可微、无状态、全局，这三点让它取代 RNN。书中给的是"一般框架"（打分函数 $s$ 可任选），不是主流的 $\mathrm{softmax}(QK^\top/\sqrt{d_k})V$；缩放因子写 $\sqrt{\max(m_q,m_k)}$（方差论证：点积方差为 $d$，除以 $\sqrt d$ 后方差为 1，避免 softmax 饱和）；多头合并是加权和 $\sum_h W_c^h u^h$（不是 concat）。位置编码必需，因为自注意力是置换等变的——不注入位置，模型不知词序。**"链长"是"序列维度（横向）"的概念——自注意力链长 1、RNN 链长 $|t-\tau|$、CNN 链长 = 层数（感受野累积）——与"层数（纵向）"独立**。三种机制可以混合（CRNN、Conformer、CoAtNet、Transformer-XL），RNN 在边缘/流式/超长序列仍活跃（xLSTM、Mamba），未来是混合架构。**残差 + LayerNorm 不是"并联"（`I + LN(·)`），是"串联"——Post-LN（书中 7.31：先加后归一化，主通路经过 LN）或 Pre-LN（现代主流：先归一化再进子层，主通路干净，梯度有 $I$ 通路）**——你写的 `x + LN(x)` 不是标准（无子层）。**与主流的 3 处差异是书中刻意的"一般化"，不是笔误——不要"纠正"。**

### 25.3 思维导图（终极版）

> **注意力 = 软寻址（query/key/value）→ 一般框架（$s$ 可任选）→ 缩放 $\sqrt{\max(m_q,m_k)}$（方差论证：方差 $d$ → 除以 $\sqrt d$ → 方差 1）→ 自注意力（query/key/value 同源）→ 多头（多个视角）→ 合并是加权和 $\sum_h W_c^h u^h$（不是 concat）→ 位置编码（置换等变 → 必须注入位置）→ Transformer 块（注意力 + 残差/LayerNorm + FFN）→ 参数量 $4p+2N_1p+N_1+p+H(2mp+2m_vp)$ → **3 处差异：一般框架 vs 具体公式、$\sqrt{\max}$ vs $\sqrt{d_k}$、加权和 vs concat——按原文，不要"纠正"** → **链长 = 序列维度（自注意力 1、RNN $|t-\tau|$、CNN 层数）≠ 层数（纵向）** → **"直接连接"代价 $O(T^2)$** → **CNN 不是链长 1（感受野累积）** → **三种机制可混合（CRNN、Conformer、CoAtNet、Transformer-XL）** → **RNN 在边缘/流式/超长序列仍活跃（xLSTM、Mamba）** → **残差 + LN 是串联：Post-LN（书中 7.31，主通路过 LN）vs Pre-LN（现代主流，主通路干净）** → **你写的 `x + LN(x)` 无子层，非标准**。
