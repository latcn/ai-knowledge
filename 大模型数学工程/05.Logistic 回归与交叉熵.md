## 第一部分：学习计划与核心任务

### 1.1 第 5 天学习安排

**读**：第 3.1–3.2 节 + 附录 B.1 + 拆书对应部分

**核心任务**：
- 从伯努利最大似然推出二元交叉熵：
  $$
  L = \prod_i \phi_i^{y_i}(1-\phi_i)^{1-y_i} \Rightarrow \ell = \sum_i [y_i \log \phi_i + (1-y_i)\log(1-\phi_i)]
  $$
- 写出 logistic 梯度：
  $$
  \nabla C_i = (\hat y_i - y^{(i)}) \begin{bmatrix} 1 \\ x^{(i)} \end{bmatrix}, \qquad \text{其中 } \hat y_i := \sigma(w^\top x^{(i)} + b)
  $$
  （注：全文统一用 $$\hat y_i$$ 表示 sigmoid 输出，$$\sigma(w^\top x^{(i)} + b)$$ 是它的展开形式。）
- 理解 $$\sigma' = \sigma(1-\sigma)$$ 是关键。

**深入浅出讲解**：
> Logistic 回归就是把线性回归的输出塞进一个 sigmoid 函数，把它变成概率。为什么用交叉熵而不是平方误差？因为交叉熵的梯度是“预测减标签”，形式极简，而且损失函数是凸的。平方误差会导致非凸，容易卡在局部极小。

**验收**：从伯努利似然出发，推出交叉熵，再推出梯度。

## 第二部分：第一性原理——为什么是 sigmoid + 交叉熵？

### 2.1 问题的起点：二分类

**任务**：给定输入 $$x \in \mathbb{R}^p$$，预测一个二值标签 $$y \in \{0, 1\}$$。

**例子**：
- 输入：病人的 30 项体检指标 $$x$$；
- 输出：$$y = 1$$ 表示恶性，$$y = 0$$ 表示良性。

### 2.2 为什么用 sigmoid？

**第一个问题**：线性模型 $$w^\top x + b$$ 输出的是实数 $$(-\infty, +\infty)$$，但我们要的是概率 $$P(y = 1 \mid x) \in [0, 1]$$。怎么办？

**答案**：用 sigmoid 函数把实数映射到 $$(0, 1)$$：

$$
\sigma(z) = \frac{1}{1 + e^{-z}}
$$

性质：
- $$z \to +\infty$$ 时 $$\sigma(z) \to 1$$；
- $$z \to -\infty$$ 时 $$\sigma(z) \to 0$$；
- $$z = 0$$ 时 $$\sigma(0) = 0.5$$；
- 严格单调递增，连续可导。

**所以 logistic 回归的模型是**：
$$
\phi(x) = P(y = 1 \mid x; \theta) = \sigma(w^\top x + b)
$$

**补充澄清**：

- **$$[0,1]$$ 指什么？** $$[0,1]$$ 是概率 $$P(y=1|x)$$ 的取值范围，不是 $$x$$ 的定义域。$$x \in \mathbb{R}^p$$ 可以是任意实数（如病人的 30 项体检指标，每项都是实数）。
- **sigmoid 的 $$z$$ 是什么？** $$z = w^\top x + b$$，线性组合的结果，取值 $$(-\infty, +\infty)$$。
- **“sigmoid 不可能达到 0 和 1”指什么？** sigmoid 输出在**开区间** $$(0,1)$$，理论上永远达不到 0 和 1。证明：$$z \to +\infty$$ 时 $$e^{-z} \to 0$$，$$\sigma(z) \to 1$$ 但永远小于 1（分母 $$1 + e^{-z} > 1$$）；$$z \to -\infty$$ 时 $$\sigma(z) \to 0$$ 但永远大于 0。这避免了交叉熵在 $$\hat y = 1$$ 且 $$y = 0$$ 时的数值爆炸（$$-\log 0 = +\infty$$）。

**工程注记（反馈 3 修订）**：理论推导中 $$\hat y \in (0,1)$$，但在代码实现时，由于浮点数精度限制（如 float32 下 $$e^{-z}$$ 在 $$z > 88$$ 时下溢为 0），$$\sigma(z)$$ 可能被计算为**精确的 0 或 1**，导致 $$-\log 0 = +\infty$$ 或 $$\log 1 = 0$$ 的数值问题（NaN 或梯度消失）。实践中通常采用以下两种方式之一：① 对 $$\hat y$$ 进行裁剪（clip to $$[\epsilon, 1-\epsilon]$$，如 $$\epsilon = 10^{-7}$$）；② 使用数值稳定的 `log_sigmoid` / `softplus` 函数直接计算 $$\log \sigma(z)$$，避免先算 $$\sigma(z)$$ 再取对数。

### 2.3 为什么用交叉熵而不是平方误差？

**三个第一性原理层面的理由**：

**理由 1：统计层面——交叉熵 = 伯努利分布的最大似然**

如果假设 $$y \mid x$$ 服从伯努利分布 $$P(y = 1 \mid x) = \phi(x)$$，那么最大似然估计直接推出交叉熵（第三部分完整推导）。**平方误差对应的是高斯噪声假设，但二分类的标签不是“高斯噪声下的连续值”，而是伯努利分布的 0/1。** 用平方误差在统计上是“错误的噪声模型”。

**理由 2：优化层面——在 logistic 回归中交叉熵是凸的，平方误差是非凸的**（反馈 2 修订）

- **在 logistic 回归等线性模型中**，交叉熵损失关于参数 $$\theta$$ 是**凸函数**（Hessian 半正定），梯度为零就是全局最小；
- 平方误差损失关于 $$\theta$$ 是**非凸的**，可能有多个局部极小；
- **注意**：对于深度神经网络（$$\hat y = f_\theta(x)$$ 非线性），交叉熵关于 $$\theta$$ 一般**是非凸的**。凸性是“logistic 回归 + 交叉熵”这个特定组合的性质，不是“交叉熵”本身的普适性质。

**书中第 3.2 节的 Figure 3.4 明确对比了这一点**：用平方误差时损失地形有多个坑洼，用交叉熵时是光滑的碗状。

**理由 3：梯度层面——交叉熵的梯度是“预测减标签”，形式极简**

$$
\nabla C_i = (\hat y_i - y_i) \tilde{x}^{(i)}
$$

这个“预测减标签”乘以输入的形式，是所有深度学习梯度推导的模板。平方误差的梯度多乘了一个 $$\sigma'(z)$$，当 $$\sigma$$ 饱和时梯度会消失得更快。

**一句话**：**sigmoid 来自“把实数映射为概率”，交叉熵来自“伯努利分布的最大似然”。两者结合，既统计正确，又优化友好。**

## 第三部分：高斯分布 vs. 伯努利分布——为什么回归对应高斯，二分类对应伯努利？

### 3.1 高斯分布（正态分布）的定义

**定义**：连续随机变量 $$y \in \mathbb{R}$$，概率密度：

$$
p(y \mid \mu, \sigma^2) = \frac{1}{\sqrt{2\pi\sigma^2}} \exp\left( -\frac{(y - \mu)^2}{2\sigma^2} \right)
$$

- **取值**：$$y \in (-\infty, +\infty)$$，连续；
- **参数**：均值 $$\mu$$，方差 $$\sigma^2$$；
- **形状**：钟形曲线，对称，尾部指数衰减。

### 3.2 伯努利分布的定义

**定义**：离散随机变量 $$y \in \{0, 1\}$$，概率质量函数：

$$
p(y \mid \phi) = \phi^y (1 - \phi)^{1 - y}
$$

- **取值**：$$y \in \{0, 1\}$$，离散（只有两个值）；
- **参数**：正类概率 $$\phi = P(y = 1) \in (0, 1)$$；
- **形状**：两个点上的概率质量。

### 3.3 核心区别

| 维度 | 高斯分布 | 伯努利分布 |
|---|---|---|
| **取值空间** | 连续，$$(-\infty, +\infty)$$ | 离散，$$\{0, 1\}$$ |
| **输出** | 概率密度（可以 > 1） | 概率质量（$$\in [0,1]$$） |
| **参数** | 均值 $$\mu$$，方差 $$\sigma^2$$ | 正类概率 $$\phi$$ |
| **适用场景** | 回归（输出是连续值） | 二分类（输出是 0/1） |
| **最大似然推出的损失** | **平方误差** | **交叉熵** |

### 3.4 为什么回归对应高斯噪声？

**回归任务**：输出 $$y \in \mathbb{R}$$ 是连续值（如房价、温度）。

**数据生成模型**：
$$
y = f(x) + \epsilon, \qquad \epsilon \sim \mathcal{N}(0, \sigma^2)
$$

即：真实输出 = 确定性函数 $$f(x)$$ + 高斯噪声 $$\epsilon$$。

**为什么假设高斯噪声？** 中心极限定理：大量独立小因素叠加（如测量误差、未观测变量），趋近高斯分布。

**最大似然推出平方误差**：

给定 $$x$$，$$y$$ 的分布是 $$\mathcal{N}(f(x), \sigma^2)$$：

$$
p(y \mid x) = \frac{1}{\sqrt{2\pi\sigma^2}} \exp\left( -\frac{(y - f(x))^2}{2\sigma^2} \right)
$$

似然函数：
$$
L = \prod_i \frac{1}{\sqrt{2\pi\sigma^2}} \exp\left( -\frac{(y_i - f(x_i))^2}{2\sigma^2} \right)
$$

取对数：
$$
\ell = -\frac{n}{2}\log(2\pi\sigma^2) - \frac{1}{2\sigma^2}\sum_i (y_i - f(x_i))^2
$$

最大化 $$\ell$$ 等价于最小化 $$\sum_i (y_i - f(x_i))^2$$——**这就是平方误差**。

**关键**：高斯分布的密度里有 $$(y - \mu)^2$$ 这个平方项，取对数后平方项保留，所以最大似然推出平方误差。

### 3.5 为什么二分类对应伯努利分布？

**二分类任务**：输出 $$y \in \{0, 1\}$$ 是离散值（如恶性/良性、猫/狗）。

**数据生成模型**：
$$
y \sim \text{Bernoulli}(\phi(x)), \qquad \phi(x) = P(y=1 \mid x)
$$

即：给定 $$x$$，$$y$$ 服从伯努利分布，正类概率是 $$\phi(x)$$（由模型预测）。

**为什么假设伯努利分布？** 因为标签只有两个取值，伯努利分布是“二值随机变量”的自然分布。

**最大似然推出交叉熵**：

$$
p(y \mid x) = \phi(x)^y (1 - \phi(x))^{1-y}
$$

似然函数：
$$
L = \prod_i \phi_i^{y_i} (1 - \phi_i)^{1-y_i}
$$

取对数：
$$
\ell = \sum_i \left[ y_i \log \phi_i + (1 - y_i) \log(1 - \phi_i) \right]
$$

最大化 $$\ell$$ 等价于最小化负对数似然——**这就是交叉熵**。

**关键**：伯努利分布的概率质量函数里有 $$y \log \phi + (1-y)\log(1-\phi)$$ 这个对数项，所以最大似然推出交叉熵。

### 3.6 具体例子

**回归例子**：预测房价。

- 真实关系：房价 = $$2 \times$$ 房间数 + $$100$$（万元）；
- 实际观测：房价 = 真实关系 + 测量误差（如 $$\pm 5$$ 万元的随机波动）；
- 误差服从高斯分布 $$\mathcal{N}(0, 25)$$；
- 用平方误差训练，等价于假设误差是高斯噪声。

**二分类例子**：预测肿瘤恶性/良性。

- 真实关系：某些指标组合决定恶性概率（如 80%）；
- 每个病人：以 80% 概率恶性，20% 概率良性（伯努利抽样）；
- 用交叉熵训练，等价于假设标签服从伯努利分布。

### 3.7 概率密度 vs. 概率质量——深入澄清

**概率质量（PMF）**：离散随机变量，取值在 $$[0,1]$$，求和为 1。**概率质量就是“真实的概率”**：$$p(1) = 0.3$$ 表示“$$X = 1$$ 的概率是 30%”。

**概率密度（PDF）**：连续随机变量，**可以大于 1**，积分等于 1。$$f(x)$$ 不是“$$X = x$$ 的概率”（连续变量取单点概率为 0），而是“$$X$$ 落在 $$x$$ 附近小区间的概率密度”。

**概率与密度的关系**：
$$
P(a \leq X \leq b) = \int_a^b f(x) \, dx
$$
即：**概率是密度在区间上的积分**。

**为什么密度可以大于 1？** 例子：均匀分布 $$X \sim \text{Uniform}(0, 0.5)$$，密度 $$f(x) = 2$$（在 $$[0, 0.5]$$ 上）。概率集中在很短的区间（长度 0.5），密度必须大于 1，才能让积分等于 1。**密度大不代表概率大，概率要看积分。**

**对比表**：

| 维度 | 概率质量（PMF） | 概率密度（PDF） |
|---|---|---|
| **随机变量类型** | 离散（如 $$\{0,1\}$$、$$\{1,\dots,K\}$$） | 连续（如 $$\mathbb{R}$$） |
| **取值** | $$p(x) \in [0, 1]$$ | $$f(x) \geq 0$$，**可以 > 1** |
| **归一化** | $$\sum_x p(x) = 1$$ | $$\int f(x) dx = 1$$ |
| **含义** | $$p(x) = P(X = x)$$（真实概率） | $$f(x)$$ 是密度，不是概率 |
| **区间概率** | $$P(X \in A) = \sum_{x \in A} p(x)$$ | $$P(X \in A) = \int_A f(x) dx$$ |
| **典型分布** | 伯努利、二项、类别分布 | 高斯、均匀、拉普拉斯 |
| **对应任务** | 分类（标签是离散的） | 回归（输出是连续的） |

**$$p(y \mid x)$$ 代表什么？概率还是密度？**

| 任务 | $$y$$ 的类型 | $$p(y \mid x)$$ 是什么 | 符号约定 |
|---|---|---|---|
| **回归** | 连续（$$y \in \mathbb{R}$$） | **概率密度**（PDF） | 通常写 $$p(y \mid x)$$ 或 $$f(y \mid x)$$ |
| **二分类** | 离散（$$y \in \{0, 1\}$$） | **概率质量**（PMF），即概率 | 通常写 $$P(y \mid x)$$ |
| **多分类** | 离散（$$y \in \{1, \dots, K\}$$） | **概率质量**（PMF），即概率 | 通常写 $$P(y \mid x)$$ |

**高斯密度是什么的概率密度？和 $$y$$ 有关吗？**

高斯密度 $$p(y \mid x)$$ 是“给定 $$x$$ 后，$$y$$ 这个随机变量的概率密度”。$$x$$ 是条件（给定），$$y$$ 是随机变量。**和 $$y$$ 非常有关**：密度是 $$y$$ 的函数，峰值在 $$y = f(x)$$ 处，离 $$f(x)$$ 越远密度越小，对 $$y$$ 积分等于 1。

**例子**：设 $$f(x) = 2$$，$$\sigma^2 = 1$$。
- $$y = 2$$：密度 $$\approx 0.399$$（最大）；
- $$y = 3$$：密度 $$\approx 0.242$$；
- $$y = 5$$：密度 $$\approx 0.0044$$。

## 第四部分：从伯努利最大似然推出交叉熵（完整推导）

### 4.1 数据与模型

**训练数据**：$$\mathcal{D} = \{(x^{(1)}, y^{(1)}), \dots, (x^{(n)}, y^{(n)})\}$$，其中 $$y^{(i)} \in \{0, 1\}$$。

**模型**：对每个样本 $$i$$，给定 $$x^{(i)}$$，预测正类的概率：
$$
\phi_i := \phi(x^{(i)}) = P(y^{(i)} = 1 \mid x^{(i)}; \theta) = \sigma(w^\top x^{(i)} + b)
$$

**$$\phi_i$$ 是什么？是先验还是预估？**

$$\phi_i = P(y^{(i)}=1 \mid x^{(i)}; \theta) = \sigma(w^\top x^{(i)} + b)$$ 是模型对第 $$i$$ 个样本的**预估条件概率**（给定输入 $$x^{(i)}$$ 后，标签为正类的概率）。

- **不是先验**：先验 $$P(y=1)$$ 不看 $$x$$，是常数；$$\phi_i$$ 依赖输入 $$x^{(i)}$$ 和参数 $$\theta$$。
- **不同样本的 $$\phi_i$$ 不同**：样本 1 预测 0.8，样本 2 预测 0.3，因为输入不同。
- 它是**模型对具体样本的预测概率**，不是“预估样本”。

### 4.2 第 1 步：写出单个样本的伯努利分布

伯努利分布的概率质量函数：

$$
P(y^{(i)} \mid x^{(i)}; \theta) = \phi_i^{y^{(i)}} (1 - \phi_i)^{1 - y^{(i)}}
$$

**验证**：
- 若 $$y^{(i)} = 1$$：$$\phi_i^1 (1-\phi_i)^0 = \phi_i$$，正确；
- 若 $$y^{(i)} = 0$$：$$\phi_i^0 (1-\phi_i)^1 = 1 - \phi_i$$，正确。

### 4.3 第 2 步：i.i.d. 假设下的似然函数

假设所有样本独立同分布，则整个数据集的似然函数是各样本概率的乘积：

$$
L(\theta) = \prod_{i=1}^n P(y^{(i)} \mid x^{(i)}; \theta) = \prod_{i=1}^n \phi_i^{y^{(i)}} (1 - \phi_i)^{1 - y^{(i)}}
$$

**这就是核心任务中的第一个式子。**

**似然函数是什么？和样本顺序无关吗？**

似然函数是参数 $$\theta$$ 的函数：$$L(\theta; \mathcal{D}) = P(\mathcal{D} \mid \theta)$$。它表示“在参数 $$\theta$$ 下，观测到当前数据的概率（或密度）”。

- **和样本顺序无关**：i.i.d. 假设下是连乘，乘法交换律，样本排列顺序不影响乘积。
- **但与“哪些样本属于哪个类别”有关**：交换两个标签不同的样本的输入，似然会变（因为 $$\phi_i$$ 依赖 $$x^{(i)}$$）。

### 4.4 第 3 步：取对数（为什么可以取对数？）

**关键**：$$\log$$ 是严格单调递增函数，最大化 $$L(\theta)$$ 等价于最大化 $$\log L(\theta)$$。

**为什么取对数？** 因为连乘在数值上容易下溢（多个小于 1 的数相乘趋近 0），而且连乘的导数难算。取对数把连乘变成连加，求导容易，数值稳定。

$$
\ell(\theta) = \log L(\theta) = \log \prod_{i=1}^n \phi_i^{y^{(i)}} (1 - \phi_i)^{1 - y^{(i)}}
$$

### 4.5 第 4 步：对数的性质展开连乘

对数把乘积变成和：
$$
\ell(\theta) = \sum_{i=1}^n \log \left[ \phi_i^{y^{(i)}} (1 - \phi_i)^{1 - y^{(i)}} \right]
$$

### 4.6 第 5 步：对数的性质展开指数

对数把指数拉下来：
$$
\ell(\theta) = \sum_{i=1}^n \left[ y^{(i)} \log \phi_i + (1 - y^{(i)}) \log(1 - \phi_i) \right]
$$

**这就是核心任务中的第二个式子——对数似然。**

### 4.7 第 6 步：最大似然 → 最小化负对数似然

**最大似然估计（MLE）**：
$$
\hat\theta_{\text{MLE}} = \arg\max_\theta \ell(\theta)
$$

等价于最小化负对数似然（因为 $$\arg\max f = \arg\min (-f)$$）：

$$
\hat\theta_{\text{MLE}} = \arg\min_\theta \left[ -\ell(\theta) \right]
$$

**除以 $$n$$（不影响最优解，但让损失有“平均”的含义）**：

$$
C(\theta) = -\frac{1}{n}\ell(\theta) = \frac{1}{n}\sum_{i=1}^n \left[ -y^{(i)} \log \phi_i - (1 - y^{(i)}) \log(1 - \phi_i) \right]
$$

**单个样本的损失**：

$$
\boxed{C_i(\theta) = -\left[ y^{(i)} \log \hat y^{(i)} + (1 - y^{(i)}) \log(1 - \hat y^{(i)}) \right]}
$$

其中 $$\hat y^{(i)} = \phi_i = \sigma(w^\top x^{(i)} + b)$$。

**这就是二元交叉熵（Binary Cross-Entropy, BCE）。**

### 4.8 最小化交叉熵等价于最大化似然

$$
\arg\max_\theta \ell(\theta) = \arg\min_\theta C(\theta)
$$

**为什么等价？** 因为 $$C = -\frac{1}{n}\ell$$，取负号翻转优化方向，$$1/n$$ 是常数不改变最优解。**“最大化似然”与“最小化交叉熵”是同一个优化问题的两种写法。**

**本质是什么？** 从信息论看，交叉熵 $$H(p, q_\theta)$$ 衡量“用模型分布 $$q_\theta$$ 编码真实分布 $$p$$ 的样本时的平均信息量”。最小化交叉熵 = 让模型分布 $$q_\theta$$ 逼近真实分布 $$p$$（等价于最小化 KL 散度 $$D_{\mathrm{KL}}(p \| q_\theta)$$）。

**“交叉熵越小越相似，预测越准，损失越小”对吗？**

- **交叉熵越小越相似**：对。$$H(p,q) = H(p) + D_{\mathrm{KL}}(p\|q)$$，$$H(p)$$ 是常数，交叉熵越小 $$\iff$$ KL 散度越小 $$\iff$$ $$q$$ 越接近 $$p$$。
- **预测越准**：需要精确化。交叉熵小通常意味着预测准，但交叉熵（概率分布匹配度）和准确率（分类决策正确率）**不是严格等价的**。
- **损失越小**：对，交叉熵就是损失函数。

### 4.9 交叉熵与信息论的联系

**附录 B.1 公式 (B.2)** 给出了交叉熵的定义：
$$
H(p, q) = -\sum_x p(x) \log q(x)
$$

对于二分类，$$p$$ 是真实分布（$$y^{(i)}$$ 的 one-hot：$$p(1) = y^{(i)}, p(0) = 1 - y^{(i)}$$），$$q$$ 是模型预测（$$q(1) = \hat y^{(i)}, q(0) = 1 - \hat y^{(i)}$$）。代入：

$$
H(p, q) = -\left[ y^{(i)} \log \hat y^{(i)} + (1 - y^{(i)}) \log(1 - \hat y^{(i)}) \right]
$$

**这正是 $$C_i(\theta)$$。** 所以二元交叉熵不是“随便起的一个名字”，它是**信息论中交叉熵在二分类下的具体形式**。

**附录 B.1 还给出了 KL 散度与交叉熵的关系**：
$$
D_{\mathrm{KL}}(p \| q) = H(p, q) - H(p)
$$

即：**交叉熵 = KL 散度 + 熵**。因为真实分布的熵 $$H(p)$$ 与模型参数 $$\theta$$ 无关，所以最小化交叉熵等价于最小化 KL 散度——即让模型分布 $$q$$ 尽量接近真实分布 $$p$$。

## 第五部分：Logistic 梯度的完整推导

### 5.1 需要推导的目标

对单个样本 $$i$$，损失为：
$$
C_i = -\left[ y_i \log \hat y_i + (1 - y_i) \log(1 - \hat y_i) \right]
$$

其中：
$$
\hat y_i = \sigma(z_i), \qquad z_i = w^\top x^{(i)} + b
$$

**目标**：求 $$\nabla_\theta C_i$$，其中 $$\theta = (b, w_1, \dots, w_p)^\top$$。

### 5.2 关键预备：sigmoid 的导数

$$
\sigma(z) = \frac{1}{1 + e^{-z}}
$$

**求导**：

$$
\sigma'(z) = \frac{d}{dz} (1 + e^{-z})^{-1}
$$

**第 1 步：链式法则**

设 $$u = 1 + e^{-z}$$，则 $$\sigma = u^{-1}$$。

$$
\frac{d\sigma}{dz} = \frac{d\sigma}{du} \cdot \frac{du}{dz}
$$

**第 2 步：逐项求导**

$$
\frac{d\sigma}{du} = -u^{-2} = -\frac{1}{(1 + e^{-z})^2}
$$

$$
\frac{du}{dz} = \frac{d}{dz}(1 + e^{-z}) = -e^{-z}
$$

**第 3 步：合并**

$$
\sigma'(z) = -\frac{1}{(1 + e^{-z})^2} \cdot (-e^{-z}) = \frac{e^{-z}}{(1 + e^{-z})^2}
$$

**第 4 步：用 $$\sigma$$ 表示**

注意到：
$$
\sigma(z) = \frac{1}{1 + e^{-z}}, \qquad 1 - \sigma(z) = \frac{e^{-z}}{1 + e^{-z}}
$$

所以：
$$
\sigma(z)(1 - \sigma(z)) = \frac{1}{1 + e^{-z}} \cdot \frac{e^{-z}}{1 + e^{-z}} = \frac{e^{-z}}{(1 + e^{-z})^2} = \sigma'(z)
$$

**结论**：
$$
\boxed{\sigma'(z) = \sigma(z)(1 - \sigma(z))}
$$

**这就是核心任务中说的“$$\sigma' = \sigma(1-\sigma)$$ 是关键”。** 它的作用是：后面推导梯度时，分子分母会精确约掉，最后只剩下 $$(\hat y - y)$$。

### 5.3 第 1 步：对 $$z_i$$ 求导

**先求 $$\frac{\partial C_i}{\partial \hat y_i}$$**：

$$
C_i = -\left[ y_i \log \hat y_i + (1 - y_i) \log(1 - \hat y_i) \right]
$$

逐项求导：

$$
\frac{\partial C_i}{\partial \hat y_i} = -\left[ y_i \cdot \frac{1}{\hat y_i} + (1 - y_i) \cdot \frac{1}{1 - \hat y_i} \cdot (-1) \right]
$$

$$
= -\frac{y_i}{\hat y_i} + \frac{1 - y_i}{1 - \hat y_i}
$$

**通分**：

$$
= \frac{-y_i (1 - \hat y_i) + (1 - y_i) \hat y_i}{\hat y_i (1 - \hat y_i)}
$$

**展开分子**：

$$
= \frac{-y_i + y_i \hat y_i + \hat y_i - y_i \hat y_i}{\hat y_i (1 - \hat y_i)}
$$

**合并同类项**（$$y_i \hat y_i$$ 抵消）：

$$
= \frac{\hat y_i - y_i}{\hat y_i (1 - \hat y_i)}
$$

**所以**：
$$
\boxed{\frac{\partial C_i}{\partial \hat y_i} = \frac{\hat y_i - y_i}{\hat y_i (1 - \hat y_i)}}
$$

### 5.4 第 2 步：对 $$z_i$$ 求导（链式法则）

$$
\frac{\partial C_i}{\partial z_i} = \frac{\partial C_i}{\partial \hat y_i} \cdot \frac{\partial \hat y_i}{\partial z_i}
$$

其中 $$\hat y_i = \sigma(z_i)$$，所以 $$\frac{\partial \hat y_i}{\partial z_i} = \sigma'(z_i) = \hat y_i (1 - \hat y_i)$$。

代入：

$$
\frac{\partial C_i}{\partial z_i} = \frac{\hat y_i - y_i}{\hat y_i (1 - \hat y_i)} \cdot \hat y_i (1 - \hat y_i)
$$

**分子分母中的 $$\hat y_i (1 - \hat y_i)$$ 精确约掉**：

$$
\boxed{\frac{\partial C_i}{\partial z_i} = \hat y_i - y_i}
$$

**这就是“$$\sigma' = \sigma(1-\sigma)$$ 是关键”的体现**：$$\sigma'$$ 的分母正好是 $$\frac{\partial C_i}{\partial \hat y_i}$$ 的分母，两者精确约掉，最后只剩下“预测减标签”。

### 5.5 第 3 步：对参数 $$\theta = (b, w)$$ 求导

**对 $$b$$ 求导**：$$z_i = w^\top x^{(i)} + b$$，所以 $$\frac{\partial z_i}{\partial b} = 1$$。

$$
\frac{\partial C_i}{\partial b} = \frac{\partial C_i}{\partial z_i} \cdot \frac{\partial z_i}{\partial b} = (\hat y_i - y_i) \cdot 1 = \hat y_i - y_i
$$

**对 $$w_j$$ 求导**：$$\frac{\partial z_i}{\partial w_j} = x_j^{(i)}$$。

$$
\frac{\partial C_i}{\partial w_j} = \frac{\partial C_i}{\partial z_i} \cdot \frac{\partial z_i}{\partial w_j} = (\hat y_i - y_i) \cdot x_j^{(i)}
$$

**合并成向量形式**：

$$
\boxed{\nabla C_i = (\hat y_i - y_i) \begin{bmatrix} 1 \\ x^{(i)} \end{bmatrix}}
$$

**这就是核心任务中的 logistic 梯度公式。**

### 5.6 整个数据集的梯度

$$
\nabla C(\theta) = \frac{1}{n}\sum_{i=1}^n \nabla C_i = \frac{1}{n}\sum_{i=1}^n (\hat y_i - y_i) \begin{bmatrix} 1 \\ x^{(i)} \end{bmatrix}
$$

**形式极简**：每个样本的梯度 = “预测误差” × “输入特征”。

## 第六部分：$$\sigma' = \sigma(1-\sigma)$$ 为什么是关键？

### 6.1 数学上：精确约掉

在 5.4 节中：

$$
\frac{\partial C_i}{\partial z_i} = \frac{\hat y_i - y_i}{\hat y_i (1 - \hat y_i)} \cdot \hat y_i (1 - \hat y_i) = \hat y_i - y_i
$$

**如果没有 $$\sigma' = \sigma(1-\sigma)$$ 这个性质**，分子分母不会约掉，梯度会变成复杂的表达式。正是因为这个性质，交叉熵 + sigmoid 的组合才产生“预测减标签”这样极简的梯度。

### 6.2 与平方误差的对比

**如果用平方误差** $$C_i = \frac{1}{2}(\hat y_i - y_i)^2$$：

$$
\frac{\partial C_i}{\partial z_i} = (\hat y_i - y_i) \cdot \sigma'(z_i) = (\hat y_i - y_i) \cdot \hat y_i (1 - \hat y_i)
$$

**多了一个 $$\hat y_i (1 - \hat y_i)$$ 因子。** 当 $$\hat y_i$$ 接近 0 或 1（sigmoid 饱和）时，这个因子趋近 0，梯度消失。**这就是平方误差 + sigmoid 的梯度消失问题。**

**交叉熵 + sigmoid 的梯度没有这个因子**，所以即使 $$\hat y_i$$ 饱和，梯度仍然是 $$(\hat y_i - y_i)$$，不会消失。

### 6.3 对比表

| 组合 | 梯度 | 饱和时是否消失 |
|---|---|---|
| **交叉熵 + sigmoid** | $$\hat y - y$$ | **不消失** |
| 平方误差 + sigmoid | $$(\hat y - y) \sigma'$$ | 消失（$$\sigma' \to 0$$） |

**这就是为什么分类任务用交叉熵而不是平方误差的核心原因之一**：梯度更稳定，不会因为预测饱和而消失。

## 第七部分：Logistic 梯度“预测 − 真实”的合理性（第一性原理 + 直觉）

### 7.1 从第一性原理看“预测 − 真实”的合理性

**梯度下降的更新**：$$\theta^{(t+1)} = \theta^{(t)} - \alpha \nabla_\theta C(\theta^{(t)})$$。

**第一性原理**：$$\nabla_\theta C$$ 指向损失增长最快的方向，负梯度方向是损失下降最快的方向。所以，任何合理的梯度，其“方向”必须让参数朝着“降低损失”的方向走。

**一个“好的”梯度应满足三个性质**：

| 性质 | 含义 | Logistic 梯度是否满足 |
|---|---|---|
| **方向正确** | 预测过大时参数往“减小预测”的方向走，预测过小时往“增大预测”的方向走 | ✅ |
| **幅度合理** | 错得越离谱，更新越大；预测准确时更新趋近于 0 | ✅ |
| **不因饱和而消失** | 预测接近 0 或 1 但真实相反时，梯度不能消失 | ✅ |

**逐条验证**：

**性质 1：方向正确**
- 若 $$\hat y_i > y_i$$（预测正类概率过高）：$$\hat y_i - y_i > 0$$，梯度为正，沿负梯度方向更新会**减小**参数在 $$\tilde{x}^{(i)}$$ 方向的分量，从而**拉低** $$\hat y_i$$；
- 若 $$\hat y_i < y_i$$（预测正类概率过低）：$$\hat y_i - y_i < 0$$，梯度为负，沿负梯度方向更新会**增大**参数在 $$\tilde{x}^{(i)}$$ 方向的分量，从而**拉高** $$\hat y_i$$；
- 若 $$\hat y_i = y_i$$（预测准确）：梯度为零，**不更新**。

**性质 2：幅度合理**
- $$|\hat y_i - y_i|$$ 最大为 1（当预测完全错时），最小为 0（预测完全对时）；
- **错得越多，更新越大；错得越少，更新越小**——这符合“按错误程度纠正”的直觉。

**性质 3：不因饱和而消失**
- 如果 $$\hat y_i = 0.01$$，真实 $$y_i = 1$$：$$\hat y_i - y_i = -0.99$$，**梯度很大**，强有力地拉高预测；
- 如果 $$\hat y_i = 0.99$$，真实 $$y_i = 1$$：$$\hat y_i - y_i = -0.01$$，**梯度很小**，温和地微调（已经预测对了）。
- **对比平方误差**：平方误差的梯度是 $$(\hat y_i - y_i)\sigma'(z_i)$$，当 $$\hat y_i \to 0$$ 或 1 时 $$\sigma'(z_i) \to 0$$，梯度**消失**，无法纠正“自信的错误”。

### 7.2 梯度不是“设计”的，是“推导”的

**关键澄清**：$$(\hat y_i - y_i)$$ 不是人为“设计”的形式，而是**从伯努利最大似然严格推导出来的**。

推导链条：

```
伯努利似然 L = ∏ φ^y (1-φ)^(1-y)
    ↓ 取对数
对数似然 ℓ = ∑ [y log φ + (1-y) log(1-φ)]
    ↓ 对 φ 求导
∂ℓ/∂φ = (y - φ) / (φ(1-φ))
    ↓ 乘以 sigmoid 的导数 φ(1-φ)
∂ℓ/∂z = y - φ = y - ŷ
    ↓ 取负（最小化负对数似然）
∂C/∂z = ŷ - y
    ↓ 乘以 ∂z/∂θ = x̃
∇C = (ŷ - y) x̃
```

**每一步都是数学必然，没有人为选择。** 唯一的“选择”是：① 假设伯努利分布；② 用最大似然。这两条是二分类任务的“自然选择”，不是任意的。

### 7.3 为什么 sigmoid 的导数恰好约掉？——指数族的性质

$$
\frac{\partial C_i}{\partial \hat y_i} = \frac{\hat y_i - y_i}{\hat y_i(1-\hat y_i)}, \qquad \frac{\partial \hat y_i}{\partial z_i} = \hat y_i(1-\hat y_i)
$$

两者相乘，分母精确约掉。**这不是巧合，而是指数族分布的性质**：

- 伯努利分布属于指数族，其对数似然对自然参数的导数是 $$(y - \mu)$$；
- sigmoid 是伯努利分布的自然参数到均值参数的映射；
- 两者组合，导数自然简化。

**更一般地**：任何“指数族分布 + 对应的链接函数 + 交叉熵”的组合，都会产生“预测 − 真实”的梯度。这就是**广义线性模型（GLM）**的核心性质。logistic 回归只是其中最简单的例子。

### 7.4 Logistic 是不是“这样设计和筛选”的？

**不是“设计”的，是“推导”的**：

1. **任务给定**：二分类，标签 $$y \in \{0, 1\}$$；
2. **概率模型自然选择**：伯努利分布是二值随机变量的唯一自然分布；
3. **估计方法自然选择**：最大似然是统计估计的标准方法；
4. **推导结果**：梯度自然呈现 $$(\hat y - y)\tilde{x}$$。

**但“筛选”确实存在**——“sigmoid + 交叉熵”这个组合是被历史实践筛选出来的：

| 候选方案 | 为什么被淘汰/保留 |
|---|---|
| **平方误差 + sigmoid** | 梯度多乘 $$\sigma'$$，饱和时消失；损失非凸，有局部极小。**被淘汰**。 |
| **绝对误差 + sigmoid** | 0 点不可导，无闭式梯度，优化困难。**被淘汰**。 |
| **Hinge 损失 + 线性**（SVM） | 不输出概率，只输出决策边界；无法做概率预测。**部分场景被淘汰**。 |
| **交叉熵 + sigmoid** | 梯度简洁、凸优化、输出概率、统计正确。**被保留**。 |

**所以 logistic 是“统计原理推导 + 历史实践筛选”共同作用的结果。**

### 7.5 直觉角度：为什么梯度是“预测 − 真实”？

**纠错直觉：像调音量**

想象你在调一个音量旋钮（参数），目标是让音量（预测）等于目标值（真实标签）。

- **预测过高**（$$\hat y = 0.9$$，目标 $$y = 0$$）：你听到声音太大，于是**往下调**。调多少？按“大了多少”来调——大得越多，调得越多。$$\hat y - y = 0.9$$，往下调 0.9 的力度。
- **预测过低**（$$\hat y = 0.1$$，目标 $$y = 1$$）：你听到声音太小，于是**往上调**。$$\hat y - y = -0.9$$，往上调 0.9 的力度。
- **预测正好**（$$\hat y = y$$）：不用调，梯度为零。

**教学直觉：像老师批改作业**

- 学生答“这题 90% 是 A”（$$\hat y = 0.9$$），正确答案是 B（$$y = 0$$）；
- 老师说：“你太自信了，往 B 的方向改一改。”改多少？按“自信程度”来改——越自信，改得越狠。
- 学生答“这题 10% 是 A”（$$\hat y = 0.1$$），正确答案是 A（$$y = 1$$）；
- 老师说：“你太没自信了，往 A 的方向改一改。”改多少？按“不自信程度”来改。

**几何直觉：沿着“减少误差”的方向走**

把损失 $$C$$ 想象成一个碗，碗底是 $$\hat y = y$$。梯度 $$(\hat y - y)$$ 是“当前位置到碗底的方向”（带符号）：
- 如果 $$\hat y > y$$，你在碗的右边，梯度指向右（正），负梯度指向左（往碗底走）；
- 如果 $$\hat y < y$$，你在碗的左边，梯度指向左（负），负梯度指向右（往碗底走）。

**信息论直觉：编码代价的梯度**

交叉熵 $$H(p, q) = -\sum p \log q$$ 是“用 $$q$$ 编码 $$p$$ 的代价”。梯度 $$(\hat y - y)$$ 是“调整 $$q$$ 以减少编码代价的方向”：
- 如果 $$q$$ 在真实类别上给的概率太低（$$\hat y < y$$），梯度为负，更新会**提高** $$q$$ 在真实类别上的概率，减少编码代价；
- 如果 $$q$$ 在真实类别上给的概率太高（$$\hat y > y$$），梯度为正，更新会**降低** $$q$$，减少“浪费的编码”。

**一句话直觉**：

> **“预测 − 真实”就是“当前偏差”：正数表示高估，负数表示低估，绝对值表示偏离程度。梯度下降就是“按偏差纠正”——偏差越大，纠正越狠；偏差为零，停止纠正。这就是 logistic 梯度的直觉本质。**

## 第八部分：交叉熵损失的计算公式（从定义推导）

### 8.1 公式总览

**二分类交叉熵（Binary Cross-Entropy, BCE）**：

对单个样本 $$(x, y)$$，$$y \in \{0, 1\}$$，模型预测 $$\hat y = \sigma(w^\top x + b) \in (0, 1)$$：

$$
\boxed{C_i = -\big[ y \log \hat y + (1 - y) \log(1 - \hat y) \big]}
$$

对 $$n$$ 个样本平均：

$$
C = -\frac{1}{n}\sum_{i=1}^n \big[ y^{(i)} \log \hat y^{(i)} + (1 - y^{(i)}) \log(1 - \hat y^{(i)}) \big]
$$

**多分类交叉熵（Categorical Cross-Entropy, CCE）**：

对单个样本 $$(x, y)$$，$$y \in \{1, \dots, K\}$$，模型预测概率向量 $$\hat y = \text{Softmax}(z) \in \Delta^{K-1}$$：

$$
\boxed{C_i = -\sum_{k=1}^K \mathbf{1}\{y = k\} \log \hat y_k = -\log \hat y_y}
$$

对 $$n$$ 个样本平均：

$$
C = -\frac{1}{n}\sum_{i=1}^n \sum_{k=1}^K \mathbf{1}\{y^{(i)} = k\} \log \hat y_k^{(i)} = -\frac{1}{n}\sum_{i=1}^n \log \hat y^{(i)}_{y^{(i)}}
$$

### 8.2 从信息论定义推导二分类交叉熵

**附录 B.1 公式 (B.2)** 给出了离散分布 $$p$$ 和 $$q$$ 的交叉熵：

$$
H(p, q) = -\sum_{x \in \mathcal{X}} p(x) \log q(x)
$$

**二分类设定**：

- 样本空间：$$\mathcal{X} = \{0, 1\}$$；
- 真实分布 $$p$$：$$p(1) = y$$，$$p(0) = 1 - y$$（one-hot，取决于真实标签）；
- 模型分布 $$q$$：$$q(1) = \hat y$$，$$q(0) = 1 - \hat y$$。

**代入**：

$$
H(p, q) = -\big[ p(1) \log q(1) + p(0) \log q(0) \big] = -\big[ y \log \hat y + (1 - y) \log(1 - \hat y) \big]
$$

**这就是 BCE。**

### 8.3 从信息论定义推导多分类交叉熵

**多分类设定**：

- 样本空间：$$\mathcal{X} = \{1, \dots, K\}$$；
- 真实分布 $$p$$：$$p(k) = \mathbf{1}\{y = k\}$$（one-hot）；
- 模型分布 $$q$$：$$q(k) = \hat y_k$$（softmax 输出）。

**代入**：

$$
H(p, q) = -\sum_{k=1}^K p(k) \log q(k) = -\sum_{k=1}^K \mathbf{1}\{y = k\} \log \hat y_k = -\log \hat y_y
$$

**这就是 CCE。**

**补充：Softmax + CCE 的梯度同样约简为 $$\hat y - y$$（反馈 4 修订）**

与二分类中 sigmoid 的导数 $$\sigma' = \hat y(1-\hat y)$$ 与 BCE 导数分母精确约掉类似，多分类中 Softmax 的雅可比与 CCE 的导数结合后，同样产生极简梯度。推导如下：

设 $$z = (z_1, \dots, z_K)$$ 是 softmax 的输入，$$\hat y_k = \frac{e^{z_k}}{\sum_j e^{z_j}}$$。Softmax 的雅可比为：
$$
\frac{\partial \hat y_k}{\partial z_j} = \hat y_k(\delta_{kj} - \hat y_j)
$$
CCE 对 $$\hat y_k$$ 的导数为 $$-\frac{\mathbf{1}\{y=k\}}{\hat y_k}$$。由链式法则：
$$
\frac{\partial C_i}{\partial z_j} = \sum_{k=1}^K \left( -\frac{\mathbf{1}\{y=k\}}{\hat y_k} \right) \hat y_k(\delta_{kj} - \hat y_j) = -\left( \delta_{yj} - \hat y_j \right) = \hat y_j - \delta_{yj}
$$
即：
$$
\boxed{\nabla_z C_i = \hat y - e_y}
$$
其中 $$e_y$$ 是真实标签的 one-hot 向量。**这与二分类的 $$\hat y - y$$ 完全同构**——都是“预测减标签”。这就是大模型训练效率的关键：无论二分类还是多分类，交叉熵 + sigmoid/softmax 的梯度都是极简的“预测减标签”，不需要额外的雅可比计算。

### 8.4 验证：两种极端情况

**情况 1：$$y = 1$$（真实是正类）**

$$
H(p, q) = -\big[ 1 \cdot \log \hat y + 0 \cdot \log(1 - \hat y) \big] = -\log \hat y
$$

- 若 $$\hat y = 1$$（完美预测）：$$-\log 1 = 0$$，损失为 0；
- 若 $$\hat y = 0.5$$（猜硬币）：$$-\log 0.5 \approx 0.693$$，损失较大；
- 若 $$\hat y \to 0$$（完全预测错）：$$-\log \hat y \to +\infty$$，损失爆炸。

**情况 2：$$y = 0$$（真实是负类）**

$$
H(p, q) = -\big[ 0 \cdot \log \hat y + 1 \cdot \log(1 - \hat y) \big] = -\log(1 - \hat y)
$$

- 若 $$\hat y = 0$$（完美预测）：$$-\log 1 = 0$$，损失为 0；
- 若 $$\hat y = 0.5$$：$$-\log 0.5 \approx 0.693$$；
- 若 $$\hat y \to 1$$（完全预测错）：$$-\log(1-\hat y) \to +\infty$$。

**结论**：交叉熵损失“惩罚自信的错误”——预测越自信且越错，损失越大。

### 8.5 二分类是多分类的特例

**验证**：取 $$K = 2$$，$$y \in \{1, 2\}$$。
- 若 $$y = 1$$（正类）：$$C = -\log \hat y_1 = -\log \hat y$$；
- 若 $$y = 2$$（负类）：$$C = -\log \hat y_2 = -\log(1 - \hat y)$$。

**用 $$y \in \{0, 1\}$$ 的记号**：
- $$y = 1$$：$$C = -\log \hat y$$；
- $$y = 0$$：$$C = -\log(1 - \hat y)$$。

**统一写成**：
$$
C = y(-\log \hat y) + (1 - y)(-\log(1 - \hat y)) = -\big[ y \log \hat y + (1 - y) \log(1 - \hat y) \big]
$$

**这正是二元交叉熵。** 所以二分类交叉熵是多分类交叉熵在 $$K = 2$$ 时的特例。

### 8.6 交叉熵的关键性质

**非负性**：$$H(p, q) \ge 0$$。因为 $$-\log q \ge 0$$（$$q \in (0, 1]$$），且 $$p \ge 0$$，所以求和非负。

**凸性（对 $$\hat y$$）**：$$-\log \hat y$$ 关于 $$\hat y$$ 是凸函数（二阶导 $$1/\hat y^2 > 0$$）。所以交叉熵关于模型输出 $$\hat y$$ 是凸的。**但注意**：关于参数 $$\theta$$，凸性取决于模型。**在 logistic 回归等线性模型中**，交叉熵关于 $$\theta$$ 是凸的；对于深度网络，一般是非凸的。

**惩罚“自信的错误”**：真实 $$y = 1$$，预测 $$\hat y = 0.99$$：损失 0.01（很小）；预测 $$\hat y = 0.01$$：损失 4.605（很大）；预测 $$\hat y \to 0$$：损失 $$\to +\infty$$。

**与 KL 散度的关系**：$$H(p, q) = H(p) + D_{\mathrm{KL}}(p \| q)$$。最小化交叉熵 = 最小化 KL 散度（因为 $$H(p)$$ 是常数）。

## 第九部分：交叉熵小但分布差异大——信息论本质与局限性

### 9.1 本质：用错编码方案的代价

假设真实分布是 $$p$$，我们基于模型分布 $$q$$ 设计一套编码方案。

- **最优编码定理**（Shannon）：如果数据真实来自 $$q$$，用基于 $$q$$ 的最优编码，每个样本平均需要 $$H(q)$$ 比特。
- **但现在数据来自 $$p$$，我们却用基于 $$q$$ 的编码。** 此时每个样本平均需要的比特数是 $$H(p, q) = -\sum_x p(x) \log q(x)$$。

$$
H(p, q) = H(p) + D_{\mathrm{KL}}(p \| q)
$$

- $$H(p)$$：如果知道真实分布 $$p$$ 并用最优编码，需要的比特数（理论下界）；
- $$D_{\mathrm{KL}}(p \| q)$$：因为用错编码方案而“浪费”的比特数。

**所以交叉熵的本质是：用模型分布 $$q$$ 的编码方案去编码真实分布 $$p$$ 的样本时的平均代价。**

### 9.2 前向 KL 的行为：mode-covering

交叉熵最小化 = 最小化前向 KL：

$$
\min_\theta H(p, q_\theta) = \min_\theta D_{\mathrm{KL}}(p \| q_\theta)
$$

$$
D_{\mathrm{KL}}(p \| q) = \sum_x p(x) \log \frac{p(x)}{q(x)}
$$

**权重是 $$p(x)$$**：
- 如果 $$p(x) > 0$$ 但 $$q(x) \to 0$$：这一项 $$\to +\infty$$（严重惩罚）；
- 如果 $$p(x) = 0$$ 但 $$q(x) > 0$$：这一项为 $$0$$（**不惩罚**）。

**后果**：前向 KL 只惩罚“$$p$$ 有质量但 $$q$$ 没覆盖”的情况，**不惩罚“$$q$$ 在 $$p$$ 没质量的地方乱放质量”**。这导致最优的 $$q$$ 倾向于**mode-covering（模式覆盖）**：在 $$p$$ 有质量的所有地方都放一些质量，但可能在某些区域“过度覆盖”。

**语境澄清（反馈 5 修订）**：Mode-covering 导致的“过度覆盖”问题主要出现在 **$$p$$ 本身是多峰分布的生成建模场景**中（如 VAE、GAN 的生成分布拟合）。在**判别式分类任务**（如 Logistic 回归、LLM 的 next token prediction）中，$$p$$ 是 **one-hot 分布**（单峰，支撑集只有一个点），此时“$$q$$ 在 $$p$$ 没质量的地方乱放质量”虽然存在（$$q$$ 会给其他类别分配概率），但不会导致“过度覆盖”的灾难——因为交叉熵的分母 $$\hat y_y$$ 只关心“$$q$$ 在真实类别上的概率”，其他类别的概率被 softmax 归一化约束。**所以第 9.3 节的四种“交叉熵小但分布差异大”的情况，主要适用于生成模型，不直接适用于 one-hot 标签的分类任务。**

**对比反向 KL**：$$D_{\mathrm{KL}}(q \| p)$$ 权重是 $$q(x)$$，惩罚“$$q$$ 在 $$p$$ 没质量的地方放质量”，倾向于**mode-seeking（模式寻找）**。

### 9.3 交叉熵很小但实际相差很大：四种情况

**情况一：$$q$$ 在 $$p$$ 的“空白区”乱放质量**

设 $$p = 0.5 \delta_{-10} + 0.5 \delta_{+10}$$（双峰），$$q = 0.4 \delta_{-10} + 0.4 \delta_{+10} + 0.2 \delta_0$$（在中间点 0 放了 20% 质量）。

$$
H(p, q) = -[0.5 \log 0.4 + 0.5 \log 0.4] \approx 0.916
$$

而 $$H(p) = \log 2 \approx 0.693$$。交叉熵只比最优值大了 0.223 比特，但 $$q$$ 在 $$x = 0$$ 处放了 20% 的质量——这个区域 $$p$$ 完全没有质量。**交叉熵“看起来不大”，但 $$q$$ 和 $$p$$ 的分布形状差异很大。**

**情况二：$$p$$ 重尾，$$q$$ 轻尾**

$$p$$ 是柯西分布（重尾），$$q$$ 是高斯分布（轻尾）。交叉熵有限（$$q$$ 尾部不为零），但 $$p$$ 的尾部厚、$$q$$ 的尾部薄，极端值行为完全不同。

**情况三：经验交叉熵 vs. 真实交叉熵（过拟合）**

训练时只能计算经验交叉熵 $$\hat H = -\frac{1}{n}\sum_i \log q(x^{(i)})$$，这是真实交叉熵的蒙特卡洛估计。如果模型过拟合，对训练样本给出极高概率（经验交叉熵很小），但对新样本给出极低概率（真实交叉熵很大）。**经验交叉熵小，不代表真实交叉熵小。**

**情况四：矩匹配但高阶矩不匹配**

$$p$$ 和 $$q$$ 都是高斯，但方差不同（$$q = \mathcal{N}(0, 1+\epsilon)$$）。交叉熵接近最优值，但 $$q$$ 的方差比 $$p$$ 大。更极端：$$p$$ 是双峰高斯混合，$$q$$ 是单峰高斯，但均值和方差匹配——交叉熵可能“看起来还行”，但 $$q$$ 完全无法捕捉 $$p$$ 的双峰结构。

### 9.4 总结：交叉熵小的真正含义

$$
H(p, q) \text{ 小} \iff D_{\mathrm{KL}}(p \| q) \text{ 小} \iff q \text{ 在 } p \text{ 有质量的地方“覆盖足够”}
$$

**它只保证“单向覆盖”，不保证“双向匹配”。**

- 不意味着 $$q$$ 和 $$p$$ 形状相同；
- 不意味着 $$q$$ 的尾部行为对；
- 不意味着泛化好；
- 不意味着高阶结构匹配。

**一句话总结**：

> **交叉熵的本质是“用模型分布 $$q$$ 的编码方案去编码真实分布 $$p$$ 的样本时的平均代价”。它最小化的是前向 KL 散度 $$D_{\mathrm{KL}}(p \| q)$$，这个散度是“单向”的：只惩罚“$$q$$ 在 $$p$$ 有质量的地方覆盖不足”，不惩罚“$$q$$ 在 $$p$$ 没质量的地方乱放质量”。所以交叉熵小可以只意味着“$$q$$ 在 $$p$$ 的支撑集上覆盖够了”，而不意味着“$$q$$ 和 $$p$$ 的形状完全相同”。**

### 9.5 实践含义

| 场景 | 交叉熵小但分布差异大的风险 | 应对 |
|---|---|---|
| **生成模型** | 模型在训练分布外生成“乱放”的样本 | 用反向 KL、GAN、扩散模型等替代 |
| **重尾数据** | 模型轻尾，无法捕捉极端事件 | 用重尾分布（如 t 分布）建模 |
| **过拟合** | 经验交叉熵小，真实交叉熵大 | 用验证集、正则化、早停 |
| **多峰数据** | 模型单峰，无法捕捉多峰结构 | 用混合模型、生成模型 |

**交叉熵是“必要的”，但不是“充分的”**：它是分类任务的标准损失，但“交叉熵小”不等于“模型完美”。

## 第十部分：为什么大模型大部分使用交叉熵？有其他的改进方法吗？

### 10.1 为什么大模型普遍使用交叉熵？

**数学上的必然与简洁**：
- **与任务本质完美匹配**：LLM 的预训练任务是“预测下一个词元”，本质是在巨大词汇表上进行**多分类**。交叉熵正是分类任务最自然的损失函数。
- **梯度形式极简**：交叉熵与 Softmax 结合时，梯度精确约简为“预测减标签”。计算效率和数值稳定性极高。
- **凸性与信息论基础**：对于 Softmax 回归（不考虑深层网络），交叉熵是凸函数。同时它等价于**最小化模型分布与真实分布的 KL 散度**，有坚实的信息论支撑。

**工程实践的“甜蜜点”**：
- **简单且可扩展**：实现极其简单，计算复杂度与词表大小呈线性关系，适合数万亿 token 的大规模分布式训练。
- **与现有优化器生态兼容**：简单梯度形式与 Adam 等自适应优化器配合得天衣无缝。
- **经验上的巨大成功**：GPT、LLaMA 等所有主流模型的成功，都建立在交叉熵损失之上。

### 10.2 交叉熵的局限与改进方案

**改进方向一：应对“类别不平衡”与“易学 Token 主导”**

交叉熵平等对待所有词元，导致模型在常见词元上快速学习，而稀有词元的梯度被“淹没”。

- **标签平滑（Label Smoothing）**：将硬标签软化为 $$[ε/V, ..., 1-ε+ε/V, ...]$$，防止过度自信，起正则化作用。
- **Focal Loss**：在交叉熵基础上增加调制因子 $$(1-p_t)^γ$$，**自动降低“易学样本”的权重，让模型聚焦于“难学样本”**。研究表明，在 LLM 微调中，Focal Loss 等替代损失可比交叉熵**平均提升 36% 的精确匹配率**。

**改进方向二：解决“数值 Token”的序关系缺失**

标准交叉熵假设类别是**无序的**，因此无法理解数字“2”和“3”比“2”和“100”更接近，这严重制约了模型的数学与数值推理能力。

- **数值 Token 回归损失（Number Token Loss, NTL）**：通过最小化预测数字与真实数字在数值上的 **Lp 范数或 Wasserstein 距离**来训练模型。实验表明，NTL 在数学相关任务上能稳定提升性能。

**改进方向三：超越“前向 KL”的“模式覆盖”**

标准交叉熵最小化的是**前向 KL 散度**，它倾向于让模型“覆盖”所有模式，可能在本应确定的词元上分散概率。

- **RLHF（基于人类反馈的强化学习）**：通过奖励模型学习人类偏好，使用 PPO 等算法优化，**直接优化“生成质量”这个标量奖励**。
- **DPO（直接偏好优化）**：**绕过了显式奖励模型，将 RLHF 的目标转化为一个简单的二元交叉熵损失**，直接在偏好数据对上优化语言模型。

**其他探索性改进**：
- **f-散度与 α-散度**：用更一般的 f-散度替代 KL 散度。研究发现，**α=1.5 的 α-散度损失在多项任务上表现良好**。
- **对比学习与度量学习**：通过对比损失或三元组损失，直接优化样本间的距离。
- **基于距离的谐波损失（Harmonic Loss）**：研究表明，**基于余弦的谐波损失能同时改善困惑度、训练稳定性和表示结构**。
- **广义交叉熵（GCE）**：基于 Tsallis 对数的一族损失函数，**对标签噪声更具鲁棒性**。
- **Lovász Loss**：在 LLM 微调时，在数学应用题和问答任务上，**可比交叉熵平均提升 36% 的精确匹配率**。

### 10.3 总结表

| 改进方向 | 代表方法 | 核心思想 | 解决交叉熵的什么问题 |
|---|---|---|---|
| **加权/聚焦** | Focal Loss, 标签平滑 | 降低易学样本权重，聚焦难学样本；软化标签防过自信 | 类别不平衡、易学 Token 主导 |
| **回归化** | Number Token Loss (NTL) | 用数值距离替代分类错误 | 数值 Token 缺乏序关系 |
| **范式转换** | RLHF, DPO | 用“生成质量”的标量奖励或偏好对替代逐词元似然 | 前向 KL 的“模式覆盖”问题 |
| **几何/度量** | 对比/度量学习, 余弦谐波损失 | 直接优化表示空间中的类内紧凑性与类间分离性 | 交叉熵不关注表示结构 |
| **理论泛化** | f-散度/α-散度, GCE | 用更一般的散度族或广义对数替代 KL 散度 | 为超越交叉熵提供理论框架 |

**交叉熵因其与语言建模任务的数学同构性、极简的梯度形式以及工程上的可扩展性，成为了大模型训练的“默认选择”。** 它的局限是明确的，并已催生出丰富的改进方案。这些方法并非要完全取代交叉熵，而是在特定场景（如数学推理、人类对齐、长尾分布）下对其短板进行精准补强。

## 第十一部分：似然函数与多分类的深入澄清

### 11.1 似然函数是什么？

似然函数是参数 $$\theta$$ 的函数：$$L(\theta; \mathcal{D}) = P(\mathcal{D} \mid \theta)$$。它表示“在参数 $$\theta$$ 下，观测到当前数据的概率（或密度）”。

**似然不是“解释概率分布”，而是“在给定已观测数据下，评估哪个参数最可能生成这些数据”。**

- 如果 $$\theta$$ 使得 $$L(\theta)$$ 大，说明这个 $$\theta$$ “很好地解释了当前数据”；
- 如果 $$\theta$$ 使得 $$L(\theta)$$ 小，说明这个 $$\theta$$ “难以解释当前数据”。

**似然 vs. 概率**：

| 概念 | 数据 | 参数 | 含义 |
|---|---|---|---|
| **概率** $$P(\mathcal{D} \mid \theta)$$ | 变量 | 固定 | 给定参数，数据出现的概率 |
| **似然** $$L(\theta; \mathcal{D})$$ | 固定 | 变量 | 给定数据，哪个参数最可能生成它 |

**数学形式相同，但视角不同**：概率是“参数固定，看数据”；似然是“数据固定，看参数”。

### 11.2 似然连乘密度，得到的是概率吗？

**不是。** 如果 $$p$$ 是高斯密度，$$L(\theta) = \prod_i p(y^{(i)} \mid x^{(i)}; \theta)$$ 是**密度的连乘**，不是概率的连乘。

**严格说**，观测到 $$y^{(i)}$$ 的“概率”是 $$P(y^{(i)} \in [y^{(i)}, y^{(i)} + dy]) \approx p(y^{(i)} \mid x^{(i)}) \, dy$$。连乘：

$$
\prod_i p(y^{(i)} \mid x^{(i)}) \, dy = \left( \prod_i p(y^{(i)} \mid x^{(i)}) \right) (dy)^n
$$

**$$(dy)^n$$ 与 $$\theta$$ 无关**，所以最大化似然等价于最大化密度连乘。**密度连乘虽然不是概率，但它的最大值位置与“真实概率”的最大值位置一致。**

**高阶补充（测度论视角，反馈 6）**：严格来说，似然函数是数据联合分布关于某个**参考测度（dominating measure）**的 **Radon-Nikodym 导数**的乘积。对于连续变量，参考测度是 Lebesgue 测度，Radon-Nikodym 导数就是概率密度 $$p(y \mid x)$$；对于离散变量，参考测度是计数测度，Radon-Nikodym 导数就是概率质量 $$P(y \mid x)$$。最大化似然函数，等价于最大化“数据在真实概率测度下的可能性”。这个视角统一了连续和离散两种情况，但初学阶段用“密度连乘 + 小区间宽度与参数无关”的解释已经足够。

### 11.3 多分类中“哪个是真实的”？没法评估？

**“真实类别”就是每个训练样本的已知标签 $$y^{(i)}$$（人工标注）。**

**多分类似然**：

$$
L(\theta) = \prod_{i=1}^n \prod_{k=1}^K (\hat y^{(i)}_k)^{\mathbf{1}\{y^{(i)} = k\}} = \prod_{i=1}^n \hat y^{(i)}_{y^{(i)}}
$$

**关键**：每个样本只贡献“模型预测它属于真实类别的概率”。

**例子**：3 分类，样本 1 真实标签 $$y^{(1)} = 2$$（狗），模型预测 $$\hat y^{(1)} = (0.1, 0.7, 0.2)$$。贡献：$$\hat y^{(1)}_2 = 0.7$$。

**似然能评估“哪个模型对真实类别更自信”**：
- 模型 A：真实类别 2，预测 $$(0.1, 0.8, 0.1)$$，贡献 0.8；
- 模型 B：真实类别 2，预测 $$(0.05, 0.8, 0.15)$$，贡献 0.8。

两者对真实类别的预测都是 0.8，似然相同。**似然不区分“其他类别的分布”——它只关心“真实类别的预测概率”。这不是“没法评估”，而是“似然函数的设计目标就是只评估真实类别”。**

**如果想评估“对其他类别的预测”，用其他指标**：

| 指标 | 评估什么 | 是否关心非真实类别 |
|---|---|---|
| **似然/交叉熵** | 模型对真实类别的预测概率 | **否**（只关心真实类别） |
| **准确率** | 预测类别是否等于真实类别 | **是**（预测错了就不对） |
| **混淆矩阵** | 每个类别被预测成什么 | **是**（显示所有类别的预测分布） |
| **校准误差** | 预测概率是否与真实频率匹配 | **是**（评估概率的可靠性） |

## 第十二部分：Logistic 的适用范围与优缺点

### 12.1 适合的场景

| 场景 | 为什么适合 |
|---|---|
| **二分类，需要概率输出** | logistic 天然输出 $$(0,1)$$ 的概率，可解释为“属于正类的可能性” |
| **线性可分或近似线性可分** | logistic 的决策边界是线性的；如果数据本身近似线性，效果很好 |
| **需要可解释性** | 参数 $$w_j$$ 可解释为“特征 $$j$$ 每增加一单位，对数几率增加 $$w_j$$” |
| **小数据、低维特征** | 参数少（$$p+1$$ 个），不容易过拟合；训练快 |
| **需要统计推断** | 可以计算参数的置信区间、假设检验（Wald 检验、似然比检验） |
| **作为神经网络的最后一层** | 深度学习分类任务的最后一层就是 logistic（二分类）或 softmax（多分类） |
| **基线模型** | 任何二分类任务都应该先试 logistic，作为基线 |

### 12.2 不适合的场景

| 场景 | 为什么不适合 | 替代方案 |
|---|---|---|
| **非线性决策边界** | logistic 只能画直线（超平面） | 神经网络、核 SVM、树模型 |
| **特征交互复杂** | 需要手工构造交互特征 | 神经网络自动学习交互 |
| **高维稀疏数据**（如文本） | 无正则化时容易过拟合 | 加 $$L_1/L_2$$ 正则，或用朴素贝叶斯、线性 SVM |
| **类别极度不平衡** | 交叉熵会被多数类主导 | 加类别权重、Focal Loss、重采样 |
| **需要多分类** | logistic 只处理二分类 | softmax 回归（logistic 的多分类推广） |
| **对离群点敏感** | 交叉熵对“自信的错误”惩罚极重 | 加正则化、用鲁棒损失 |
| **需要捕捉长程依赖** | logistic 是无记忆的 | RNN、Transformer |

### 12.3 优点

| 优点 | 说明 |
|---|---|
| **简单、快速** | 参数少，训练快，适合大规模数据 |
| **凸优化（仅限线性模型）**（反馈 2 修订） | 在 logistic 回归中，损失是凸函数，梯度下降保证收敛到全局最优。深度网络中交叉熵一般非凸，此优势不成立。 |
| **梯度简洁** | $$(\hat y - y)\tilde{x}$$，计算高效，数值稳定 |
| **概率输出** | 输出可解释为概率，便于决策和校准 |
| **可解释性强** | 参数 $$w_j$$ 对应“对数几率”，可直接解释特征影响 |
| **统计基础扎实** | 最大似然估计，有渐近正态性、置信区间、假设检验 |
| **作为神经网络的原子** | 深度学习分类任务的最后一层就是 logistic/softmax |
| **正则化友好** | $$L_1/L_2$$ 正则直接加在损失上，闭式解或高效优化 |

### 12.4 缺点

| 缺点 | 说明 | 缓解方法 |
|---|---|---|
| **只能线性决策边界** | 无法捕捉非线性关系 | 特征工程（多项式、交互项）、核方法、神经网络 |
| **对特征工程依赖强** | 需要人工构造非线性特征 | 用自动特征学习（深度学习） |
| **对多重共线性敏感** | 特征高度相关时，参数估计不稳定 | 加 $$L_2$$ 正则（岭回归）、PCA 降维 |
| **对离群点敏感** | 交叉熵对“自信的错误”惩罚极重 | 加正则化、用鲁棒损失、清洗数据 |
| **类别不平衡时偏向多数类** | 交叉熵被多数类主导 | 类别权重、Focal Loss、重采样、调整阈值 |
| **无法捕捉特征交互** | 需要手工构造交互项 | 加交互特征、用树模型/神经网络 |
| **不适用于序列/图像数据** | 无法利用空间/时间结构 | CNN、RNN、Transformer |

### 12.5 与其他模型的对比

| 模型              | 决策边界    | 输出概率    | 可解释性 | 适合场景        |
| --------------- | ------- | ------- | ---- | ----------- |
| **Logistic 回归** | 线性      | ✅       | 强    | 二分类基线、可解释场景 |
| **线性 SVM**      | 线性      | ❌（需校准）  | 中    | 高维稀疏数据      |
| **核 SVM**       | 非线性     | ❌（需校准）  | 弱    | 中小规模非线性数据   |
| **决策树/随机森林**    | 非线性（分段） | ✅（投票比例） | 中    | 表格数据、特征交互   |
| **神经网络**        | 任意非线性   | ✅       | 弱    | 大规模、复杂数据    |

## 第十三部分：验收与常见卡点

### 13.1 验收标准

合上书，你应该能做到：

1. **从伯努利分布写出似然函数**：$$L = \prod_i \phi_i^{y_i}(1-\phi_i)^{1-y_i}$$；
2. **取对数展开**：$$\ell = \sum_i [y_i \log \phi_i + (1-y_i)\log(1-\phi_i)]$$；
3. **写出交叉熵损失**：$$C_i = -[y_i \log \hat y_i + (1-y_i)\log(1-\hat y_i)]$$；
4. **从信息论定义推出交叉熵**：$$H(p,q) = -\sum p \log q$$，代入 one-hot 和模型概率；
5. **推导 $$\sigma' = \sigma(1-\sigma)$$**：从 $$\sigma(z) = 1/(1+e^{-z})$$ 出发，用链式法则推出；
6. **推导 logistic 梯度**：
   - $$\frac{\partial C_i}{\partial \hat y_i} = \frac{\hat y_i - y_i}{\hat y_i(1-\hat y_i)}$$；
   - $$\frac{\partial C_i}{\partial z_i} = \hat y_i - y_i$$（$$\sigma'$$ 约掉）；
   - $$\nabla C_i = (\hat y_i - y_i) \begin{bmatrix} 1 \\ x^{(i)} \end{bmatrix}$$；
7. **解释为什么交叉熵是凸的**：在 logistic 回归中，Hessian 是“正标量 × Gram 矩阵”，半正定；深度网络中一般非凸；
8. **解释为什么平方误差 + sigmoid 会梯度消失**：梯度多乘了 $$\sigma'$$，饱和时趋近 0；
9. **说清交叉熵与信息论的关系**：交叉熵 = KL 散度 + 熵，最小化交叉熵等价于最小化 KL 散度；
10. **说清梯度“预测 − 真实”的合理性**：方向正确、幅度合理、不因饱和消失；不是设计的，是从伯努利最大似然推导的；
11. **说清 Logistic 的适用范围和优缺点**：适合线性二分类、需要概率、可解释；不适合非线性、复杂交互、序列/图像；
12. **说清高斯分布 vs. 伯努利分布的区别**：连续 vs. 离散，密度 vs. 质量，平方误差 vs. 交叉熵；
13. **说清概率密度 vs. 概率质量的区别**：密度可以 > 1，积分等于 1；质量在 [0,1]，求和等于 1；
14. **说清 $$p(y|x)$$ 是概率还是密度**：取决于 $$y$$ 的类型，回归是密度，分类是概率；
15. **说清 $$\phi_i$$ 是什么**：模型对样本 $$i$$ 的预估条件概率，不是先验；
16. **说清 Softmax + CCE 的梯度**：同样约简为 $$\hat y - e_y$$，与二分类同构；
17. **说清 mode-covering 的语境**：主要适用于生成模型（$$p$$ 多峰），分类任务中 $$p$$ 是 one-hot，不直接适用；
18. **说清 sigmoid 的工程数值稳定性**：理论开区间 vs. 浮点数精度，需要裁剪或 `log_sigmoid`。

### 13.2 常见卡点

| 卡点 | 原因 | 应对 |
|---|---|---|
| 不知道为什么取对数 | 没理解“连乘数值下溢”和“求导方便” | 记住：取对数把连乘变连加，数值稳定，求导容易；且 $$\log$$ 单调，不改变最优解。 |
| $$\sigma'$$ 推导卡住 | 链式法则不熟练 | 设 $$u = 1 + e^{-z}$$，$$\sigma = u^{-1}$$，分步求导，最后用 $$\sigma$$ 和 $$1-\sigma$$ 表示。 |
| 梯度推导中分子分母约不掉 | 没记住 $$\sigma' = \sigma(1-\sigma)$$ | 先算 $$\partial C/\partial \hat y$$，再乘以 $$\sigma'$$，看分母是否精确约掉。 |
| 不理解为什么交叉熵是凸的 | 没看 Hessian | 在 logistic 回归中，Hessian = $$\sigma(1-\sigma) \tilde{x}\tilde{x}^\top$$，正标量 × Gram 矩阵，半正定。深度网络中非凸。 |
| 不理解平方误差为什么梯度消失 | 没对比两种损失的梯度 | 平方误差梯度多乘 $$\sigma'$$，饱和时 $$\sigma' \to 0$$；交叉熵没有这个因子。 |
| 混淆交叉熵和 KL 散度 | 没看附录 B.1 | 交叉熵 = KL 散度 + 熵。熵与参数无关，所以最小化交叉熵 = 最小化 KL 散度。 |
| 混淆概率密度和概率质量 | 没区分连续 vs. 离散 | 密度用于连续变量，可以 > 1，积分等于 1；质量用于离散变量，在 [0,1]，求和等于 1。 |
| 以为 $$p(y\|x)$$ 总是概率 | 没注意 $$y$$ 的类型 | 回归的 $$y$$ 连续，$$p(y\|x)$$ 是密度；分类的 $$y$$ 离散，$$p(y\|x)$$ 是概率。 |
| 以为 $$\phi_i$$ 是先验 | 没理解“条件概率” | $$\phi_i = P(y^{(i)}=1\|x^{(i)};\theta)$$ 依赖输入 $$x^{(i)}$$，不是先验。 |
| 以为似然连乘密度得到概率 | 没理解“密度的连乘不是概率” | 密度连乘不是概率，但最大化它的位置与最大化真实概率一致（小区间宽度与参数无关）。 |
| 以为多分类似然“没法评估” | 没理解“每个样本只贡献真实类别的概率” | 似然能评估“哪个模型对真实类别更自信”；要评估“对其他类别的预测”用准确率、混淆矩阵。 |
| 以为多分类梯度不简洁 | 没看 Softmax 梯度约简 | Softmax 雅可比与 CCE 导数结合后，同样约简为 $$\hat y - e_y$$，与二分类同构。 |
| 以为 mode-covering 适用于分类任务 | 没区分生成模型和判别模型 | Mode-covering 主要适用于生成模型（$$p$$ 多峰）；分类任务中 $$p$$ 是 one-hot 单峰，不直接适用。 |
| 以为 sigmoid 在工程中总能避免 0/1 | 没考虑浮点数精度 | 实践中需要裁剪 $$\hat y$$ 或用 `log_sigmoid` 等数值稳定函数。 |

### 13.3 延伸思考

1. **如果 $$y$$ 不是 0/1 而是 $$-1/+1$$**，交叉熵的形式会怎样变？提示：用 $$y \in \{-1, +1\}$$ 时，$$P(y \mid x) = \sigma(y z)$$，损失是 $$-\log \sigma(y z)$$。
2. **如果标签有噪声（如 10% 的标签被随机翻转）**，交叉熵还合适吗？提示：需要 label smoothing 或噪声鲁棒损失。
3. **为什么多标签分类用 sigmoid + BCE，而不是 softmax + 交叉熵？** 提示：softmax 假设标签互斥，sigmoid 允许标签共存。
4. **交叉熵的梯度 $$(\hat y - y)\tilde{x}$$ 和线性回归的梯度有什么联系？** 提示：形式完全一样，区别在于 $$\hat y$$ 的定义不同（线性 vs. sigmoid）。
5. **如果 sigmoid 换成 tanh**，交叉熵的形式和梯度会怎样变？提示：tanh 输出 $$(-1, 1)$$，需要重新定义概率映射。
6. **交叉熵小但分布差异大——你能构造一个具体的例子吗？** 提示：$$q$$ 在 $$p$$ 的空白区放质量，前向 KL 不惩罚。
7. **为什么大模型用交叉熵而不是其他损失？** 提示：与任务匹配、梯度简洁、可扩展、经验成功。
8. **Focal Loss 和交叉熵的区别是什么？** 提示：Focal Loss 增加调制因子 $$(1-p_t)^\gamma$$，降低易学样本权重。
9. **Softmax + CCE 的梯度为什么也是 $$\hat y - y$$？** 提示：Softmax 雅可比 $$\hat y_k(\delta_{kj} - \hat y_j)$$ 与 CCE 导数结合，约简为 $$\hat y - e_y$$。

## 第十四部分：核心问答速查表

| 问题 | 核心答案 |
|---|---|
| **为什么用 sigmoid？** | 把线性输出 $$(-\infty, +\infty)$$ 映射到概率 $$(0, 1)$$。 |
| **sigmoid 能达到 0 和 1 吗？** | 理论上不能，输出在开区间 $$(0,1)$$。工程上浮点数可能算出精确 0/1，需裁剪或 `log_sigmoid`。 |
| **为什么用交叉熵而不是平方误差？** | ① 交叉熵 = 伯努利最大似然，统计正确；② 在 logistic 回归中交叉熵是凸的，平方误差是非凸的；③ 交叉熵梯度是“预测减标签”，不会因饱和而消失。 |
| **伯努利似然是什么？** | $$L = \prod_i \phi_i^{y_i}(1-\phi_i)^{1-y_i}$$，其中 $$\phi_i = \sigma(w^\top x^{(i)} + b)$$。 |
| **对数似然是什么？** | $$\ell = \sum_i [y_i \log \phi_i + (1-y_i)\log(1-\phi_i)]$$。 |
| **交叉熵损失是什么？** | $$C_i = -[y_i \log \hat y_i + (1-y_i)\log(1-\hat y_i)]$$。 |
| **交叉熵从信息论怎么推？** | $$H(p,q) = -\sum p \log q$$，代入 $$p$$ 为 one-hot、$$q$$ 为模型概率，得到 $$C_i = -\log \hat y_y$$（多分类）或 BCE（二分类）。 |
| **$$\sigma'$$ 是什么？** | $$\sigma'(z) = \sigma(z)(1-\sigma(z))$$。推导：设 $$u = 1+e^{-z}$$，分步链式法则。 |
| **$$\sigma'$$ 为什么关键？** | 它和交叉熵的导数分母精确约掉，使梯度变成极简的 $$\hat y - y$$。 |
| **logistic 梯度是什么？** | $$\nabla C_i = (\hat y_i - y_i) \begin{bmatrix} 1 \\ x^{(i)} \end{bmatrix}$$。 |
| **梯度推导的步骤？** | ① $$\partial C/\partial \hat y = (\hat y - y)/(\hat y(1-\hat y))$$；② 乘以 $$\sigma' = \hat y(1-\hat y)$$，约掉；③ 得到 $$\partial C/\partial z = \hat y - y$$；④ 乘以 $$\partial z/\partial \theta = \tilde{x}$$。 |
| **为什么交叉熵是凸的？** | 在 logistic 回归中，Hessian = $$\sigma(1-\sigma)\tilde{x}\tilde{x}^\top$$，正标量 × Gram 矩阵，半正定。深度网络中一般非凸。 |
| **为什么平方误差 + sigmoid 梯度消失？** | 梯度多乘 $$\sigma'$$，饱和时 $$\sigma' \to 0$$，梯度消失。交叉熵没有这个因子。 |
| **交叉熵与 KL 散度的关系？** | 交叉熵 = KL 散度 + 熵。熵与参数无关，最小化交叉熵 = 最小化 KL 散度。 |
| **交叉熵与信息论的关系？** | 交叉熵 $$H(p, q) = -\sum p \log q$$，在二分类下就是 BCE。 |
| **最小化交叉熵等价于最大化似然？** | 是。$$C = -\frac{1}{n}\ell$$，取负号翻转优化方向，$$1/n$$ 是常数。 |
| **“交叉熵越小越相似，预测越准，损失越小”对吗？** | 交叉熵越小 $$\iff$$ KL 散度越小 $$\iff$$ $$q$$ 越接近 $$p$$（相似，对）；通常预测越准（但交叉熵和准确率不等价）；损失越小（对）。 |
| **交叉熵小但分布差异大可能吗？** | 可能。前向 KL 只惩罚“$$q$$ 在 $$p$$ 有质量处覆盖不足”，不惩罚“$$q$$ 在 $$p$$ 没质量处乱放质量”。四种情况：$$q$$ 在空白区乱放、$$p$$ 重尾 $$q$$ 轻尾、经验交叉熵过拟合、矩匹配但高阶不匹配。**注意：这主要适用于生成模型；分类任务中 $$p$$ 是 one-hot 单峰，不直接适用。** |
| **为什么大模型用交叉熵？** | 与任务匹配（多分类）、梯度简洁、可扩展、经验成功。 |
| **交叉熵有什么改进方案？** | Focal Loss、标签平滑、NTL（数值回归）、RLHF/DPO（偏好优化）、f-散度、对比学习、谐波损失、GCE、Lovász Loss。 |
| **多标签分类用什么？** | sigmoid + BCE（每个标签独立），不是 softmax + 交叉熵（softmax 假设互斥）。 |
| **logistic 回归和深度学习的关系？** | logistic 回归是“单层 + sigmoid + BCE”的浅层网络；深度学习只是把输入 $$x$$ 换成学到的特征 $$h$$，最后一层仍是 logistic。 |
| **高斯分布 vs. 伯努利分布？** | 高斯是连续分布，密度可 > 1，最大似然推出平方误差（适合回归）；伯努利是离散二值分布，质量在 [0,1]，最大似然推出交叉熵（适合二分类）。 |
| **概率密度 vs. 概率质量？** | 密度用于连续变量，可以 > 1，积分等于 1；质量用于离散变量，在 [0,1]，求和等于 1。 |
| **$$p(y\|x)$$ 是概率还是密度？** | 取决于 $$y$$ 的类型：回归（连续）→ 密度；分类（离散）→ 概率。 |
| **$$\phi_i$$ 是什么？先验还是预估？** | $$\phi_i = P(y^{(i)}=1\|x^{(i)};\theta)$$ 是模型对样本 $$i$$ 的预估条件概率。不是先验（先验不看 $$x$$），依赖输入和参数。 |
| **似然函数是什么？和样本顺序无关吗？** | 参数 $$\theta$$ 的函数，表示“在 $$\theta$$ 下观测到当前数据的概率/密度”。i.i.d. 下是连乘，与样本排列顺序无关。 |
| **似然连乘密度得到概率吗？** | 不是。密度连乘不是概率，但最大化它的位置与最大化真实概率一致（小区间宽度与参数无关）。严格说是 Radon-Nikodym 导数的乘积。 |
| **多分类中“哪个是真实的”？没法评估？** | 真实类别是已知标签 $$y^{(i)}$$。似然 $$L = \prod_i \hat y^{(i)}_{y^{(i)}}$$，每个样本只贡献真实类别的概率，能评估“哪个模型对真实类别更自信”。要评估“对其他类别的预测”用准确率、混淆矩阵。 |
| **Softmax + CCE 的梯度是什么？** | $$\nabla_z C_i = \hat y - e_y$$，与二分类的 $$\hat y - y$$ 同构。Softmax 雅可比与 CCE 导数结合，精确约简。 |
| **梯度“预测 − 真实”为什么合理？** | ① 方向正确；② 幅度合理（错得越多更新越大）；③ 不因饱和消失。不是设计的，是从伯努利最大似然推导的——sigmoid 导数与交叉熵导数分母精确约掉。 |
| **logistic 是“设计”的还是“筛选”的？** | 梯度是推导的（伯努利最大似然）。但“sigmoid + 交叉熵”组合是历史实践筛选的（比平方误差、绝对误差、hinge 更适合概率二分类）。 |
| **直觉上为什么是“预测 − 真实”？** | 它是“当前偏差”：正数高估，负数低估。梯度下降就是“按偏差纠正”——偏差越大纠正越狠，偏差为零停止。像调音量、像老师批改作业。 |
| **Logistic 的适用范围？** | 适合：二分类需要概率、线性可分、可解释、小数据低维、统计推断、神经网络最后一层、基线。不适合：非线性边界、复杂交互、高维稀疏、极度不平衡、多分类、序列/图像。 |
| **Logistic 的优点？** | 简单快速、凸优化（仅限线性模型）、梯度简洁、概率输出、可解释性强、统计基础扎实、正则化友好、神经网络的原子。 |
| **Logistic 的缺点？** | 只能线性边界、依赖特征工程、对共线性敏感、对离群点敏感、类别不平衡偏向多数类、无法捕捉特征交互、不适用于序列/图像。 |
| **mode-covering 在分类任务中适用吗？** | 不直接适用。Mode-covering 主要适用于生成模型（$$p$$ 多峰）；分类任务中 $$p$$ 是 one-hot 单峰，不会导致“在空白区乱放质量”的灾难。 |
| **sigmoid 的工程数值稳定性怎么处理？** | 裁剪 $$\hat y$$ 到 $$[\epsilon, 1-\epsilon]$$，或用 `log_sigmoid`/`softplus` 直接计算 $$\log \sigma(z)$$，避免先算 $$\sigma(z)$$ 再取对数。 |
