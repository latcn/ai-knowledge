## 一、总公式：一切模型的母公式

$$a^{[\ell-1]}\xrightarrow{\ \text{Affine}\ }z^{[\ell]}:=W^{[\ell]}a^{[\ell-1]}+b^{[\ell]}\xrightarrow{\ \text{Activation}\ }a^{[\ell]}:=S^{[\ell]}(z^{[\ell]})$$

$$y=f_\theta(x)=f^{[L]}_{\theta^{[L]}}\Big(f^{[L-1]}_{\theta^{[L-1]}}\big(\cdots f^{[1]}_{\theta^{[1]}}(x)\cdots\big)\Big),\qquad x=a^{[0]},\ y=a^{[L]}$$

**学习** $=\min_\theta C(\theta)$。

## 二、第 2 章：把学习写成优化

| 要算的东西 | 公式 |
|---|---|
| 多元线性模型 | $y=b+w^\top x+\epsilon=\theta^\top\tilde x+\epsilon$ |
| 梯度 | $\nabla_\theta\|y-X\theta\|^2=-2X^\top y+2X^\top X\theta$ |
| 正规方程 | $X^\top X\theta=X^\top y$ |
| **最小二乘解** | $\hat\theta=(X^\top X)^{-1}X^\top y=X^\dagger y$ |
| 伪逆 | $X^\dagger=V\Sigma^+U^\top$ |
| 梯度下降 | $\theta^{(t+1)}=\theta^{(t)}-\alpha\nabla C(\theta^{(t)})$ |
| 线性模型梯度 | $\nabla C=\frac{2}{n}X^\top(X\theta-y)$ |
| 步长上界 | $\alpha<\dfrac{2}{\lambda_{\max}(X^\top X/n)}$ |
| **偏差-方差-噪声** | $\mathbb{E}_{\text{unseen}}=\underbrace{(\mathbb{E}[\hat f]-\mathbb{E}[f])^2}_{\text{Bias}^2}+\underbrace{\mathrm{Var}(\hat f)}_{\text{Var}}+\underbrace{\mathbb{E}[\epsilon^2]}_{\text{不可约}}$ |
| 岭回归 | $\hat\theta=(X^\top X+\lambda I)^{-1}X^\top y$ |
| PCA | $\max_{\|v\|=1}v^\top Sv$；$Sv_i=\lambda_i v_i$；$\lambda_i=\sigma_i^2/n$ |

## 三、第 3 章：基本损失与梯度

| 要算的东西 | 公式 |
|---|---|
| sigmoid | $\sigma(u)=\frac{1}{1+e^{-u}}$，$\sigma'=\sigma(1-\sigma)$ |
| softmax | $\mathrm{softmax}(z)_i=\frac{e^{z_i}}{\sum_j e^{z_j}}$ |
| 二元交叉熵 | $-\big[y\log\hat y+(1-y)\log(1-\hat y)\big]$ |
| 分类交叉熵 | $-\sum_k 1\{y=k\}\log\hat y_k=-\log\hat y_y$ |
| **logistic 梯度** | $\nabla C_i=(\sigma(w^\top x^{(i)}+b)-y^{(i)})\begin{bmatrix}1\\x^{(i)}\end{bmatrix}$ |
| **softmax 梯度** | $\dfrac{\partial C_i}{\partial b}=\hat y-e_{y^{(i)}}$，$\dfrac{\partial C_i}{\partial W}=(\hat y-e_{y^{(i)}})x^{(i)\top}$ |
| softmax 雅可比 | $\partial\hat y_k/\partial z_j=\hat y_k(\delta_{kj}-\hat y_j)$ |

> **一句话**：$\sigma'=\sigma(1-\sigma)$ 与 softmax 雅可比，就是"梯度 = 预测 − 标签"的全部来源。

## 四、第 4 章：ADAM 与自动微分

**ADAM**（$\alpha$ 学习率，$\beta$ 动量，$\gamma$ RMSProp；$t$ 从 0 起）

$$g=\nabla C_{I_t}(\theta);\quad v\leftarrow\beta v+(1-\beta)g;\quad s\leftarrow\gamma s+(1-\gamma)(g\odot g)$$
$$\hat v=\frac{v}{1-\beta^{t+1}};\quad \hat s=\frac{s}{1-\gamma^{t+1}};\quad \theta\leftarrow\theta-\alpha\frac{\hat v}{\sqrt{\hat s}+\epsilon}$$

| 要算的东西 | 公式 |
|---|---|
| 指数平滑 | $\bar u^{(t+1)}=\beta\bar u^{(t)}+(1-\beta)u^{(t)}$ |
| 动量 | $v^{(t+1)}=\beta v^{(t)}+(1-\beta)\nabla C(\theta^{(t)})$；$\theta^{(t+1)}=\theta^{(t)}-\alpha v^{(t+1)}$ |
| AdaGrad / RMSProp | $s_i=\sqrt{\sum_\tau(\partial C/\partial\theta_i)^2}$ ／ $s_i=\gamma s_i+(1-\gamma)(\cdot)^2$ |
| 前向模式（JVP） | $\dot a_i=\nabla f_i(u)^\top\dot u$ |
| **反向模式（VJP）** | $\gamma_i=\frac{\partial C}{\partial a_i}$；$\gamma_i=\sum_k\frac{\partial a_{i_k}}{\partial a_i}\gamma_{i_k}$ |
| 牛顿法 | $\theta^{(t+1)}=\theta^{(t)}-H_t^{-1}\nabla C(\theta^{(t)})$ |

> **代价**：前向模式求全部梯度需 $\Theta(d)$ 次遍历；反向模式**一次遍历**（因为 $C$ 是标量）。

## 五、第 5 章：反向传播 ★

$$\delta^{[\ell]}=\mathrm{Diag}\big(\dot\sigma^{[\ell]}(z^{[\ell]})\big)W^{[\ell+1]\top}\delta^{[\ell+1]},\qquad \ell=L-1,\dots,1$$

$$g^{[\ell]}_W=\delta^{[\ell]}a^{[\ell-1]\top}\ (N_\ell\times N_{\ell-1}),\qquad g^{[\ell]}_b=\delta^{[\ell]}\ (N_\ell)$$

**最后一层**：$\delta^{[L]}=\partial C/\partial z^{[L]}$；softmax+交叉熵时直接 $\delta^{[L]}=\hat y-e_k$。

| 要算的东西 | 公式 |
|---|---|
| **梯度消失/爆炸** | 前向 $\hat y=W^{[L]}W^{L-1}x$；反向 $\delta^{[\ell]}=(W^\top)^{L-\ell}\delta^{[L]}$ |
| Xavier / He | $\breve w_\ell=\frac{1}{N_{\ell-1}}$（tanh）／$\frac{2}{N_{\ell-1}}$（ReLU）／$\frac{2}{N_{\ell-1}+N_\ell}$ |
| BatchNorm | $\bar z=\frac{z-\hat\mu}{\sqrt{\hat\sigma^2+\varepsilon}}$；$\tilde z=\gamma\odot\bar z+\beta$ |
| 权重衰减 | $\theta^{(t+1)}=(1-\alpha\lambda)\theta^{(t)}-\alpha\nabla C(\theta^{(t)})$ |

> **两条独立坏路径**：① 矩阵幂（换 ReLU **治不了**）；② 激活饱和（ReLU **能治**）。

## 六、第 6 章：卷积

| 要算的东西 | 公式 |
|---|---|
| **输出尺寸** | $M_h^{[1]}=1+\Big\lfloor\dfrac{M_h^{[0]}-d_h(K_h-1)-1+p_h}{s_h}\Big\rfloor$ |
| 无 padding/stride | $(M_h-K_h+1)\times(M_v-K_v+1)$ |
| same padding | $p=K-1$ |
| **参数量** | $M_c^{[\ell]}\big(M_c^{[\ell-1]}K_hK_v+1\big)$ ← **不含 $M_h,M_v$** |
| 全连接参数量 | $N^{[\ell-1]}N^{[\ell]}+N^{[\ell]}$ |
| 计算量 | $\text{MACs}\approx M_c^{[\ell]}M_h^{[\ell]}M_v^{[\ell]}M_c^{[\ell-1]}K_hK_v$ |
| 残差 | $y=x+F(x)$，$\partial a^{[\ell+\tilde\ell]}/\partial u=I+\partial r/\partial u$ |

**暴力对比**：输入 $224^2=50176$、$K=3\times3$、输出 $222^2=49284$ 神经元  
⟹ 全连接 $49284\times50177=\mathbf{2{,}472{,}923{,}268}$；卷积 $3\times3+1=\mathbf{10}$。

## 七、第 7 章：序列与注意力

| 要算的东西 | 公式 |
|---|---|
| RNN | $h^{(t)}=S_h(W_{hh}h^{(t-1)}+W_{hx}x^{(t)}+b_h)$；$\hat y^{(t)}=S_y(W_{yh}h^{(t)}+b_y)$ |
| BPTT 梯度消失 | $\zeta^{(t)}=(W_{hh}^\top)^{T-t}\zeta^{(T)}$；$\partial h^{(t+1)}/\partial h^{(t)}=W_{hh}^\top\mathrm{Diag}(\dot\sigma)$ |
| LSTM | $c^{(t)}=g_f\odot c^{(t-1)}+g_i\odot\tanh(\tilde c^{(t)})$；$h^{(t)}=g_o\odot\tanh(c^{(t)})$ |
| GRU | $h^{(t)}=(1-g_u)\odot h^{(t-1)}+g_u\odot\tanh(\cdot)$ |
| **注意力权重** | $\alpha^{(t)}=S_{\text{softmax}}\big(\big[s(z_q^{(t)},z_k^{(1)}),\dots,s(z_q^{(t)},z_k^{(T_{\text{in}})})\big]^\top\big)$ |
| **上下文向量** | $u^{(t)}=\sum_\tau\alpha^{(t)}_\tau v^{(\tau)}$（因果时 $\tau\le t$） |
| 多头合并 | $u^{(t)}=\sum_{h=1}^{H}W^h_c u^{h,(t)}$ ← **加权和，非 concat** |
| 位置编码 | $r^{(t)}_{2i}=\sin(t/M^{2i/p_e})$，$r^{(t)}_{2i+1}=\cos(t/M^{2i/p_e})$，$M=10^4$ |
| LayerNorm | $\gamma\odot\frac{z-\mu_z}{\sqrt{\sigma_z^2+\varepsilon}}+\beta$ |
| 块参数量 | $4p+2N_1p+N_1+p+H(2mp+2m_vp)$；$512/2048/64/8\Rightarrow\mathbf{3{,}150{,}336}$ |

> ⚠ **本书没有 $\mathrm{softmax}(QK^\top/\sqrt{d_k})V$**；归一化写作 $\sqrt{\max(m_q,m_k)}$，定位为数值稳定性因子。

## 八、第 8 章：生成、决策、关系

| 要算的东西 | 公式 |
|---|---|
| **ELBO** | $\log p_\theta(x)=\mathrm{ELBO}+D_{\mathrm{KL}}(q_\phi(z\|x)\|p_\theta(z\|x))$ |
| ELBO 落地式 | $\mathbb{E}\log p_\theta(x\|Z)-D_{\mathrm{KL}}(q_\phi(z\|x)\|p(z))$ |
| **重参数化（VAE）** | $z^*=\mu_\phi(x)+\Gamma_\phi(x)\epsilon^*$，$\Sigma_\phi=\Gamma_\phi\Gamma_\phi^\top$ |
| 扩散累积系数 | $\gamma_t=\prod_{i=0}^{t-1}(1-\beta_i)$ |
| 扩散闭式 | $q(z_t\|x)=\mathcal{N}(z_t;\sqrt{\gamma_t}x,(1-\gamma_t)I)$ |
| 噪声预测损失 | $\frac{\beta_{t-1}^2}{\sigma_t^2(1-\gamma_t)(1-\beta_{t-1})}\|\epsilon_t^*-\hat\mu_{\theta_t}(z_t^*)\|^2$ |
| GAN | $\max_\theta\min_\phi C_\theta$；$C_\theta$ = 判别器交叉熵；$2\log2-2J_\theta\le\bar C$ |
| **Bellman** | $V^*(z)=\max_a\{\underbrace{r(z,a)+\gamma\sum_{z'}p^{(a)}(z'\|z)V^*(z')}_{Q^*(z,a)}\}$ |
| Q-learning | $\hat Q\leftarrow(1-\alpha_t)\hat Q+\alpha_t\big(r_t+\gamma\max_{a'}\hat Q(z_{t+1},a')\big)$ |
| GCN | $h^{[\ell]}=S\big(\tilde D^{-1/2}(A+I)\tilde D^{-1/2}h^{[\ell-1]}W^{[\ell]}+B^{[\ell]}\big)$ |

> ⚠ **两处重参数化目的不同**：VAE 是为了**让梯度穿过采样**；扩散是为了**把预测均值换成预测噪声**（其编码器没有可学参数）。

## 九、附录

| 要算的东西 | 公式 |
|---|---|
| 链式法则（雅可比） | $J_{f\circ g}(u)=J_f(g(u))J_g(u)$ |
| 矩阵乘梯度 | $\partial z/\partial W=\frac{\partial z}{\partial z}u^\top$（即 $g_W=\delta a^\top$ 的来源） |
| Jacobian 连乘 | $J_f=J_{h_L}\cdots J_{h_1}$ |
| KL / 交叉熵 / 熵 | $D_{\mathrm{KL}}(p\|q)=H(p,q)-H(p)$ |
| 多元正态 KL | $D_{\mathrm{KL}}=\frac12\big[(\mu_1-\mu_2)^\top\Sigma_2^{-1}(\mu_1-\mu_2)-m+\mathrm{tr}(\Sigma_2^{-1}\Sigma_1)+\log\frac{\det\Sigma_2}{\det\Sigma_1}\big]$ |
| 对标准正态的 KL | $\frac12\|\mu_1\|^2-\frac m2+\frac{\mathrm{tr}(\Sigma_1)}{2}-\frac{\log\det(\Sigma_1)}{2}$ |
| 对数密度 | $\log\mathcal{N}=-\frac12(x-\mu)^\top\Sigma^{-1}(x-\mu)-\frac m2\log(2\pi)-\frac12\log\det\Sigma$ |

## 十、跨章符号陷阱（最容易丢分的地方）

| 符号 | 在不同章的含义 |
|---|---|
| $\alpha$ | 学习率（2/4/5）；三元组损失的 margin（6）；RL 学习率 $\alpha_t$（8） |
| $\beta$ | 动量系数（4）；扩散每步加噪方差 $\beta_t$（8） |
| $\gamma$ | RMSProp 系数（4）；LayerNorm 缩放（7）；扩散累积系数（8） |
| $\sigma$ | 激活函数 vs 标准差／协方差 |
| $p$ | 特征数（2/3）；模型维度（7）；padding $p_h,p_v$（6）；性能函数 $P(\cdot,\cdot)$（2） |
| $L$ | 层数（5）vs 损失（6） |
| $m$ | 隐维度（3/5）；$m_q,m_k,m_v$ 注意力维度（7） |
