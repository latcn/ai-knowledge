## 2. 第一性原理：为什么需要"软寻址"

### 2.1 问题：RNN 的信息传递是"链式"的

**RNN 的痛点**（第 15–16 天）：$h^{(t)}$ 依赖 $h^{(t-1)}$——信息沿时间"逐级传递"，每级都乘 $W_{hh}$。$t=100$ 的信息传到 $t=0$，要乘 $W_{hh}^{100}$——**指数衰减**。

**LSTM/GRU 的改进**：加法路径绕开矩阵幂——但**仍是"沿时间传递"**（只是衰减慢了）。

**核心问题**：**能不能让"任意两个位置"直接连接，不经过中间的任何传递链？**

### 2.2 注意力的第一性原理：软寻址

**类比：查字典**。
- 你有一个**查询（query）** ——"我想找'苹果'的意思"；
- 字典里有**键（key）** ——每个词条；
- 你拿 query 和每个 key 比较**相似度**——"苹果"和"水果"相似度高，"苹果"和"汽车"相似度低；
- 根据相似度给每个词条一个**权重**——"水果"权重 0.8，"汽车"权重 0.01；
- 用权重对**值（value）** 做**加权平均**——得到"综合的意思"。

**这就是注意力**：**用 query 和 key 的相似度，对 value 做"软寻址"（soft addressing）**。

**关键属性**：
- **可微**：相似度、softmax、加权和都是可微的——可以端到端训练；
- **无状态**：每个位置独立计算，不依赖"上一步的状态"——可以并行；
- **全局**：每个位置直接看所有位置——**无时间衰减**。

**这三点一起，解释了为什么注意力取代了 RNN**（书中 7.4 节的核心论点）。

### 2.3 自注意力：query/key/value 从同一序列来

**自注意力（self-attention）** ：query、key、value **都来自同一个序列**。

**含义**：序列内部的每个位置，都"看"序列内部的所有位置——**建模"序列内部的关系"**（如"这个词和那个词是什么关系"）。

**交叉注意力（cross-attention）** ：query 来自一个序列，key/value 来自另一个序列——**建模"两个序列之间的关系"**（如"翻译时，目标语言的词和源语言的词是什么关系"）。

## 4. 注意力的一般框架 (7.20)(7.21)

### 4.1 打分与权重（书中 (7.20)）

**给定**：
- **query 代理向量** $z_q^{(t)}\in\mathbb{R}^{m_q}$；
- **key 代理向量** $z_k^{(1)},\dots,z_k^{(T_{\text{in}})}\in\mathbb{R}^{m_k}$；
- **打分函数** $s:\mathbb{R}^{m_q}\times\mathbb{R}^{m_k}\to\mathbb{R}$。

**注意力权重**：

$$\boxed{\alpha^{(t)} = S_{\text{softmax}}\Big(\big[s(z_q^{(t)}, z_k^{(1)}), \dots, s(z_q^{(t)}, z_k^{(T_{\text{in}})})\big]^\top\Big) \in \mathbb{R}^{T_{\text{in}}}} \tag{7.20}$$

**维度检查**：$s(\cdot,\cdot)$ 输出标量，$T_{\text{in}}$ 个拼成 $T_{\text{in}}\times 1$，softmax 保持维度。✓

### 4.2 上下文向量（书中 (7.21)）

**给定**：**value 向量** $v^{(1)},\dots,v^{(T_{\text{in}})}\in\mathbb{R}^{m_v}$。

**上下文向量**：

$$\boxed{u^{(t)} = \sum_{\tau=1}^{T_{\text{in}}}\alpha^{(t)}_\tau\,v^{(\tau)}} \tag{7.21（非因果）}$$

**因果版本**（只看前 $t$ 个）：

$$u^{(t)} = \sum_{\tau=1}^{t}\alpha^{(t)}_\tau\,v^{(\tau)} \tag{7.21（因果）}$$

**维度检查**：$\alpha^{(t)}_\tau$ 是标量，$v^{(\tau)}$ 是 $m_v\times 1$，加权和是 $m_v\times 1$。✓

### 4.3 一般框架的三个可替换部件

| 部件 | 书中写法 | 可替换为 |
|---|---|---|
| **打分函数** $s(\cdot,\cdot)$ | 内积（最简单） | General、Concat、Additive（第 5 节） |
| **归一化** | softmax | 其他（如 sparsemax，书中未提） |
| **value 来源** | 输入序列 | 可任选（如 cross-attention 用另一序列） |

**关键**：**书中没有把"注意力"绑定到"$\mathrm{softmax}(QK^\top/\sqrt{d_k})V$"这个具体形式**——它给的是**更一般的框架**。

### 4.4 "缩放因子"在一般框架里的位置

**书中原话（7.4 节）**："It is typical to have normalization as part of the score function with a factor such as $\sqrt{\max(m_q,m_k)}$. This normalization maintains score values at a reasonable range for numerical stability."

**读法**：
- **缩放是"打分函数的一部分"**；
- **作用是"数值稳定性"**；
- **因子是 $\sqrt{\max(m_q,m_k)}$**（不是 $\sqrt{d_k}$）。

**这就是书中与主流的第一处差异**——主流把"缩放"单独提出来；书中把"缩放"**内嵌进打分函数**。

## 5. 打分的四种形式

### 5.1 书中给的四种打分函数（7.4 节）

> **修订注记（审核问题 5）**：原标题"三种形式"实列四种（内积/General/Concat/Additive）——计数错误，应为"**四种形式**"。本节已修正。

**内积**（最简单，要求 $m_q=m_k$）：

$$s(z_q, z_k) = z_q^\top z_k$$

**General**（带可学矩阵 $W_s$）：

$$s(z_q, z_k) = z_q^\top W_s\, z_k,\quad W_s\in\mathbb{R}^{m_q\times m_k}$$

**Concat**（拼接后过 MLP）：

$$s(z_q, z_k) = w_s^\top\tanh\big(\tilde W_s[z_q, z_k]\big)$$

**Additive**（Bahdanau 注意力）：

$$s(z_q, z_k) = w_s^\top\tanh(W_{sa}z_q + W_{sb}z_k)$$

### 5.2 四种形式的对比

| 形式 | 参数 | 计算复杂度 | 用在哪 |
|---|---|---|---|
| **内积** | 无 | $O(m_q)$ | Transformer（最常用） |
| **General** | $W_s$ | $O(m_q m_k)$ | 一般注意力 |
| **Concat** | $\tilde W_s, w_s$ | $O(\tilde m(m_q+m_k))$ | 较少用 |
| **Additive** | $W_{sa}, W_{sb}, w_s$ | $O(\tilde m(m_q+m_k))$ | Bahdanau（RNN 时代） |

## 6. 缩放因子：$\sqrt{\max(m_q,m_k)}$ 的方差论证

### 6.1 为什么需要缩放

**问题**：内积 $q^\top k = \sum_{i=1}^{d} q_i k_i$ 的**量级随维度 $d$ 增长**。

**如果 $q_i, k_i$ 各分量独立、零均值、单位方差**：

$$\mathrm{Var}(q^\top k) = \sum_{i=1}^{d}\mathrm{Var}(q_i k_i) = \sum_{i=1}^{d}1 = d$$

**所以**：

$$\boxed{\mathrm{Var}(q^\top k) = d}$$

**后果**：当 $d$ 很大时，$q^\top k$ 的值可能很大（如 $d=512$ 时，标准差 $\sqrt{512}\approx 22.6$）。**softmax 的输入量级太大 → softmax 进入饱和区 → 梯度消失**。

### 6.2 缩放：除以 $\sqrt{d}$

$$\mathrm{Var}\Big(\frac{q^\top k}{\sqrt{d}}\Big) = \frac{d}{d} = 1$$

**含义**：**缩放后方差恒为 1**——**不随 $d$ 增长**。

### 6.3 书中为什么写 $\sqrt{\max(m_q,m_k)}$

**为什么用 $\max(m_q,m_k)$**：
- 内积要求 $m_q=m_k$；但书中允许 $m_q\neq m_k$（General 打分）；
- 用 $\max(m_q,m_k)$ 是**保守的缩放**——保证分母足够大。

**主流写 $\sqrt{d_k}$**：假设 $m_q=m_k=d_k$——**二者一致**。

**结论**：**书中的 $\sqrt{\max(m_q,m_k)}$ 是主流的 $\sqrt{d_k}$ 的"一般化版本"**。

### 6.4 数值验证

**设定**：$d=512$，$q,k$ 各分量 $\sim\mathcal{N}(0,1)$，独立。

**未缩放**：$\mathrm{Var}(q^\top k) = 512$，标准差 $\approx 22.6$。

**缩放后**：$\mathrm{Var}(q^\top k/\sqrt{512}) = 1$，标准差 $\approx 1$。✓

## 7. 自注意力（7.23)(7.24)

### 7.1 最简单的自注意力（7.23）

**query/key/value 都直接取输入**：

$$z_q^{(t)} = x^{(t)},\quad z_k^{(t)} = x^{(t)},\quad v^{(t)} = x^{(t)}$$

**因果版本**（7.23）：

$$u^{(t)} = \sum_{\tau\le t}\alpha^{(t)}_\tau\,x^{(\tau)},\quad \alpha^{(t)}_\tau = \frac{e^{s(x^{(t)}, x^{(\tau)})}}{\sum_{t'=1}^{t}e^{s(x^{(t)}, x^{(t')})}} \tag{7.23}$$

### 7.2 带参数的自注意力（7.24）

**query/key/value 是输入的线性变换**：

$$z_q^{(t)} = W_q x^{(t)},\quad z_k^{(t)} = W_k x^{(t)},\quad v^{(t)} = W_v x^{(t)}$$

**因果版本**（7.24）：

$$u^{(t)} = \sum_{\tau\le t}\alpha^{(t)}_\tau\,W_v x^{(\tau)},\quad \alpha^{(t)}_\tau = \frac{e^{s(W_q x^{(t)}, W_k x^{(\tau)})}}{\sum_{t'=1}^{t}e^{s(W_q x^{(t)}, W_k x^{(t')})}} \tag{7.24}$$

### 7.3 因果 vs 非因果

| 版本 | 看多少 | 用在哪 |
|---|---|---|
| **因果** | 只看 $\tau\le t$（前 $t$ 个） | 解码器（自回归生成） |
| **非因果** | 看所有 $\tau$ | 编码器（双向理解） |

## 8. 多头注意力（7.25)(7.26）：**加权和，不是 concat**

### 8.1 多头：多个"视角"并行

**$H$ 个头**，每个头有自己的 $W_q^h, W_k^h, W_v^h$：

$$u^{h,(t)} = \sum_{\tau=1}^{T}\alpha^{h,(t)}_\tau\,W_v^h x^{(\tau)},\quad \alpha^{h,(t)}_\tau = \frac{e^{s(W_q^h x^{(t)}, W_k^h x^{(\tau)})}}{\sum_{t'=1}^{T}e^{s(W_q^h x^{(t)}, W_k^h x^{(t')})}} \tag{7.25}$$

### 8.2 多头合并（7.26）：**加权和**

$$\boxed{u^{(t)} = \sum_{h=1}^{H}W_c^h\,u^{h,(t)}} \tag{7.26}$$

**关键**：**这是"加权和"，不是"concat + projection"**。

### 8.3 与主流写法的对比（第 3 处差异）

**主流写法**：

$$\mathrm{MultiHead}(Q,K,V) = \mathrm{Concat}(\text{head}_1,\dots,\text{head}_H)\,W_O$$

**书中写法**：

$$u^{(t)} = \sum_{h=1}^{H}W_c^h\,u^{h,(t)}$$

**二者数学上等价**（当 $W_O$ 按头分块时），**但表述不同**——书中强调"**本质是加权和**"，主流强调"**concat 这个操作**"。

**"不要纠正"**：书中这样写是**刻意的**——它想强调"多头合并本质是加权和"。

### 8.4 多头的维度分配

**典型配置**：$p=512$，$H=8$，$m=m_v=64$——**每个头的维度是 $p/H=64$**。

**参数量**（多头部分）：$H\times(2mp + 2m_vp) = 8\times 131072 = 1{,}048{,}576$。

## 9. 位置编码（7.28)(7.29)(7.30）：为什么必需

### 9.1 自注意力是置换等变的

**关键性质**：**自注意力对输入序列是"置换等变"的**。

**含义**：如果把输入序列打乱（置换 $P$），输出也只是同样打乱——**模型"不知道"词序**。

**数学**：$\mathrm{Attention}(PX) = P\,\mathrm{Attention}(X)$（无掩码时，详见第 27 节）。

**后果**：**不注入位置信息，模型无法区分"猫追狗"和"狗追猫"**。

### 9.2 位置编码：注入位置信息

**可学习位置编码**（7.28）：

$$\tilde x^{(t)} = W_1 S\big(W_2 x^{(t)} + W_3 e_t + b_2\big) \tag{7.28}$$

**正余弦位置编码**（7.29）：

$$\boxed{r^{(t)}_{2i} = \sin\Big(\frac{t}{M^{2i/p_e}}\Big),\quad r^{(t)}_{2i+1} = \cos\Big(\frac{t}{M^{2i/p_e}}\Big)} \tag{7.29}$$

（$i\in\{0,\dots,p_e/2-1\}$，$M=10{,}000$）

**加到输入上**（7.30）：

$$\tilde x^{(t)} = \big(x^{(t)}_1 + r^{(t)}_0,\ x^{(t)}_2 + r^{(t)}_1,\ \dots,\ x^{(t)}_p + r^{(t)}_{p-1}\big) \tag{7.30}$$

> **修订注记（审核问题 4）**：(7.30) 用了 $r^{(t)}_0,\dots,r^{(t)}_{p-1}$——**$p$ 个分量**。这**隐含假设 $p_e = p$**（符号表定义 $p_e = \tilde p - p$，二者只有在 $p_e=p$ 时自洽）。**原文未显式说明此假设**，读者应注意。

### 9.3 正余弦编码的性质

> **🔴 修订注记（审核问题 1，最严重硬伤）**：**原文档写"低维编码粗位置，高维编码细位置"——方向完全反了**。正确应为：
> - **$i$ 越小（低维）→ 分母 $M^{2i/p_e}$ 越接近 1 → 频率越高 → 变化越快 → 编码"细位置"**（精细区分近邻）；
> - **$i$ 越大（高维）→ 频率越低 → 变化越慢 → 编码"粗位置"**（只能区分远距离整体趋势）。
>
> **正确表述："低维细（高频）、高维粗（低频）"**。
>
> **术语纠正**：$M^{2i/p_e}$ 是"**波长/周期**"（出现在分母），**不是"频率"**。频率应为 $1/M^{2i/p_e}$。原文写"$i$ 越大，频率 $M^{2i/p_e}$ 越大"——**术语错误**（$M^{2i/p_e}$ 是波长，不是频率）。
>
> **原文 §9.4 的数值例子恰好证伪了自己的结论**：$i=0$（低维）变化快、$i=1$（高维）变化慢——这正是"低维细、高维粗"，但原文结论写"符合'低维粗、高维细'"——**自相矛盾**。
>
> **全文修正**：§9.3、§13.2、§14 等多处的"低维粗、高维细"均应改为"**低维细、高维粗**"。

**为什么用正余弦**：
- **有界**：$\sin,\cos\in[-1,1]$——不会让输入爆炸；
- **频率递减**：$i$ 越大，波长 $M^{2i/p_e}$ 越大，$\sin(t/M^{2i/p_e})$ 变化越慢——**低维细、高维粗**；
- **相对位置可推断**：$\sin(t+\Delta)$ 可以用 $\sin(t),\cos(t)$ 的线性组合表示——**模型可以从绝对位置推断相对位置**（这正是 RoPE 的出发点，详见第 29 节）。

### 9.4 数值验证

**设定**：$p_e=4$，$M=10000$，$t=1,2,3$。

**$i=0$**：$M^{2\cdot 0/4}=1$——$r^{(t)}_0=\sin(t)$，$r^{(t)}_1=\cos(t)$。
- $t=1$：$\sin(1)\approx 0.841$，$\cos(1)\approx 0.540$；
- $t=2$：$\sin(2)\approx 0.909$，$\cos(2)\approx -0.416$；
- $t=3$：$\sin(3)\approx 0.141$，$\cos(3)\approx -0.990$。

**$i=1$**：$M^{2/4}=100$——$r^{(t)}_2=\sin(t/100)$，$r^{(t)}_3=\cos(t/100)$。
- $t=1$：$\sin(0.01)\approx 0.010$，$\cos(0.01)\approx 0.99995$；
- $t=2$：$\sin(0.02)\approx 0.020$，$\cos(0.02)\approx 0.9998$；
- $t=3$：$\sin(0.03)\approx 0.030$，$\cos(0.03)\approx 0.9996$。

**观察**：低维（$i=0$）变化快，高维（$i=1$）变化慢——**符合"低维细、高维粗"**。

## 10. Transformer 块（7.31)(7.32）

### 10.1 块的内部结构

**Step 1：多头自注意力**

$$u_{[1]}^{(1)},\dots,u_{[1]}^{(T)} = \mathrm{MultiHeadSelfAttention}(a_{\text{in}}^{(1)},\dots,a_{\text{in}}^{(T)})$$

**Step 2：残差 + LayerNorm**（7.31）：

$$\boxed{u_{[2]}^{(t)} = \mathrm{LayerNorm}\big(\underbrace{a_{\text{in}}^{(t)} + u_{[1]}^{(t)}}_{\text{残差}};\gamma,\beta\big)} \tag{7.31}$$

**Step 3：前馈网络（FFN）** ：

$$u_{[3]}^{(t)} = W^{[2]}S\big(W^{[1]}u_{[2]}^{(t)} + b^{[1]}\big) + b^{[2]}$$

**Step 4：残差 + LayerNorm**：

$$a_{\text{out}}^{(t)} = \mathrm{LayerNorm}\big(u_{[2]}^{(t)} + u_{[3]}^{(t)};\tilde\gamma,\tilde\beta\big)$$

### 10.2 LayerNorm 的定义

$$\mathrm{LayerNorm}(z;\gamma,\beta) = \gamma\odot\frac{z-\mu_z}{\sqrt{\sigma_z^2+\epsilon}} + \beta$$

（$\mu_z = \frac{1}{p}\sum_i z_i$，$\sigma_z^2 = \frac{1}{p}\sum_i(z_i-\mu_z)^2$——**跨特征维，单样本**）

### 10.3 块参数量（7.32）

$$\boxed{\#\text{params} = \underbrace{4p}_{\gamma,\beta,\tilde\gamma,\tilde\beta} + \underbrace{2N_1p}_{W^{[1]},W^{[2]}} + \underbrace{N_1 + p}_{b^{[1]},b^{[2]}} + H\times(\underbrace{2mp}_{W_k^h,W_q^h} + \underbrace{2m_vp}_{W_v^h,W_c^h})} \tag{7.32}$$

**书中例子**：$p=512$，$N_1=2048$，$m=m_v=64$，$H=8$：

$$= 3{,}150{,}336$$

## 11. **与主流写法的 3 处差异（按原文不要"纠正"）**

### 11.1 差异 1：**没有** $\mathrm{softmax}(QK^\top/\sqrt{d_k})V$ 这个式子

**主流**：$\mathrm{softmax}(QK^\top/\sqrt{d_k})V$——把"内积 + 缩放 + softmax + 加权和"绑定成一个公式。

**书中**：一般框架 $s(\cdot,\cdot)$ + softmax + 加权和——$s$ 可任选。

**为什么书中这样写**：强调"**注意力是框架，不是固定公式**"。

### 11.2 差异 2：**缩放因子**写 $\sqrt{\max(m_q,m_k)}$，**不是** $\sqrt{d_k}$

**书中**：$\sqrt{\max(m_q,m_k)}$——一般化（$m_q\neq m_k$ 时也保守缩放），定位为"**数值稳定性因子**"。

**主流**：$\sqrt{d_k}$——常被当作"经验技巧"。

**"不要纠正"**：书中用 $\max$ 是**更一般的写法**。

### 11.3 差异 3：**多头合并**是加权和，**不是** concat + projection

**书中**：$u^{(t)} = \sum_{h=1}^{H}W_c^h u^{h,(t)}$——**加权和**。

**主流**：concat + projection。

**"不要纠正"**：书中写法**更本质**——它揭示了"多头合并 = 每个头独立投影后加权求和"。

### 11.4 三处差异总结

| 差异 | 主流 | 书中 | 书中的定位 |
|---|---|---|---|
| **1. 公式** | $\mathrm{softmax}(QK^\top/\sqrt{d_k})V$ | 一般框架 $s(\cdot,\cdot)$ + softmax + 加权和 | 强调"注意力是框架" |
| **2. 缩放** | $\sqrt{d_k}$ | $\sqrt{\max(m_q,m_k)}$ | 数值稳定性因子 |
| **3. 多头合并** | concat + projection | 加权和 $\sum_h W_c^h u^h$ | 本质是加权和 |

## 17. "任意两个位置直接连接"——链长分析

### 17.1 "传递链"的精确含义

**"链长"** = 从"位置 $\tau$ 的输入"到"位置 $t$ 的输出"，中间经过了几次"非线性变换 + 状态传递"。

- **链长 = 1**：位置 $\tau$ 的输入**直接**进入位置 $t$ 的计算；
- **链长 = $k$**：要经过 $k-1$ 次中间状态。

### 17.2 RNN：链长 $= |t-\tau|$

**RNN 的递推**：$h^{(t)} = S_h(W_{hh}h^{(t-1)} + \cdots)$。

**$x^{(\tau)}$ 到 $h^{(t)}$ 的链长**：**$t-\tau$**。

**衰减**：$(W_{hh}^\top)^{t-\tau}$——**链越长，衰减越厉害**。

**数值例子**（$T=20$，谱半径 0.9）：$0.9^{19}\approx 0.135$——**$x^{(1)}$ 到 $h^{(20)}$ 只剩 13.5%**。

### 17.3 自注意力：链长 $= 1$

**自注意力的公式**：$u^{(t)} = \sum_{\tau=1}^{T}\alpha_\tau^{(t)}v^{(\tau)}$。

**$v^{(\tau)}$ 到 $u^{(t)}$ 的链长**：**1**（直接加权和）。

**衰减**：$\alpha_\tau^{(t)}$ 是标量——**不随 $|t-\tau|$ 变化**。

### 17.4 关键对比

| 维度 | **RNN** | **注意力** |
|---|---|---|
| **链长** | $|t-\tau|$ | **1** |
| **信息衰减** | 指数 | **无** |
| **并行性** | 串行 | **并行** |
| **时间/内存** | $O(T)$ / $O(1)$ | **$O(T^2)$ / $O(T^2)$** |

### 17.5 "直接连接"的代价：$O(T^2)$

**"直接连接"不是免费的**——**它用 $O(T^2)$ 的时间和内存，换"链长 1、无衰减"**。

### 17.6 注意力不是"记忆"，是"每次重新看全部"

**误解**："注意力把信息'直接传过去'，像'记忆'一样。"

**纠正**：**注意力不是"记忆"，是"每次重新看全部"**。**"看"不衰减，"传"才衰减**。

### 17.7 与残差的对照

| 维度 | **残差** | **注意力** |
|---|---|---|
| **绕开什么** | **层间**传递链 | **位置间**传递链 |
| **解决什么** | 深网络的梯度消失 | 长序列的长程依赖 |
| **维度** | **深度**（$L$ 层） | **长度**（$T$ 步） |

**两者结合 = Transformer**。

## 18. "链长"与"层数"是两个独立维度

### 18.1 两个独立的维度

| 维度 | 方向 | 管什么 |
|---|---|---|
| **序列维度（横向）** | 沿时间/位置 | **同一序列内不同位置之间的信息路径** |
| **层维度（纵向）** | 沿深度 | **不同层之间的信息路径** |

**第 17–18 天讨论的"链长"，是"序列维度"的**——**与"层数（纵向）"独立**。

### 18.2 用户的理解正确

**用户说**："连接指的是同一输入信息序列的相互之间的联系路径，对于自注意力其步长都为 1，但对于 RNN，相隔的步数是两个信息的间隔。"

**完全正确**：自注意力链长 1，RNN 链长 $|t-\tau|$。

**用户说**："这部分讲的和多少层神经网络无关？"

**也正确**：**链长是"序列维度"的——与"层数"独立**。

### 18.3 为什么与"层数"无关

**单层 RNN**：链长 $|t-\tau|$ 已经存在。

**多层 RNN**：链长仍是 $|t-\tau|$——**层数增加了，但"链长"没变**。

**层维度的"直接连接"是残差**——**自注意力是"序列维度的残差"，残差是"层维度的注意力"**。

## 19. CNN 不是"链长 1"——卷积的"局部连接 + 层数累积"

### 19.1 单层卷积：局部连接，链长 $K$

**单层卷积**：$z_{i',j'} = \sum_{u,v}w_{u,v}x_{i'+u,j'+v}$。

**链长**：**1**（局部加权和）——但**$K\times K$ 之外的输入，单层卷积"看不到"**。

### 19.2 多层卷积：感受野累积，链长随层数增长

**$L$ 层 $3\times3$ 卷积**：**感受野 $(2L+1)\times(2L+1)$**，**空间链长 $L$**。

### 19.3 三者"横向路径"对照

| 机制 | **链长** | **衰减** | **能并行** |
|---|---|---|---|
| **RNN** | $|t-\tau|$ | 矩阵幂（指数） | ❌ |
| **CNN** | 层数 $L$（空间） | 层间矩阵幂（指数） | ✅ |
| **自注意力** | **1** | 无 | ✅ |

**关键**：**CNN 的"长程"靠"层数累积"**——**不是"链长 1"**。

## 20. RNN/CNN/注意力可以混合

### 20.1 混合的合法性

**三种机制作用在"不同维度"或"不同子任务"上**：

| 混合 | 各管什么 | 例子 |
|---|---|---|
| **CNN + RNN** | CNN 管"空间特征"，RNN 管"序列依赖" | CRNN（OCR、语音识别） |
| **CNN + 自注意力** | CNN 管"局部特征"，注意力管"全局关系" | Conformer（语音）、CoAtNet（视觉） |
| **RNN + 自注意力** | RNN 管"局部时序"，注意力管"全局" | Transformer-XL（段间缓存 + 段内注意力） |

### 20.2 为什么"混合"不是"矛盾"

**因为"链长"是分维度讨论的**——**CNN 的"空间链长"和自注意力的"序列链长"是两个独立的"链"**，可以**同时存在**。

### 20.3 混合的哲学

**没有"唯一正确"的机制**——**RNN、CNN、自注意力各有优劣**。**混合 = 按任务需求组合优势**——**这是现代架构设计的常态**。

## 21. 自注意力之后，RNN 还常使用吗？

### 21.1 结论

**RNN 未被完全替代，而是从"通用主力"转变为"特种部队"**——在 Transformer 的瓶颈（长上下文、资源受限、严格因果）处，RNN 的线性复杂度优势不可替代。

### 21.2 RNN 仍活跃的场景

| 场景 | 为什么 RNN 仍优 |
|---|---|
| **资源受限的边缘设备** | RNN 轻量、推理延迟低 |
| **长序列时间序列预测** | RNN 是 $O(N)$，Transformer 是 $O(N^2)$ |
| **流式/因果推理** | RNN 逐 token 处理，天然因果 |
| **数据稀缺领域** | 紧凑 RNN 比巨型 Transformer 更具竞争力 |

### 21.3 "RNN 回归"趋势

**Transformer 的瓶颈是 RNN 回归的驱动力**。

**现代 RNN 变体**：
- **xLSTM（2024）** ：指数门控 + 协方差记忆规则，具备与 Transformer 相当的联想检索能力；
- **Mamba / SSM**：**吞吐量约为同规模 Transformer 的 3–5 倍**（依基线而定；原始 Mamba 论文与 H3 等线性注意力基线对比时报告 3–5 倍提升），内存随序列长度线性增长。

> **修订注记（审核问题 7）**：原文写"Mamba 吞吐量可达 Transformer 的 **6 倍**、内存仅 **1/3**"——**这个组合的数字需要核实**。Mamba 论文（Gu & Dao, 2023）与 H3 等线性注意力基线对比时报告 **3–5 倍吞吐提升**；与 Transformer++ 对比时常引用"快约 5 倍、上下文长度可扩 8 倍"。**"6 倍 + 1/3"的组合缺乏直接文献依据**，建议改为"**约 3–5 倍吞吐提升（依基线而定）**"。

### 21.4 混合架构是主流

- **谷歌 Titans**：融合 RNN 和 Transformer，处理 **200 万 token** 上下文。

> **修订注记（审核问题 8）**：原文写"谷歌 Titans（NeurIPS 2025）"——**会议名需核实**。Titans（"Titans: Learning to Memorize at Test Time"，Google Research）正式发表渠道据审核为 **ICML 2025**（arXiv 2025 年 1 月），**非 NeurIPS 2025**。**建议核实后订正**。

- **RNN-Transformer 混合体**：循环结构（如 SSM）+ 注意力机制，保持线性复杂度的同时恢复长程精确建模。

### 21.5 一句话

> **RNN 的价值定位已转变**：不再是"万能工具"，但凭借**线性复杂度**的数学本质，在**边缘计算、流式处理、超长序列**等场景中不可替代。**未来是混合架构的天下**。

## 22. 残差 + LayerNorm 的正确组合：Post-LN、Pre-LN 与 `I + LN(·)` 为什么不是标准形式

### 22.1 结论先行

**残差和 LayerNorm 不是"并联"（`I + LN(·)`），是"串联"**：

| 写法 | 公式 | 主通路是否过 LN | 有子层 |
|---|---|---|---|
| **Post-LN**（书中 7.31） | $\mathrm{LN}(x + F(x))$ | ✅ | 有 |
| **Pre-LN**（现代主流） | $x + F(\mathrm{LN}(x))$ | ❌ | 有 |
| **你写的** | $x + \mathrm{LN}(x)$ | ✅ | **无** |

### 22.2 书里 7.31 是 Post-LN

$$u_{[2]}^{(t)} = \mathrm{LayerNorm}\big(a_{\text{in}}^{(t)} + u_{[1]}^{(t)};\gamma,\beta\big) \tag{7.31}$$

**顺序**：**先加残差，再归一化**。**主通路经过了 LayerNorm**。

### 22.3 Pre-LN：现代 LLM 的主流

$$u_{[2]}^{(t)} = a_{\text{in}}^{(t)} + F\big(\mathrm{LayerNorm}(a_{\text{in}}^{(t)};\gamma,\beta)\big)$$

**顺序**：**先归一化，再进子层，残差加在子层输出上**。**主通路不经过 LayerNorm**。

### 22.4 你的直觉"$I$ 应该独立"——在 Pre-LN 里实现

**你写的 `I + LN(x)`** 想表达"$I$ 独立于 LN"——**在 Pre-LN 里实现为"$a_{\text{in}}$ 绕过 $F$ 和 LN"**。

**不是"$I$ 和 LN 并列"，是"$I$ 绕过"**。

### 22.5 为什么 `x + LN(x)` 不是标准

**标准 Transformer 块必须有"子层"**（多头注意力或 FFN）——**`x + LN(x)` 没有子层**，**它只是"输入加自己的归一化"**——**没有任何"学习"发生**。

### 22.6 四种容易混的写法

| 写法 | 公式 | 是标准吗 | 问题 |
|---|---|---|---|
| **Post-LN**（书中 7.31） | $\mathrm{LN}(x + F(x))$ | ✅ | 主通路经过 LN |
| **Pre-LN** | $x + F(\mathrm{LN}(x))$ | ✅ | 无 |
| **你写的** | $x + \mathrm{LN}(x)$ | ❌ | 没有子层 |
| **另一种错误** | $\mathrm{LN}(x) + F(x)$ | ❌ | $F$ 作用于**未归一化的 $x$** |

## 23. Pre-LN vs Post-LN 的梯度严格对比

### 23.1 Post-LN 的梯度

**Post-LN**：$u = \mathrm{LN}(a + F(a))$。

$$\frac{\partial u}{\partial a} = \underbrace{J_{\mathrm{LN}}(a+F(a))}_{\text{LayerNorm 的雅可比}}\cdot\Big(I + \frac{\partial F}{\partial a}\Big)$$

**关键**：**$J_{\mathrm{LN}}$ 夹在梯度路径中间**——**它会"压缩"梯度**。

> **修订注记（审核问题 6）**：原文说"Post-LN 深层时累积压缩、梯度变小"——**这是单层直觉**。严格的已知结论（Xiong et al., 2020, *On Layer Normalization in the Transformer Architecture*）是：**Post-LN 在最后一层的期望梯度量级偏大（$O(\sqrt{d\ln d})$），导致需要 warmup**，而非简单的"逐层压缩→梯度变小"。**原文的"压缩累积"是直觉解释，方向对（Post-LN 训练不稳、Pre-LN 有干净 $I$ 通路），但因果链与严格结论不完全一致**。建议标注为"直觉解释"。

### 23.2 Pre-LN 的梯度

**Pre-LN**：$u = a + F(\mathrm{LN}(a))$。

$$\frac{\partial u}{\partial a} = I + \underbrace{\frac{\partial F}{\partial \mathrm{LN}}\cdot J_{\mathrm{LN}}(a)}_{\text{子层分支的雅可比}}$$

**关键**：**$I$ 这一项是"干净的"**——**不经过 LayerNorm、不经过子层**。

### 23.3 对照表

| 维度 | **Post-LN** | **Pre-LN** |
|---|---|---|
| **公式** | $\mathrm{LN}(a + F(a))$ | $a + F(\mathrm{LN}(a))$ |
| **主通路** | 经过 LN | **不经过 LN** |
| **梯度** | $J_{\mathrm{LN}}\cdot(I+\partial F/\partial a)$ | $I + \partial F/\partial \mathrm{LN}\cdot J_{\mathrm{LN}}$ |
| **训练稳定性** | 需要 warmup | **更稳** |
| **代表模型** | 原始 Transformer | GPT-2、GPT-3、LLaMA、Qwen、DeepSeek |

> **修订注记（审核问题 9）**：表中"代表模型"列写 LLaMA/Qwen/DeepSeek 用 Pre-LN——**这正确**，但**它们实际用的是 RMSNorm 而非 LayerNorm**（无均值中心化、无 $\beta$ 偏置）。**应在文中加注**："现代 LLM 多以 RMSNorm 替代 LayerNorm；梯度分析结论（Pre-LN 有干净 $I$ 通路）不变。"（详见第 29 节）

### 23.4 一句话

> **Post-LN 的梯度要穿过 LayerNorm 的雅可比；Pre-LN 的梯度有一条"不经过任何东西"的 $I$ 通路。这就是现代 LLM 用 Pre-LN 的原因。**

## 26. 【新增】位置编码为什么采用正余弦？其他方法及优劣对比

### 26.1 正余弦位置编码的设计约束

原始Transformer采用正弦/余弦函数，并非随意选择，而是为了同时满足一组严格的设计约束：

| 约束 | 要求 | 正余弦如何满足 |
|---|---|---|
| **唯一性** | 不同位置编码必须不同 | 不同频率的三角函数组合 |
| **有界性** | 编码值应在 $[-1,1]$ 内 | $\sin,\cos$ 天然有界 |
| **平滑性** | 相邻位置编码应接近 | 连续函数 |
| **相对位置可线性变换** | $PE(pos+k)$ 应是 $PE(pos)$ 的线性函数 | 存在旋转矩阵 $M_k$ 使得 $PE(pos+k)=M_k\cdot PE(pos)$ |
| **外推能力** | 推理时可处理训练中未见过的长度 | 公式对任意 $pos$ 都有定义 |

**为什么是正弦而非方波/锯齿波**：关键在于"相对位置可线性变换"——只有正余弦函数天然提供旋转矩阵表示，方波、锯齿波无法满足这一线性结构。

**几何直觉**：每一对 $(\sin(\omega_i\cdot pos),\cos(\omega_i\cdot pos))$ 是在高维环面上的旋转。位置从 $pos$ 到 $pos+k$，等价于在该环面上旋转 $k$ 角度，这就是相对位置可以被线性提取的几何根源。这一思想直接启发了后来的 **RoPE**——RoPE不再将位置编码加到词嵌入上，而是直接对Q/K向量施加旋转。

**频率设计**：频率 $\omega_i=1/10000^{2i/d_{\text{model}}}$，**低维（$i$ 小）频率高、变化快，编码细位置；高维（$i$ 大）频率低、变化慢，编码粗位置**。这与傅里叶分析的思想一致：用多频率信号叠加来表示位置。

### 26.2 位置编码的完整谱系

**第一代：绝对位置编码**

| 方法 | 代表模型 | 机制 |
|---|---|---|
| **正弦/余弦** | 原始Transformer | 固定公式 $PE(pos,2i)=\sin(pos/10000^{2i/d})$ |
| **可学习绝对编码（APE）** | GPT-2、BERT | 每个位置一个可训练向量，查表获取 |

**第二代：相对位置编码**

| 方法 | 代表模型 | 机制 |
|---|---|---|
| **Shaw相对编码** | — | 在Key/Value上加相对距离向量 |
| **Transformer-XL** | XLNet | 跨段记忆+相对位置 |
| **T5相对偏置** | T5 | 将相对位置压缩为标量偏置，加到注意力分数上 |

**第三代：旋转位置编码（RoPE）**

| 方法 | 代表模型 | 机制 |
|---|---|---|
| **RoPE** | LLaMA、Qwen、DeepSeek、Mistral | 对Q/K向量施加位置相关的旋转，使内积自然依赖相对角度 |

**替代路线：基于偏置的方法**

| 方法 | 代表模型 | 机制 |
|---|---|---|
| **ALiBi** | BLOOM | 不添加位置向量，直接在注意力分数上减一个与距离成正比的线性惩罚 |

### 26.3 主流方法优劣对比

| 方法 | 外推能力 | 长上下文表现 | 额外参数 | KV Cache兼容性 | 核心缺陷 |
|---|---|---|---|---|---|
| **正弦绝对** | 弱 | 超出训练长度急剧退化 | 无 | ✅ | 训练范围外，注意力分布无约束 |
| **可学习绝对（APE）** | **无** | 锁死在训练长度 | 有（$L_{\max}\times d$） | ✅ | 位置表固定，超出即越界 |
| **T5相对偏置** | **较好** | 长度泛化优于RoPE/ALiBi | 少量 | ✅ | 相对距离有截断上限 |
| **RoPE** | **中等**（需缩放） | 直接外推会退化；经YaRN/NTK等可扩展 | 无 | ✅ | 低频波长未转满一圈时退化为绝对位置 |
| **ALiBi** | **强** | 训1K可用4K+ | 无 | ✅ | 硬编码近因偏好，**无法利用远处信息** |

**关键洞见**：

- **APE（可学习绝对编码）** 的外推能力为零——训练长度2048，推理就不能超过2048。
- **RoPE** 是当前LLM的默认方案，但它并非"无代价的外推"——直接外推时质量退化严重，需要配合Position Interpolation、NTK-aware scaling、YaRN等长上下文扩展技术。
- **ALiBi** 的外推是"假外推"——它靠强制近距离偏好让远处token的权重接近零，所以"不会崩"，但代价是**模型确实无法利用远处信息**。
- **T5相对偏置**在长度泛化基准上反而优于RoPE和ALiBi，但在主流LLM中采用度不如RoPE。
- **一个反直觉的结论**：能够计算超出训练长度的位置特征，不等于模型能可靠理解长上下文——上下文扩展必须通过检索、推理、长代码等任务来评估。

## 27. 【新增】置换等变：严格定义、数值例子、因果掩码例外

### 27.1 严格定义

**置换等变（Permutation Equivariance）** ：设 $P$ 是任意置换矩阵（对行进行重排）。一个函数 $f$ 是置换等变的，当且仅当：

$$f(PX) = P\cdot f(X)$$

**读法**：**打乱输入的"行序"，输出也只是跟着换行——每一行的内容不变，只是位置变了**。

### 27.2 无掩码自注意力是置换等变的：三行推导

设 $X$ 是 $n\times d$ 的输入矩阵，$P$ 是 $n\times n$ 置换矩阵。自注意力：

$$\mathrm{SA}(X) = \mathrm{softmax}\Big(\frac{XW_Q(XW_K)^\top}{\sqrt{d_k}}\Big)XW_V$$

**第一步**：$Q'=PXW_Q=P(XW_Q)=PQ$，$K'=P(XW_K)=PK$。

**第二步**：$Q'K'^\top = PQ\cdot(PK)^\top = P(QK^\top)P^\top$——行列被同一个置换同时重排。

**第三步**：逐行softmax与"行列同时置换"可交换，$A'=\mathrm{softmax}(P(QK^\top)P^\top/\sqrt{d})=P\,\mathrm{softmax}(QK^\top/\sqrt{d})\,P^\top=PAP^\top$。

**第四步**：$A'V'=PAP^\top\cdot PV=PA(P^\top P)V=PAV$（因为 $P^\top P=I$）。

**结论**：$\mathrm{SA}(PX)=P\cdot\mathrm{SA}(X)$——**自注意力是置换等变的**。

### 27.3 数值例子

设 $X=\begin{bmatrix}1&0\\0&2\end{bmatrix}$，$W_Q=W_K=W_V=I$，$d_k=2$。

**原始输入**：

- 分数 $XX^\top=\begin{bmatrix}1&0\\0&4\end{bmatrix}$，除以 $\sqrt{2}$ 得 $\begin{bmatrix}0.707&0\\0&2.828\end{bmatrix}$。
- 第1行softmax：$e^{0.707}=2.028$，$e^0=1$，权重 $[0.6698,0.3302]$。
- 第1行输出：$0.6698\times[1,0]+0.3302\times[0,2]=[0.6698,0.6605]$。
- 第2行输出：$[0.0558,1.8884]$。

**打乱输入行序**：交换两行，$X'=\begin{bmatrix}0&2\\1&0\end{bmatrix}$。

- 输出变为 $[0.0558,1.8884]$ 和 $[0.6698,0.6605]$——**恰好是上面两行对调，逐位相同**。

**模型"看不出"第1行在前这件事**——输出只跟着输入换行，内容不变。

### 27.4 关键例外：因果掩码

上面的推导有一个前提：**注意力没有掩码**。

**带因果掩码时，置换等变不再成立**。因为掩码 $M$ 定义了"第 $i$ 行只能看前 $i$ 列"，这个约束是**依赖位置**的——打乱输入行序，掩码的"因果结构"被破坏，输出不再只是简单换行。

**含义**：
- **双向自注意力（编码器）** ：必须是置换等变的，所以**必须显式注入位置信息**，否则无法区分词序。
- **因果自注意力（解码器）** ：掩码本身携带了顺序信息。**仅解码器模型即使完全不加位置编码也能学到顺序**（NoPE路线）。显式位置编码在解码器上仍被普遍采用，原因是**收敛更快、外推行为更可控**，而不是"没有它就不工作"。

### 27.5 一句话总结

> **置换等变 = "打乱输入的行序，输出只是跟着换行，内容不变"**。无掩码自注意力天然具有这一性质，所以**双向Transformer必须注入位置信息**才能区分"猫追狗"和"狗追猫"。**因果掩码是例外**——掩码本身携带顺序，解码器即使不加位置编码也能学到顺序（NoPE），但显式位置编码仍因收敛更快、外推更可控而被广泛采用。

## 28. 【新增】位置编码的目的不止"词序"——三类模式与外推能力

### 28.1 结论先行

**位置编码的目的不止"词序"**，准确说是"注入位置信号，让模型能学到位置相关的模式"。具体要支撑**三类模式**：

| 模式 | 例子 | 位置编码怎么支撑 |
|---|---|---|
| **绝对位置** | "句首的词通常是大写" | 正弦 PE / APE 给每个位置唯一表示 |
| **相对距离** | "修饰语通常紧挨被修饰语" | 正弦 PE 的"相对位置可线性变换"；RoPE 的旋转角度只依赖相对距离 |
| **局部性/近因偏好** | "最近的词对当前预测影响更大" | ALiBi 的线性惩罚；RoPE 的衰减性质 |

**"词序"只是第一类（绝对位置）的通俗说法**。真正让 Transformer 有用的是**三类一起**：知道"谁在前"（绝对）、知道"谁离谁近"（相对）、知道"该不该看远处"（局部性）。

### 28.2 不同位置编码方法，目的侧重不同

| 方法 | 侧重解决什么 | 设计动机 |
|---|---|---|
| **正弦 PE** | **相对位置可线性变换** | 让模型能"从绝对位置推断相对位置" |
| **APE（可学习）** | **绝对位置记忆** | 让模型自己学"位置表示"，但外推为零 |
| **RoPE** | **相对位置旋转** | 让注意力分数**天然只依赖相对距离** |
| **ALiBi** | **近因偏好** | 硬编码"近的更重要"，换取强外推 |
| **T5 相对偏置** | **相对距离的可学习偏置** | 用少量参数学"距离多远该加多少分" |

### 28.3 "训练学习到词序"这个表述要精确化

**位置编码本身不"学习"词序**——正弦 PE 和 RoPE 是固定公式，不训练、不更新。**模型学习的是"如何利用这个信号"**——注意力权重怎么分配、FFN 怎么组合、残差怎么累积，这些是训练学到的。

**因果解码器即使完全不加位置编码，也能学到顺序**——因为**因果掩码本身携带了顺序信息**。**NoPE（No Positional Encoding）** 的研究表明：仅解码器模型在因果掩码下，不加位置编码也能达到与加位置编码相当的性能。

**但为什么主流仍加位置编码**：**收敛更快、外推行为更可控、长上下文扩展更方便**——不是"没有它就不工作"，是"有它更好训"。

### 28.4 位置编码的"额外目的"：外推与长上下文

| 方法 | 外推能力 | 机制 |
|---|---|---|
| **APE** | **零** | 位置表固定，超出即越界 |
| **正弦 PE** | 弱 | 公式对任意位置有定义，但训练范围外注意力分布无约束 |
| **RoPE** | 中等（需缩放） | 直接外推退化，需 Position Interpolation / NTK / YaRN |
| **ALiBi** | 强 | 线性惩罚让远处权重趋零，"不会崩"但"看不到远处" |
| **T5 相对偏置** | 较好 | 相对距离有截断，但泛化优于 RoPE/ALiBi |

**"词序"和外推是两个不同的问题**——词序是"能不能区分顺序"，外推是"训练 2K、推理 8K 时还能不能用"。**位置编码的设计要同时兼顾两者**。

### 28.5 精确总结

> **位置编码的主要目的不止"学词序"**。最直接目的是**打破置换等变**，但真正要支撑的是**三类模式**：绝对位置、相对距离、局部性/近因偏好。"词序"只是第一类的通俗说法。**位置编码本身不"学习"词序**（正弦/RoPE 是固定公式），模型学习的是"如何利用位置信号"。**因果解码器即使不加位置编码也能学到顺序**（掩码本身携带顺序），加位置编码是为了**收敛更快、外推更可控**。

## 29. 【新增】RMSNorm 与 RoPE：现代 LLM 的两个标配（审核缺失补充）

### 29.1 RMSNorm：现代 LLM 的归一化选择

**审核问题 9 指出**：文档通篇用 LayerNorm 讨论 LLaMA/Qwen/DeepSeek——**但它们实际用的是 RMSNorm**。

**RMSNorm 与 LayerNorm 的区别**：

| | **LayerNorm** | **RMSNorm** |
|---|---|---|
| **减均值** | ✅（$z-\mu_z$） | ❌（只用 $z$） |
| **缩放** | ✅（$\gamma\odot\frac{\cdot}{\sigma}$） | ✅（$\gamma\odot\frac{\cdot}{\text{RMS}}$） |
| **偏置** | ✅（$+\beta$） | ❌（无 $\beta$） |
| **计算量** | 需要算均值 | 只需算均方根 |

**RMSNorm 的公式**：

$$\mathrm{RMSNorm}(z) = \gamma\odot\frac{z}{\sqrt{\frac{1}{p}\sum_i z_i^2 + \epsilon}}$$

**为什么 RMSNorm 有效**：**均值中心化（$-\mu_z$）在实践中收益有限**——去均值后，主通路的"信息"可能被削弱（尤其残差流需要保留累积的均值信息）。**去掉均值中心化，保留了缩放，简化为 RMSNorm，训练更稳定、更快**。

**对梯度分析的影响**：**Pre-LN 的"干净 $I$ 通路"结论不变**——RMSNorm 也是"归一化 + 可学缩放"，只是去掉了均值中心化，梯度路径的结构（$I + \partial F/\partial \mathrm{Norm}\cdot J_{\mathrm{Norm}}$）不变。

### 29.2 RoPE：现代 LLM 的位置编码标配

**审核问题 10 指出**：文档只讲正弦位置编码，未提 **RoPE**——当前主流 LLM（LLaMA、Qwen、DeepSeek、GLM）**全部使用 RoPE**。

**RoPE（Rotary Position Embedding，Su et al. 2021）** ：

- **机制**：把位置信息编码为 Q/K 向量的**旋转角度**——对 Q/K 乘一个旋转矩阵，使注意力分数自然依赖**相对距离**；
- **不是"加一个向量"**（那是正弦 PE），而是"**乘一个旋转矩阵**"；
- **核心卖点**：$\langle R_m q, R_n k\rangle = \langle q, R_{n-m} k\rangle$——**注意力分数只依赖相对位置 $n-m$**，不依赖绝对位置。

**为什么现代 LLM 用 RoPE**：
- **相对位置可推断**（与正弦 PE 的第三条性质一致，但更直接）；
- **无需学习参数**（旋转角度由位置决定）；
- **与线性注意力/长上下文扩展兼容**（可以通过调整旋转角度外推）。

**与正弦 PE 的关系**：**RoPE 是正弦 PE 思想的"升级版"**——正弦 PE 把位置**加**到词嵌入上，RoPE 把位置**乘**（旋转）到 Q/K 上，让"相对位置"直接体现在注意力分数里，而不是靠模型"从绝对位置推断"。

### 29.3 一句话

> **现代 LLM 的两个标配：RMSNorm（替代 LayerNorm，去均值中心化，训练更稳）+ RoPE（替代正弦 PE，旋转 Q/K，相对位置直接体现在注意力分数里）。文档用 LayerNorm/正弦 PE 讨论 LLaMA/Qwen/DeepSeek 是不准确的——应加注"实际用 RMSNorm + RoPE，梯度分析结论不变"。**

## 30. 【新增】全文档终极总结（含审核修订 + 位置编码完整讨论）

### 30.1 全文档 22 条核心结论

1–8. 同第 16.1 节（注意力 = 软寻址、一般框架、缩放方差论证、多头加权和、位置编码、Transformer 块、参数量）。

9. **"链长"指"序列维度（横向）"的信息路径**——**自注意力链长 1，RNN 链长 $|t-\tau|$，CNN 链长 = 层数（感受野累积）**。**这与"层数（纵向）"是独立维度**。

10. **"直接连接"不是免费的**——**它用 $O(T^2)$ 的时间和内存，换"链长 1、无衰减"**。注意力不是"记忆"，是"每次重新看全部"。

11. **残差和注意力都是"绕开传递链"**——**残差绕开"层间"（深度），注意力绕开"位置间"（长度）**。两者结合 = Transformer。

12. **CNN 不是"链长 1"**——**单层卷积只连 $K\times K$ 邻域，多层卷积的感受野随层数累积**。

13. **三种机制可以混合**——CNN+RNN（CRNN）、CNN+自注意力（Conformer/CoAtNet）、RNN+自注意力（Transformer-XL）。

14. **RNN 未被完全替代**——在边缘、流式、超长序列场景，RNN 的线性复杂度优势不可替代。**现代 RNN 变体（xLSTM、Mamba）正在回归**——Mamba 吞吐量约为同规模 Transformer 的 3–5 倍（依基线而定）。**未来是混合架构的天下**。

15. **残差 + LayerNorm 不是"并联"（`I + LN(·)`），是"串联"**——**Post-LN**（书中 7.31）和 **Pre-LN**（现代主流）。**你写的 `I + LN(x)` 不是标准形式——没有子层**。

16. **Pre-LN 训练更稳**——**梯度有干净的 $I$ 通路**，不经过 LayerNorm；Post-LN 的梯度被 $J_{\mathrm{LN}}$ 夹住。

17. **位置编码（7.29)(7.30）**：$r^{(t)}_{2i}=\sin(t/M^{2i/p_e})$，$r^{(t)}_{2i+1}=\cos(t/M^{2i/p_e})$，$M=10^4$。**方向：低维细（高频、变化快）、高维粗（低频、变化慢）**（审核修订）。

18. **块参数量 (7.32)**：$4p+2N_1p+N_1+p+H(2mp+2m_vp)$；$p=512,N_1=2048,m=m_v=64,H=8$ 时 **3,150,336**。

**19（位置编码方法谱系）** ：正弦 PE（相对位置可线性变换）、APE（绝对位置记忆，外推为零）、RoPE（相对位置旋转，现代 LLM 标配）、ALiBi（近因偏好，强外推但看不到远处）、T5 相对偏置（可学习相对距离）。

**20（置换等变）** ：无掩码自注意力是置换等变的（$\mathrm{SA}(PX)=P\,\mathrm{SA}(X)$），所以双向 Transformer 必须注入位置信息。**因果掩码是例外**——掩码本身携带顺序，解码器即使不加位置编码也能学到顺序（NoPE）。

**21（位置编码目的不止词序）** ：位置编码要支撑**三类模式**（绝对位置、相对距离、局部性/近因偏好）+ **外推能力**。"词序"只是第一类的通俗说法。**位置编码本身不"学习"词序**（正弦/RoPE 是固定公式），模型学习的是"如何利用位置信号"。

**22（现代 LLM 两个标配）** ：**RMSNorm**（替代 LayerNorm，去均值中心化，训练更稳）+ **RoPE**（替代正弦 PE，旋转 Q/K，相对位置直接体现在注意力分数里）。文档用 LayerNorm/正弦 PE 讨论 LLaMA/Qwen/DeepSeek 不准确，应加注"实际用 RMSNorm + RoPE，梯度分析结论不变"。

### 30.2 一句话总结（终极版）

> **注意力是"软寻址"——query 和 key 比较相似度，softmax 给权重，对 value 加权和。它可微、无状态、全局，这三点让它取代 RNN。书中给的是"一般框架"（打分函数 $s$ 可任选），不是主流的 $\mathrm{softmax}(QK^\top/\sqrt{d_k})V$；缩放因子写 $\sqrt{\max(m_q,m_k)}$（方差论证：点积方差为 $d$，除以 $\sqrt d$ 后方差为 1，避免 softmax 饱和）；多头合并是加权和 $\sum_h W_c^h u^h$（不是 concat）。位置编码必需，因为自注意力是置换等变的（因果掩码例外）——**位置编码的方向是"低维细、高维粗"**（审核修订），它要支撑三类模式（绝对/相对/局部性）+ 外推能力，**不止"词序"**。**位置编码方法谱系**：正弦 PE（相对位置可线性变换）、APE（外推为零）、RoPE（现代 LLM 标配）、ALiBi（强外推但看不到远处）、T5 相对偏置。**现代 LLM 两个标配：RMSNorm + RoPE**。**"链长"是"序列维度（横向）"的概念——自注意力链长 1、RNN 链长 $|t-\tau|$、CNN 链长 = 层数——与"层数（纵向）"独立**。三种机制可以混合，RNN 在边缘/流式/超长序列仍活跃（xLSTM、Mamba），未来是混合架构。**残差 + LayerNorm 不是"并联"（`I + LN(·)`），是"串联"——Post-LN（书中 7.31）或 Pre-LN（现代主流，梯度有 $I$ 通路）**——你写的 `x + LN(x)` 不是标准（无子层）。**与主流的 3 处差异是书中刻意的"一般化"，不是笔误——不要"纠正"。**

### 30.3 思维导图（终极版）

> **注意力 = 软寻址（query/key/value）→ 一般框架（$s$ 可任选）→ 缩放 $\sqrt{\max(m_q,m_k)}$（方差论证）→ 自注意力（同源）→ 多头（多视角）→ 合并是加权和（不是 concat）→ 位置编码（置换等变 → 必须注入；**低维细、高维粗**；**不止词序——绝对/相对/局部性 + 外推**）→ 方法谱系（正弦/APE/RoPE/ALiBi/T5）→ **现代 LLM：RMSNorm + RoPE** → Transformer 块（注意力 + 残差/LN + FFN）→ 参数量 $4p+2N_1p+N_1+p+H(2mp+2m_vp)$ → **3 处差异：一般框架、$\sqrt{\max}$、加权和——按原文不要"纠正"** → **链长 = 序列维度（自注意力 1、RNN $|t-\tau|$、CNN 层数）≠ 层数** → **"直接连接"代价 $O(T^2)$** → **三种机制可混合（CRNN、Conformer、CoAtNet、Transformer-XL）** → **RNN 在边缘/流式/超长序列仍活跃（xLSTM、Mamba）** → **残差 + LN 是串联：Post-LN（书中 7.31）vs Pre-LN（现代主流）** → **你写的 `x + LN(x)` 无子层，非标准**。
