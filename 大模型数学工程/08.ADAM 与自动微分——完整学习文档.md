## 第二部分：ADAM 与 AdamW 的全称与概念

### 2.1 ADAM 的全称与定义

**ADAM = Adaptive Moment Estimation（自适应矩估计）**。

ADAM 是一种为随机目标函数设计的一阶梯度优化算法，其核心思想是**同时利用梯度的一阶矩（均值）和二阶矩（平方的均值）来动态调整每个参数的学习率**。

**【修订：审核意见】** 这里应写“二阶矩（平方的均值）”，不是“二阶矩（方差）”。$$s = \mathbb{E}[g^2]$$ 是未中心化二阶矩，方差是 $$\mathbb{E}[g^2] - (\mathbb{E}[g])^2 = s - v^2$$。文档 6.5 节明确写了 $$s - v^2 = \text{Var}(g)$$，两处应统一。

**核心机制**：
- **动量（Momentum）**：通过计算历史梯度的指数加权移动平均（一阶矩 $$v$$），为参数更新引入“惯性”，加速收敛并穿越鞍点。
- **RMSProp**：通过计算历史梯度平方的指数加权移动平均（二阶矩 $$s$$），为每个参数提供独立的自适应学习率。

**参数更新公式**：
$$
\theta_{t+1} = \theta_t - \eta \cdot \frac{\hat{m}_t}{\sqrt{\hat{v}_t} + \epsilon}
$$
其中 $$\hat{m}_t = \frac{m_t}{1-\beta_1^t}$$，$$\hat{v}_t = \frac{v_t}{1-\beta_2^t}$$ 是偏差校正后的一阶矩和二阶矩。原论文默认超参数为 $$\beta_1=0.9, \beta_2=0.999, \alpha=10^{-3}$$。

**【修订：审核意见】** LLM 训练实践中通常不用论文默认值——GPT-3 用 $$\beta_2 = 0.95$$、lr $$= 0.6\times10^{-4}$$；LLaMA 用 $$\beta_2 = 0.95$$、lr $$= 3\times10^{-4}$$ 加 cosine decay 和 warmup。$$\beta_2 = 0.95$$ 是大模型训练的常见调整（更长记忆在大规模训练中反而不稳）。文档只给原论文默认值，作为教学没问题，但与“大模型事实标准”的论断搭配时最好提一句实践值不同。

### 2.2 AdamW 的全称与定义

**AdamW = Adam with Decoupled Weight Decay（带解耦权重衰减的 Adam）**，由 Loshchilov 和 Hutter 在 2019 年提出（论文 *Decoupled Weight Decay Regularization*，ICLR 2019，arXiv 2017）。

**为什么需要 AdamW？** 标准 ADAM 中，L2 正则化（向损失函数添加 $$\frac{\lambda}{2}\|\theta\|^2$$ 项）与自适应学习率机制是**耦合**的。这导致正则化效果被自适应的学习率缩放，对梯度大的参数正则化不足，对梯度小的参数又可能过度正则化。

**AdamW 的核心改进**：将权重衰减（Weight Decay）与梯度更新**解耦**。它不再将 L2 正则项加入损失函数，而是**直接对参数本身进行衰减**，使其独立于自适应学习率的计算过程。

**更新公式**：
$$
\theta_{t+1} = \theta_t - \eta \cdot \frac{\hat{m}_t}{\sqrt{\hat{v}_t} + \epsilon} - \eta \cdot \lambda \cdot \theta_t
$$

**总结**：
- **ADAM**：结合动量和 RMSProp，实现自适应学习率，辅以偏差校正，是深度学习最常用的默认优化器（对 Transformer/LLM 类模型）。**CNN 视觉领域 SGD + 动量仍常用。**
- **AdamW**：在 ADAM 基础上解耦权重衰减，解决了 ADAM 中 L2 正则化与自适应学习率耦合的问题。实验证明效果更优，已成为训练大语言模型（LLaMA、GPT 系列）的事实标准。

## 第三部分：指数平滑的深入理解

### 3.1 指数平滑的定义

$$
\bar u^{(t+1)} = \beta \bar u^{(t)} + (1-\beta) u^{(t)}, \qquad \beta \in [0,1)
$$

**展开形式**：
$$
\bar u^{(t+1)} = (1-\beta)\sum_{\tau=0}^{t} \beta^{t-\tau} u^{(\tau)}
$$

这是对历史序列的**加权平均**，权重随时间指数衰减。越近的观测权重越大。

### 3.2 $$u^{(t)}$$ 是什么？$$u^{(0)}, u^{(1)}, u^{(2)}$$ 一样吗？

$$u^{(t)}$$ 是**序列第 $$t$$ 时刻的观测值**。一般**各不相同**。

**例 1（时间序列）**：股价 $$u^{(0)}=10, u^{(1)}=12, u^{(2)}=11$$。

**例 2（ADAM 中的梯度）**：每个 mini-batch 的梯度 $$g^{(t)}$$ 不同。

**特殊情况**：在推导偏差校正时，假设 $$u^{(t)} = u$$ 对所有 $$t$$ 成立，这是为了分析平滑值的期望行为，是分析技巧，不是实际情况。

### 3.3 为什么需要指数平滑？——四个目的

**目的 1：噪声抑制**

单个观测有噪声。平滑值是多个历史观测的加权平均，噪声被平均掉，趋势更清晰。

**目的 2：内存效率 $$O(1)$$**

要计算“所有历史的平均”，直观方法需要保存所有历史。指数平滑只需保存一个值，内存 $$O(1)$$，却能近似“所有历史的加权平均”。

**目的 3：近期权重更大**

简单平均对近期变化不敏感。指数平滑让近期观测权重更大，对趋势变化响应更快。

**目的 4：递推实现 $$O(1)$$**

每次只需一次乘加，计算 $$O(1)$$。

### 3.4 指数平滑的优缺点

**优点**：
| 优点 | 说明 |
|---|---|
| 内存 $$O(1)$$ | 只需存一个平滑值 |
| 计算 $$O(1)$$ | 每次一次乘加 |
| 近期权重更大 | 对趋势变化响应较快 |
| 通用性强 | 时间序列、优化、控制理论都用 |

**缺点**：
| 缺点 | 说明 | 缓解方法 |
|---|---|---|
| 有滞后（lag） | 平滑值落后于真实趋势 | 减小 $$\beta$$ |
| 初值偏差 | 从 0 开始，初期被压小 | 偏差校正 |
| $$\beta$$ 需要调 | $$\beta$$ 大则滞后，$$\beta$$ 小则噪声大 | 经验值（0.9） |
| 对离群点敏感 | 一个大离群点影响后续多步 | 中位数滤波或截断 |

### 3.5 与其他平滑方法的比较

| 方法 | 内存 | 计算 | 初值偏差 | 离群点鲁棒 | 响应速度 |
|---|---|---|---|---|---|
| **指数平滑** | **$$O(1)$$** | **$$O(1)$$** | **有**（需校正） | 弱 | 中 |
| 简单移动平均（SMA） | $$O(W)$$ | $$O(1)$$ | 无 | 弱 | 中 |
| 加权移动平均（WMA） | $$O(W)$$ | $$O(1)$$ | 无 | 弱 | 中 |
| 中位数滤波 | $$O(W)$$ | $$O(W\log W)$$ | 无 | **强** | 慢 |
| Kalman 滤波 | $$O(d^2)$$ | $$O(d^3)$$ | 无 | 中 | 中 |

**指数平滑的优势**：**内存和计算都是 $$O(1)$$**，这是它在大规模优化中被广泛采用的核心原因。深度网络有百万到千亿参数，每个参数需要独立的平滑值，内存和计算必须极其高效。

### 3.6 为什么 $$(1-\beta)$$ 是归一化因子？

**归一化的含义**：让所有历史观测的权重之和等于 1。

**验证**：
$$
\sum_{\tau=0}^{t} (1-\beta)\beta^{t-\tau} = (1-\beta)\sum_{k=0}^{t}\beta^k = (1-\beta)\cdot\frac{1-\beta^{t+1}}{1-\beta} = 1-\beta^{t+1}
$$

当 $$t \to \infty$$ 时，权重和 $$\to 1$$。

**如果没有 $$(1-\beta)$$**：权重和趋于 $$\frac{1}{1-\beta}$$。当 $$\beta = 0.9$$ 时，权重和趋于 10，平滑值是真实平均的 10 倍，完全错误。

**另一个视角（凸组合）**：$$\beta + (1-\beta) = 1$$，所以 $$\bar u^{(t+1)}$$ 是 $$\bar u^{(t)}$$ 和 $$u^{(t)}$$ 的凸组合，平滑值落在两者之间，不发散。

### 3.7 指数平滑 vs. 简单平均：除内存外的深层考虑

**核心问题**：如果不考虑内存，简单平均是否也有效？

**答案**：取决于梯度分布是“平稳”还是“非平稳”。

**平稳环境（如信号去噪）**：
- 简单平均方差最小（$$\sigma^2/N$$），无偏，是充分统计量。
- 指数平滑有效样本量小，方差更大。
- **简单平均更优。**

**非平稳环境（深度学习优化）**：
- 梯度分布随时间变化（训练阶段、损失地形、mini-batch 采样）。
- 简单平均的“无限记忆”导致滞后，可能错过方向反转。
- 指数平滑的“遗忘”机制快速适应。
- **指数平滑更优。**

**具体例子（梯度方向反转）**：

梯度序列 $$20, 16, 12, 8, 4, -4, -8$$（越过最优解后反转）。

- 简单平均（$$t=6$$）：$$(20+16+12+8+4-4-8)/7 = 48/7 \approx 6.86$$，**仍为正**，优化器继续往错误方向走。【复核：$$48/7 = 6.857...$$，四舍五入到两位小数是 6.86，**正确**。】
- 指数平滑（$$\beta=0.9$$）：$$v$$ 快速下降并变负，方向及时反转。

**结论**：在非平稳环境下，简单平均的“无限记忆”是**负担**，指数平滑的“遗忘”是**优势**。

**方差-偏差权衡**：

| 方法 | 方差 | 偏差（滞后） |
|---|---|---|
| 简单平均 N 个 | $$\sigma^2/N$$（小） | **大**（旧数据拖累） |
| 指数平滑 | $$\sigma^2(1-\beta)/(1+\beta)$$（中） | **小**（近期权重高） |

**在非平稳环境下，偏差的代价远大于方差。** 因为偏差导致“系统性错误”（如错过最优解），方差只是“随机波动”。

**有效样本量**：

指数平滑的有效样本量 $$\approx \frac{1+\beta}{1-\beta}$$（Kish 公式）。$$\beta = 0.9$$ 时 $$N_{\text{eff}} \approx 19$$；$$\beta = 0.999$$ 时 $$N_{\text{eff}} \approx 1999$$。指数平滑的方差是 $$\sigma^2 \cdot \frac{1-\beta}{1+\beta}$$。

**其他考虑**：
- **凸组合保证**：指数平滑的 $$\beta+(1-\beta)=1$$ 自动保证不发散，不需要显式除 N。
- **滑动窗口平均**：内存 $$O(W)$$，权重“硬切换”，不如指数平滑的“软衰减”。
- **Polyak 平均**：对参数取平均（用于输出），不是对梯度取平均（用于更新），两者不要混淆。

## 第四部分：ADAM 五步的完整推导与符号详解

### 4.1 ADAM 算法的完整形式

**初始化**：
- $$\theta^{(0)}$$：初始参数；
- $$v^{(0)} = 0$$：一阶矩（动量）初始值；
- $$s^{(0)} = 0$$：二阶矩（梯度平方的平滑）初始值；
- $$\alpha > 0$$：学习率；
- $$\beta \in [0,1)$$：动量平滑系数（常用 0.9）；
- $$\gamma \in [0,1)$$：RMSProp 平滑系数（常用 0.999）；
- $$\epsilon > 0$$：小常数，防止除零（常用 $$10^{-8}$$）。

**迭代**（对 $$t = 0, 1, 2, \dots$$）：

**第 1 步：计算梯度**
$$
g^{(t)} = \nabla C_{I_t}(\theta^{(t)})
$$

**第 2 步：更新一阶矩（动量）**
$$
v^{(t+1)} = \beta v^{(t)} + (1-\beta) g^{(t)}
$$

**第 3 步：更新二阶矩（RMSProp）**
$$
s^{(t+1)} = \gamma s^{(t)} + (1-\gamma)(g^{(t)} \odot g^{(t)})
$$

**第 4 步：偏差校正**
$$
\hat v^{(t+1)} = \frac{v^{(t+1)}}{1-\beta^{t+1}}, \qquad \hat s^{(t+1)} = \frac{s^{(t+1)}}{1-\gamma^{t+1}}
$$

**第 5 步：更新参数**
$$
\theta^{(t+1)} = \theta^{(t)} - \alpha \frac{\hat v^{(t+1)}}{\sqrt{\hat s^{(t+1)}} + \epsilon}
$$

**所有运算（$$\odot$$、$$\sqrt{\cdot}$$、除法、加法 $$\epsilon$$）都是逐元素的。**

### 4.2 符号全表

| 符号 | 名称 | 类型 | 作用 | 初值 |
|---|---|---|---|---|
| $$C$$ | 损失函数 | 标量函数 | 要最小化的目标 | — |
| $$\theta$$ | 参数向量 | 与参数形状一致 | 待优化的变量 | $$\theta^{(0)}$$ |
| $$I_t$$ | mini-batch 索引 | 随机变量 | 第 $$t$$ 步采样的数据子集 | — |
| $$g^{(t)}$$ | 梯度 | 与参数形状一致 | $$\nabla C_{I_t}(\theta^{(t)})$$ | — |
| $$v^{(t)}$$ | 一阶矩（动量） | 与参数形状一致 | 历史梯度的指数平滑，估计“平均方向” | $$0$$ |
| $$s^{(t)}$$ | 二阶矩 | 与参数形状一致 | 历史梯度平方的指数平滑，估计“平均幅度平方” | $$0$$ |
| $$\beta$$ | 一阶矩平滑系数 | 标量 $$\in [0,1)$$ | 控制动量记忆长度，常用 0.9 | — |
| $$\gamma$$ | 二阶矩平滑系数 | 标量 $$\in [0,1)$$ | 控制 RMSProp 记忆长度，常用 0.999 | — |
| $$\hat v^{(t)}$$ | 偏差校正一阶矩 | 与参数形状一致 | 校正 $$v$$ 的初值偏差 | — |
| $$\hat s^{(t)}$$ | 偏差校正二阶矩 | 与参数形状一致 | 校正 $$s$$ 的初值偏差 | — |
| $$\alpha$$ | 学习率 | 标量 $$> 0$$ | 控制步长，常用 $$10^{-3}$$ | — |
| $$\epsilon$$ | 数值稳定常数 | 标量 $$> 0$$ | 防止除零，常用 $$10^{-8}$$ | — |
| $$t$$ | 迭代步数 | 整数 | 从 0 开始计数 | $$0$$ |

**$$v, s, g$$ 的形状**：与参数 $$\theta$$ 一致。对权重矩阵是矩阵，对偏置是向量，展平后是 $$d$$ 维向量。**所有运算都是逐元素的。**

### 4.3 五步的关联

```
θ ──→ g = ∇C(θ)
        │
        ├──→ v ← βv + (1-β)g        （一阶矩：方向）
        │       │
        │       └──→ v̂ = v/(1-β^{t+1})   （偏差校正）
        │
        └──→ s ← γs + (1-γ)(g⊙g)     （二阶矩：幅度平方）
                │
                └──→ ŝ = s/(1-γ^{t+1})   （偏差校正）
                        │
θ ← θ - α · v̂/(√ŝ + ε) ←─────────────┘
```

### 4.4 为什么 $$v$$ 和 $$s$$ 的更新公式是这个形式？

**指数平滑的本质**：对历史序列的加权平均。

**为什么 $$v$$ 对梯度 $$g$$ 做平滑？** 估计梯度的“平均方向”。单个 mini-batch 的梯度有噪声，直接用它更新会导致方向震荡。平滑历史梯度，保留一致方向，抑制震荡。

**为什么 $$s$$ 对梯度平方 $$g \odot g$$ 做平滑？** 估计每个坐标的“梯度幅度平方”。这是 RMSProp 的核心。

**为什么用平方 $$g \odot g$$ 而不是 $$|g|$$？**
1. **非负性**：平方保证 $$s_j \geq 0$$，开方后可作分母；
2. **与方差一致**：$$\mathbb{E}[g_j^2] = \text{Var}(g_j) + (\mathbb{E}[g_j])^2$$；
3. **光滑性**：平方处处可导；
4. **与二阶泰勒展开一致**。

**为什么 $$\gamma$$ 通常远大于 $$\beta$$？** 二阶矩估计的是“梯度的典型幅度”，变化较慢，需要更长记忆才稳定。方向变化快，需要短记忆快速响应。

## 第五部分：偏差校正的完整推导

### 5.1 问题的根源：初值为 0 导致的系统性压小

**设输入序列恒为 $$u$$**（每个时刻梯度都是 $$u$$）：

$$
v^{(t+1)} = \beta v^{(t)} + (1-\beta) u
$$

**逐项展开**：
- $$v^{(0)} = 0$$；
- $$v^{(1)} = (1-\beta)u$$；
- $$v^{(2)} = (1-\beta)(1+\beta)u$$；
- ……
- $$v^{(t+1)} = (1-\beta)\left(\sum_{\tau=0}^t \beta^\tau\right)u = (1-\beta)\cdot\frac{1-\beta^{t+1}}{1-\beta}\cdot u = (1-\beta^{t+1})u$$。

**关键**：期望的平滑值是 $$u$$，但实际是 $$(1-\beta^{t+1})u$$，**被压小了 $$1-\beta^{t+1}$$ 倍**。

### 5.2 偏差校正：除以 $$(1-\beta^{t+1})$$

$$
\hat v^{(t+1)} = \frac{v^{(t+1)}}{1-\beta^{t+1}} = u
$$

**还原为 $$u$$，正确。**

### 5.3 数值例子：$$\beta = 0.9$$，$$u = 1$$

| $$t$$ | $$v^{(t+1)}$$ | $$1-\beta^{t+1}$$ | $$\hat v^{(t+1)}$$ |
|---|---|---|---|
| 0 | 0.1 | 0.1 | 1 |
| 1 | 0.19 | 0.19 | 1 |
| 2 | 0.271 | 0.271 | 1 |
| 5 | 0.469 | 0.469 | 1 |
| 10 | **0.686** | **0.686** | 1 |
| $$\infty$$ | 1 | 1 | 1 |

**【修订：审核意见】** 原文 $$t=10$$ 行写 $$v^{(11)} = 0.651$$，这是错误的。正确值应为 $$1 - 0.9^{11} = 1 - 0.3138 = \mathbf{0.686}$$。原文的 0.651 实际是 $$1 - 0.9^{10} = 0.6513$$，即 $$t=9$$ 的值，属于索引错位错误。已修正。

**未校正的 $$v$$ 从 0.1 缓慢爬升到 1，前期被严重压小；校正后始终是 1。当 $$t \to \infty$$ 时，校正作用消失。**

### 5.4 为什么指数是 $$t+1$$ 而不是 $$t$$？

$$t$$ 从 0 开始计数。$$t = 0$$ 时第一次更新，$$v^{(1)}$$，校正因子 $$1-\beta^1$$。一般地，$$v^{(t+1)}$$ 对应校正因子 $$1-\beta^{t+1}$$。如果 $$t$$ 从 1 开始计数，则校正因子是 $$1-\beta^t$$。两种写法等价。

### 5.5 二阶偏差校正：完全同理，但更关键

**$$\gamma = 0.999$$ 时，$$1-\gamma = 0.001$$ 非常小。前几步 $$s$$ 几乎为 0。如果不校正，分母 $$\sqrt{s}$$ 太小，步长爆炸：**

以第 1 步为例（$$t=0$$，此时 $$v^{(1)} = (1-\beta)g$$，$$s^{(1)} = (1-\gamma)g^2$$）：

$$
\text{未校正步长} = \alpha \cdot \frac{(1-\beta)g}{\sqrt{(1-\gamma)g^2}} = \alpha \cdot \frac{0.1g}{0.0316|g|} \approx 3.16\alpha
$$

**步长是正常值的 3 倍多，初期剧烈震荡。校正后步长恰好是 $$\alpha$$。这就是为什么二阶偏差校正必须做。**

**【修订：审核意见】** 应标注“以第 1 步为例”。实际步长随 $$t$$ 增大，$$1-\beta^{t+1}$$ 和 $$1-\gamma^{t+1}$$ 都趋于 1，未校正与校正的差距缩小。3.16α 是第一步的极端情况。

## 第六部分：一阶矩与二阶矩的作用及结合机制

### 6.1 一阶矩 $$v$$ 的作用：方向平滑

$$v$$ 是历史梯度的指数平滑，代表“平均方向”。作用：抑制震荡，加速一致方向。

### 6.2 二阶矩 $$s$$ 的作用：逐坐标自适应学习率

$$s$$ 是历史梯度平方的指数平滑，代表“每个坐标的梯度典型幅度平方”。$$\sqrt{s_j}$$ 是第 $$j$$ 个坐标梯度的 RMS。

### 6.3 二者如何结合？

$$
\theta^{(t+1)} = \theta^{(t)} - \alpha \frac{\hat v^{(t+1)}}{\sqrt{\hat s^{(t+1)}} + \epsilon}
$$

- **分子 $$\hat v$$**：方向（往哪走）；
- **分母 $$\sqrt{\hat s}$$**：尺度（这个参数的梯度典型幅度）；
- **比值 $$\hat v/\sqrt{\hat s}$$**：逐元素归一化的梯度。

**逐坐标看**：
$$
|\Delta \theta_j| = \alpha \frac{|v_j|}{\sqrt{s_j} + \epsilon} < \alpha
$$

每步更新幅度不超过 $$\alpha$$（严格说由于 $$\epsilon > 0$$，是严格小于）。

**【修订：审核意见】** 这个界依赖 $$\sqrt{s} \geq |v|$$，即 $$\beta = \gamma$$ 时才严格成立。应加“在 $$\beta = \gamma$$ 的理想情况下”。

### 6.4 为什么这样更新有用？——五个视角

**视角 A：符号梯度的平滑版**

$$\hat v/\sqrt{\hat s}$$ 是符号梯度的平滑版：一致方向时接近 $$\text{sign}$$，震荡方向时接近 0。

**视角 B：对角线预条件（Hessian 对角近似）**

理想牛顿法用 $$H^{-1}$$ 预条件。ADAM 用 $$\text{diag}(1/\sqrt{s})$$ 近似 $$H^{-1}$$，每个坐标的有效学习率是 $$\alpha/\sqrt{s_j}$$。

**视角 C：信噪比视角**

$$|v_j|/\sqrt{s_j}$$ 是“梯度的信噪比”。一致方向时信噪比接近 1，震荡时接近 0。

**视角 D：尺度不变性**

如果把损失乘以常数 $$c$$，梯度 $$g' = cg$$，$$v' = cv$$，$$s' = c^2 s$$，比值 $$v'/\sqrt{s'} = v/\sqrt{s}$$ **不变**。ADAM 对损失函数的整体尺度不敏感。

**视角 E：与 AdaGrad/RMSProp 的谱系**

- AdaGrad：$$s_j = \sum_\tau (g_j^{(\tau)})^2$$（累加），学习率单调递减到 0；
- RMSProp：$$s_j = \gamma s_j + (1-\gamma)(g_j)^2$$（指数平滑），学习率不衰减到 0；
- ADAM = 动量 + RMSProp + 偏差校正。

### 6.5 关键证明：$$\sqrt{s} \geq |v|$$（$$\beta = \gamma$$ 时）

**由方差非负**：
$$
s = \mathbb{E}[g^2] = \text{Var}(g) + (\mathbb{E}[g])^2 = \text{Var}(g) + v^2 \geq v^2
$$

**所以**：
$$
\sqrt{s} \geq |v| \implies \left|\frac{v}{\sqrt{s}}\right| \leq 1
$$

**含义**：
- 每步更新幅度 $$\leq \alpha$$，这是 ADAM 的“步长有界”性质；
- $$s - v^2 = \text{Var}(g)$$ 是梯度的方差；
- $$\sqrt{s}$$ 是“总幅度”（信号+噪声），$$|v|$$ 是“信号幅度”，$$|v|/\sqrt{s}$$ 是“信噪比”。

**$$\beta \neq \gamma$$ 时**：不严格成立，但通常仍成立，短暂反例会被偏差校正和指数平滑修正。

### 6.6 梯度的方差：精确公式与澄清

**方差的标准定义**：

$$
\mathrm{Var}(X) = \mathbb{E}\big[(X - \mathbb{E}[X])^2\big]
$$

**展开**：

$$
\mathbb{E}\big[(X - \mathbb{E}[X])^2\big] = \mathbb{E}\big[X^2 - 2X\mathbb{E}[X] + (\mathbb{E}[X])^2\big] = \mathbb{E}[X^2] - 2(\mathbb{E}[X])^2 + (\mathbb{E}[X])^2 = \mathbb{E}[X^2] - (\mathbb{E}[X])^2
$$

**所以**：

$$
\boxed{\mathrm{Var}(X) = \mathbb{E}[X^2] - (\mathbb{E}[X])^2}
$$

**用户常写的“E(v² - 均值²)”方向对，但标准写法是“平方的期望减期望的平方”。**

**在 ADAM 语境下**：

| 符号 | 含义 | 近似什么 |
|---|---|---|
| $$g$$ | 单个 mini-batch 的梯度（随机变量） | — |
| $$v$$ | 一阶矩，历史梯度的指数平滑 | 近似 $$\mathbb{E}[g]$$（梯度均值） |
| $$s$$ | 二阶矩，历史梯度平方的指数平滑 | 近似 $$\mathbb{E}[g^2]$$（梯度平方的均值） |

**梯度的方差**：

$$
\mathrm{Var}(g) = \mathbb{E}[g^2] - (\mathbb{E}[g])^2 \approx s - v^2
$$

**注意**：
- 这里是 $$s - v^2$$，**不是** $$v^2 - s$$；
- 因为 $$\mathrm{Var}(g) \geq 0$$，所以 $$s \geq v^2$$，即 $$\sqrt{s} \geq |v|$$——这就是步长有界性质；
- $$s$$ 和 $$v$$ 都是指数平滑，所以 $$s - v^2$$ 是方差的**近似**，不是严格等于。

**数值例子验证**：梯度序列 $$g = (1, -1, 1, -1)$$（时间序列），$$\beta = \gamma = 0.9$$。

- $$v \to 0$$（正负抵消），$$s \to 1$$（平方不抵消）；
- $$s - v^2 = 1 - 0 = 1$$；
- $$\mathrm{Var}(g) = \mathbb{E}[g^2] - (\mathbb{E}[g])^2 = 1 - 0 = 1$$；
- **验证通过**。

**另一个例子**：梯度一致 $$g = (1, 1.1, 0.9, 1.05)$$。

- $$v \approx 1.0125$$，$$s \approx 1.026$$；
- $$s - v^2 \approx 0.001$$；
- $$\mathrm{Var}(g) \approx 0.001$$；
- **验证通过**。

### 6.7 $$v/\sqrt{s}$$ 不是 $$v$$ 方向的单位向量

**数值例子**：$$v = (3, 4)$$，$$s = (9, 16)$$，$$v/\sqrt{s} = (1, 1)$$。

- $$v$$ 的方向是 $$(3, 4)$$ 方向，与 $$(1,1)$$ 不同；
- $$v/\sqrt{s}$$ 的模长是 $$\sqrt{2} \neq 1$$，**不是单位向量**。

**三种“归一化”的对比**：

| 形式 | 操作 | 模长 | 方向 |
|---|---|---|---|
| $$v/\|v\|$$ | 全局除以 $$\|v\|$$ | 1（单位向量） | 与 $$v$$ 相同 |
| $$v/\sqrt{s}$$ | 逐元素除以 $$\sqrt{s_j}$$ | 通常 $$\neq 1$$ | 与 $$v$$ 通常不同 |
| $$\text{sign}(v)$$ | 逐元素取符号 | $$\sqrt{d}$$ | 每个分量 $$\pm 1$$ |

**ADAM 用逐元素归一化**：让每个参数以“自己的典型幅度”为基准更新，不受其他参数影响。全局单位化会淹没小梯度参数；逐元素符号化对震荡过度敏感。

## 第七部分：$$v$$ 的形状与“接近 0”的精确含义

### 7.1 $$v$$ 的形状：与参数 $$\theta$$ 一致

| 参数 | 形状 | $$g$$（梯度） | $$v$$（一阶矩） | $$s$$（二阶矩） |
|---|---|---|---|---|
| 权重矩阵 $$W^{[\ell]}$$ | $$N_\ell \times N_{\ell-1}$$ | **矩阵** | **矩阵** | **矩阵** |
| 偏置向量 $$b^{[\ell]}$$ | $$N_\ell$$ | **向量** | **向量** | **向量** |
| LayerNorm 的 $$\gamma$$ | $$d$$ | **向量** | **向量** | **向量** |

展平后，$$g, v, s$$ 是 $$d$$ 维向量。**所有运算（$$\odot$$、$$\sqrt{\cdot}$$、除法、加法 $$\epsilon$$）都是逐元素的。**

### 7.2 $$g = (1, -1, 1, -1)$$ 的两种解读

**解读 A：时间序列（标量）**

一维参数 $$\theta$$，梯度是标量，4 个时间步：

- $$g^{(0)} = 1, g^{(1)} = -1, g^{(2)} = 1, g^{(3)} = -1$$。

**$$v$$ 是标量**，计算：

- $$v^{(1)} = 0.1$$；
- $$v^{(2)} = 0.9 \times 0.1 + 0.1 \times (-1) = -0.01$$；
- $$v^{(3)} = 0.9 \times (-0.01) + 0.1 \times 1 = 0.091$$；
- $$v^{(4)} = 0.9 \times 0.091 + 0.1 \times (-1) = -0.0181$$；
- ……

**$$v$$ 收敛到 0**，因为正负交替抵消。

**解读 B：4 维梯度向量**

4 维参数，每个时间步的梯度向量都是 $$g = (1, -1, 1, -1)$$。

**$$v$$ 是 4 维向量**，每个分量独立平滑：

- $$v_1 \to 1$$；
- $$v_2 \to -1$$；
- $$v_3 \to 1$$；
- $$v_4 \to -1$$。

**$$v \to (1, -1, 1, -1)$$，不是零向量。**

### 7.3 “$$v$$ 接近 0”的精确含义

**“$$v_j$$ 接近 0”**（第 $$j$$ 个分量接近 0）意味着：
- 第 $$j$$ 个参数的梯度在时间上正负交替（震荡）；
- 平滑后正负抵消，$$v_j$$ 接近 0；
- 优化器对这个参数“没有一致的方向”，步长 $$v_j/\sqrt{s_j}$$ 接近 0，**几乎不动**。

**“$$v$$ 接近 0”**（整个向量接近零向量）意味着：
- **所有**参数的梯度都在时间上震荡；
- 这种情况很少见（通常部分参数一致、部分震荡）。

**精确表述**：

> **“$$v$$ 接近 0”永远指“某个分量接近 0”，不是“整个向量是零向量”。$$v$$ 的形状始终与参数一致。之前写“$$v$$ 接近 0”时隐含假设是“一维参数的时间序列”，容易被误读为“4 维梯度向量”。更精确的写法应该是：“某个参数分量在时间步上的梯度序列是 $$g^{(0)} = 1, g^{(1)} = -1, \dots$$（时间上震荡），该分量的平滑值 $$v_j \to 0$$。”**

### 7.4 混合情况数值例子

**设定**：2 维参数 $$\theta = (\theta_1, \theta_2)$$，$$\beta = 0.9$$。

| 时间步 $$t$$ | $$g_1^{(t)}$$（震荡） | $$g_2^{(t)}$$（一致） |
|---|---|---|
| 0 | 1 | 1 |
| 1 | -1 | 1.1 |
| 2 | 1 | 0.9 |
| 3 | -1 | 1.05 |
| 4 | 1 | 1.02 |

**收敛**：$$v \to (0, 1)$$。第 1 分量接近 0（震荡），第 2 分量接近 1（一致）。

**ADAM 的更新**：
- 第 1 个参数：$$v_1/\sqrt{s_1} \approx 0$$，**几乎不动**（方向不确定）；
- 第 2 个参数：$$v_2/\sqrt{s_2} \approx 1$$，**走满步长 $$\alpha$$**（方向确定）。

## 第八部分：ADAM 的更新时机——立即更新 vs. 梯度累积

### 8.1 一个 mini-batch 对应几次前馈 + 反向？

**标准情况：一次**。$$n_b$$ 个样本被组织成矩阵 $$X \in \mathbb{R}^{n_b \times p}$$，一次前馈（矩阵运算）+ 一次反向，得到 $$n_b$$ 个样本梯度的平均，更新一次参数。**不是 $$n_b$$ 次。**

**用户可能误解的原因**：
1. 混淆“样本数”和“前馈次数”（矩阵化处理，不是循环）；
2. 混淆“mini-batch”和“epoch”（一个 epoch 有 $$n/n_b$$ 个 mini-batch，每个 mini-batch 一次）；
3. 梯度累积（显存不足时 K 个小 batch 累加，一次更新）；
4. 数据增强或多视图（特定任务的特殊设计）。

### 8.2 标准 ADAM：每个 mini-batch 立即更新

对每个 mini-batch $$I_t$$：算梯度 $$g^{(t)}$$ → 立即更新 $$v, s$$ → 立即更新 $$\theta$$。没有“等多次再更新”的环节。

**立即更新的原因**：
1. 非平稳性要求快速响应；
2. 指数平滑的递推设计要求每步吸收新信息；
3. 更新频率决定收敛速度。

### 8.3 变体：梯度累积——多次算梯度，一次更新

显存不足时，用 K 个小 batch 分别算梯度、累加，然后一次更新 $$v, s, \theta$$。

| 维度 | 标准 ADAM | 梯度累积（K 步） |
|---|---|---|
| 梯度计算频率 | 每个 mini-batch | 每个 mini-batch |
| $$v, s, \theta$$ 更新频率 | **每个 mini-batch** | **每 K 个 mini-batch** |
| 等效 batch size | $$n_b$$ | $$K \cdot n_b$$ |
| 显存 | 需要放 $$n_b$$ | 只需放 $$n_b$$，梯度累加 |
| 非平稳适应性 | **快** | 慢 K 倍 |

**梯度累积是工程妥协，不是标准做法。**

### 8.4 为什么“立即更新”是标准？

- 随机优化的收敛性分析通常假设“每步用新梯度更新”；
- 立即更新让每步都有独立随机噪声，帮助逃离局部极小；
- 更新次数 = epoch 数 × (n / n_b)。立即更新让相同 epoch 数下参数走得最快。

## 第九部分：梯度怎么计算？和损失的关系？

### 9.1 梯度的定义

$$
\nabla_\theta C(\theta) = \left[\frac{\partial C}{\partial \theta_1}, \dots, \frac{\partial C}{\partial \theta_d}\right]^\top
$$

每个分量 $$\partial C/\partial \theta_j$$ 表示“第 $$j$$ 个参数增大一点，损失变化多少”。

### 9.2 梯度计算的例子

**一维二次函数**：$$C(\theta) = (\theta - 3)^2$$，$$\nabla C = 2(\theta - 3)$$。

**线性回归**：$$C = \|y - X\theta\|^2$$，$$\nabla C = 2X^\top(X\theta - y)$$。

**logistic 回归**：$$C_i = -[y_i\log\hat y_i + (1-y_i)\log(1-\hat y_i)]$$，$$\nabla C_i = (\hat y_i - y_i)\tilde{x}^{(i)}$$。

**深度网络（反向传播）**：
$$
\delta^{[\ell]} = \mathrm{Diag}(\dot\sigma^{[\ell]}(z^{[\ell]})) W^{[\ell+1]\top}\delta^{[\ell+1]}, \quad g_W^{[\ell]} = \delta^{[\ell]} a^{[\ell-1]\top}
$$

### 9.3 梯度和损失的关系：四个层面

1. **方向**：梯度指向损失增长最快的方向，负梯度指向下降最快的方向；
2. **大小**：梯度模长反映地形陡峭程度；
3. **优化**：梯度为零是局部最优的必要条件（但不充分，需 Hessian 判断）；
4. **计算**：梯度是损失对每个参数的一阶敏感度。

## 第十部分：自动微分——前向模式 vs. 反向模式

### 10.1 问题的起点

**目标**：给定 $$f: \mathbb{R}^d \to \mathbb{R}$$（损失），计算 $$\nabla f(\theta) \in \mathbb{R}^d$$。$$d$$ 可能百万到千亿。

**三种方法对比**：

| 方法 | 原理 | 代价 | 精度 |
|---|---|---|---|
| 数值微分（单侧差分） | $$\frac{f(\theta + h e_i) - f(\theta)}{h}$$ | $$d+1$$ 次前向 | 有截断误差和舍入误差 |
| 数值微分（中心差分） | $$\frac{f(\theta + h e_i) - f(\theta - h e_i)}{2h}$$ | $$2d$$ 次前向 | 精度更高 |
| 符号微分 | 计算机代数系统 | 表达式膨胀 | 精确 |
| **自动微分** | 链式法则 + 计算图 | 前向 $$O(d)$$，反向 $$O(m)$$ | 精确 |

**【修订：审核意见】** 原文写“$$d+1$$ 次前向”默认是单侧差分。中心差分是 $$2d$$ 次。应补充说明差分类型。

### 10.2 计算图

把复杂函数分解为基本操作（加、乘、sin、exp 等），用有向无环图（DAG）表示。每个节点有 primal（前向值）和 tangent/adjoint（导数值）。

**例子**：$$C(\theta) = \sin(\theta_1 \theta_2) + \exp(\theta_2 + \theta_3) - 2\theta_3$$。

节点 1：$$a_1 = \theta_1 \theta_2$$；节点 2：$$a_2 = \theta_2 + \theta_3$$；节点 3：$$a_3 = -2\theta_3$$；节点 4：$$a_4 = \sin(a_1)$$；节点 5：$$a_5 = \exp(a_2)$$；节点 6：$$a_6 = a_3 + a_4 + a_5$$。

### 10.3 前向模式（JVP）：传播雅可比-向量积

**核心公式**：
$$
\dot a_i = \sum_{k=1}^{\ell_i} \frac{\partial f_i(u)}{\partial u_k} \dot u_k = \nabla f_i(u)^\top \dot u
$$

**$$\theta_i$$ 和 $$\dot\theta_i$$ 的区别**：

| 符号 | 含义 | 类型 | 例子 |
|---|---|---|---|
| $$\theta_i$$ | 第 $$i$$ 个输入的具体数值 | 标量（常量） | $$\theta_2 = 2$$ |
| $$\dot\theta_i$$ | 第 $$i$$ 个输入方向的切向量分量 | 标量（0 或 1，或任意方向） | 求 $$\partial C/\partial \theta_2$$ 时，$$\dot\theta = (0, 1, 0)$$ |

**逐步计算**（$$j = 2$$，$$\theta = (\pi/6, 2, 5)$$，$$\dot\theta = (0, 1, 0)$$）：

- 节点 1：$$a_1 = \pi/3$$，$$\dot a_1 = \theta_2 \dot\theta_1 + \theta_1 \dot\theta_2 = 0 + (\pi/6)(1) = \pi/6$$；
- 节点 2：$$a_2 = 7$$，$$\dot a_2 = \dot\theta_2 + \dot\theta_3 = 1$$；
- 节点 3：$$a_3 = -10$$，$$\dot a_3 = -2\dot\theta_3 = 0$$；
- 节点 4：$$a_4 = \sqrt{3}/2$$，$$\dot a_4 = \cos(a_1)\dot a_1 = (1/2)(\pi/6) = \pi/12$$；
- 节点 5：$$a_5 = e^7$$，$$\dot a_5 = \exp(a_2)\dot a_2 = e^7$$；
- 节点 6：$$a_6 = \sqrt{3}/2 + e^7 - 10$$，$$\dot a_6 = 0 + \pi/12 + e^7$$。

**结果**：$$\partial C/\partial\theta_2 = \pi/12 + e^7$$。

**代价**：每次求一个输入维度，$$d$$ 维需要 $$d$$ 次遍历。

### 10.4 反向模式（VJP）：传播向量-雅可比积

**核心公式**：
$$
\bar a_i = \sum_{k=1}^{\tilde\ell_i} \frac{\partial a_{i_k}}{\partial a_i} \bar a_{i_k}
$$

**计算流程**：

**前向**：算所有 primal 值。

**反向**：初始化 $$\bar a_6 = 1$$，逆拓扑遍历：

- $$\bar a_3 = \bar a_4 = \bar a_5 = 1$$；
- $$\bar a_1 = \cos(a_1)\bar a_4 = 1/2$$；
- $$\bar a_2 = \exp(a_2)\bar a_5 = e^7$$；
- $$\partial C/\partial\theta_1 = \theta_2 \bar a_1 = 1$$；
- $$\partial C/\partial\theta_2 = \theta_1 \bar a_1 + 1 \cdot \bar a_2 = \pi/12 + e^7$$；
- $$\partial C/\partial\theta_3 = 1 \cdot \bar a_2 - 2 \cdot \bar a_3 = e^7 - 2$$。

**一次反向遍历求出全部三个梯度。**

**交叉验证**：两种模式得到的 $$\partial C/\partial\theta_2$$ 都是 $$\pi/12 + e^7$$；与解析梯度 $$\theta_1\cos(\theta_1\theta_2) + e^{\theta_2+\theta_3}$$ 一致。**完美自洽。**

### 10.5 对比与结论

| 维度 | 前向模式（JVP） | 反向模式（VJP） |
|---|---|---|
| 传播对象 | 雅可比-向量积 | 向量-雅可比积 |
| 方向 | 输入→输出 | 输出→输入 |
| 每次遍历求什么 | 一个输入维度的偏导 | 一个输出维度的偏导 |
| 求全部梯度代价 | $$O(d)$$ 次遍历 | $$O(m)$$ 次遍历 |
| 适合场景 | $$d$$ 小、$$m$$ 大 | $$d$$ 大、$$m$$ 小 |
| 深度学习 | 不适合 | **标准方法** |

**为什么深度学习用反向模式**：$$m = 1$$（标量损失），反向模式 1 次遍历求出全部梯度；前向模式需要 $$d$$ 次（$$d$$ 可能千亿）。

**反向传播 = 反向模式自动微分在深度网络上的具体实现**（Baydin et al., 2018 综述原文即如此定义）。

**注意概念区分**：自动微分是“计算梯度”的方法，不是“调整参数”的方法。调整参数是优化器（ADAM）的事。JVP 和 VJP 都是“计算梯度的方法”，输出是梯度值，不是更新后的参数。

## 第十一部分：ADAM 的优缺点与适用范围

### 11.1 优点

| 优点 | 说明 |
|---|---|
| 自适应学习率 | 每个参数有自己的有效学习率 |
| 动量加速 | 一致方向加速，震荡方向抵消 |
| 偏差校正 | 初期不低估 |
| 实现简单 | 五步，逐元素运算，GPU 友好 |
| 默认选择（对 Transformer/LLM） | 深度学习实践的“默认优化器” |
| 适合稀疏梯度 | RMSProp 让稀疏梯度也有较大更新 |

### 11.2 缺点

| 缺点 | 说明 | 缓解方法 |
|---|---|---|
| 可能不收敛 | 某些凸问题上可能不收敛（Reddi et al., ICLR 2018, *On the Convergence of Adam and Beyond*） | 用 AMSGrad，或后期切 SGD |
| 泛化可能不如 SGD | 某些任务上 SGD + 动量泛化更好（CNN 视觉领域） | 用 AdamW，或后期切 SGD |
| 超参数仍需调 | 学习率 $$\alpha$$ 最关键 | 网格搜索、warmup |
| 内存开销 | 每个参数存 $$v$$ 和 $$s$$，内存是**普通 SGD 的 3 倍、SGD + 动量的 1.5 倍** | 用 SGD + 动量（2 份）或 SGD（1 份） |
| weight decay 耦合 | 原始 ADAM 的 L2 与自适应学习率耦合 | 用 **AdamW** |

**【修订：审核意见】** 原文“内存是 SGD 的 3 倍”中“SGD”默认指普通 SGD（1 份：参数）。但缓解方法建议“用 SGD + 动量”（2 份：参数 + 动量），此时 Adam 是 1.5 倍。基准不一致，已修正。

### 11.3 适用范围

**适合**：深度网络默认优化器（对 Transformer/LLM）；稀疏梯度；参数尺度差异大；快速原型。

**不适合**：需要严格收敛保证的凸优化（用 SGD 或 L-BFGS）；内存极度受限（用 SGD）；需要最佳泛化（后期切 SGD + 动量）。

## 第十二部分：数值例子——ADAM 完整走一遍

### 12.1 设定

目标：最小化 $$C(\theta) = \theta^2$$，真实梯度 $$\nabla C = 2\theta$$。初始 $$\theta^{(0)} = 1$$。超参数 $$\alpha = 0.1$$，$$\beta = 0.9$$，$$\gamma = 0.999$$，$$\epsilon = 10^{-8}$$。初始 $$v^{(0)} = s^{(0)} = 0$$。

### 12.2 第 1 步（$$t = 0$$）

- 梯度：$$g^{(0)} = 2$$；
- 一阶矩：$$v^{(1)} = 0.1 \times 2 = 0.2$$；
- 二阶矩：$$s^{(1)} = 0.001 \times 4 = 0.004$$；
- 偏差校正：$$\hat v^{(1)} = 0.2/0.1 = 2$$，$$\hat s^{(1)} = 0.004/0.001 = 4$$；
- 更新：$$\theta^{(1)} = 1 - 0.1 \times 2/\sqrt{4} = 1 - 0.1 = 0.9$$。

**验证**：$$C(0.9) = 0.81 < 1$$，正确下降。

### 12.3 第 2 步（$$t = 1$$）

- 梯度：$$g^{(1)} = 1.8$$；
- 一阶矩：$$v^{(2)} = 0.9 \times 0.2 + 0.1 \times 1.8 = 0.36$$；
- 二阶矩：$$s^{(2)} = 0.999 \times 0.004 + 0.001 \times 3.24 = 0.007236$$；
- 偏差校正：$$\hat v^{(2)} = 0.36/0.19 \approx 1.895$$，$$\hat s^{(2)} = 0.007236/0.001999 \approx 3.620$$；
- 更新：$$\theta^{(2)} = 0.9 - 0.1 \times 1.895/\sqrt{3.620} \approx 0.9 - 0.1 \times 0.996 \approx 0.8004$$。

**验证**：$$C(0.8004) \approx 0.6406 < 0.81$$，继续下降。

### 12.4 观察

- 偏差校正让前几步的 $$\hat v, \hat s$$ 接近真实值；
- 自适应学习率：分母 $$\sqrt{\hat s}$$ 反映梯度 RMS；
- 动量：$$v$$ 累积历史方向。

## 第十三部分：验收与常见卡点

### 13.1 验收标准

合上书，你应该能做到：

1. **默写 ADAM 五步**：$$g, v, s, \hat v, \hat s, \theta$$ 更新；
2. **解释偏差校正**：设输入恒为 $$u$$，$$v^{(t+1)} = (1-\beta^{t+1})u$$，除以 $$1-\beta^{t+1}$$ 还原；
3. **说清指数是 $$t+1$$**：$$t$$ 从 0 开始计数；
4. **说清前向模式（JVP）**：传播切向量，每次求一个输入维度的偏导，代价 $$O(d)$$；
5. **说清反向模式（VJP）**：传播伴随量，每次求一个输出维度的偏导，代价 $$O(m)$$；
6. **说清为什么深度学习用反向模式**：$$m = 1$$，1 次遍历求出全部梯度；
7. **说清反向传播 = 反向模式自动微分**；
8. **说清 AdamW**：解耦 weight decay，现代大模型标准；
9. **说清 $$v, s, g$$ 的形状**：与参数一致，所有运算逐元素；
10. **说清 $$\sqrt{s} \geq |v|$$**：由方差非负 $$s - v^2 = \text{Var}(g) \geq 0$$，步长有界；
11. **说清 $$v/\sqrt{s}$$ 不是单位向量**：逐元素归一化，方向被扭曲；
12. **说清指数平滑 vs. 简单平均**：非平稳环境下指数平滑更优；
13. **说清立即更新 vs. 梯度累积**：标准是每个 mini-batch 立即更新；
14. **说清梯度的方差公式**：$$\mathrm{Var}(g) = \mathbb{E}[g^2] - (\mathbb{E}[g])^2 \approx s - v^2$$。

### 13.2 常见卡点

| 卡点 | 原因 | 应对 |
|---|---|---|
| 偏差校正推导卡住 | 没做等比数列求和 | 设输入恒为 $$u$$，展开归纳，用等比数列公式 |
| 混淆 $$t$$ 和 $$t+1$$ | 没注意 $$t$$ 从 0 开始 | $$t=0$$ 时校正因子 $$1-\beta^1$$ |
| 前向/反向模式混淆 | 没理解“传播什么” | 前向 JVP（输入→输出），反向 VJP（输出→输入） |
| 不理解为什么反向模式代价与 $$d$$ 无关 | 没理解“标量损失” | $$m=1$$ 时反向模式 1 次遍历 |
| 以为 ADAM 一定收敛 | 没看 Reddi et al. | 用 AMSGrad 或后期切 SGD |
| 混淆 ADAM 和 AdamW | 没理解 weight decay 解耦 | AdamW 直接作用在参数上 |
| 以为 $$v$$ 是标量 | 没区分时间序列和向量 | $$v$$ 形状与参数一致 |
| 以为 $$g = (1,-1,1,-1)$$ 表示 4 维向量 | 没区分时间序列和向量 | 时间序列：一维参数的 4 个时间步；向量：4 个参数的梯度 |
| 以为 $$v/\sqrt{s}$$ 是单位向量 | 没看逐元素归一化 | 逐元素除法，方向扭曲，模长通常 $$\neq 1$$ |
| 以为所有参数都走 $$\alpha$$ | 没理解信噪比 | 一致方向接近 $$\alpha$$，震荡方向接近 0 |
| 以为梯度累积是标准做法 | 没理解显存妥协 | 标准是每个 mini-batch 立即更新 |
| 二阶矩写成“方差” | 没区分未中心化 vs. 中心化 | $$s = \mathbb{E}[g^2]$$，方差是 $$s - v^2$$ |
| 方差公式写成 $$\mathbb{E}[X^2 - (\mathbb{E}[X])^2]$$ | 符号不标准 | 标准写法是 $$\mathbb{E}[X^2] - (\mathbb{E}[X])^2$$ |

### 13.3 延伸思考

1. 如果 $$t$$ 从 1 开始计数，偏差校正的指数是多少？提示：$$1-\beta^t$$。
2. ADAM 和 SGD + 动量 + RMSProp 的关系？提示：ADAM = 动量 + RMSProp + 偏差校正。
3. 为什么 AdamW 的 weight decay 要解耦？提示：原始 ADAM 的 L2 被自适应学习率缩放。
4. 前向模式在什么场景下比反向模式好？提示：$$m \gg d$$。
5. 反向模式的内存代价是什么？提示：保存所有中间激活，梯度检查点可以时间换空间。
6. 为什么指数平滑的有效样本量是 $$(1+\beta)/(1-\beta)$$？提示：Kish 公式。
7. 为什么 $$g = (1,-1,1,-1)$$ 时 $$v$$ 接近 0？提示：这是时间序列（一维参数的 4 个时间步），正负交替抵消。
8. 为什么 $$\beta_2$$ 在 LLM 实践中常取 0.95 而不是 0.999？提示：更长记忆在大规模训练中反而不稳。

## 第十四部分：核心问答速查表

| 问题 | 核心答案 |
|---|---|
| **ADAM 全称？** | Adaptive Moment Estimation（自适应矩估计）。 |
| **AdamW 全称？** | Adam with Decoupled Weight Decay（带解耦权重衰减的 Adam）。 |
| **ADAM 五步？** | $$g = \nabla C_{I_t}(\theta)$$；$$v \leftarrow \beta v + (1-\beta)g$$；$$s \leftarrow \gamma s + (1-\gamma)(g\odot g)$$；$$\hat v = v/(1-\beta^{t+1})$$，$$\hat s = s/(1-\gamma^{t+1})$$；$$\theta \leftarrow \theta - \alpha \hat v/(\sqrt{\hat s}+\epsilon)$$。 |
| **二阶矩是什么？** | $$s = \mathbb{E}[g^2]$$，是“平方的均值”（未中心化二阶矩），不是方差。方差是 $$s - v^2$$。 |
| **$$u^{(t)}$$ 是什么？** | 序列第 $$t$$ 时刻的观测值。一般各不相同。推导偏差校正时假设 $$u^{(t)}=u$$ 是分析技巧。 |
| **为什么指数平滑？** | 对历史序列加权平均，近期权重大。解决：噪声抑制、内存 $$O(1)$$、近期权重更大、递推实现 $$O(1)$$。 |
| **指数平滑 vs. 简单平均？** | 平稳环境简单平均更优（方差最小）；非平稳环境指数平滑更优（快速适应）。深度学习非平稳，用指数平滑。 |
| **为什么 $$(1-\beta)$$ 是归一化？** | 让权重和等于 1。没有 $$(1-\beta)$$ 时权重和趋于 $$1/(1-\beta)$$（如 10），平滑值错误。 |
| **$$v$$ 的作用？** | 平滑历史梯度，代表“方向”。抑制震荡，加速一致方向。 |
| **$$s$$ 的作用？** | 平滑梯度平方，代表“每个坐标的梯度典型幅度”。$$\sqrt{s}$$ 是 RMS。 |
| **如何结合？** | $$\theta \leftarrow \theta - \alpha \hat v/(\sqrt{\hat s}+\epsilon)$$。分子给方向，分母给尺度。 |
| **为什么有用？** | ① 符号梯度的平滑版；② Hessian 逆的对角近似；③ 信噪比；④ 尺度不变性；⑤ 继承 AdaGrad/RMSProp。 |
| **偏差校正？** | 初值 0 导致平滑值被压小 $$1-\beta^{t+1}$$ 倍，除以 $$1-\beta^{t+1}$$ 还原。二阶校正更关键（$$\gamma$$ 接近 1）。 |
| **$$\sqrt{s} \geq |v|$$？** | $$\beta=\gamma$$ 时严格成立（方差非负 $$s - v^2 = \mathrm{Var}(g) \geq 0$$）。步长 $$\leq \alpha$$。 |
| **梯度的方差公式？** | $$\mathrm{Var}(g) = \mathbb{E}[g^2] - (\mathbb{E}[g])^2 \approx s - v^2$$。 |
| **$$v/\sqrt{s}$$ 是单位向量吗？** | 不是。逐元素归一化，方向扭曲，模长通常 $$\neq 1$$。 |
| **一个 mini-batch 几次前馈+反向？** | 一次。$$n_b$$ 个样本矩阵化处理。 |
| **立即更新 vs. 梯度累积？** | 标准是每个 mini-batch 立即更新。梯度累积是显存不足时的妥协。 |
| **梯度怎么计算？** | 链式法则。简单函数直接求导；深度网络用反向传播。 |
| **梯度和损失的关系？** | 方向（最速上升/下降）、大小（陡峭程度）、优化（零梯度是局部最优必要条件）、计算（一阶敏感度）。 |
| **$$g = (1,-1,1,-1)$$ 时 $$v$$ 为什么接近 0？** | 这是时间序列（一维参数的 4 个时间步），正负交替抵消。$$v$$ 是标量。如果是 4 维向量，$$v$$ 是 4 维向量，不一定是零向量。 |
| **$$\theta_i$$ 和 $$\dot\theta_i$$ 的区别？** | $$\theta_i$$ 是输入数值（常量），$$\dot\theta_i$$ 是切向量（求导方向）。 |
| **前向模式（JVP）？** | 传播雅可比-向量积，每次求一个输入维度的偏导，代价 $$O(d)$$。 |
| **反向模式（VJP）？** | 传播向量-雅可比积，每次求一个输出维度的偏导，代价 $$O(m)$$。 |
| **为什么深度学习用反向模式？** | $$m=1$$（标量损失），反向模式 1 次遍历求出全部梯度；前向模式需要 $$d$$ 次。 |
| **反向传播是什么？** | 反向模式自动微分在深度网络上的具体实现。 |
| **ADAM 和 AdamW 的区别？** | AdamW 解耦 weight decay，直接作用在参数上，不经过自适应学习率分母。 |
| **ADAM 的缺点？** | 可能不收敛（用 AMSGrad）；泛化可能不如 SGD（后期切 SGD）；内存是普通 SGD 的 3 倍、SGD+动量的 1.5 倍；weight decay 耦合（用 AdamW）。 |
| **ADAM 适合什么场景？** | 深度网络默认优化器（对 Transformer/LLM）；稀疏梯度；参数尺度差异大；快速原型。 |
| **自动微分是调整参数吗？** | 不是。自动微分是“计算梯度”的方法，调整参数是优化器的事。 |
| **LLM 实践中 ADAM 超参数？** | $$\beta_1=0.9$$，$$\beta_2=0.95$$（不是默认 0.999），lr $$3\times10^{-4}$$（LLaMA）+ cosine decay + warmup。 |
| **数值微分代价？** | 单侧差分 $$d+1$$ 次，中心差分 $$2d$$ 次。 |

### 15.3 梯度方差公式的澄清

**用户疑问**：“梯度的方差，方差是 E(v² - 均值²)？”

**澄清**：
- 方差标准定义：$$\mathrm{Var}(X) = \mathbb{E}[(X - \mathbb{E}[X])^2]$$；
- 展开：$$\mathrm{Var}(X) = \mathbb{E}[X^2] - (\mathbb{E}[X])^2$$；
- 用户写的 `E(v² - 均值²)` 方向对，但标准写法是“平方的期望减期望的平方”；
- 在 ADAM 中：$$\mathrm{Var}(g) \approx s - v^2$$，其中 $$s \approx \mathbb{E}[g^2]$$，$$v \approx \mathbb{E}[g]$$。
