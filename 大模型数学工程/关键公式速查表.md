## 符号总表（全书统一）

| 符号 | 含义 |
|---|---|
| $x\in\mathbb{R}^p$ | 输入/特征向量（$p$ 个特征） |
| $y$ | 输出/标签（回归为 $\mathbb{R}$，分类为类别，序列为序列） |
| $\theta$ | 全部可训练参数；整模型为 $\theta$，第 $\ell$ 层为 $\theta^{[\ell]}$ |
| $W^{[\ell]},b^{[\ell]}$ | 第 $\ell$ 层的权重矩阵与偏置向量 |
| $z^{[\ell]},a^{[\ell]}$ | 第 $\ell$ 层的仿射输出（pre-activation）与激活输出 |
| $S^{[\ell]}(\cdot)$ | 第 $\ell$ 层的激活函数（向量情形逐坐标作用） |
| $[\,\ell\,]$ 上标 | 层号（书中一律用方括号，与幂区分） |
| $L$ | 总层数；$x=a^{[0]}$，$y=a^{[L]}$ |
| $n$ | 样本数；$d$ | 参数个数 |
| $\tilde x$ | 增广特征（首坐标补 1，吸收截距） |
| $X$ | 设计矩阵（$n\times p$） |
| $\hat y$ | 模型预测；$\hat\theta$ | 估计值 |
| $\|u\|$ | 默认 $L_2$ 范数 $\sqrt{u^\top u}$ |
| $\nabla C$ | 目标函数 $C$ 的梯度 |
| $\odot$ | 逐元素乘积 |
| $\dagger$ | Moore–Penrose 伪逆 |
| $1\{\cdot\}$ | 指示函数 |

> ⚠ **全书有三处符号重载，跨章阅读时注意切换**：
> 1. **$\alpha$**：第 2、4、5 章是**学习率**；第 6 章的三元组损失里是 **margin**；第 8 章的 RL 里 $\alpha_t$ 是 **Q-learning 的学习率**。
> 2. **$\beta$**：第 4 章是**动量的指数平滑系数**；第 8 章扩散模型中 $\beta_t$ 是**每步加噪方差**。
> 3. **$\gamma$**：第 4 章是 **RMSProp 的指数平滑系数**；第 7 章 $\gamma,\beta$ 是 LayerNorm 的缩放/平移；第 8 章扩散模型中 $\gamma_t=\prod_{i<t}(1-\beta_i)$ 是**累积保留系数**。
> 4. **$\sigma$**：既指激活函数 $\sigma(\cdot)$（第 3–5 章），也指标准差 $\sigma$／$\Sigma$（协方差，第 2、8 章）。
> 5. **$p$**：第 2–3 章是**特征数**；第 7 章是**模型维度**；第 6 章 $p_h,p_v$ 是 **padding**；第 2 章 $P(\cdot,\cdot)$ 是**性能函数**。

## 第 2 章　机器学习原理

### 2.1 数据与描述统计

| 编号 | 公式 | 符号与用途 |
|---|---|---|
| (2.1) | $\bar x_j=\frac1n\sum_{i=1}^n x_j^{(i)}$；$s_j^2=\frac1{n-1}\sum_{i=1}^n(x_j^{(i)}-\bar x_j)^2$ | 样本均值与样本方差。用于特征标准化 |
| (2.2) | $x_j^{(i)}\leftarrow\dfrac{x_j^{(i)}-\bar x_j}{s_j}$ | 标准化。**在划分训练/测试集之后，只能用训练集统计量**，否则信息泄漏 |

### 2.2 监督学习与评价

| 编号 | 公式 | 符号与用途 |
|---|---|---|
| (2.3) | $y=\beta_0+\beta_1x+\epsilon$ | 一元线性回归 |
| (2.4) | $y=\beta_0+\beta_1x+\beta_2x^2+\epsilon$ | 多项式回归：**线性模型 + 非线性特征**（不是非线性模型！） |
| (2.5) | $\hat y=1$（positive）若 $\hat y>\tau$，其中 $\hat y=f_\theta(x)$ | 阈值分类器 |
| (2.6) | $\text{Accuracy}=\dfrac{\#\{\text{correct}\}}{n_{\text{test}}}$ | 分类精度 |
| (2.7) | $F_1=2\cdot\dfrac{\text{Precision}\cdot\text{Recall}}{\text{Precision}+\text{Recall}}$ | 不平衡数据下比精度更有意义 |
| (2.8) | $y=b+w^\top x+\epsilon$ | **多元线性模型**：$b$ 是截距/偏置，$w$ 是回归/权重向量 |
| (2.9) | $y=[\,b\ \ w_1\ \cdots\ w_p\,]\begin{bmatrix}1\\x_1\\\vdots\\x_p\end{bmatrix}+\epsilon=\theta^\top\tilde x+\epsilon$ | **紧凑形式**：把截距吸收进增广特征 $\tilde x$。全书默认写法 |
| (2.10) | $X=\begin{bmatrix}\tilde x^{(1)\top}\\\vdots\\\tilde x^{(n)\top}\end{bmatrix}\in\mathbb{R}^{n\times(p+1)}$ | 设计矩阵：$y=X\theta+\epsilon$ 的矩阵形式 |

### 2.3 损失函数与最小二乘

| 编号 | 公式 | 符号与用途 |
|---|---|---|
| (2.11) | $C(\theta)=\sum_{i=1}^n C_i(\theta)$ | 总损失 = 样本损失之和（**经验风险**） |
| (2.12) | $C_i(\theta)=\big(y^{(i)}-\hat y^{(i)}\big)^2$ | 平方误差损失 |
| (2.13) | $\min_{\theta\in\mathbb{R}^d}\ \|y-X\theta\|^2$ | **最小二乘问题**的最小化形式 |
| (2.14) | $\nabla_\theta\|y-X\theta\|^2=-2X^\top y+2X^\top X\theta$ | 梯度；**令其为零**给出正规方程 |
| (2.15) | $X^\top X\theta=X^\top y$ | **正规方程（normal equations）** |
| (2.16) | $\hat\theta=(X^\top X)^{-1}X^\top y$ | **最小二乘闭式解** |
| (2.17) | $X^\dagger=V\Sigma^+U^\top$ | 伪逆（基于 SVD $X=U\Sigma V^\top$）。$X^\top X$ 不可逆/病态时的补救 |
| (2.18) | $C_i(\theta)=\big|y^{(i)}-\hat y^{(i)}\big|$ | 绝对误差损失（对离群点更稳健） |
| (2.19) | $C_i(\theta)=\begin{cases}\frac12(y^{(i)}-\hat y^{(i)})^2,&|y^{(i)}-\hat y^{(i)}|\le\delta\\ \delta|y^{(i)}-\hat y^{(i)}|-\frac12\delta^2,&\text{otherwise}\end{cases}$ | Huber 损失：小误差平方、大误差线性 |

### 2.4 迭代优化

| 编号 | 公式 | 符号与用途 |
|---|---|---|
| (2.20) | $\theta^{(t+1)}=\theta^{(t)}-\alpha\nabla C\big(\theta^{(t)}\big)$ | **梯度下降更新式**；$\alpha$ 是学习率（步长） |
| (2.21) | $\nabla C(\theta)=\frac{2}{n}X^\top(X\theta-y)$ | 线性模型 + 平方损失的梯度（用于代入 (2.20)） |
| (2.22) | $\|\theta^{(t)}-\theta^{(t+1)}\|<\varepsilon$ | 停机准则 |
| (2.23) | 步长条件：$\alpha<\dfrac{2}{\lambda_{\max}(X^\top X/n)}$ | **收敛要求**。$\lambda_{\max}$ 是最大特征值。太大就发散 |

### 2.5 泛化、正则化与验证

| 编号 | 公式 | 符号与用途 |
|---|---|---|
| (2.24) | $E_{\text{unseen}}=\mathbb{E}_{x',y'}\big[P(\hat y(x'),y')\big]$ | **泛化（真实）性能**：对未见数据的期望损失 |
| (2.25) | $E_{\text{train}}=\frac1n\sum_{i=1}^n P(\hat y(x^{(i)}),y^{(i)})$ | 训练性能 |
| (2.26) | $E_{\text{test}}=\frac{1}{n_{\text{test}}}\sum_{i=1}^{n_{\text{test}}}P(\hat y(x'^{(i)}),y'^{(i)})$ | 测试性能（$E_{\text{unseen}}$ 的估计） |
| (2.27) | $E_{\text{unseen}}$ 的估计式（同 (2.24) 的经验版） | 泛化性能 |
| (2.28) | $E_{\text{gap}}=E_{\text{unseen}}-E_{\text{train}}$ | **泛化间隙**：过拟合的直接度量 |
| (2.29) | $y=\beta_0+\beta_1x+\beta_2x^2+\cdots+\beta_kx^k+\epsilon$ | 多项式族：$k$ 控制模型复杂度 |
| (2.30) | $y=f(x)+\epsilon$，$\mathbb{E}[\epsilon]=0$，$\epsilon$ 与 $x$ 独立 | 偏差-方差分解所要求的**数据生成假设** |
| (2.31) | $\mathbb{E}_{\text{unseen}}=\mathbb{E}_{D,x',\epsilon}\Big[\big(\hat f(x';D)-(f(x')+\epsilon)\big)^2\Big]$ | 期望泛化性能 |
| **(2.32)** | $\mathbb{E}_{\text{unseen}}=\underbrace{\big(\mathbb{E}[\hat f(x';D)]-\mathbb{E}[f(x')]\big)^2}_{\text{Bias}^2}+\underbrace{\mathrm{Var}\big(\hat f(x';D)\big)}_{\text{Variance}}+\underbrace{\mathbb{E}[\epsilon^2]}_{\text{Inherent Noise}}$ | **偏差-方差-噪声分解**。欠拟合=高偏差，过拟合=高方差，噪声项不可约 |
| (2.33) | $\min_\theta\ C(\theta;D)+R_\lambda(\theta)$ | **正则化的一般形式** |
| (2.34) | $R_\lambda(\theta)=\lambda\|\theta\|^2$（记 $\lambda$ 与 $\lambda^2$ 的换算） | $L_2$ 正则项 |
| (2.35) | $\min_\theta\ \|y-X\theta\|^2+\lambda\|\theta\|^2$ | **岭回归目标** |
| (2.36) | $\hat\theta=(X^\top X+\lambda I)^{-1}X^\top y$ | **岭回归闭式解**。$+\lambda I$ 同时改善数值条件 |
| (2.37) | 交叉验证误差的平均式 | 用 $K$ 折交叉验证估计 $E_{\text{unseen}}$ 以选 $\lambda^*$ |
| (2.38) | 验证集选择流程 | 用验证集选超参，**测试集只用一次** |

### 2.6 无监督学习

| 编号 | 公式 | 符号与用途 |
|---|---|---|
| (2.39) | $\min_{\{\mu_k\},\{C_k\}}\sum_{k=1}^K\sum_{x\in C_k}\|x-\mu_k\|^2$ | **K-means 目标** |
| (2.40) | $\mu_k=\frac{1}{|C_k|}\sum_{x\in C_k}x$ | 均值更新步 |
| (2.41) | $\ell(x)=\arg\min_{k\in\{1,\dots,K\}}\|x-\mu_k\|$ | 指派步（交替进行，只保证局部最优；用"肘点"选 $K$） |
| (2.42) | $X=XD^{-1}$（去均值） | 中心化数据矩阵。PCA 的输入 |
| (2.43) | $S=\frac1n X^\top X$ | **样本协方差矩阵** |
| (2.44) | $\hat X=X\hat V$，$\hat V=[v_1,\dots,v_m]$ | 载荷矩阵（loading vectors） |
| (2.45) | $Sv_i=\lambda_i v_i$ | 特征方程：PCA 主方向 = $S$ 的特征向量 |
| (2.46) | $\max_{v\in\mathbb{R}^p}\ v^\top Sv$，约束 $\|v\|=1$ | **PCA 的优化表述** |
| (2.47) | $v^\top Sv-v^\top\lambda v+\lambda$ | 拉格朗日函数：驻点条件给出 $Sv=\lambda v$ |
| (2.48) | $X=U\Sigma V^\top$，$\Sigma=\mathrm{diag}(\sigma_1,\dots,\sigma_r)$，$\sigma_i>0$ | **SVD** |
| (2.49)–(2.50) | 比较 $S$ 的特征值与 $X$ 的奇异值：$\lambda_i=\sigma_i^2/n$ | **PCA ↔ SVD 的桥梁** |
| (2.51)–(2.53) | $\hat X=XV$（主成分得分）；Eckart–Young–Mirsky 最优低秩逼近 | 截断 SVD 是最优降维 |

## 第 3 章　简单神经网络

### 3.1 Logistic 回归（统计学视角）

| 编号 | 公式 | 符号与用途 |
|---|---|---|
| (3.1) | $\mathbb{P}(Y=1\mid X=x)=\phi(x)$，$\mathbb{P}(Y=0\mid X=x)=1-\phi(x)$ | 伯努利响应假设 |
| (3.2) | $\mathrm{Logit}(u)=\log\dfrac{u}{1-u}$，$u\in(0,1)$ | log-odds（logit 链接） |
| (3.3) | $\mathrm{Logit}\big(\phi(x)\big)=b+w^\top x$ | **GLM 的线性假设** |
| (3.4) | $\sigma_{\mathrm{Sig}}(u)=\dfrac{1}{1+e^{-u}}$ | **sigmoid**；与 logit 互为反函数 |
| (3.5) | $\phi(x)=\mathbb{P}(Y=1\mid X=x;\theta)=\sigma_{\mathrm{Sig}}(b+w^\top x)=\dfrac{1}{1+e^{-(b+w^\top x)}}$ | **logistic 回归模型** |
| (3.6) | $Z=b+w^\top X+\epsilon$，$Y=1\{Z\ge0\}$，$\epsilon\sim$ Logistic$(0,1)$ | 潜变量解释：sigmoid 的由来；换成高斯 $\epsilon$ 就得 probit |
| (3.7) | $L(\theta;\mathcal{D})=\prod_{i=1}^n\mathbb{P}\big(Y=y^{(i)}\mid X=x^{(i)};\theta\big)$ | 似然（i.i.d. ⟹ 连乘） |
| (3.8) | $L(\theta;\mathcal{D})=\prod_{i=1}^n\phi(x^{(i)})^{y^{(i)}}\big(1-\phi(x^{(i)})\big)^{1-y^{(i)}}$ | 伯努利似然的显式形式 |
| (3.9) | $\ell(\theta;\mathcal{D})=\sum_{i=1}^n\Big[y^{(i)}\log\phi(x^{(i)})+(1-y^{(i)})\log\big(1-\phi(x^{(i)})\big)\Big]$ | **对数似然** |
| (3.10) | $\hat\theta_{\text{MLE}}=\arg\max_\theta\ell(\theta;\mathcal{D})=\arg\min_\theta-\frac1n\ell(\theta;\mathcal{D})$ | **最大似然 = 最小化负对数似然**（凸） |
| (3.11)(3.12) | $C(\theta;\mathcal{D})=\frac1n\sum_i\Big[-\Big(y^{(i)}\log\hat y^{(i)}+(1-y^{(i)})\log(1-\hat y^{(i)})\Big)\Big]$；$\mathrm{CE}_{\text{binary}}(y,\hat y)=-\big(y\log\hat y+(1-y)\log(1-\hat y)\big)$ | **二元交叉熵 = 负对数似然**。实现时用 $\log(u+\varepsilon)$ 防 $\log0$ |
| (3.13) | $\log\dfrac{\hat y}{1-\hat y}=\hat b+\hat w_1x_1+\hat w_2x_2$；$\dfrac{\hat y}{1-\hat y}=e^{\hat b+\hat w_1x_1+\hat w_2x_2}$ | 参数解释：$e^{\hat w_j}$ 是 odds ratio |
| (3.14) | $\hat Y=1$ 若 $H(x)>0$，$H(x)=\check b+\check w^\top x$，$\check b=\hat b+\log(\tau^{-1}-1)$，$\check w=\hat w$ | **logistic 回归是线性分类器** |

### 3.2 Logistic 回归（神经网络视角）

| 编号 | 公式 | 符号与用途 |
|---|---|---|
| (3.15) | $\hat y=\sigma\big(\underbrace{b+w^\top x}_{z}\big)=\underbrace{\sigma(z)}_{a}$ | **单个人工神经元**：仿射 + 激活 |
| (3.16) | $\nabla C(\theta)=\frac1n\sum_{i=1}^n\nabla C_i(\theta)$ | 总梯度 = 样本梯度平均（贯穿全书） |

### 3.3 Softmax 多分类

| 编号 | 公式 | 符号与用途 |
|---|---|---|
| (3.18)(3.19) | $\phi(x)=(\phi_1(x),\dots,\phi_K(x))$，$\phi_k(x)=\mathbb{P}(Y=k\mid X=x)$ | 类概率向量 |
| (3.20) | $\mathbb{P}(Y_1=u_1,\dots,Y_K=u_K\mid X=x)=\prod_{k=1}^K\phi_k(x)^{u_k}$ | categorical 分布（one-hot 响应） |
| (3.21)(3.22)(3.23) | $\phi_k(x)=\dfrac{e^{b_k+w_{(k)}^\top x}}{1+\sum_{j=1}^{K-1}e^{b_j+w_{(j)}^\top x}}$（$k\le K-1$），$\phi_K(x)=1-\sum_{j<K}\phi_j(x)$；$d=(K-1)(p+1)$ | **统计参数化**（可辨识；令 $b_K=0,w_{(K)}=0$） |
| (3.24) | $\phi_k(x)=\dfrac{e^{b_k+w_{(k)}^\top x}}{\sum_{j=1}^K e^{b_j+w_{(j)}^\top x}}$ | 统一形式（两种参数化都成立） |
| **(3.25)** | $S_{\text{Softmax}}(z)=\dfrac{1}{\sum_{i=1}^K e^{z_i}}\begin{bmatrix}e^{z_1}\\\vdots\\e^{z_K}\end{bmatrix}$ | **softmax**：输出恒为概率向量；**对整体平移不变** |
| (3.26)(3.27) | $\hat y=S_{\text{Softmax}}\big(\underbrace{b+Wx}_{z\in\mathbb{R}^K}\big)=a\in\mathbb{R}^K$，$W$ 的第 $k$ 行是 $w_{(k)}^\top$ | **多项回归 = 浅层神经网络**（向量进、向量出）；$d=K(p+1)$ |
| (3.28) | $\ell(\theta;\mathcal{D})=\sum_i\sum_k 1\{y^{(i)}=k\}\log\phi_k(x^{(i)})=\sum_i\log\phi_{y^{(i)}}(x^{(i)})$ | 多项对数似然 |
| (3.29)–(3.33) | $C_i=-\log\hat y^{(i)}_{y^{(i)}}$；$\mathrm{CE}_{\text{categorical}}(y,\hat y)=-\sum_k 1\{y=k\}\log\hat y_k=-\log\hat y_y$ | **分类交叉熵**；$\mathrm{CE}_{\text{binary}}(y,\hat y)=\mathrm{CE}_{\text{categorical}}\big(2-y,[\hat y,1-\hat y]^\top\big)$ |
| **(p92)** | $\dfrac{\partial C_i}{\partial b}=S_{\text{Softmax}}\big(b+Wx^{(i)}\big)-e_{y^{(i)}}$；$\dfrac{\partial C_i}{\partial W}=\Big(S_{\text{Softmax}}\big(b+Wx^{(i)}\big)-e_{y^{(i)}}\Big)x^{(i)\top}$ | **softmax + 交叉熵的梯度 = 预测 − 标签**（外积输入） |
| (3.34) | $\hat{\mathcal Y}=\arg\max_{k}\hat y_k$ | MAP 决策规则 |
| (3.35) | $\check b+\check w_1x_1+\check w_2x_2+\check w_3x_1^2+\check w_4x_2^2+\check w_5x_1x_2\ge0$ | 特征工程后的**弯曲决策边界** |

### 3.4 超越线性边界

| 公式 | 符号与用途 |
|---|---|
| 单项式特征 $x_1^{k_1}\cdots x_p^{k_p}$，$k_1+\cdots+k_p\le r$ | 多项式特征扩展 |

### 3.5 浅层自编码器

| 编号 | 公式 | 符号与用途 |
|---|---|---|
| (3.36) | $C_i(\theta)=\big\|x^{(i)}-f_\theta(x^{(i)})\big\|^2$ | **重构损失**（目标是输入自身） |

## 第 4 章　优化算法

### 4.1 优化问题的形式化

| 编号 | 公式 | 符号与用途 |
|---|---|---|
| (4.1) | $\min_\theta\ C(\theta)\quad\text{subject to}\ \theta\in\Theta$ | **优化问题的一般形式**；$\Theta$ 是可行域 |
| (4.2) | $\theta^*=\arg\min_{\theta\in\Theta}C(\theta)$ | 解（minimizer）的定义 |
| (4.3) | $C\big(\lambda\theta+(1-\lambda)\varphi\big)\le\lambda C(\theta)+(1-\lambda)C(\varphi)$ | **凸性定义**（$\lambda\in[0,1]$） |
| (4.4) | $C(\theta):=C(\theta;\mathcal{D})=\dfrac1n\sum_{i=1}^n C_i(\theta)$ | **经验风险**（深度学习的目标函数标准形式） |
| (4.5) | $\nabla C(\theta)=\dfrac1n\sum_i\nabla C_i(\theta)$，$\nabla^2C(\theta)=\dfrac1n\sum_i\nabla^2C_i(\theta)$ | 梯度与 Hessian 的平均结构 |
| (4.6) | $\nabla^2C(\theta)\succeq0\iff v^\top\nabla^2C(\theta)v\ge0\ \ \forall v$ | **二阶（凸性）条件** |
| (4.7) | 交叉熵损失的梯度/Hessian 形式：$\big(\sigma_{\text{Sig}}(b+w^\top x^{(i)})-1\big)\begin{bmatrix}1\\x^{(i)}\end{bmatrix}\begin{bmatrix}1&x^{(i)\top}\end{bmatrix}$ | 说明交叉熵的 Hessian 结构（凸性来源） |
| (4.8) | $C_i(\theta)=\log\sum_{j=1}^K e^{b_j+w_{(j)}^\top x^{(i)}}-\big(b_k+w_{(k)}^\top x^{(i)}\big)$ | **log-sum-exp 形式的交叉熵**（softmax 的数值稳定写法） |
| (4.9) | $C(\theta)=(1-\theta_1)^2+100(\theta_2-\theta_1^2)^2$ | **Rosenbrock 函数**：非凸、有狭长弯曲山谷，是优化算法的标准测试地形 |

### 4.3 自适应优化与 ADAM

| 编号 | 公式 | 符号与用途 |
|---|---|---|
| (4.19) | $\theta_s=-\alpha\,r\odot\nabla C(\theta)$ | **坐标级缩放**：每个坐标用不同因子（解决不同特征出现频率差异过大） |
| (4.20) | $\theta_i^{(t+1)}=\theta_i^{(t)}-\dfrac{\alpha}{\sqrt{s_i^{(t+1)}+\epsilon}}\dfrac{\partial C(\theta^{(t)})}{\partial\theta_i}$ | 坐标形式的自适应更新 |
| (4.21) | $\theta^{(t+1)}=\theta^{(t)}-\dfrac{\alpha}{\sqrt{s^{(t+1)}+\epsilon}}\odot\nabla C(\theta^{(t)})$ | 向量形式（逐元素运算） |
| (4.22) | $s_i^{(t+1)}=\begin{cases}\sqrt{\sum_{\tau=0}^{t}\Big(\frac{\partial C(\theta^{(\tau)})}{\partial\theta_i}\Big)^2},&\text{Adagrad}\\[2mm]\gamma s_i^{(t)}+(1-\gamma)\Big(\frac{\partial C(\theta^{(t)})}{\partial\theta_i}\Big)^2,&\text{RMSprop}\end{cases}$<br>$s_i^{(0)}=0$ | **Adagrad 是历史平方和（累加、不可逆）**；**RMSprop 是指数平滑（可遗忘）**。注意 Adagrad 那一支是 $\sqrt{\sum(\cdot)^2}$（**求和**，不是连乘） |
| (4.23) | $s^{(t+1)}=(1-\gamma)\sum_{\tau=0}^{t}\gamma^{t-\tau}\Big(\nabla C(\theta^{(\tau)})\odot\nabla C(\theta^{(\tau)})\Big)$ | RMSprop 的历史展开 |
| (4.24) | $\hat v^{(t+1)}=\dfrac{1}{1-\beta^{t+1}}v^{(t+1)}$，$\hat s^{(t+1)}=\dfrac{1}{1-\gamma^{t+1}}s^{(t+1)}$ | **偏差校正**。因 $v^{(0)}=s^{(0)}=0$，前期平滑量被系统性压小；除以 $1-\beta^{t+1}$ 后，当输入恒定时可还原应得的 $u$。$\beta\to1$ 时前期影响最大，随 $t$ 增大自动消失 |
| **(4.25)** | $\theta^{(t+1)}=\theta^{(t)}-\dfrac{\alpha}{\sqrt{\hat s^{(t+1)}+\epsilon}}\,\hat v^{(t+1)}$ | **ADAM 的核心更新式**（一阶矩 + 二阶矩 + 偏差校正，全部逐元素） |
| (4.33)(4.34) | $v^{(t+1)}=\beta v^{(t)}+(1-\beta)\nabla C\big(\theta^{(t)}-\alpha\beta v^{(t)}\big)$；$\theta^{(t+1)}=\theta^{(t)}-\alpha v^{(t+1)}$ | **Nesterov 动量**（在"预测的下一点"处取梯度） |
| (4.35) | $\theta^{(t+1)}=\theta^{(t)}-\alpha\big[\beta v^{(t)}+(1-\beta)\nabla C(\theta^{(t)})\big]$ | 动量的等价写法 |
| (4.36)(4.37) | $v^{(t+1)}=\beta v^{(t)}+(1-\beta)\nabla C(\theta^{(t)})$；look-ahead momentum | **Nadam** 的动力量 |
| (4.38) | $\theta^{(t)}+\dfrac{\alpha}{\sqrt{s^{(t+1)}+\epsilon}}\odot\nabla C(\theta^{(t)})$ | **Adadelta**：用历史更新量替代学习率（无需手设 $\alpha$）。注意 $\Delta\theta$ 在分子、$s$ 在分母 |
| (4.39)(4.40) | $s_i^{(t+1)}=\gamma^p s_i^{(t)}+(1-\gamma^p)|g_i^{(t)}|^p$；$\theta^{(t+1)}=\theta^{(t)}-\dfrac{\alpha}{(\hat s^{(t+1)})^{1/p}+\epsilon}\hat v^{(t+1)}$ | **AdaMax**（$L_p$ 范数推广，$p=\infty$ 时取 $\max$） |
| (4.41)(4.42) | $r_i^{(t+1)}=r_i^{(t)}+\langle\Delta\theta_i^{(t)},g_i^{(t)}\rangle$，$r_i^{(0)}=0$；$\theta^{(t+1)}=\theta^{(t)}-\dfrac{\alpha}{\sqrt{r^{(t+1)}+\epsilon}}\hat v^{(t+1)}$ | Adadelta 的累加器与更新式 |

**ADAM 完整算法（Algorithm 4.2 的数学形式）**

$$\begin{aligned}
&\textbf{初始化: } \theta^{(0)},\ v^{(0)}=0,\ s^{(0)}=0,\ \alpha>0,\ \beta\in[0,1),\ \gamma\in[0,1),\ \epsilon>0\\
&\textbf{对 } t=0,1,2,\dots\\
&\quad g^{(t)}=\nabla C_{I_t}(\theta^{(t)}) &&\text{(mini-batch 梯度)}\\
&\quad v^{(t+1)}=\beta v^{(t)}+(1-\beta)g^{(t)} &&\text{(一阶矩 / 动量估计)}\\
&\quad s^{(t+1)}=\gamma s^{(t)}+(1-\gamma)\big(g^{(t)}\odot g^{(t)}\big) &&\text{(二阶矩 / RMSProp 估计)}\\
&\quad \hat v^{(t+1)}=\frac{v^{(t+1)}}{1-\beta^{t+1}},\quad \hat s^{(t+1)}=\frac{s^{(t+1)}}{1-\gamma^{t+1}} &&\text{(偏差校正)}\\
&\quad \theta^{(t+1)}=\theta^{(t)}-\alpha\,\frac{\hat v^{(t+1)}}{\sqrt{\hat s^{(t+1)}}+\epsilon} &&\text{(参数更新，逐元素)}
\end{aligned}$$

> **符号约定（照原书 Algorithm 4.2，p134）**：$\alpha$ 是**学习率**；$\beta\in[0,1)$ 是动量的指数平滑系数；$\gamma\in[0,1)$ 是 RMSProp 的指数平滑系数。常用默认值 $\beta=0.9$、$\gamma=0.999$。
> ⚠ **偏差校正的指数是 $t+1$、不是 $t$**——因为书中算法第 1 步令 $t\leftarrow0$（$t$ 从 0 起计数）。

### 4.4 自动微分

| 编号 | 公式 | 符号与用途 |
|---|---|---|
| (4.26) | $\dfrac{\partial C(\theta)}{\partial\theta_i}\approx\dfrac{C(\theta+h e_i)-C(\theta)}{h}$ | **数值差分**：有截断误差与灾难性消减，$d$ 个参数需 $d+1$ 次前向 |
| (4.27) | 计算图示例（$d=3$，节点编号 1–6） | 前向图的构建 |
| (4.28) | $\dot a_i=\dfrac{\partial a_i}{\partial\theta_j}$ | **前向模式的中间导数** |
| (4.29) | $\dot a_i=\sum_{k=1}^{\ell_i}\dfrac{\partial f_i(u_1,\dots,u_{\ell_i})}{\partial u_k}\dot u_k=\nabla f_i(u_1,\dots,u_{\ell_i})^\top\dot u$ | 前向模式递推 = **雅可比-向量积（JVP）** |
| **(4.30)** | $\gamma_i=\dfrac{\partial C}{\partial a_i}$ | **adjoint（伴随量）的定义**——第 5 章反向传播的全部骨架 |
| **(4.31)** | $\gamma_i=\sum_{k=1}^{\tilde\ell_i}\dfrac{\partial a_{i_k}}{\partial a_i}\gamma_{i_k}$ | **反向模式递推 = 向量-雅可比积（VJP）** |
| (4.32) | $\dfrac{\partial C}{\partial\theta_j}=\sum_k\dfrac{\partial a_{j_k}}{\partial\theta_j}\gamma_{j_k}$ | 由 adjoint 组装出对参数的梯度 |

**代价对比（本书结论）**：

| 模式 | 传播对象 | 求全部 $\partial C/\partial\theta_j$（$j=1,\dots,d$）的代价 |
|---|---|---|
| 前向模式 | JVP（雅可比-向量积） | $\Theta(d)$ 次遍历 ⟹ 对 $d$ 巨大不可行 |
| **反向模式** | VJP（向量-雅可比积） | **一次遍历即可得全部**（因为 $C$ 是标量） |

> 这就是"深度学习必须用反向传播"的**结构理由**，而不是工程偏好。

| **(5.35)** | $\delta^{[\ell]}=\big(W^\top\big)^{L-\ell}\delta^{[L]}$ | **反向的矩阵幂**：$\ell$ 越小幂次越高 ⟹ 最前面的层最先消失/爆炸 |

> **梯度消失/爆炸的两条独立路径**（书中明确区分）：
> ① **重复矩阵乘的幂次效应**（(5.34)(5.35)）——除非谱半径恰为 1，否则必然发生；换 ReLU **治不了**。
> ② **激活饱和**：输入远离 0 时 $\mathrm{Diag}(\dot\sigma(z))$ 的对角元趋于 0——ReLU 类**能治**这一条。
>
> **梯度裁剪的两种做法**：逐坐标裁剪到预设绝对值**会改变梯度方向**；按整个梯度范数缩放乘固定因子**保持方向**，只把模长压到阈值。

### 5.5–5.7 初始化、归一化、正则化

| 编号 | 公式 | 符号与用途 |
|---|---|---|
| (5.36)(5.37) | $\mathrm{Var}\big(a_i^{[\ell]}\big)=\sum_{j=1}^{N_{\ell-1}}\mathrm{Var}\big(w^{[\ell]}_{i,j}a^{[\ell-1]}_j\big)$ | 方差传播的起点（用独立性拆和） |

| (5.42)(5.43)(5.44) | $\frac{\partial C}{\partial\beta}=\sum_i\frac{\partial C}{\partial\tilde z^{(i)}}$；$\frac{\partial C}{\partial\gamma}=\sum_i\frac{\partial C}{\partial\tilde z^{(i)}}\bar z^{(i)}$；$\frac{\partial C}{\partial z^{(i)}}$ 的三条路径分解 | BN 的反向（⚠ 书中 (5.44) 第二项符号与第三项 $1/n_b$ 疑为原书笔误，见 `breakdown/ch05.md` 核对注记） |

## 第 6 章　卷积神经网络

> **记号约定（易错）**：本书张量维度写成 $M_c\times M_h\times M_v$／$K_c\times K_h\times K_v$，即**通道在前**。$h$ 对应行（height），$v$ 对应列（width）。

### 6.2 卷积运算

| 编号 | 公式 | 符号与用途 |
|---|---|---|
| (6.1) | $(f\star g)(t)=\sum_{\tau\in\mathbb{Z}}f(t-\tau)g(\tau)$，$t\in\mathbb{Z}$ | **离散卷积**（母定义，**有翻转**） |
| (6.2) | $(f\star g)(t)=\int_{\mathbb{R}}f(t-\tau)g(\tau)\,d\tau$ | 连续卷积 |
| (6.3) | $z_t=\sum_{\tau}f_\tau g_{t-\tau}=\sum_{i+j=t}f_ig_j$ | 多项式乘法的系数 = 卷积；长 3 与长 6 相乘得长 $3+6-1=8$ |
| (6.4) | $(f\star g)(u)=\sum_{v\in\mathbb{Z}^d}f(u-v)g(v)=\sum_{v\in\mathbb{Z}^d}f(v)g(u-v)$ | **多维卷积**（显式写出交换性） |
| (6.5) | 经典卷积输出尺寸：$(M_h+K_h-1)\times(M_v+K_v-1)$ | 全尺寸卷积 |
| (6.6) | **DL 卷积输出尺寸**：$(M_h-K_h+1)\times(M_v-K_v+1)$ | 经典卷积的一个子矩阵 |
| **(6.7)** | $z_{i',j'}=(W\star x)_{i',j'}=\sum_{i=0}^{K_h-1}\sum_{j=0}^{K_v-1}w_{K_h-i,\,K_v-j}\,x_{i'+i,\,j'+j}$ | **真卷积**（核在两个方向都翻转）；此时 $\star$ **不可交换** |
| (6.8)(6.9) | 体卷积尺寸 $(M_c-K_c+1)\times(M_h-K_h+1)\times(M_v-K_v+1)$；$(W\star x)_{k',i',j'}=\sum_{k,i,j}W_{K_c-k,K_h-i,K_v-j}x_{k'+k,i'+i,j'+j}$ | 多通道（张量）卷积 |
| (6.10) | $W\star x=\sum_{i=1}^{K_c}W_{(i)}\star x_{(i)}$，$K_c=M_c$ | 多通道 = 各通道矩阵卷积之和 |

### 6.3 从全连接到卷积：约束链

| 编号 | 公式 | 符号与用途 |
|---|---|---|
| (6.11) | $z^{[1]}_{i',j'}=\sum_{(i,j)}w^{[1]}_{(i',j'),(i,j)}x_{i,j}+b^{[1]}_{i',j'}$ | 全连接层的图像化写法：**权重依赖输出坐标** ⟹ 参数量 = 输入尺寸 × 输出尺寸 |
| (6.12) | 换元把绝对坐标改写为**相对偏移** $w^{[1]}_{(i',j'),(i'+i'',j'+j'')}$ | 引入平移性的技术前提 |
| **(6.13)** | $w^{[1]}_{(i',j'),(i'+i'',j'+j'')}=w_{i'',j''}$，$b^{[1]}_{i',j'}=b$ | **权重共享的数学形式化**：权重与输出坐标无关 |
| **(6.14)(6.15)** | $z^{[1]}_{i',j'}=\underbrace{\sum_{i''=0}^{K_h-1}\sum_{j''=0}^{K_v-1}w_{i'',j''}x_{i'+i'',j'+j''}}_{\star}+b$；$a^{[1]}=S^{[1]}(z^{[1]})$ | **局部性约束 + 卷积层的最终定义**。这个 $\star$ 与 (6.7) 差一次翻转，书中明说"学滤波器"与"学其翻转"等价，故 DL 中省略翻转——**即深度学习实际用的是互相关** |

### 6.3 形状与参数量账（代入即用）

| 编号 | 公式 | 说明 |
|---|---|---|
| (6.16) | $M_h^{[1]}\times M_v^{[1]}=(M_h^{[0]}-K_h+1)\times(M_v^{[0]}-K_v+1)$ | 基本输出尺寸 |
| **(6.17)** | $M_h^{[1]}=1+\left\lfloor\dfrac{M_h^{[0]}-d_h(K_h-1)-1+p_h}{s_h}\right\rfloor$（$v$ 方向同理） | **一般输出尺寸**（含 padding $p$、stride $s$、dilation $d$）。令有效核 $K_h'=d_h(K_h-1)+1$ 可简写 |
| (6.18) | $(M_h^{[0]}-K_h+p_h+1)\times(M_v^{[0]}-K_v+p_v+1)$ | 只加 padding。**"same padding"取 $p=K-1$** |
| (6.19) | $1+\left\lfloor\dfrac{M_h^{[0]}-K_h+p_h}{s_h}\right\rfloor$ | padding + stride |
| (6.20) | $z^{[1]}=\Big(\sum_{i=1}^{M_c^{[0]}}W_{(i)}\star x_{(i)}\Big)+b$ | 多输入通道（单核），$b$ 是标量 |
| **(6.21)** | $z^{[1]}_{(j)}=\Big(\sum_{i=1}^{M_c^{[0]}}W_{(j),(i)}\star x_{(i)}\Big)+b_{(j)}$，$j=1,\dots,M_c^{[1]}$ | **完整卷积层**：每个输出通道有自己的核与标量偏置 |
| (6.22) | $L=L_{train}+L_{pool}$，$L_{train}=L_{conv}+L_{dense}$ | VGG19：$L=24$，$L_{train}=19$，$L_{pool}=5$，$L_{conv}=16$，$L_{dense}=3$（**"19"指 $L_{train}$**） |
| **(6.23)** | $\#\text{params}^{[\ell]}_{conv}=M_c^{[\ell]}\cdot\big(M_c^{[\ell-1]}\cdot K_h^{[\ell]}\cdot K_v^{[\ell]}+1\big)$ | **卷积层参数量**。**关键：公式中不出现 $M_h,M_v$**——这是与全连接层最本质的差别 |
| (6.24)(6.25) | $z_j=\big(\sum_i W_{j,i}x_i\big)+b_j$ 与 $z_{(j)}=\big(\sum_i W_{(j),(i)}x_i\big)+b_{(j)}$ **同形** | **$1\times1$ 卷积 = 全连接层**（故可 convolutionalization 成全卷积网络） |
| (6.26) | $\tilde z^{[\ell]}_{(j)}=\gamma^{[\ell]}_j\odot z^{[\ell]}_{(j)}+\beta^{[\ell]}_j$ | 卷积层的 BatchNorm：**$\gamma,\beta$ 是逐通道的可学标量**，统计量跨整个 mini-batch |
| (6.27)(6.28) | 三元组损失 $\mathcal{L}_i=\max\big\{\underbrace{\|f_\theta(x_a)-f_\theta(x_s)\|}_{d_{same}}-\underbrace{\|f_\theta(x_a)-f_\theta(x_d)\|}_{d_{different}}+\alpha,\ 0\big\}$ | 人脸识别/度量学习；$d_{same}-d_{different}\le-\alpha$ 时损失为 0（admissible） |
| — | 池化：$\big[a^{[\ell]}_{(j)}\big]_{i,k}=\max_{(i',k')\in\mathcal{I}_{(i,k)}}\big[a^{[\ell-1]}_{(j)}\big]_{i',k'}$（max）或均值（average）；约束 $M_c$ 不变、$M_h,M_v$ 减小；**参数量恒为 0** | 通道不变、空间下采样 |
| — | 目标定位的组合损失：$\mathcal{L}_{cls}+\lambda(1-y_1)\mathcal{L}_{loc}$，$\lambda>0$（默认 1）。$y_1=1$ 表示"nothing"，此时 $1-y_1=0$ 把定位项关掉 | 多任务损失 |

**全连接层参数量**：$\#\text{params}^{[\ell]}_{dense}=N^{[\ell-1]}N^{[\ell]}+N^{[\ell]}$。

**计算量（FLOPs）估算（书中未给编号公式，由 (6.21)(6.23) 推出）**：
$$\text{MACs}^{[\ell]}\approx M_c^{[\ell]}M_h^{[\ell]}M_v^{[\ell]}\cdot M_c^{[\ell-1]}K_h^{[\ell]}K_v^{[\ell]},\qquad \text{FLOPs}\approx2\times\text{MACs}$$

### 书中真实算例（可当答案背下来）

| 例子 | 给定 | 推出 |
|---|---|---|
| Sobel 边缘检测 | $W:3\times3$，$x:6\times7$ | $z:4\times5=(6-3+1)\times(7-3+1)$ |
| padding | $x:6\times7$，$(p_h,p_v)=(2,2)$，$K:3\times3$ | 有效输入 $8\times9$ ⟹ 输出 $6\times7$（与输入同尺寸） |

### 7.1–7.2 序列建模与基本 RNN

### 7.2 BPTT 与梯度消失

| 编号 | 公式 | 符号与用途 |
|---|---|---|
| (7.6) | $\zeta^{(t)}=\begin{cases}\frac1T\sum_{\tau=1}^{T}\dot C^{(\tau)}\big(h^{(\tau)}\big),&t=T\\[1mm]\dfrac{\partial h^{(t+1)}}{\partial h^{(t)}}\zeta^{(t+1)},&t=T-1,\dots,1\end{cases}$ | **BPTT 的反向递推**（$\zeta^{(t)}$ 是伴随量） |
| (7.7) | $g_W=\dfrac{1}{T}\sum_{t=1}^{T}\dfrac{\partial C^{(t)}(h^{(t)},y^{(t)};W)}{\partial W}$ | 参数梯度（**所有时间步共享同一个 $W$**） |
| (7.8) | $g_W=\dfrac1T\sum_{t=1}^{T}\sum_{\tau=1}^{t}\dfrac{\partial h^{(\tau)}}{\partial W}\zeta^{(\tau)}$ | 展开到时间步的写法（书中注明是"非正式"表述） |
| (7.9) | $\dfrac{\partial h_j^{(\tau)}}{\partial W}=\dot\sigma\big(W_{hh}h^{(\tau-1)}+W_{hx}x^{(\tau)}+b_h\big)e_j\big(h^{(\tau-1)}\big)^\top$ | 落到神经元层面的导数 |
| (7.10) | $g_W=\dfrac1T\sum_{t=1}^{T}\sum_{\tau=1}^{t}\sum_{j=1}^{m}\dfrac{\partial h_j^{(\tau)}}{\partial W}\zeta_j^{(\tau)}$ | BPTT 的可执行形式 |
| **(7.11)** | $\dfrac{\partial h^{(t+1)}}{\partial h^{(t)}}=W_{hh}^\top\,\mathrm{diag}\Big(\dot\sigma\big(W_{hh}h^{(t)}+W_{hx}x^{(t)}+b_h\big)\Big)$ | **递推的雅可比**：梯度问题的源头 |
| **(7.12)** | $\zeta^{(t)}=\big(W_{hh}^\top\big)^{T-t}\zeta^{(T)}$（忽略激活、输入与偏置） | **梯度消失/爆炸 = 矩阵的幂**。谱半径 $<1$ ⟹ $\zeta^{(t)}\approx0$ |
| (7.13) | $g_W\approx\dfrac1T\sum_{t=T_0}^{T}\sum_{\tau=T_0}^{t}\sum_{j=1}^{m}\dfrac{\partial h_j^{(\tau)}}{\partial W}\zeta_j^{(\tau)}$ | **梯度退化为"近端效应"**。书中例：$T=300$、$T_0=250$ ⟹ 前 250 步对梯度几乎无贡献 |

### 7.4 编码器-解码器与注意力机制

| 编号 | 公式 | 符号与用途 |
|---|---|---|
| **(7.20)** | $\alpha^{(t)}=S_{\text{softmax}}\Big(\big[s(z_q^{(t)},z_k^{(1)}),\dots,s(z_q^{(t)},z_k^{(T_{\text{in}})})\big]^\top\Big)\in\mathbb{R}^{T_{\text{in}}}$ | **注意力权重**：由 query 与全部 key 的**打分函数** $s(\cdot,\cdot)$ 经 softmax 归一化 |

> 1. **本书没有写出 $\mathrm{softmax}(QK^\top/\sqrt{d_k})V$**。它给的是上面的**一般框架**（打分函数 $s$ 可任选），(7.23)(7.24)(7.25)(7.33) 都是它的实例化。
> 2. **维度记号是 $m_q,m_k,m_v,p$**，不是 $d_k,d_v,d_{\text{model}}$。
> 3. **打分函数的归一化**：原文说 $s$ "typically have normalization as part of the score function with a factor such as $\sqrt{\max(m_q,m_k)}$… maintains score values at a reasonable range for numerical stability"（p274）。**本书把它定位为数值稳定性因子**，而非经验技巧。
> 4. **方差解释（本表补的推导，非原书原文）**：若 $q,k$ 各分量独立、零均值、单位方差，则 $q^\top k$ 的方差为 $d$；除以 $\sqrt{d}$ 后方差恒为 1，避免 softmax 进入饱和区导致梯度消失。
> 5. **多头合并是加权和**（(7.26)）$u^{(t)}=\sum_{h=1}^{H}W^h_c u^{h,(t)}$，$W^h_c\in\mathbb{R}^{p\times m_v}$，**不是 concat + projection**。

>
> ⚠ **下标约定**：本书的 $\gamma_t$ 对应标准 DDPM 记号的 $\bar\alpha_t$，且前向核写 $q(z_{t+1}|z_t)$ 配 $\beta_t$、反向式 (8.35) 配 $\beta_{t-1}$——**与标准 DDPM 差一个下标**，但内部自洽。若要统一到 $\bar\alpha$ 记号需整体平移一位。
