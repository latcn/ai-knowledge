
> 本文整合了《深入理解 AI Agent》第八章及所有相关讨论，采用第一性原理追问、苏格拉底式引导、费曼式解释和具体例子，系统梳理大模型后训练的完整知识体系。  
> 核心主线：**模型学到什么，取决于训练信号教了它什么；信号质量由数据和环境决定，不是算法。**

## 一、总览：后训练在 Agent 体系中的位置

### 1.1 核心公式

**Agent = LLM + 上下文 + 工具**  
- LLM：大脑，决策核心  
- 上下文：眼睛，看到什么  
- 工具：手脚，能做什么  

**生产形态：Agent = Model + Harness**  
Harness = 上下文管理 + 工具接口 + 约束 + 验证 + 纠正  

### 1.2 四阶段全景

| 阶段 | 类比 | 目标 | 数据 | 损失/信号 | 学到什么 |
|---|---|---|---|---|---|
| 预训练 | 通识教育 | 预测下一个词 | 海量互联网文本 | 全 token 交叉熵 | 语言、世界知识、基本推理 |
| Mid-training | 专业预科 | 补底座 | 领域文档、代码、长文本 | 继续预测下一个词 | 领域知识、基础能力、长上下文 |
| SFT | 岗前培训 | 固化协议 | 指令-回答对 | 只在回答 token 上算损失 | 格式、风格、流程、工具调用 |
| RL | 实战打磨 | 优化策略 | 任务、环境、奖励 | 最大化期望奖励 | 策略、泛化、探索示范外路径 |

**关键：四阶段不是“微调力度”，而是“分工”。**

## 二、第一性原理：模型学到什么？

### 2.1 概率分布视角

模型输出是词表上的概率分布。训练就是调整这个分布——让想要的 token 概率更高，不想要的更低。

四个环节的区别只在于：
- **想要什么**（目标）
- **用什么信号定义想要**（监督信号）

| 阶段 | 想要什么 | 信号 |
|---|---|---|
| 预训练 | 预测下一个词 | 全 token 交叉熵 |
| Mid-training | 预测下一个词（目标分布） | 全 token 交叉熵 |
| SFT | 模仿示范回答 | 只在回答 token 上算损失 |
| RL | 最大化期望奖励 | 奖励信号 |

### 2.2 苏格拉底式追问

**问：为什么不能直接用预训练模型对话？**  
答：预训练模型只学会“预测下一个词”，你问它问题，它可能续写更多问题，不会遵循指令。

**问：为什么 SFT 不能注入大量知识？**  
答：SFT 数据是几千到几万条问答对，只覆盖有限问法。它擅长训练“如何访问与表达”，不适合承载大规模、相互关联的原始知识。

**问：为什么 RL 不是从零创造能力？**  
答：RL 是放大器，不是发电机。它只能把已有但概率较低的成功行为推高，不能凭空创造模型从未学过的知识和能力。

### 2.3 费曼式类比

- **预训练**：读完图书馆所有书，博学但不会好好回答问题。
- **Mid-training**：集中研修专业教材，补上通用教育没覆盖的领域。
- **SFT**：老师示范答题，学会格式、风格、流程。
- **RL**：自己下场做题，根据结果反复打磨，探索更优解。

## 三、深入 Mid-training：补底座

### 3.1 第一性原理

**问：为什么需要 Mid-training？**  
答：通用预训练不可能覆盖所有语言、领域和能力。如果模型几乎读不懂韩语、不了解企业内部协议，直接 SFT/RL 也绕不过这个缺口。

**定义**：从已有基础模型出发，在目标数据分布上继续做语言模型训练。数据格式和损失函数与预训练相同。

**别名**：继续预训练（CPT）、领域自适应预训练（DAPT）、任务自适应预训练（TAPT）。

### 3.2 解决两类缺口

| 缺口 | 表现 | 例子 |
|---|---|---|
| 知识缺口 | 连概念和术语都不理解 | 目标语言、金融/医疗/法律、企业内部文档、某类代码库 |
| 基础能力缺口 | 足够多次采样也几乎得不到正确解 | 长上下文、代码模式、数学推导、跨模态表征 |

### 3.3 数据构造五步法

1. **从失败分布反推数据**：按主题、语言、文档类型、代码模式、上下文长度切分评估，确认低 pass@k 来自哪类底座缺口。
2. **构造高密度目标语料**：原始文档、代码仓库、教材式推导、合成释义、跨文档关联样本。
3. **按能力配比**：自然长文本 + 长文本原子能力（检索、多跳推理、指令遵循、信息聚合与统计）+ Agent 必需能力（规划、工具选择与调用、长程状态跟踪、错误恢复）。
4. **双重回放**：原始短文本和通用数据保留通用能力；长度提升后的旧任务检验长窗口能力。
5. **多维门禁**：训练 loss、留出领域任务、通用能力、原有指令遵循、目标任务 pass@1/pass@k。

### 3.4 关键实验：继续预训练学习新语言

- 基座：Mistral 7B v0.3（主要英语，韩语几乎不会）
- 方法：韩语维基百科继续预训练，80% 韩语 + 20% 英语
- 最后：韩语指令数据 SFT
- 职责分工：Mid-training 补韩语知识与语言能力，SFT 教如何用韩语接受指令
- 代价：英语能力下降 → 需要保留集、事实评估、数据质量审计

### 3.5 费曼式类比

Mid-training 像在通识教育和职业培训之间加一段“专业预科班”。学生先集中学习专业基础课，把大脑调整到适合学习专业技能的状态，再去上职业培训课。

## 四、深入 SFT：固化协议

### 4.1 本质

**SFT = 换了数据、只在回答上算损失的“预测下一个词”。**

与预训练在数学上完全相同，区别只有两点：
1. 数据换成“输入—输出”对
2. 损失只算在回答 token 上（loss masking）

### 4.2 核心价值

> SFT 的核心价值不在于注入新知识，而在于固化输出格式：把映射关系、交互格式、风格规范写入参数。

固化的内容：
- JSON / 工具调用格式
- 对话语气、风格
- 先查政策再退款的流程
- 拒绝危险请求的边界
- 多语言思考模板

### 4.3 数据来源三条路

| 来源 | 作用 | 优点 | 缺点 |
|---|---|---|---|
| 人工专家示范 | 定义格式与边界 | 质量天花板最高 | 贵、慢 |
| 教师模型生成 | 放大规模 | 批量产出，成本低 | 继承教师错误 |
| 拒绝采样（RFT） | 筛出正确轨迹 | 可验证任务上性价比极高 | 依赖验证器 |

**组合流程**：人工种子 → 教师放大 → 验证器过滤 → 去重、平衡、多样性。

**关键**：数千到数万条高质量样本通常足够固化格式。与其堆十万条脏数据，不如精修一万条干净数据。

### 4.4 四个实验

| 实验 | 固化了什么 |
|---|---|
| 语音 SFT | 风格控制协议 |
| 多语言 SFT | 思考组织模板 |
| Prompt 蒸馏 | 输入到输出的直接映射 |
| CoT 蒸馏 | 完整思考轨迹 |

### 4.5 SFT 的局限

- 容易偏向复现示范模式，新场景性能下降。
- 可能过拟合示范，需要保留集和边界集。
- 不适合承载大规模领域知识。

### 4.6 费曼式类比

SFT 像老师手把手教你答题。你学会了解题步骤和书写格式，但考试时遇到没见过的题型，容易套用旧模板。

## 五、深入 RL：优化策略

### 5.1 核心概念

**强化学习**：Agent 与环境交互，通过试错搜索和延迟奖励，学习策略最大化长期累积奖励。

**五个核心要素**：
- 动作空间
- 策略
- 奖励信号
- 价值函数
- 环境模型（可选）

**两个独特挑战**：
- 试错搜索：没有老师直接告诉正确答案
- 延迟奖励：动作影响可能在多步之后才显现

**探索与利用权衡**：一直走熟悉的路学不到新东西；一直乱试永远到不了终点。

### 5.2 SFT vs RL 的本质区别

| 维度 | SFT | RL |
|---|---|---|
| 优化目标 | 最大化标注答案概率 | 最大化期望奖励 |
| 训练信号 | 逐 token 监督 | 结果/过程奖励，通常标量 |
| 直接压力 | 模仿示范 | 强化高奖励行为 |
| 概率分布倾向 | mass-covering（覆盖多种示范） | mode-seeking（集中高奖励峰） |
| 样本效率 | 高（几千条见效） | 低（常是 SFT 几十到上百倍） |
| 分布漂移 | 取决于示范覆盖和正则化 | 取决于奖励、环境和探索 |
| 最适合 | 固化格式、风格、流程 | 泛化到新场景、探索最优策略 |

**关键**：“SFT 记忆、RL 泛化”是受控实验中的倾向，不是普遍规律。

### 5.3 三种核心算法

| 算法 | 全称 | 核心机制 | 优点 | 缺点 |
|---|---|---|---|---|
| PPO | Proximal Policy Optimization | 价值网络 + 概率比裁剪 | 通用、稳定、细粒度信用分配 | 贵、超参敏感 |
| GRPO | Group Relative Policy Optimization | 组内相对优势，无价值网络 | 省内存，适合大模型 | 全对/全错无梯度 |
| DPO | Direct Preference Optimization | 直接偏好对优化，离线 | 简单、稳定、成本低 | 不能探索，依赖偏好数据 |

**GRPO 核心**：同一问题多条 rollout，高于平均得正优势，低于平均得负优势。全对/全错时优势为零。

**PPO 裁剪**：把概率比 ρt 限制在 [1-ε, 1+ε] 内，防止单次更新过猛。

### 5.4 奖励设计

#### 三个维度

| 维度 | 选项 | 说明 |
|---|---|---|
| 来自哪里 | RLVR、RLHF、GRM | 可验证奖励、人类偏好、生成式奖励模型 |
| 什么时候给 | ORM、PRM | 结果奖励、过程奖励 |
| 表达多少信息 | 标量、半标量、向量、生成式诊断 | 分数、理由+分数、多维度、自然语言诊断 |

#### 关键原则

- 有确定答案或测试 → 优先二元标量
- 有多个独立质量目标 → 向量，或加权成标量
- 开放式、难穷举规则 → 生成式诊断 + 事实校验 + 人工抽检
- 不要为了“奖励更丰富”而堆叠不可验证的维度
- 先确认信号能在少量 rollout 中产生有意义的组内差异

#### RLVP：奖励结果，惩罚路径

总奖励：\(R = O + \beta \Phi\)
- \(O\)：任务结果
- \(\Phi\)：确定性规则逐动作计算的路径信号
- 对可验证违规动作扣分，对合规动作或可达子目标给少量部分奖励

**四点原则**：
1. 只惩罚具体动作，不惩罚“不够努力”
2. 结果奖励始终保留
3. 每个惩罚最好配一条可达的合规路径
4. 规则必须确定、难以钻空子

### 5.5 信用分配

**问题**：多轮 Agent 中，最终成功/失败很难归因到第 3 轮还是第 7 轮。

**解决**：
- 结果奖励建立基线
- 过程奖励缓解长时序信用分配
- RLVP 恢复组内差异
- Turn-level 优势 / GAE
- 折扣因子 γ = 1
- 隐藏测试 + 外部终止钩子

### 5.6 环境工程

**顺序**：任务蓝图 → 可重置模拟器 → 确定性验证器 → 训练/评估隔离 → 少量真实交互校准

**关键**：
- 可重置：每个 episode 回到确定初始状态
- 可并行：百万次交互可接受
- 可复现：状态转移可信
- 训练/评估隔离：共享生成器，不共享任务
- 验证器可能是 CPU 瓶颈，需并行 worker

### 5.7 数值一致性

**问题**：采样引擎（vLLM）和训练引擎（FSDP）对同一 token 的 log probability 有微小差异。

**放大链条**：
```
log probability 小误差 → 指数化的概率比偏差 → 长前缀上的累积 → clipping/优势加权改变 → 梯度方向与有效样本数改变
```

**具体例子**：4000 个 token，每个偏差 10⁻³，轨迹级 ρt = e⁴ ≈ 54.6。

**工程措施**：
- 更新前监控 ρt 均值、分位数、最大值、近似 KL、裁剪比例
- 同步权重、LoRA adapter、tokenizer、chat template、模型 revision、位置编码
- 保存 behavior log probability
- 对齐精度、并行布局、关键计算内核
- 保持 rollout 新鲜，限制 staleness

### 5.8 费曼式类比

RL 像教练训练运动员。教练调整的是运动员的“动作习惯”（策略参数），不是秒表（学习率），不是跑道（环境），不是评分标准（奖励函数）。

## 六、蒸馏与在轨蒸馏

### 6.1 蒸馏的本质

**蒸馏 = 知识转移方法；SFT = 训练算法。**

- 黑盒蒸馏：只学教师文本输出 → 标准 SFT
- 白盒蒸馏：学教师概率分布 → KL 散度对齐
- 在轨蒸馏：学生决定走到哪里，教师给出逐 token 分布

### 6.2 On-Policy Distillation

**核心**：学生决定走到哪里，教师负责在学生已经走到的位置告诉它下一步的完整概率分布。

**优势**：
- 一条长度 T 的 rollout 产生约 T 组逐 token 监督
- 比离轨 SFT 更贴近学生实际会犯的错
- 比纯 RL 反馈更密集、方差更低

**前提**：
- 学生能进入教师可纠正的有效状态
- 教师策略不能离学生有效支持太远
- 基模有目标语言、领域概念、基本动作

**数值一致性**：同样需要监控 sampler/trainer log probability 一致性。

### 6.3 On-Policy Self-Distillation（OPSD）

**破题**：没有更强的教师怎么办？同一个模型分饰教师和学生，教师看到特权信息（标准答案）。

**伪代码**：
```python
student_trajectory = rollout(model, task_without_answer)
loss = 0
for state in student_trajectory:
    privileged_state = add_verified_answer(state)
    teacher_logits = stop_gradient(model(privileged_state))
    loss += KL(model(state), teacher_logits)
update(model, loss + retention_regularizer)
```

**关键**：
- 特权信息只能在训练侧构造，不能泄露给部署时的 Agent
- 如果模型拿着答案也讲不清过程，自蒸馏没有额外信号
- 朴素 OPSD 可能丢失原有思考风格，需要正则稳定

### 6.4 逆向蒸馏：小模型教大模型

**Weak-to-Strong Generalization**：弱模型的监督信号有时能激发强模型本身潜在但未被激活的能力。

**可能路径**：
- 弱模型提供粗粒度奖励
- 弱模型提供检查清单
- 弱模型提供偏好对

**风险**：弱模型偏见被放大；强模型可能学会迎合弱模型。

### 6.5 费曼式类比

- **On-Policy Distillation**：请一个更强的老师来教你。
- **OPSD**：没有更强的老师，就把答案给你自己，让“看答案的你”去教“做题的你”。
- **逆向蒸馏**：小学生给大学生出题，大学生自己琢磨出更深的解法。

## 七、从评估到后训练

### 7.1 评估资产映射

| 第七章评估资产 | 第八章训练用法 |
|---|---|
| 端到端回归任务 | RL rollout 任务与可验证奖励；拒绝采样采样池 |
| 轨迹前缀回归任务 | DPO 偏好对、决策边界 SFT、On-Policy Distillation 教师状态 |
| 失败归因记录 | 过程监督负标签、RLVP 路径惩罚规则来源 |
| Rubric 多维评分 | 向量奖励各维度、GRM 训练与校准数据 |

### 7.2 案例：Coding Agent 过早结束

**归因**：首个错误定位在“准备宣称完成”的决策边界。

**训练数据**：
- 端到端回归：隐藏测试通过 +1，不通过 −1
- 轨迹前缀回归：rejected = 过早结束；chosen = 先验证再下结论
- 数据扩充：换任务类型、换缺失验证项、换完成措辞
- 小配比混入通用数据做 LoRA

**评估**：边界集 + 保留集缺一不可。只盯边界集会训练出永远不敢收尾的过度矫正状态。

### 7.3 案例：编辑文件经常失败

**归因链**：文件原始字节 → 工具返回 → Harness 序列化 → 模型上下文 → 模型 token 输出 → 解码字符串 → JSON/tool-call 解析 → 工具匹配。

**只有模型输出是链路上首个差异，才是模型精确复制能力问题。**

**训练数据**：三个可验证任务（逐字复述、相似字符串选择、JSON 参数抄写），覆盖空格、换行、反斜杠、Unicode。

**实验 8-19**：Qwen3-8B，LoRA 2 epoch，byte-exact accuracy 从 37.5% 提升到 78.9%，独立边界集 80.1%。tokenizer 无损 round-trip 也是 80.1%，说明这是共同上限。

### 7.4 费曼式类比

从问题案例到后训练，像医生看病：先诊断（失败归因），再开药（构造训练数据），最后复查（边界集+保留集）。

## 八、后训练实践要点

### 8.1 11 个陷阱

| 陷阱 | 核心问题 | 解决 |
|---|---|---|
| 1 | SFT 硬塞知识 | Mid-training + RAG |
| 2 | 格式未稳定就 RL | 先 SFT / 约束解码 |
| 3 | 标称窗口 ≠ 有效窗口 | 能力 × 长度矩阵 |
| 4 | pass@k 近零就 RL | 先补底座 / 造课程 |
| 5 | 奖励黑客 | 隐藏测试 + RLVP |
| 6 | 仿真保真度低 | 高保真 + 真实校准 |
| 7 | 过度训练 | 保留集 + 早停 |
| 8 | 价值函数崩溃 | 监控 + 熵正则 |
| 9 | 数值失配 | 监控 ρt + 对齐配置 |
| 10 | 低估 RL 成本 | 先测 pass@k，SFT 够用就不 RL |
| 11 | 数据质量低 | 去重 + 过滤 + 人工抽检 |

### 8.2 核心原则

> 在投入大规模资源前，先用小规模实验验证关键假设——小批 Mid-training 语料检查知识/能力与遗忘曲线，少量 SFT 数据测试格式能否稳定，小批 rollout 检查 pass@k、奖励差异和 sampler/trainer 数值一致性。快速失败比大规模失败更可接受。

### 8.3 与 RAG/ICL 的协同

| 方法 | 作用位置 | 适合承载 |
|---|---|---|
| ICL / 上下文 | 即时适应 | 示例、规则、当前状态 |
| RAG | 外部知识 | 动态事实、证据、可更新知识 |
| 程序 / Harness | 硬约束 | 确定性流程、权限、安全 |
| Mid-training | 参数 | 稳定领域知识、基础能力 |
| SFT / RL | 参数 | 高维感知、风格、隐式策略 |
| 蒸馏 | 参数迁移 | 大模型能力迁移到小模型 |

**选择依据**：不只是任务是否长期稳定，更重要的是**能力能否被外部符号充分表达**。

**稳健系统组合**：用 RAG 管理动态事实与证据，用 ICL 快速试验可用语言描述的策略，用程序固化确定性流程与硬约束，用 Mid-training 吸收稳定领域知识和基础能力，再用 SFT/RL 塑造难以由外部规则完整表达的行为。

## 九、思考题整合解答

（将 13 道思考题的解答整合到相应章节，此处简要列出核心观点）

1. **灾难性遗忘缓解**：数据混合、双重回放、正则化、小配比、小 rank、早停、多适配器、边界集+保留集。
2. **后训练 vs 上下文学习**：判断标准是能力能否被外部符号充分表达；动态事实走 RAG，稳定知识走 Mid-training，格式流程走 SFT，隐式策略走 RL。
3. **蒸馏三类模型难点**：Chat 学风格；Reasoning 学完整思考轨迹，需开源 CoT，过滤错误；Agentic 学交互策略，屏蔽环境 token，解决信用分配。
4. **多轮信用分配**：结果奖励 + 过程奖励 + RLVP + turn-level 优势 + γ=1 + 隐藏测试。
5. **固定预算分配**：先排除不改权重方案，测能力支持，按缺口分配：RAG 10-20%，SFT 20-30%，Mid-training 30-50%，RL 10-20%。先小规模验证。
6. **无明确奖励的自主学习**：当前依赖 RLVR/RLHF；突破方向：世界模型、内在动机、自我对弈、Meta-RL、Weak-to-Strong。
7. **专属 LoRA vs 知识库**：稳定高频隐式偏好走 LoRA；动态事实、需引用、需删除走 RAG。
8. **逆向蒸馏**：弱模型提供方向，强模型自我修正；风险是偏见放大和迎合。
9. **PRM vs ORM**：结果奖励是最终目标，过程奖励解决信用分配和 reward hacking；用 RLVP 权衡。
10. **评估集用于训练 vs 独立性**：动态参数生成、训练/评估隔离、held-out 评估集、持续更新、边界集+保留集。
11. **pass@1 低时路径判断**：测格式解析率 → pass@k → 部分进展率 → 失败归因；pass@k 近零 → Mid-training；格式不稳 → SFT；有奖励差异 → RL。
12. **长尾响应优化**：连续批处理、异步 rollout、超时截断、分桶、投机解码、优先级调度、提前开始短 rollout 训练。
13. **模拟器 reward hacking**：钻模拟器偏见、伪造通过、利用漏洞、讨好模拟器；防范：多模拟器集成、真实环境校准、红队测试、隐藏测试、RLVP、动态参数化。

## 十、总结：后训练知识体系图

```
后训练
├── 第一性原理：模型学到什么取决于训练信号
├── 四阶段分工
│   ├── 预训练：通识教育，预测下一个词
│   ├── Mid-training：专业预科，补底座
│   ├── SFT：岗前培训，固化协议
│   └── RL：实战打磨，优化策略
├── SFT
│   ├── 本质：换了数据的预测下一个词
│   ├── 数据来源：人工、教师、拒绝采样
│   ├── 固化：格式、风格、流程、协议
│   └── 局限：不注入大量知识，易过拟合
├── RL
│   ├── 算法：PPO、GRPO、DPO
│   ├── 奖励设计：来源、时机、信息量、路径约束
│   ├── 信用分配：ORM、PRM、RLVP、GAE
│   ├── 环境工程：可重置、可并行、验证器、隔离
│   └── 数值一致性：ρt 监控、长序列指数放大
├── 蒸馏
│   ├── 黑盒/白盒
│   ├── On-Policy Distillation：学生决定状态，教师逐 token 监督
│   ├── OPSD：同一模型分饰两角，特权信息
│   └── 逆向蒸馏：弱教强
├── 从评估到后训练
│   ├── 失败归因
│   ├── 轨迹前缀回归
│   ├── DPO 偏好对
│   └── LoRA 训练 + 边界集/保留集
├── 实践要点
│   ├── 11 个陷阱
│   ├── 先小规模验证
│   └── 与 RAG/ICL 协同
└── 核心判断
    ├── 数据和环境比算法更重要
    ├── 样本效率与分布一致性是 RL 瓶颈
    └── 参数只是四种载体之一：知识、指令、程序、参数
```

**最终一句话**：

> **Mid-training 补底座，SFT 立协议，RL 优策略。数据和环境比算法更重要；模拟器偏差就是训练天花板。RL 的瓶颈是样本效率与分布一致性。参数只是四种载体之一：知识、指令、程序、参数。**
