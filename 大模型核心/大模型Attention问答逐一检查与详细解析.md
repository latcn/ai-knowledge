# 一、Attention 基础与计算

## Q1：请按上传文档的方式教会一个普通本科生掌握核心知识

**回答**：核心是“广度优先建图 + 深度优先攻坚高杠杆点”。大模型知识是依赖图，不是文章。先用手画依赖图建立骨架，再对 10 个高杠杆点深挖：Attention 本质、Next-Token 交叉熵、缩放定律、残差+Pre-LN、训练配方、KV-Cache、SFT/RLHF/DPO、LoRA/量化、RAG、Agent 三件套。掌握标准是能推导、能实现、能预测改条件后的结果、能指出失效边界。

## Q2：Attention 采用的 softmax 具体是什么？QK 是矩阵吗？输出层如何选择？

**问题原文核心**：  
“Attention 采用的 softmax 函数具体是什么？先计算 QK/√dk 的 softmax 函数值？QK 不是一个矩阵吗？Q 是用户输入信息矩阵，每个 token 一个向量表示，最后通过 QKV 计算的值，需要经过前馈神经网络计算，最后获取一个值，输出层解释或概率选择这个值。”

**详细回答**：

1. **Softmax 对向量**：  
  $$
   \text{softmax}(z_i)=\frac{e^{z_i}}{\sum_j e^{z_j}}
   $$

2. **Softmax 对矩阵**：按行做。每行变成一个概率分布，和为 1。  
   $$
   \text{softmax}(M)_{i,j}=\frac{e^{M_{i,j}}}{\sum_k e^{M_{i,k}}}
   $$

3. **QK^T 是矩阵**：  
   $$Q\in\mathbb{R}^{T\times d_k}$$，$$K\in\mathbb{R}^{T\times d_k}$$，所以  
   $$
   QK^\top\in\mathbb{R}^{T\times T}
   $$  
   第 $$i$$ 行第 $$j$$ 列是 $$Q_i\cdot K_j$$，表示 token $$i$$ 和 token $$j$$ 的原始关联度。

4. **完整计算**：  
   $$
   S=\frac{QK^\top}{\sqrt{d_k}}
   $$  
   加因果掩码后，按行 softmax：  
   $$
   A=\text{softmax}(S)
   $$  
   然后：  
   $$
   Z=AV\in\mathbb{R}^{T\times d_v}
   $$  
   $$Z$$ 不是“一个值”，而是每个 token 一个 $$d_v$$ 维向量。

5. **Q 不是原始输入**：  
   $$Q=XW_Q$$，$$K=XW_K$$，$$V=XW_V$$。原始输入是 $$X$$。

6. **输出层**：  
   $$Z$$ 经过 FFN、残差、LayerNorm、多个 Block 后，得到最终隐藏状态 $$H$$。  
   输出投影：  
   $$
   \text{logits}=HW_{\text{out}}^\top\in\mathbb{R}^{T\times V}
   $$  
   训练时直接送交叉熵；推理时 softmax 后采样。

**修正点**：Attention 输出是矩阵，不是“一个值”；输出层得到的是每个位置在词表上的概率分布。

## Q3：QKV 语义，为什么需要 K，去掉 K 会怎样？自注意力对角线本质？

**问题原文核心**：  
“Q 代表输入要查什么，K 代表是什么？V 代表有什么内容？为什么不设计成找什么 Q 和 V 有什么内容直接计算，多一个 K 可不可以优化掉？计算自身对自身的注意力的本质是什么？和计算和其他 token，可以理解成相关程度吗？”

**详细回答**：

1. **QKV 语义**：  
   - Q：我在找什么。  
   - K：我是什么。  
   - V：我有什么内容。

2. **为什么不能去掉 K**：  
   - 若用 $$QQ^\top$$：只衡量查询之间的相似度，失去“查询-键”交叉匹配。  
   - 若用 $$QV^\top$$：Q 和 V 在不同语义空间，粒度不对；且 V 会同时承担“被匹配”和“被聚合”，任务矛盾。  
   - K 的作用是把“匹配”和“聚合”解耦。

3. **自注意力对角线**：  
   $$A_{i,i}$$ 是 token $$i$$ 对自己的注意力权重。  
   - 高：保留自我信息。  
   - 低：吸收外部信息。  
   - 全 0：表示趋同，失去区分 token 的能力。  
   - 全 1：$$A=I$$，退化为恒等映射，失去上下文建模。

4. **“相关程度”是否准确**：  
   可以理解为相关程度，但更准确是“在当前任务和上下文中，第 $$j$$ 个位置对第 $$i$$ 个位置的有用程度”。它是任务驱动、动态、多头的。

## Q4：除了 softmax，还有哪些归一化方法？主流大模型用什么？

**详细回答**：

| 方法 | 核心思想 | 现状 |
|---|---|---|
| Sigmoid/ReLU | 逐元素激活，可稀疏 | 2025 年研究显示经适当归一化可匹配 Softmax |
| Sparsemax/α-entmax | 直接产生稀疏概率，部分权重为 0 | 研究阶段，未降 O(n²) |
| Softpick | 不强制和为 1 | 缓解注意力沉没 |
| Softmax-N/Softmax1 | 分母加 1，允许“不关注任何 token” | 缓解注意力沉没 |
| 线性注意力/核方法 | 用核函数替换 Softmax，线性复杂度 | 超长序列，稳定性需验证 |

**主流仍用 Softmax**，因为梯度稳定、硬件优化成熟。改良方向有 Softmax-N、Sigmoid 门控；重构方向有线性注意力。

## Q5：KV 权重合并前沿；对角线权重练习

**问题原文核心**：  
“KV 计算涉及到的权重可以合并到一个进行优化，请分析；1. 用 3 个 token 构造注意力矩阵，对角线权重分别 0.9、0.5、0.1，观察输出；2. 强制对角线全 0 失去什么？3. 强制对角线全 1 失去什么？”

**详细回答**：

1. **对角线练习**：  
   - 0.9：输出接近自身。  
   - 0.5：自身和外部各半。  
   - 0.1：被外部主导。  
   - 全 0：失去原始 token 信息，表示趋同。  
   - 全 1：输出等于输入，失去上下文建模。

2. **KV 权重合并方向**：  
   - MQA：所有 Query 头共享一组 K/V。  
   - GQA：分组共享。  
   - MLA：联合低秩压缩 + 矩阵吸收。  
   - Palu：训练后低秩分解。  
   - LRKV：共享全秩 + 低秩残差。  
   - Q-K=V：K 和 V 共享投影矩阵。

## Q6：《Do Transformers Need Three Projections?》分析

**详细回答**：

- 论文比较 Q-K=V、Q=K-V、Q=K=V。
- Q-K=V：Q 独立，K 和 V 共享投影。仅 3.1% PPL 退化，减少 50% KV-Cache。
- 与 GQA/MQA 正交：Q-K=V + GQA-4 减少 87.5%，Q-K=V + MQA 减少 96.9%。
- Q=K-V 失败，因为破坏注意力方向性。
- 与 MLA 区别：Q-K=V 是投影矩阵共享；MLA 是张量联合低秩压缩。
- 与 Palu 区别：Q-K=V 无需重建，原生兼容 RoPE；Palu 需重建，RoPE 阻断融合。
- 维度处理：标准 Transformer 中 $$d_k=d_v$$，共享后维度一致。

## Q7：Q 是 m×n，K^T 是 n×m，序列长度是 m 吗？

**详细回答**：

标准约定：  
- $$m=T$$：序列长度。  
- $$n=d_k$$：Query/Key 维度。  
- $$d_v$$：Value 维度。

$$
Q\in\mathbb{R}^{m\times n},\quad K^\top\in\mathbb{R}^{n\times m}
$$
$$
QK^\top\in\mathbb{R}^{m\times m}
$$
$$
AV\in\mathbb{R}^{m\times d_v}
$$

**序列长度就是 $$m$$**。输入 $$m$$ 个 token，输出也是 $$m$$ 个 token。

---

## Q8：V 是 m 个 dv 维行向量，AV 是加权线性组合

**详细回答**：

$$
(AV)_i=\sum_{j=1}^{m}A_{i,j}V_j
$$
这是 $$V$$ 的行向量的线性组合。因为 $$A_{i,j}\ge 0$$ 且 $$\sum_j A_{i,j}=1$$，所以是**凸组合**。输出在 $$V$$ 行向量的凸包内。

---

## Q9：y=-x+1 类比凸组合

**详细回答**：

两个 Value 向量 $$v_1=[1,0]$$，$$v_2=[0,1]$$。  
权重 $$a_1,a_2\ge 0$$，$$a_1+a_2=1$$。  
输出：
$$
o=a_1v_1+a_2v_2=[a_1,a_2]
$$
因为 $$a_2=1-a_1$$，所以 $$y=1-x$$。输出在连接 $$v_1,v_2$$ 的线段上。  
**权重和为 1 是凸组合的核心条件。**

---

## Q10：[1/3,1/3,1/3] 输出点是什么？

**详细回答**：

$$
o=\frac{1}{3}v_1+\frac{1}{3}v_2+\frac{1}{3}v_3
$$
若 $$v_1=[1,0]$$，$$v_2=[0,1]$$，$$v_3=[1,1]$$，则：
$$
o=[2/3,2/3]
$$
这是三角形重心。该练习价值有限，更好的练习是构造负权重反例，观察输出跑出凸包。

---

## Q11：凸组合和凹的区别？

**详细回答**：

标准概念：

| 组合 | 系数条件 | 结果范围 |
|---|---|---|
| 线性组合 | 任意 | 整个空间 |
| 仿射组合 | 和为 1，可负 | 仿射子空间 |
| 凸组合 | 非负且和为 1 | 凸包 |
| 锥组合 | 非负，无和限制 | 凸锥 |

没有“凹组合”标准概念。若有人用，通常指仿射组合。凸函数/凹函数是函数性质，与组合不同。

# 二、有界性、残差、归一化

## Q12：Attention 有界 vs FFN 无界；softmax 两个条件；残差作用

**详细回答**：

1. **Attention 有界**：  
   $$
   (AV)_{i,k}=\sum_j A_{i,j}V_{j,k}
   $$  
   $$A_{i,j}\ge 0$$，$$\sum_j A_{i,j}=1$$，所以：
   $$
   \min_j V_{j,k}\le (AV)_{i,k}\le \max_j V_{j,k}
   $$  
   输出范数不超过 Value 最大范数。

2. **FFN 无界**：  
   $$
   \text{FFN}(x)=W_2\text{GELU}(W_1x+b_1)+b_2
   $$  
   输出范数由 $$W_1,W_2$$ 谱范数决定，权重可增长。

3. **Softmax 两个条件**：  
   - 只非负：幅度可爆炸。  
   - 只和为 1：方向可外推。  
   - 同时保证：有界凸组合。

4. **训练稳定性**：  
   - Attention 有界 → 天然稳定。  
   - FFN 无界 → 需初始化、LayerNorm、梯度裁剪、warmup。

5. **残差作用**：  
   $$
   h_l=h_{l-1}+f(h_{l-1})
   $$  
   反向：
   $$
   \frac{\partial h_l}{\partial h_{l-1}}=I+\frac{\partial f}{\partial h_{l-1}}
   $$  
   恒等项防梯度消失。**残差不防梯度爆炸，也不控制输出幅度。**

---

## Q13：残差连接只能防止梯度消失

**详细回答**：

正确。残差提供恒等梯度路径，缓解梯度消失。但它不裁剪梯度，不压缩前向幅度。防爆炸靠 LayerNorm、初始化缩放、梯度裁剪、warmup、bf16/loss scaling。

# 三、FFN 与知识存储

## Q14：QKV 计算是否检索隐性知识？

**详细回答**：

QKV 调用的是**程序性知识**：关系模式、特征提取规则。不是事实性知识。  
事实性知识主要存储在 FFN 和 Embedding。  
Attention 是信息路由器，FFN 是知识处理器。

---

## Q15：FFN 调用陈述性知识，详细说明

**详细回答**：

1. **FFN 结构**：  
   $$
   \text{FFN}(x)=W_2\text{GELU}(W_1x+b_1)+b_2
   $$

2. **键值记忆假说**：  
   Geva 等提出并提供了强实证证据支持一个可解释性假说：FFN 可被视为键值记忆。  
   $$W_1$$ 的行是键，$$W_2$$ 的列是值。  
   $$
   \text{FFN}(x)=\sum_i \text{GELU}(k_i\cdot x+b_{1,i})v_i+b_2
   $$

3. **证据**：  
   - 知识神经元：一小簇神经元与事实高度相关。  
   - 因果追踪：事实回忆关键计算在中间层 FFN。  
   - ROME/MEMIT：修改 FFN 权重可改变事实。

4. **分布式**：  
   事实是分布式、多冗余存储，不是精确数据库。知识神经元是分布式表示中可识别的关键子集。

5. **分工**：  
   Attention 路由信息，FFN 检索知识。

---

## Q16：FFN 是什么？参数怎么训练？能稳定输出事实吗？

**详细回答**：

1. **FFN 是什么**：  
   Block 第二半，逐位置变换。  
   $$
   d_{model}\to d_{ff}\to d_{model}
   $$  
   通常 $$d_{ff}=4d_{model}$$。参数量约占 2/3。

2. **参数训练**：  
   通过反向传播和梯度下降。  
   $$
   W_1\leftarrow W_1-\eta\frac{\partial L}{\partial W_1}
   $$  
   训练数据中反复出现某事实，梯度调整 $$W_1,W_2$$。

3. **能稳定输出事实吗**：  
   高频事实稳定；低频、冲突、分布外、被微调覆盖的事实不稳定。  
   根本原因：FFN 是分布式表示，不是数据库。  
   提高稳定性：增加数据/容量、数据清理、模型编辑、RAG。

# 四、Block、残差、LayerNorm、训练流程

## Q17：Block 是什么意思？

**详细回答**：

Block 是 Transformer 基本重复单元。  
内部：
```
LN → Attention → 残差
LN → FFN → 残差
```
输入输出形状均为 $$T\times d_{model}$$，可堆叠 $$L$$ 次。  
“12 层”通常指 12 个 Block。

---

## Q18：Attention 做 QKV 得 Z，Block 做交叉熵？

**详细回答**：

- Attention 输出 $$Z$$，但 $$Z$$ 只是 Block 内部中间产物。  
- Block 不计算交叉熵。  
- 交叉熵只在所有 Block 之后算一次。  
- 最小化 loss 通过反向传播和梯度下降实现，不是 Block 的功能。

---

## Q19：A 第 i 行 × V 每一列的含义

**详细回答**：

$$
(AV)_{i,k}=\sum_j A_{i,j}V_{j,k}
$$
含义：token $$i$$ 在第 $$k$$ 个特征维度上的新值，等于所有 token 在该维度的取值按注意力权重加权平均。  
权重 $$A_{i,:}$$ 对所有维度共享；每个维度独立聚合。  
Attention 做 token 混合，不做维度混合。

---

## Q20：分析 QKV 理解

**用户理解**：  
“Q 第 i 行代表 token i 要查询什么；K 第 i 行代表 key；QK^T 第 i 行第 j 列是关联度；QK^T 第 i 行是所有 token 的关联度；QK^T 第 i 行 × V 第 j 列是目标 token i 第 j 维的混合；QK^T V 是权重，计算的是对 V 的 m 行向量的线性组合。”

**检查与修正**：

- 前五条正确。  
- 唯一修正：$$QK^\top$$ 是关联度，softmax 后是权重 $$A$$，$$AV$$ 是结果。  
- 权重是 $$A$$，不是 $$AV$$。  
- $$AV$$ 是对 $$V$$ 行向量的凸组合。

---

## Q21：多头注意力是怎么回事？

**详细回答**：

1. 每个头有独立 $$W_Q^{(r)},W_K^{(r)},W_V^{(r)}$$。  
2. 每个头维度 $$d_k=d_v=d_{model}/h$$。  
3. 每个头独立计算：
   $$
   Z^{(r)}=\text{softmax}\left(\frac{Q^{(r)}K^{(r)\top}}{\sqrt{d_k}}\right)V^{(r)}
   $$
4. 拼接：
   $$
   Z=\text{Concat}(Z^{(1)},\dots,Z^{(h)})\in\mathbb{R}^{T\times d_{model}}
   $$
5. 输出投影：
   $$
   O=ZW_O
   $$
6. 参数量与单头相同。  
7. 每个头学习不同关系模式。

---

# 五、Next-Token 交叉熵

## Q22：Next-Token 交叉熵

**详细回答**：

1. **目标**：
   $$
   L=-\frac{1}{T}\sum_{t=1}^T\log p_\theta(x_t\mid x_{<t})
   $$

2. **从最大似然推**：  
   最大化 $$\prod_t p_\theta(x_t\mid x_{<t})$$ → 取 log → 取平均 → 加负号。

3. **四个身份**：训练目标、评估指标 PPL、缩放定律纵轴、采样温度来源。

4. **等价 KL**：
   $$
   H(q,p)=H(q)+\mathrm{KL}(q\|p)
   $$
   最小化交叉熵 = 最小化 KL。

5. **梯度**：
   $$
   \frac{\partial L}{\partial z_u}=p_u-y_u
   $$

6. **PPL**：$$\text{PPL}=e^L$$。

7. **温度**：推理时 $$p_\tau(v)=e^{z_v/\tau}/\sum_u e^{z_u/\tau}$$。

8. **换条件**：  
   - MSE 在 logits 上：梯度不有界，与概率语义脱节。  
   - SFT 只在回答部分计 loss：让模型专注扮演助手。

9. **失效**：交叉熵只关心相对概率，模型可以自信地错。下游评估要看任务指标。

# 六、四个综合问题

## Q23：QKV 权重约束；多头理解；所有层作用+训练推理；因果掩码矩阵例子

**详细回答**：

### 23.1 QKV 权重约束

- $$W_Q,W_K,W_V$$ 随训练变化，编码关系模式和特征提取规则。  
- 唯一约束：最小化 next-token 交叉熵。  
- 梯度只流向对应位置：$$W_Q$$ 不会收到 $$W_K$$ 的梯度。  
- 位置决定角色，训练只调数值。

### 23.2 多头理解

- 每个头独立投影，从同一 $$X$$ 提取不同表示。  
- 拼接后经 $$W_O$$ 融合。  
- 不是“把 QKV 切成 h 份”，而是“h 套不同投影”。

### 23.3 所有层作用 + 一次训练和推理经过

| 层 | 作用 |
|---|---|
| Embedding | token ID → 向量 |
| 位置编码 | 注入位置信息 |
| Attention | token 间信息路由 |
| FFN | 逐位置变换 + 知识检索 |
| 残差 | 防梯度消失，保留信息 |
| LayerNorm | 控制幅度 |
| 输出投影 | 隐藏状态 → logits |
| Softmax | logits → 概率 |
| 交叉熵 | 训练时算 loss |

**一次训练**：Embedding → 位置编码 → L 个 Block → 输出投影 → logits → softmax → 交叉熵 → 反向传播 → 更新参数。  
**一次推理**：Embedding → 位置编码 → L 个 Block → 输出投影 → logits → 温度/top-k/top-p → softmax → 采样 → 拼接 → 重复。

### 23.4 因果掩码矩阵例子

设 $$T=4$$，$$d_k=2$$，$$Q=K=X$$。  
$$
QK^\top=\begin{bmatrix}
1&0&1&2\\
0&1&1&0\\
1&1&2&2\\
2&0&2&4
\end{bmatrix}
$$
缩放后，上三角设 $$-\infty$$：
$$
S_{\text{masked}}=\begin{bmatrix}
0.707&-\infty&-\infty&-\infty\\
0&0.707&-\infty&-\infty\\
0.707&0.707&1.414&-\infty\\
1.414&0&1.414&2.828
\end{bmatrix}
$$
softmax 后：
$$
A=\begin{bmatrix}
1&0&0&0\\
0.330&0.670&0&0\\

上三角为 0，因果性满足。

# 七、多层 Block 与残差 LayerNorm

## Q24：多层 Block 作用；为什么残差处理两次？归一化呢？

**详细回答**：

1. **多层 Block**：  
   每层输出作为下一层输入，形状不变。  
   浅层学局部模式，深层学抽象语义。  
   $$L$$ 个 Block 串联，逐层抽象。

2. **残差为什么两次**：  
   一个 Block 有两个子层：Attention 和 FFN。  
   每个子层独立需要残差保护梯度路径和信息流动。  
   所以每 Block 残差 2 次；$$L$$ 个 Block 共 $$2L$$ 次。

3. **LayerNorm**：  
   每个子层输入前一次 LN，控制幅度。  
   每 Block LN 2 次；$$L$$ 个 Block 共 $$2L$$ 次。

# 八、用词修正

## Q25：Geva 和知识神经元的用词修正

**详细回答**：

- “证明”过重。应为“提出假说并提供了强实证证据”。  
- “每个事实对应特定神经元”过强。应为“一小簇神经元与事实高度相关，且分布式、多冗余存储”。  
- 与分布式表示不矛盾：知识神经元是分布式表示中可识别的关键子集，不是唯一存储位置。  
- ROME 编辑会影响邻近事实，说明存储有干扰，不是精确数据库。

| 主题 | 核心结论 |
|---|---|
| Attention 计算 | QKV 投影 → QK^T → 缩放 → mask → softmax → AV |
| Softmax | 按行归一化，非负且和为 1，输出凸组合有界 |
| QKV 语义 | Q 查询，K 键，V 值；K 不可去，解耦匹配与聚合 |

| FFN | 逐位置变换 + 键值记忆假说，存储事实，分布式非数据库 |
| Block | Attention + FFN，各带残差和 LN，可堆叠 |
| 残差 | 只防梯度消失，不防爆炸 |
| LayerNorm | 每子层一次，控制幅度，防爆炸 |
| 交叉熵 | 只在训练时计算，推理时采样 |
| KV 优化 | MQA/GQA/MLA/Palu/LRKV/Q-K=V，各有权衡 |
| 因果掩码 | softmax 前设 -∞，训练并行，推理 KV-Cache |
