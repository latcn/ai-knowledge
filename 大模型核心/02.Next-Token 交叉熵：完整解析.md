## 一、语言模型到底输出什么

给定输入序列 $x_1, x_2, \dots, x_{t-1}$，语言模型要预测下一个 token $x_t$。

模型最后一层输出 **logits**：

$$
z = f_\theta(x_{<t}) \in \mathbb{R}^{V}
$$

其中 $V$ 是词表大小。$z_v$ 是模型给词表第 $v$ 个 token 的未归一化分数。

经过 softmax 得到概率分布：

$$
p_\theta(v \mid x_{<t}) = \frac{e^{z_v}}{\sum_{u=1}^{V} e^{z_u}}
$$

**模型对每个可能的下一个 token 都给出一个概率。**

训练的目标：让真实下一个 token 的概率尽可能大。

---

## 二、从最大似然到交叉熵

### 2.1 最大似然

给定一个训练序列 $x_1, x_2, \dots, x_T$，模型预测整个序列的联合概率为：

$$
p_\theta(x_1, \dots, x_T) = \prod_{t=1}^{T} p_\theta(x_t \mid x_{<t})
$$

**最大似然估计**：找参数 $\theta$，让这个联合概率最大。

$$
\max_\theta \prod_{t=1}^{T} p_\theta(x_t \mid x_{<t})
$$

### 2.2 取对数

连乘容易下溢，且求导不方便。取对数（单调变换，不改变极值点）：

$$
\max_\theta \sum_{t=1}^{T} \log p_\theta(x_t \mid x_{<t})
$$

### 2.3 取平均、加负号

变成最小化问题：

$$
L = -\frac{1}{T} \sum_{t=1}^{T} \log p_\theta(x_t \mid x_{<t})
$$

**这就是 next-token 交叉熵损失。**

- 负号：把最大化变成最小化。
- $1/T$：取平均，使 loss 与序列长度无关，便于比较。

### 2.4 为什么叫“交叉熵”

对每个位置 $t$，真实分布是 one-hot 分布 $q$：

$$
q(v) = \begin{cases}
1, & v = x_t \\
0, & v \neq x_t
\end{cases}
$$

模型分布是 $p_\theta(\cdot \mid x_{<t})$。

交叉熵定义：

$$
H(q, p) = -\sum_{v=1}^{V} q(v) \log p(v)
$$

因为 $q$ 只在真实 token 处为 1，所以：

$$
H(q, p) = -\log p_\theta(x_t \mid x_{<t})
$$

对所有位置平均，就是 $L$。

## 三、具体数字例子

设词表 $V = 3$，真实下一个 token 是第 2 个词（索引从 1 开始）。

模型输出 logits：

$$
z = [2.0,\ 1.0,\ 0.5]
$$

### 3.1 Softmax

$$
e^{2.0} = 7.389, \quad e^{1.0} = 2.718, \quad e^{0.5} = 1.649
$$

$$
\text{sum} = 7.389 + 2.718 + 1.649 = 11.756
$$

$$
p = \left[\frac{7.389}{11.756},\ \frac{2.718}{11.756},\ \frac{1.649}{11.756}\right] = [0.6285,\ 0.2312,\ 0.1403]
$$

### 3.2 交叉熵

真实 token 是第 2 个，所以：

$$
L = -\log p_2 = -\log(0.2312) = 1.464
$$

如果真实 token 是第 1 个：

$$
L = -\log(0.6285) = 0.464
$$

**真实 token 概率越高，loss 越小。**

## 四、交叉熵的梯度

这是交叉熵最重要的性质。

设 logits 为 $z_v$，softmax 输出为 $p_v$，真实标签为 one-hot $y_v$。

交叉熵：

$$
L = -\sum_{v=1}^{V} y_v \log p_v
$$

对 $z_u$ 求导：

$$
\frac{\partial L}{\partial z_u} = p_u - y_u
$$

**推导**：

$$
\frac{\partial p_v}{\partial z_u} = p_v (\delta_{vu} - p_u)
$$

$$
\frac{\partial L}{\partial z_u} = -\sum_v \frac{y_v}{p_v} \cdot p_v (\delta_{vu} - p_u) = -\sum_v y_v (\delta_{vu} - p_u)
$$

$$
= -y_u + p_u \sum_v y_v = p_u - y_u
$$

**结论**：

> **交叉熵对 logits 的梯度 = 模型预测概率 - 真实 one-hot 标签。**

- 预测正确且自信：$p_u \approx y_u$，梯度接近 0。
- 预测错误：$p_u$ 和 $y_u$ 差距大，梯度大。

这个梯度形式非常优雅，也是交叉熵适合分类任务的核心原因。

## 五、为什么等价于最小化 KL

KL 散度定义：

$$
\mathrm{KL}(q \| p) = \sum_v q(v) \log \frac{q(v)}{p(v)}
$$

交叉熵：

$$
H(q, p) = -\sum_v q(v) \log p(v)
$$

关系：

$$
H(q, p) = H(q) + \mathrm{KL}(q \| p)
$$

其中 $H(q) = -\sum_v q(v) \log q(v)$ 是真实分布的熵。

**对于 one-hot 标签，$H(q) = 0$。** 所以：

$$
H(q, p) = \mathrm{KL}(q \| p)
$$

更一般地，如果真实分布不是 one-hot，$H(q)$ 与模型参数 $\theta$ 无关。所以：

$$
\min_\theta H(q, p) \iff \min_\theta \mathrm{KL}(q \| p)
$$

**最小化交叉熵 = 最小化模型分布与数据分布之间的 KL 散度。**

## 六、PPL：困惑度

PPL（Perplexity）定义：

$$
\text{PPL} = e^{L}
$$

如果 $L$ 是自然对数下的平均交叉熵。

**含义**：模型在每一步预测时，平均面临多少个“等概率选择”。

- PPL = 1：模型完全确定，每一步都预测正确。
- PPL = V：模型完全均匀，随机猜。
- PPL = 10：模型平均在 10 个词之间犹豫。

**注意**：PPL 和 loss 是单调关系，$L = \ln(\text{PPL})$。

## 七、采样温度与交叉熵的关系

推理时，从模型分布采样。可以调整温度 $\tau$：

$$
p_\tau(v) = \frac{e^{z_v / \tau}}{\sum_u e^{z_u / \tau}}
$$

- $\tau = 1$：原始分布。
- $\tau > 1$：分布更平坦，更多样，但可能不准确。
- $\tau < 1$：分布更尖锐，更确定，但可能重复。
- $\tau \to 0$：退化为 argmax，贪心解码。

**交叉熵 loss 是在 $\tau = 1$ 下计算的。** 温度只影响推理采样，不改变训练目标。

**常见误解**：温度不是模型参数，是推理时的超参数。

## 八、与缩放定律的关系

缩放定律研究的是：测试损失 $L$ 如何随参数量 $N$、数据量 $D$、计算量 $C$ 变化。

典型形式：

$$
L(N, D) = \left(\frac{N_c}{N}\right)^{\alpha} + \left(\frac{D_c}{D}\right)^{\beta} + L_\infty
$$

**交叉熵 loss 就是缩放定律的纵轴。** 所有关于“该训多大模型、该喂多少数据”的讨论，都建立在这个 loss 上。

Chinchilla 的结论：给定算力，参数量和 token 数应大致同比例增长，约 20 token/参数。

## 九、换条件

### 9.1 换成 MSE 在 logits 上

假设 loss：

$$
L_{\text{MSE}} = \frac{1}{2} \sum_{v=1}^{V} (z_v - y_v)^2
$$

梯度：

$$
\frac{\partial L_{\text{MSE}}}{\partial z_u} = z_u - y_u
$$

**问题**：

1. **梯度不有界**：$z_u$ 可以很大，梯度也很大，即使已经预测正确。
2. **与概率语义脱节**：logits 不是概率，MSE 不关心 softmax 后的分布。
3. **采样无意义**：MSE 不保证输出是概率分布。

**交叉熵的梯度 $p_u - y_u$ 在 $[ -1, 1 ]$ 之间，更稳定。**

### 9.2 SFT 只在回答部分计 loss

指令微调数据：

```
问题：中国的首都是哪里？
回答：北京。
```

如果全序列计 loss，模型会同时学习“如何提问”和“如何回答”。

**常见做法**：只对回答部分计 loss，问题部分 mask 掉。

实现：构造 labels 时，问题部分的 token 设为 `-100`（PyTorch 的 ignore_index），交叉熵忽略这些位置。

```python
labels = input_ids.clone()
labels[:len(question_tokens)] = -100
loss = cross_entropy(logits, labels, ignore_index=-100)
```

**效果**：模型专注学习“扮演助手”，而不是“模仿用户提问”。

## 十、标失效

交叉熵只关心相对概率，不关心绝对概率。

**问题一：模型可以自信地错**

如果真实 token 概率 0.01，错误 token 概率 0.99，loss 很高。但模型可能在其他位置 loss 很低，平均下来还不错。**平均 loss 低不代表每个位置都可靠。**

**问题二：模型可以均匀分布**

如果模型对所有 token 都输出 $1/V$，loss = $\log V$。这不高不低，但模型没有学到任何东西。

**问题三：下游评估不能只看 loss**

- loss 低：模型在训练分布上预测得准。
- 但任务指标（准确率、F1、BLEU、人工评分）可能差。
- 模型可能过拟合训练分布，在分布外表现差。

**所以：loss 是训练信号，不是最终评估。下游评估要看任务指标。**

## 十一、完整流程图

```
输入 x_<t
  │
  ▼
Transformer Blocks
  │
  ▼
最终隐藏状态 H_t
  │
  ▼
输出投影 W_out (d_model × V)
  │
  ▼
logits z (V 维)
  │
  ▼
softmax
  │
  ▼
概率分布 p (V 维)
  │
  ▼
与真实 token x_t 比较
  │
  ▼
交叉熵 loss = -log p(x_t)
  │
  ▼
反向传播，梯度 = p - y
  │
  ▼
更新所有参数
```

## 十二、常见误解

| 误解 | 正确理解 |
|---|---|
| 交叉熵是模型算的 | 交叉熵是损失函数，在输出层之后算 |
| 每个 Block 算一次交叉熵 | 只在所有 Block 之后算一次 |
| 温度是训练参数 | 温度是推理时的采样超参数 |
| PPL 就是 loss | PPL = exp(loss)，单调关系 |
| loss 低就代表模型好 | loss 只是训练信号，下游评估要看任务指标 |
| SFT 全序列计 loss | 通常只对回答部分计 loss |
| 交叉熵关心绝对概率 | 只关心相对概率，模型可以自信地错 |

## 十四、一句话总结

> **Next-Token 交叉熵 = 对每个位置，真实 token 的负对数概率，取平均。它从最大似然推出，等价于最小化 KL 散度，梯度是 $p - y$，是语言模型训练的核心目标。PPL 是它的指数形式，缩放定律以它为纵轴，采样温度只影响推理不影响训练。它只关心相对概率，所以不能只看 loss，要看下游任务指标。**
