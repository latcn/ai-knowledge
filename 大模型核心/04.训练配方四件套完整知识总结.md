## 1. 先问与先猜

### 先问

你的 loss 不降 / 爆炸 / 变 NaN，先查什么？

### 先猜

“调学习率。”

这是最常见的错误答案。  
为什么错？

因为 90% 的问题不在学习率。  
学习率只是四件套之一，而且往往不是第一嫌疑人。

真正要先查的是：

1. 初始化对不对？
2. 数据有没有问题？
3. 梯度有没有爆炸？
4. 数值精度有没有溢出？

学习率是最后才动的旋钮，不是第一个。

## 2. 第一性原理：训练为什么会不稳定

要理解四件套，先要理解训练不稳定的第一性原因。

### 2.1 训练的本质：在高维非凸损失面上找极小值

参数 \(\theta\)，损失 \(L(\theta)\)，更新规则：

\[
\theta_{t+1} = \theta_t - \eta \nabla L(\theta_t)
\]

其中 \(\eta\) 是学习率。

训练稳定需要三个条件同时满足：

1. **梯度方向可靠**：\(\nabla L(\theta_t)\) 不能噪音太大。
2. **更新步长合适**：\(\eta \|\nabla L\|\) 不能太大也不能太小。
3. **数值表示不溢出**：每一步计算结果在浮点表示范围内。

三个条件任何一个被破坏，loss 就会不降、爆炸或变 NaN。

### 2.2 为什么梯度方向会不可靠

反向传播是雅可比连乘（第 3 讲）：

\[
\frac{\partial L}{\partial h_0}
=
\frac{\partial L}{\partial h_L}
J_L J_{L-1} \cdots J_1
\]

即使有残差 + Pre-LN 保证 \(I\) 项存在，连乘中的其他项 \(G_l\) 仍然可能让梯度范数波动很大。

具体表现：

- 某些 batch 的梯度范数突然是平均值的 100 倍 → 更新步长爆炸。
- 某些层的梯度范数接近 0 → 该层学不动。
- 梯度中某些维度数值极大 → fp16 溢出。

### 2.3 为什么更新步长会失控

即使梯度方向可靠，学习率 \(\eta\) 固定时：

\[
\|\theta_{t+1} - \theta_t\| = \eta \|\nabla L(\theta_t)\|
\]

如果 \(\|\nabla L\|\) 波动 100 倍，那么实际更新步长也波动 100 倍。  
初期参数离最优解远，大步长可能直接跳出合理区域。  
后期参数接近最优解，大步长会来回震荡。

### 2.4 为什么数值会溢出

浮点数有表示范围：

- fp16：最小正规数约 \(6.1 \times 10^{-5}\)，最大正规数约 65504
- bf16：最小正规数约 \(1.2 \times 10^{-38}\)，最大正规数约 \(3.4 \times 10^{38}\)
- fp32：最小正规数约 \(1.2 \times 10^{-38}\)，最大正规数约 \(3.4 \times 10^{38}\)

如果中间计算结果超过最大值 → Inf → NaN。  
如果小于最小正规数 → 下溢为 0 → 除零 → NaN。

### 2.5 四件套对应解决这四个问题

| 问题 | 对应工具 |
|---|---|
| 初始化不当导致初始方差爆炸/消失 | 初始化缩放 |
| 学习率固定导致初期震荡、后期不收敛 | 学习率调度（warmup + cosine） |
| 梯度范数波动导致更新步长失控 | 梯度裁剪 |
| 数值溢出导致 NaN | 混合精度（bf16 优先） |

## 3. 四件套之一：初始化

### 3.1 先问

为什么初始化不能随便设？为什么 GPT-2 用 0.02 缩放？

### 3.2 第一性原理：前向方差传播

考虑一层线性层：

\[
y = Wx
\]

其中 \(x \in \mathbb{R}^{d_{\text{in}}}\)，\(W \in \mathbb{R}^{d_{\text{out}} \times d_{\text{in}}}\)。

假设 \(x\) 各维度独立，均值 0，方差 \(\sigma_x^2\)。  
假设 \(W\) 各元素独立，均值 0，方差 \(\sigma_W^2\)。

则 \(y\) 的第 \(i\) 个维度：

\[
y_i = \sum_{j=1}^{d_{\text{in}}} W_{ij} x_j
\]

方差：

\[
\mathrm{Var}(y_i)
=
\sum_{j=1}^{d_{\text{in}}}
\mathrm{Var}(W_{ij} x_j)
\]

因为 \(W_{ij}\) 和 \(x_j\) 独立，均值都为 0：

\[
\mathrm{Var}(W_{ij} x_j)
=
\mathrm{Var}(W_{ij}) \mathrm{Var}(x_j)
=
\sigma_W^2 \sigma_x^2
\]

所以：

\[
\mathrm{Var}(y_i)
=
d_{\text{in}} \sigma_W^2 \sigma_x^2
\]

要让输出方差等于输入方差：

\[
d_{\text{in}} \sigma_W^2 \sigma_x^2 = \sigma_x^2
\]

即：

\[
\sigma_W^2 = \frac{1}{d_{\text{in}}}
\]

所以：

\[
\sigma_W = \frac{1}{\sqrt{d_{\text{in}}}}
\]

这就是 Xavier 初始化的核心。  
如果 \(d_{\text{in}} = 768\)，则 \(\sigma_W \approx 0.036\)。  
GPT-2 用 0.02，略小于 \(1/\sqrt{768} \approx 0.036\)，因为还有残差分支的额外缩放。

### 3.3 反向方差传播

反向传播时，梯度从输出传回输入：

\[
\frac{\partial L}{\partial x}
=
W^\top \frac{\partial L}{\partial y}
\]

类似推导，要让梯度方差保持不变，需要：

\[
\sigma_W^2 = \frac{1}{d_{\text{out}}}
\]

前向要求 \(1/d_{\text{in}}\)，反向要求 \(1/d_{\text{out}}\)。  
两者不能同时满足，除非 \(d_{\text{in}} = d_{\text{out}}\)。

折中方案：

\[
\sigma_W^2 = \frac{2}{d_{\text{in}} + d_{\text{out}}}
\]

这就是 Xavier 初始化。

### 3.4 残差分支的额外缩放

第 3 讲讲过的 Pre-LN 方差累积：

\[
x_L = x_0 + \sum_{l=1}^{L} \left[ \mathrm{Attn}_l(\cdot) + \mathrm{MLP}_l(\cdot) \right]
\]

一共 \(2L\) 个子层往残差主路径上加东西。

如果每个子层输出方差是 \(\sigma^2\)：

\[
\mathrm{Var}(x_L) = \mathrm{Var}(x_0) + 2L \sigma^2
\]

要让 \(\mathrm{Var}(x_L)\) 和 \(\mathrm{Var}(x_0)\) 同量级：

\[
\sigma^2 \sim \frac{1}{2L}
\]

所以残差分支上的输出投影权重要额外按 \(1/\sqrt{2L}\) 缩放。

GPT-2 的做法：

- 普通线性层：\(\mathcal{N}(0, 0.02^2)\)
- 残差分支输出投影：\(\mathcal{N}(0, (0.02/\sqrt{2L})^2)\)

### 3.5 换条件

- 不做初始化缩放，只做 Pre-LN：深层激活方差随 \(2L\) 线性增长，最终 norm 压力大，训练初期不稳定。
- 不做 Pre-LN，只做初始化缩放：恒等路径被 LayerNorm 挡住，梯度仍然可能不稳。
- 两者都不做：深层 Transformer 基本训不起来。
- 如果 block 有三个子层（比如加上 cross-attention），则按 \(1/\sqrt{3L}\) 缩放。

### 3.6 标失效

初始化缩放保证的是**初始时刻**前向和反向方差稳定。  
它不保证训练过程中方差一直稳定。  
训练过程中权重会更新，方差可能漂移。  
所以还需要归一化（LayerNorm/RMSNorm）配合。

## 4. 四件套之二：学习率调度

### 4.1 先问

为什么不能用一个固定学习率？为什么需要 warmup + cosine？

### 4.2 第一性原理：为什么固定学习率不行

考虑三种情况：

**情况一：学习率太大**

\[
\theta_{t+1} = \theta_t - \eta \nabla L(\theta_t)
\]

如果 \(\eta\) 太大，更新步长 \(\eta \|\nabla L\|\) 可能超过损失面的曲率半径。  
表现：loss 震荡、爆炸、变 NaN。

**情况二：学习率太小**

更新步长太小，训练极慢，可能卡在局部极小值或鞍点。

**情况三：学习率固定且合适**

初期可能合适，但后期参数接近最优解时，固定学习率会导致在最优解附近来回震荡，无法精细收敛。

所以需要**动态调整学习率**。

### 4.3 Warmup：为什么初期要从小学习率开始

训练初期，参数是随机初始化的，离最优解很远。  
此时梯度方向可能不可靠，梯度范数可能很大。

如果一开始就用大学习率：

\[
\eta_{\text{large}} \|\nabla L(\theta_0)\|
\]

可能直接跳出合理区域，导致 loss 爆炸。

Warmup 的做法：

\[
\eta_t = \eta_{\max} \cdot \frac{t}{T_{\text{warmup}}}, \quad t < T_{\text{warmup}}
\]

前 \(T_{\text{warmup}}\) 步，学习率从 0 线性增长到 \(\eta_{\max}\)。

这样初期更新步长小，模型有时间进入一个梯度方向可靠的区域。

### 4.4 为什么大模型需要更长的 warmup

大模型初期更脆弱，原因：

1. 参数更多，随机初始化的方差更大。
2. 层数更深，梯度连乘的波动更大。
3. 残差主路径上累加的子层更多，初期激活方差更大。

所以大模型需要更长的 warmup，让模型慢慢进入稳定区域。

实际例子：

- GPT-3 175B：warmup 约 375M token。
- LLaMA 65B：warmup 约 2000 步。
- 小模型（< 1B）：warmup 几百步就够。

### 4.5 Cosine 衰减：为什么后期要降低学习率

Warmup 之后，学习率按 cosine 曲线衰减：

\[
\eta_t = \eta_{\min} + \frac{1}{2}(\eta_{\max} - \eta_{\min})\left(1 + \cos\left(\frac{t - T_{\text{warmup}}}{T_{\text{total}} - T_{\text{warmup}}}\pi\right)\right)
\]

**纠正：Cosine 在 \((0,\pi)\) 的导数不是先变小再变大。**

常用 cosine 学习率调度：

\[
\eta(p)=\eta_{\min}+\frac12(\eta_{\max}-\eta_{\min})\big(1+\cos(\pi p)\big), \quad p\in[0,1]
\]

对 \(p\) 求导：

\[
\frac{d\eta}{dp}
=
-\frac{\pi}{2}(\eta_{\max}-\eta_{\min})\sin(\pi p)
\]

\(\sin(\pi p)\) 在 \(p=0\) 为 0，在 \(p=0.5\) 为 1，在 \(p=1\) 为 0。

所以学习率下降速度：

- 开始 \(p=0\)：导数为 0，下降最慢。
- 中间 \(p=0.5\)：导数绝对值最大，下降最快。
- 结束 \(p=1\)：导数为 0，下降最慢。

**正确说法：cosine 衰减是两端慢、中间快。**  
不是“初期下降慢，后期下降快”。

### 4.6 换条件

- 模型放大 10 倍，warmup 要变长还是变短？→ 变长。大模型初期更脆弱。
- 不用 warmup，直接用大学习率：前几百步容易震荡或爆炸。
- 不用 cosine，用固定学习率：后期在最优解附近震荡，最终 loss 略高。
- 用 exponential decay 替代 cosine：也能跑，但 cosine 更平滑。

### 4.7 标失效

Warmup + cosine 是“能训”的保证，不是“训得最好”的保证。  
最优学习率调度取决于模型大小、数据分布、batch size。  
没有万能配方，只有适合当前设置的配方。

## 5. 四件套之三：梯度裁剪

### 5.1 先问

为什么需要梯度裁剪？梯度爆炸不是已经被残差解决了吗？

### 5.2 第一性原理：残差解决的是“平均情况”，不是“最坏情况”

第 3 讲讲的是：

> 残差保证梯度连乘中有一项 \(I\)，不让梯度指数衰减。

但残差没有保证：

> 每个 batch 的梯度范数都不爆炸。

实际情况：

- 大多数 batch 梯度范数正常。
- 少数 batch（坏数据、罕见 token、长序列）梯度范数可能是平均值的 100 倍。
- 这些“尖峰”梯度会导致更新步长爆炸，破坏模型。

梯度裁剪的做法：

\[
\text{if } \|\nabla L\| > \tau:
\quad
\nabla L \leftarrow \nabla L \cdot \frac{\tau}{\|\nabla L\|}
\]

其中 \(\tau\) 是阈值。

效果：

- 梯度方向不变。
- 梯度范数被限制在 \(\tau\) 以内。
- 防止单个 batch 破坏模型。

### 5.3 为什么按全局范数裁剪

全局范数：

\[
\|\nabla L\|_2 = \sqrt{\sum_i (\nabla L_i)^2}
\]

按全局范数裁剪，意味着所有参数的梯度一起缩放。  
这保持了梯度方向不变，只改变步长。

如果按逐层范数裁剪：

- 每层梯度独立裁剪。
- 梯度方向可能改变。
- 不同层之间的相对比例被破坏。

所以实践中用全局范数裁剪。

### 5.4 阈值怎么选

常见做法：

- GPT-2：1.0
- GPT-3：1.0
- LLaMA：1.0
- 大多数模型：1.0

为什么是 1.0？

- 太小：梯度被过度裁剪，训练变慢。
- 太大：起不到防止爆炸的作用。
- 1.0 是经验值，实践中效果稳定。

也可以监控梯度范数，选一个略大于平均范数的值。

### 5.5 全局裁剪是否会让小梯度消失？

**问题：** 全局范数裁剪把所有梯度一起缩放。如果某些参数梯度本来很小，缩放后会不会变成 0，导致这些参数学不动？

**回答：**

设梯度向量 \(g\)，全局范数 \(\|g\|_2\)。如果 \(\|g\|_2>\tau\)，则：

\[
g\leftarrow g\cdot\frac{\tau}{\|g\|_2}
\]

缩放因子：

\[
\alpha=\frac{\tau}{\|g\|_2}<1
\]

所有分量乘以同一个 \(\alpha\)：

\[
g_i'=\alpha g_i
\]

相对比例：

\[
\frac{g_i'}{g_j'}=\frac{\alpha g_i}{\alpha g_j}=\frac{g_i}{g_j}
\]

保持不变。

举例：

\[
g=[100,\ 0.01,\ 0.001],\quad \|g\|\approx100,\quad \tau=1
\]

缩放因子 \(\alpha=0.01\)。

缩放后：

\[
g'=[1,\ 0.0001,\ 0.00001]
\]

小梯度数值确实变小了，但相对比例没变。  
如果使用 fp32 或 bf16，不会下溢为 0。  
如果使用 fp16，\(0.00001\) 可能下溢，这是精度问题，不是裁剪逻辑问题。

**结论：全局裁剪不会让某些梯度“单独消失”，它只是等比例缩小所有梯度。**  
如果长期频繁触发裁剪，说明学习率可能过大，或数据中有很多坏 batch。应该调小学习率、检查数据，而不是只依赖裁剪。

### 5.6 梯度裁剪与数据清洗的关系

**问题：** 首先不应该检查数据，去除一些异常或错误数据的影响吧？如果还有才使用梯度裁剪？而且这种梯度裁剪会将原来应该快速学习训练到的，变成不易学习的？

**回答：**

- **数据清洗优先**：实践中如果出现梯度爆炸，第一嫌疑人是数据。常见数据问题：异常长序列、重复 token、编码错误字符、标签错位、罕见 token。这些应该先查。数据干净后，梯度尖峰可能就消失了。
- **梯度裁剪是第二道防线**：即使数据干净，仍然可能有天然罕见但合理的样本、长尾分布中的极端值、随机初始化导致的初期不稳定。这些无法完全靠数据清洗消除。
- **裁剪会减慢学习**：如果阈值设得太小，所有 batch 的梯度都被裁剪，更新步长被限制，训练变慢。所以阈值不能随便设。常见做法：先监控梯度范数的分布，选一个略大于平均范数的阈值，只裁剪那些异常大的梯度。
- **正确诊断顺序**：1. 打印梯度范数分布。2. 找出尖峰对应的 batch。3. 检查这些 batch 的数据。4. 清洗数据。5. 如果还有尖峰，调学习率或加 warmup。6. 最后才用梯度裁剪兜底。

### 5.7 换条件

- 不做梯度裁剪：少数坏 batch 可能导致 loss 尖峰，甚至 NaN。
- 阈值设太小（如 0.01）：梯度被过度裁剪，训练极慢。
- 阈值设太大（如 100）：起不到防止爆炸的作用。
- 用逐层裁剪替代全局裁剪：梯度方向可能改变，效果通常更差。

### 5.8 标失效

梯度裁剪是“防止最坏情况”的工具，不是“提升平均性能”的工具。  
它不解决梯度方向错误的问题。  
如果梯度方向本身是错的（比如数据标签错位），裁剪也没用。

## 6. 四件套之四：混合精度

### 6.1 先问

为什么要用混合精度？fp16 和 bf16 有什么区别？为什么 bf16 优先？

### 6.2 第一性原理：浮点数的表示范围与精度

浮点数由三部分组成：

- 符号位
- 指数位：决定表示范围
- 尾数位：决定表示精度

三种格式对比（**纠正之前表格错误**）：

| 格式 | 符号 | 指数 | 尾数 | 最小正规数 | 最大正规数 | 有效精度 |
|---|---|---|---|---|---|---|
| fp32 | 1 | 8 | 23 | \(1.2 \times 10^{-38}\) | \(3.4 \times 10^{38}\) | 24 位 |
| fp16 | 1 | 5 | 10 | \(6.1 \times 10^{-5}\) | \(65504\) | 11 位 |
| bf16 | 1 | 8 | 7 | \(1.2 \times 10^{-38}\) | \(3.4 \times 10^{38}\) | 8 位 |

**关键区分：**

- **范围**由指数位决定。bf16 指数位多，范围大，最小正规数更小。
- **精度**由尾数位决定。fp16 尾数位多，有效精度更高。

### 6.3 为什么 bf16 最小正规数更小，精度却更低？

**问题：** bf16 的最小正规数远远小于 fp16，为什么有效精度还没有 fp16 高？

**回答：**

- 范围大和精度高不是一回事。
- 在同一个数量级下，比如都在 \(1.0\) 附近：
  - fp16 尾数 10 位，间隔 \(2^{-10}\approx0.0009766\)。
  - bf16 尾数 7 位，间隔 \(2^{-7}\approx0.0078125\)。
- bf16 的间隔约是 fp16 的 8 倍，所以舍入误差更大。
- bf16 用更多的指数位换更大的范围，代价是尾数位更少，精度更低。

### 6.4 为什么 fp16 需要 loss scaler

fp16 的最小正规数是 \(6.1 \times 10^{-5}\)。  
如果梯度小于这个值，会下溢为 0。

Loss scaler 的做法：

1. 前向时把 loss 乘以一个大的缩放因子 \(S\)。
2. 反向时梯度也被放大 \(S\) 倍。
3. 更新前把梯度除以 \(S\)。

这样梯度在 fp16 范围内不会下溢。

### 6.5 为什么 bf16 通常不需要 scaler

bf16 的指数位和 fp32 一样。  
所以 bf16 的最小正规数和 fp32 一样，是 \(1.2 \times 10^{-38}\)。  
梯度下溢的风险几乎不存在。  
所以 bf16 通常不需要 loss scaler。

### 6.6 混合精度的实际做法

- 前向和反向：用 bf16 计算。
- 参数更新：用 fp32 主权重。
- 归一化、softmax：用 fp32 计算。

### 6.7 换条件

- 换 bf16 后 scaler 还要不要？→ 通常不要，因为 bf16 动态范围和 fp32 一样。
- 用 fp16 不用 scaler：梯度下溢为 0，训练停滞。
- 用 bf16 但归一化也用 bf16：可能精度不够，loss 略高。
- 用 fp32 训练：稳定但慢，显存占用大。

### 6.8 标失效

混合精度解决的是数值表示问题，不是训练稳定性问题。  
如果 loss 爆炸是因为学习率太大，换 bf16 也没用。  
如果 loss 不降是因为数据有问题，换 bf16 也没用。

## 7. 诊断表：loss 出问题时先查什么

### 7.1 loss 一开始就不降

| 可能原因 | 验证手段 |
|---|---|
| lr 过大 | 打印 grad norm；用 10 条样本过拟合 |
| 数据标签错位 | 检查数据预处理；可视化样本 |
| 初始化错 | 检查初始化缩放；打印初始激活方差 |

为什么用 10 条样本过拟合？

如果模型连 10 条样本都过拟合不了，说明模型太小或太大、学习率不对、数据有问题、初始化有问题。这是最快的诊断方法。

### 7.2 loss 中途出尖峰

| 可能原因 | 验证手段 |
|---|---|
| 坏 batch | 梯度裁剪；跳过该 batch；回滚 checkpoint |
| 梯度爆炸 | 监控梯度范数；检查梯度裁剪阈值 |

### 7.3 loss 变 NaN

| 可能原因 | 验证手段 |
|---|---|
| fp16 溢出 | 换 bf16；检查 log(0)、√负数 |
| 除零 | 检查 LayerNorm 的 ε；检查 softmax 的数值稳定性 |
| lr 过大 | 降低学习率；加 warmup |

### 7.4 验证集上升

| 可能原因 | 验证手段 |
|---|---|
| 过拟合 | 查 mask；加 dropout；早停 |
| 数据泄漏 | 检查训练集和验证集是否重叠 |

## 8. 补充问答：误差传递与参数更新机制

### 8.1 独立随机变量方差相乘的推导

**问题：** 两个独立随机变量 \(W\) 和 \(x\)，为什么 \(\mathrm{Var}(Wx)=\mathrm{Var}(W)\mathrm{Var}(x)\)？

**回答：**

方差的定义：

\[
\mathrm{Var}(Wx)=E[(Wx)^2]-\big(E[Wx]\big)^2
\]

因为 \(W\) 和 \(x\) 独立：

\[
E[Wx]=E[W]E[x]
\]

\[
E[W^2x^2]=E[W^2]E[x^2]
\]

代入并展开：

\[
\mathrm{Var}(Wx)=\mathrm{Var}(W)\mathrm{Var}(x)
+\mathrm{Var}(W)E[x]^2
+\mathrm{Var}(x)E[W]^2
\]

只有当 \(E[W]=0\) 且 \(E[x]=0\) 时，才有：

\[
\mathrm{Var}(Wx)=\mathrm{Var}(W)\mathrm{Var}(x)
\]

**独立 → 联合分布可分解 → 期望可乘。**  
\(E[Wx]=E[W]E[x]\) 只依赖独立性，不依赖均值。

### 8.2 反向传播中 \(L,x,y,W\) 的定义与推导

**问题：** 反向传播时，梯度从输出传回输入，\(L,x,y,W\) 都详细说明定义，并举例推导。

**回答：**

以单层线性层 + 激活 + 损失为例：

- \(x\)：输入向量
- \(W\)：权重矩阵
- \(y=Wx\)：线性输出
- \(z=\sigma(y)\)：激活输出
- \(t\)：目标值
- \(L=\frac12\|z-t\|^2\)：损失

标量版本推导：

前向：

\[
y=wx,\quad z=\sigma(y),\quad L=\frac12(z-t)^2
\]

反向：

\[
\frac{\partial L}{\partial z}=z-t
\]

\[
\frac{\partial L}{\partial y}=(z-t)\sigma'(y)
\]

\[
\frac{\partial L}{\partial w}=(z-t)\sigma'(y)x
\]

\[
\frac{\partial L}{\partial x}=(z-t)\sigma'(y)w
\]

向量版本：

\[
\delta=\frac{\partial L}{\partial y}
\]

\[
\frac{\partial L}{\partial W}=\delta x^\top
\]

\[
\frac{\partial L}{\partial x}=W^\top \delta
\]

举例：\(x=[1,2]^\top\)，\(W=\begin{bmatrix}0.1&0.2\\0.3&0.4\end{bmatrix}\)，\(y=[0.5,1.1]^\top\)，\(L=\frac12\|y\|^2\)，则 \(\delta=y\)，\(\partial L/\partial W=\delta x^\top\)，\(\partial L/\partial x=W^\top\delta\)。

### 8.3 误差如何从下一层传递到上一层

**问题：** B 的误差要变小，需要调 W 或 A，误差怎么一层层传回 A？

**回答：**

两层：\(B=WA\)，\(L=\frac12\|B-T\|^2\)。

误差信号：

\[
\delta_B=\frac{\partial L}{\partial B}=B-T
\]

对 A 的梯度：

\[
\frac{\partial L}{\partial A}=W^\top \delta_B
\]

对 W 的梯度：

\[
\frac{\partial L}{\partial W}=\delta_B A^\top
\]

多层时，\(\partial L/\partial A\) 继续作为下一层的误差信号，乘以局部雅可比，一层层往前传。

### 8.4 误差传递时，会同时更新本层参数吗？

**问题：** 大模型训练时，误差在传递过程中，会同时更新本层的参数吗？还是传递到第一层后，才调整第一层的权重？

**回答：**

标准做法：**先算完所有梯度，再统一更新所有参数。**

反向传播只负责算梯度，不负责更新参数。  
参数更新发生在反向传播完全结束之后。

数学上：

- 计算 \(\partial L/\partial W_1\) 时，用到的 \(W_2,\dots,W_L\) 全部是更新前的旧值。
- 计算 \(\partial L/\partial W_2\) 时，用到的 \(W_1,W_3,\dots,W_L\) 也全部是更新前的旧值。
- 所有梯度对应同一个参数快照。
- 然后优化器统一更新所有参数。

PyTorch 示例：

```python
output = model(input)
loss = criterion(output, target)
loss.backward()      # 只算梯度
optimizer.step()     # 统一更新
optimizer.zero_grad()
```

### 8.5 所有梯度算完后统一更新，是否会造成误差重复消除？

**问题：** 误差已经传递到第 1 层，第一层到第二层的权重更新后，相当于第一层的误差就没有了，其他层再重新更新参数，有没有可能造成误差重复消除，导致消除过度？

**回答：**

不会。原因在于标准梯度下降是**同步更新**，而不是顺序消除。

- 误差不是被“消除”了，而是被“分配”了。
- 每一层只负责自己那部分梯度，所有梯度基于同一时刻的参数快照。
- 所有更新同时发生，不存在“第一层更新后，误差没了，其他层再更新就过度”的问题。
- 如果更新后损失变大，那是学习率太大导致过冲，不是重复消除。

### 8.6 假设只更新第一层，第二层不变，误差可能变小吗？

**问题：** 假设有两层，误差为 err，第一层原来的输出值是 od1，第二层是 od2，反向传播后，第一层更新权重，输出值为 n1，第 2 层不变，由输入值 n1 计算，得出 n2，那么 n2 的值有没有可能和预计值一样，误差较小了？请分析，这种为什么不可能？

**回答：**

**有可能。** 但这是偶然的、有条件的，不是标准反向传播保证的。

只更新第一层，第二层不变：

\[
n_2 = W_2 (W_1 - \eta W_2^\top err x^\top) x
\]

\[
err' = (I - \eta \|x\|^2 W_2 W_2^\top) err
\]

如果 \(\eta\) 合适，误差范数可能变小。  
但固定第二层会限制输出空间。如果目标不在第二层的值域内，第一层怎么调都无法完全消除误差。

标准做法同时更新所有层，下降更快、更充分。  
顺序更新会破坏梯度一致性，用旧梯度更新新参数，方向可能错误。

## 10. 换条件与标失效总结

### 10.1 换条件

- 模型放大 10 倍，warmup 要变长还是变短？→ 变长。大模型初期更脆弱。
- 换 bf16 后 scaler 还要不要？→ 通常不要，因为 bf16 动态范围和 fp32 一样。
- 不用梯度裁剪：少数坏 batch 可能导致 loss 尖峰。
- 不用 warmup：前几百步容易震荡。
- 不用 cosine：后期在最优解附近震荡。

### 10.2 标失效

这套配方是“能训”的保证，不是“训得好”的保证。  
训得好要靠数据、架构、规模。

- 初始化缩放保证初始方差稳定，不保证训练过程方差稳定。
- Warmup + cosine 保证学习率合理，不保证最优学习率。
- 梯度裁剪防止最坏情况，不提升平均性能。
- 混合精度解决数值表示，不解决训练稳定性。

## 11. 如何确保自己没有理解偏差：四关学习法

### 11.1 费曼关：讲给一个没训过模型的人

> 训练模型就像下山。  
> 初始化决定你从哪个位置出发。如果出发位置太偏，怎么走都到不了谷底。  
> 学习率决定你每步走多大。初期路不熟，要走小步（warmup）；后期接近谷底，也要走小步（cosine 衰减）。  
> 梯度裁剪是安全绳。万一某一步踩空，安全绳拉住你，不让你滚下山。  
> 混合精度是望远镜。bf16 看得远（范围大），fp16 看得清（精度高），但 fp16 容易看漏（下溢）。

### 11.2 苏格拉底关：连续追问

1. 为什么初始化不能随便设？前向方差和反向方差为什么不能同时满足？
2. 为什么残差分支要额外按 \(1/\sqrt{2L}\) 缩放？
3. 为什么需要 warmup？为什么大模型需要更长 warmup？
4. 为什么用 cosine 而不是线性衰减？cosine 的导数是什么形状？
5. 残差不是已经解决梯度爆炸了吗？为什么还需要梯度裁剪？
6. 为什么按全局范数裁剪而不是逐层裁剪？全局裁剪会让小梯度消失吗？
7. 阈值为什么常选 1.0？
8. fp16 和 bf16 的本质区别是什么？为什么 bf16 范围大精度低？
9. 为什么 fp16 需要 loss scaler 而 bf16 不需要？
10. 混合精度为什么主权重用 fp32？
11. loss 一开始就不降，先查什么？
12. 这套配方在什么条件下失效？

### 11.3 第一性原理关：合上书，从零推

从问题出发：

> 我要让训练稳定跑起来。  
> 训练不稳定来自四个问题：初始化不当、学习率不当、梯度爆炸、数值溢出。  
> 初始化：前向方差 \(d_{\text{in}} \sigma_W^2 \sigma_x^2 = \sigma_x^2\) → \(\sigma_W = 1/\sqrt{d_{\text{in}}}\)。  
> 残差分支：\(2L\) 个子层 → 额外 \(1/\sqrt{2L}\)。  
> 学习率：初期梯度不可靠 → warmup；后期接近最优 → cosine 衰减。  
> 梯度裁剪：少数 batch 梯度爆炸 → 全局范数裁剪到 1.0。  
> 混合精度：fp16 范围小 → 需要 scaler；bf16 范围大 → 不需要 scaler。

### 11.4 预测实验关

1. 不做 warmup，直接用大学习率：前几百步 loss 震荡或爆炸。
2. 不做梯度裁剪：少数坏 batch 导致 loss 尖峰。
3. 用 fp16 不用 scaler：梯度下溢为 0，训练停滞。
4. 用 bf16 不用 scaler：正常训练，loss 略高于 fp32 但可接受。
5. 不做初始化缩放：深层激活方差爆炸，训练初期不稳定。

## 15. 最终一句话总结

第 4 讲的核心不是“四件套是什么”，而是：

> 训练不稳定的第一性原因是：初始化不当导致方差失控、学习率不当导致步长失控、梯度爆炸导致更新失控、数值溢出导致计算失控。  
> 初始化缩放控制初始方差。  
> Warmup + cosine 控制学习率。  
> 梯度裁剪控制最坏情况。  
> 混合精度控制数值范围。  
> 四件套配合，才能让第 3 讲的残差 + Pre-LN 真正跑起来。

这就是杠杆点 #5：

> 没有训练配方，残差 + Pre-LN 只是理论。  
> 有了训练配方，100 层 Transformer 才能从“能训”走到“训得好”。
